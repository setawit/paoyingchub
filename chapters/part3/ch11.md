# บท 11: เมื่อไหร่ต้องเรียกนักดนตรีจริง

<span class="chapter-meta">ภาค 3 — ยกระดับสู่งานมืออาชีพ | ประมาณ 25 นาที</span>

Suno ทำได้มาก แต่ไม่ได้ทำได้ทุกอย่าง

โปรดิวเซอร์มืออาชีพรู้ว่า "เมื่อไหร่จะหยุดใช้ AI และเรียกมนุษย์" คือทักษะที่สำคัญไม่แพ้การ prompt เป็น

---

## เกณฑ์ตัดสินใจ: 5 สถานการณ์ที่ต้องใช้มนุษย์

### สถานการณ์ที่ 1: งานออกอากาศ (Broadcast)

เมื่อเพลงจะออกทางโทรทัศน์, วิทยุ, หรือ streaming platform ใหญ่ (YouTube monetized, Spotify, Apple Music) — ต้องการเพลงที่มี production standard ระดับ broadcast และ clearance ที่ชัดเจน

**เหตุผล:** แม้ Suno Pro จะมีสิทธิ์เชิงพาณิชย์ แต่สำหรับงาน broadcast ระดับใหญ่ ความเสี่ยงทางกฎหมายยังคลุมเครือ นักดนตรีมืออาชีพสามารถออก clearance เป็นลายลักษณ์อักษรได้

---

### สถานการณ์ที่ 2: งาน Brand หลัก (Flagship Brand)

เพลงที่จะกลายเป็น "เสียงของแบรนด์" ระยะยาว เช่น jingle โฆษณาหลัก, เพลง corporate anthem ที่ใช้ 5 ปีขึ้นไป

**เหตุผล:** เพลง AI ไม่มี "ความเป็นเจ้าของ" ที่ชัดเจนในทางศีลธรรม แบรนด์ระดับสูงต้องการให้ทุกคนใน value chain ภูมิใจกับที่มาของเพลง และสามารถพูดได้ว่า "เพลงนี้แต่งโดย X"

---

### สถานการณ์ที่ 3: ต้องการ Timing ที่แม่นยำ

เพลงที่ต้อง sync กับ visual frame-by-frame เช่น เพลงประกอบโฆษณา 30 วินาที ที่ beat ต้องตรงกับ cut ทุก cut

**เหตุผล:** Suno ไม่สามารถ adjust phrasing หรือ timing ตาม reference ได้ ต้องใช้นักดนตรีที่ฟัง edit และปรับได้

---

### สถานการณ์ที่ 4: ต้องการอารมณ์ที่ "มนุษย์เท่านั้นทำได้"

เพลงที่ต้องการ micro-expression เช่น เสียงร้องที่ "สั่น" ด้วยความเจ็บปวด, เสียงกีตาร์ที่ "โหยหา" จริง ๆ, เปียโนที่ pause ในจังหวะที่ไม่ควร pause

**เหตุผล:** AI reproduce pattern ได้ แต่ไม่มี "intention" ที่แท้จริง

---

### สถานการณ์ที่ 5: งาน Live Performance

เพลงที่จะถูก perform สด บนเวที หน้าคน

**เหตุผล:** Suno ให้ recorded track ได้ แต่ live performance ต้องการนักดนตรีที่ interact กับ audience ได้แบบ real-time

---

## เกณฑ์ด่วน: ถามตัวเองก่อนตัดสิน

| คำถาม | ใช่ → | ไม่ใช่ → |
|-------|-------|---------|
| งานนี้จะออกอากาศสาธารณะ? | เรียกนักดนตรี | Suno ได้ |
| เพลงนี้จะใช้นานกว่า 2 ปี? | พิจารณาจ้างนักดนตรี | Suno ได้ |
| ต้องการ sync frame-by-frame? | เรียกนักดนตรี | Suno ได้ |
| มีงบเกิน 20,000 บาท? | คุ้มค่าจ้างนักดนตรี | Suno ประหยัดกว่า |
| ต้องการ live performance? | เรียกนักดนตรี | Suno ได้ |

## Hybrid Workflow: ใช้ทั้ง AI และมนุษย์

วิธีที่คุ้มค่าที่สุดสำหรับงานระดับกลาง คือ **ใช้ Suno สร้าง demo แล้วส่งให้มนุษย์ finish**

### ตัวอย่าง Hybrid Workflow (5 วัน)

**วันที่ 1–2: AI Phase**
- สร้าง brief + เขียนเนื้อเพลง
- Generate ด้วย Suno 8–10 versions
- คัดเลือกเหลือ 1–2 เพลงที่ดีที่สุด
- ส่ง demo ให้ stakeholder approve direction

**วันที่ 3: Recording Phase**
- ส่ง Suno demo ให้นักร้อง/นักดนตรีฟังเป็น reference
- นักร้องอัด vocal จริงทับ track Suno (หรือ track ใหม่)
- Focus ที่ "ท่อนฮุก" — ส่วนที่คนจะจำมากที่สุด

**วันที่ 4: Mix Phase**
- Mix engineer ผสม vocal จริงกับ instrumental จาก Suno (หรือ re-recorded)
- Normalize, EQ, และ master

**วันที่ 5: Delivery**
- ส่งมอบ final file พร้อม clearance document

### ราคาตลาด (ประมาณการ 2025–2026)

| บริการ | ราคาโดยประมาณ |
|-------|-------------|
| นักร้องหน้าห้อง (studio session) | 3,000–8,000 บาท/เพลง |
| Session singer มืออาชีพ | 5,000–15,000 บาท/เพลง |
| Mix engineer | 3,000–10,000 บาท/เพลง |
| Suno Pro (1 เดือน) | ~280 บาท |

**ประหยัดสูงสุด:** ใช้ Suno ทำ instrumental + arrangement, จ้างแค่ "เสียงร้อง" — ลดต้นทุนได้ 50–70% เทียบกับจ้างทำทั้งหมด

---

## สรุปบท

- 5 สถานการณ์ที่ต้องใช้มนุษย์: broadcast, flagship brand, precise sync, human emotion, live performance
- ใช้ตารางเกณฑ์ด่วน 5 ข้อตัดสินใจเร็ว
- Hybrid Workflow คือ sweet spot: AI ทำ demo → มนุษย์ finish vocal/mix
- ต้นทุน hybrid ต่ำกว่า full production 50–70% แต่คุณภาพ final สูงกว่า AI-only
