## แผนฝึก 30 วัน วันละ 15 นาที

### Week 1: ฝึกฟัง (วันที่ 1–7)
**เป้าหมาย:** พัฒนา "หู" ให้ได้ยินสิ่งที่มืออาชีพได้ยิน

- วันที่ 1–2: ฟังเพลงงาน event ที่คุณเคยชอบ 3 เพลง วิเคราะห์ BPM + Energy curve
- วันที่ 3–4: หาเพลงที่ใช้ในงานองค์กรจริง (YouTube: "[ชื่อบริษัท] event music") ฟังและวิเคราะห์
- วันที่ 5–6: เปรียบเทียบเพลงเดียวกันในสอง version (ช้า vs เร็ว) — รู้สึกต่างยังไง
- วันที่ 7: กรอกแบบฝึกฟัง 5 เพลงจาก บท 6

### Week 2: ฝึก Prompt (วันที่ 8–14)
**เป้าหมาย:** generate เพลงที่ "ใกล้กับที่ต้องการ" ได้ในครั้งแรก

- วันที่ 8: เปิด Suno (free) generate ด้วย prompt จาก หมวด A ข้อ A1
- วันที่ 9: เปรียบเทียบ A1 vs A2 — ได้ยินความต่างไหม?
- วันที่ 10: ปรับ A1 ด้วยการเพิ่ม/เปลี่ยน 1 element แล้ว generate ใหม่
- วันที่ 11–12: ลอง generate จาก Brief ของงานจริงที่คุณเคยทำ
- วันที่ 13: generate เพลงที่มี Exclude List แล้วเปรียบเทียบกับไม่มี
- วันที่ 14: กรอก Lyric Sheet template แล้วส่งให้ Suno ใน Custom Mode

### Week 3: ฝึกเขียนเนื้อ (วันที่ 15–21)
**เป้าหมาย:** เขียน Chorus ที่ "จำได้ตั้งแต่ฟังครั้งแรก"

- วันที่ 15: เลือก Core Message 1 ประโยค เขียน Chorus 3 versions
- วันที่ 16: ทดสอบ versions กับคนอื่น 2 คน ถามว่า "จำได้ไหม"
- วันที่ 17: ปรับ Chorus ที่ดีที่สุด แล้วเขียน Verse 1 ต่อ
- วันที่ 18–19: เขียน Pre-Chorus + Bridge ให้ครบ
- วันที่ 20: ใส่ Lyric ครบใน Suno Custom Mode แล้ว generate
- วันที่ 21: ฟัง 3 รอบ กรอกตารางตรวจ 7 ด้าน

### Week 4: Project จริง (วันที่ 22–30)
**เป้าหมาย:** ทำเพลง 1 เพลงสมบูรณ์สำหรับงานจริง (หรืองานสมมุติ)

- วันที่ 22: เลือกงาน (จริงหรือสมมุติ) กรอก Creative Brief Form
- วันที่ 23: กรอก Sound Journey Planner
- วันที่ 24: เขียนเนื้อเพลงหลัก (Chorus ก่อน)
- วันที่ 25–26: Generate + คัด + เลือก
- วันที่ 27: Fade + Normalize ด้วย Audacity
- วันที่ 28: ฝัง PowerPoint + ทดสอบ
- วันที่ 29: ทำ Cue Sheet
- วันที่ 30: ทบทวน — อะไรทำงานได้ดี? จะปรับอะไรครั้งหน้า?

## สรุปบท

- Prompt Library 80+ ข้อ — ใช้เป็น starting point แล้วปรับตาม brief จริงเสมอ
- Template 3 แบบ: Brief Form / Lyric Sheet / Cue Sheet — ใช้ทุกงาน
- แผนฝึก 30 วัน: ฟัง (Week 1) → Prompt (Week 2) → เขียนเนื้อ (Week 3) → Project จริง (Week 4)
- ทักษะที่ฝึกได้เร็วที่สุดคือ "การฟัง" — ลงทุนเวลาใน Week 1 มากที่สุด
