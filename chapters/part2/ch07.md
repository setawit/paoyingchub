# บท 7: STEP 3 — เขียนเนื้อให้คนร้องได้

<span class="chapter-meta">ภาค 2 — กระบวนการ 7 ขั้น | ประมาณ 35 นาที</span>

เนื้อเพลงที่ดีไม่ใช่บทกวีที่ดี

กวีเขียนเพื่อให้อ่าน เนื้อเพลงเขียนเพื่อให้ร้อง — และนั่นทำให้กฎเปลี่ยนไปโดยสิ้นเชิง เนื้อเพลงที่ "อ่านแล้วสวย" บนกระดาษอาจ "ร้องแล้วงุ่มง่าม" ได้ง่ายมาก

บทนี้จะสอนโครงสร้าง สูตรฮุก และกับดักภาษาไทยที่ AI มักทำผิด

---

## โครงสร้าง Verse–Pre-Chorus–Chorus–Bridge

นี่คือโครงสร้างมาตรฐานที่นักแต่งเพลงมืออาชีพใช้ ไม่ใช่เพราะ "กฎ" แต่เพราะมันทำงานได้จริงกับสมองมนุษย์

### Verse (บท) — สร้างบริบท

**หน้าที่:** บอกเรื่องราว วางฉาก ให้ผู้ฟังเข้าใจว่าเพลงนี้พูดถึงอะไร

**ลักษณะ:**
- เนื้อหา "เฉพาะเจาะจง" กว่า chorus
- แต่ละ verse อาจบอกเรื่องคนละแง่มุม (Verse 1 = ปัญหา, Verse 2 = การเดินทาง)
- ทำนองมักต่ำกว่าหรือเรียบกว่า chorus

**ตัวอย่าง Verse ที่ดี:**
> "เช้าวันนั้นฟ้ายังมืด ก้าวแรกยังลังเล
> แต่มีมือหนึ่งยื่นมา บอกว่าไม่ต้องกลัว"

---

### Pre-Chorus (ก่อนฮุก) — สร้างแรงดัน

**หน้าที่:** เป็น "ทางลาดขึ้น" จาก verse ไปสู่ chorus ทำให้ chorus รู้สึก "คุ้มค่า"

**ลักษณะ:**
- สั้น (2–4 บรรทัด)
- พลังงานเพิ่มขึ้น ทำนองขึ้น
- อาจมีหรือไม่มีก็ได้ แต่ถ้ามี ทำให้ chorus "ระเบิด" ได้ดีขึ้น

**ตัวอย่าง Pre-Chorus:**
> "เพราะวันนี้ไม่เหมือนเดิม
> เราพร้อมแล้ว เราพร้อมแล้ว"

---

### Chorus (ฮุก) — หัวใจของเพลง

**หน้าที่:** คือสิ่งที่คนจะจำ คือ Core Message ที่กลั่นมาแล้วจาก STEP 1

**ลักษณะ:**
- ซ้ำ 2–3 ครั้งในเพลง (ทั้งเนื้อและทำนอง)
- คำต้องง่าย ออกเสียงง่าย ร้องตามได้ในครั้งที่ 2
- ต้องมี Core Message อยู่ใน 1–2 บรรทัดแรก
- ทำนองสูงและมีพลังงานกว่า verse

**ตัวอย่าง Chorus ที่ดี:**
> "เราอยู่ตรงนี้เสมอ ไม่ทิ้งกัน
> ทุกก้าวที่ก้าว มีเราอยู่ด้วย
> เราอยู่ตรงนี้เสมอ ไม่เคยห่าง
> วันนี้และทุกวัน เราคือหนึ่งเดียว"

---

### Bridge (สะพาน) — เปลี่ยนมุมมอง

**หน้าที่:** สร้าง contrast หลังจาก chorus ซ้ำ 2 ครั้ง ทำให้ chorus ครั้งสุดท้าย "รู้สึกใหม่อีกครั้ง"

**ลักษณะ:**
- ปรากฏครั้งเดียวในเพลง (ไม่ซ้ำ)
- ทำนองแตกต่างจาก verse และ chorus
- อาจเปลี่ยน key, เปลี่ยน groove, หรือลดดนตรีลงจนเหลือแค่เสียงร้อง

**ตัวอย่าง Bridge:**
> "แม้ข้างหน้าจะมืดแค่ไหน
> เรารู้ว่าไม่ได้เดินคนเดียว"

---

## สูตรฮุก: ซ้ำ + คำง่าย + Core Message

ฮุกที่จำได้ต้องมี 3 องค์ประกอบนี้พร้อมกัน:

### 1. ซ้ำ (Repetition)
ไม่ใช่แค่ "ซ้ำเพราะขี้เกียจคิด" แต่เพราะสมองต้องการ pattern

กฎ: Core Message ต้องปรากฏอย่างน้อย 2 ครั้งในเพลงเดียวกัน และต้องเป็นคำหรือวลีเดิม ไม่ใช่ paraphrase

ผิด: "เราอยู่ตรงนี้เสมอ" (verse 1) → "เราไม่เคยทิ้งกัน" (chorus) — ความหมายเหมือนกัน แต่จำไม่ได้

ถูก: "เราอยู่ตรงนี้เสมอ" (chorus ครั้งที่ 1) → "เราอยู่ตรงนี้เสมอ" (chorus ครั้งที่ 2) — เหมือนกันทุกคำ

### 2. คำง่าย (Simple Words)
ฮุกไม่ใช่ที่แสดงศัพท์หรือความซับซ้อน

- ใช้คำ 1–2 พยางค์เป็นหลัก
- หลีกเลี่ยงคำทับศัพท์ในฮุก (เพราะ AI ออกเสียงผิดบ่อย)
- ทดสอบ: ถ้าคนได้ยินครั้งแรกแล้วร้องตามได้ในครั้งที่ 2 → ผ่าน

### 3. Core Message อยู่ท้าย
สมองจำสิ่งสุดท้ายที่ได้ยินในประโยคได้ดีที่สุด (Recency Effect)

วางคำสำคัญไว้ท้าย ไม่ใช่ต้น:
- ผิด: "ความสำเร็จ คือสิ่งที่เราทำด้วยกัน"
- ถูก: "ทุกก้าวที่ก้าว เราทำ**ด้วยกัน**"

## กับดักภาษาไทยใน AI

Suno (และ AI ดนตรีส่วนใหญ่) ไม่ได้ถูก train มาด้วยภาษาไทยเป็นหลัก ต่อไปนี้คือปัญหาที่พบบ่อย พร้อมวิธีแก้

### กับดักที่ 1: ควบกล้ำ

AI มักออกเสียงควบกล้ำ "กล", "กว", "ขว", "ปร", "ปล" ได้ไม่ถูกต้อง หรือออกเสียงเป็น 2 พยางค์

| คำที่ AI มักออกผิด | ทางเลือกที่ปลอดภัยกว่า |
|------------------|----------------------|
| กลาง | ตรงกลาง, ใจกลาง |
| กว้าง | ไกล, มาก |
| ขวัญ | ใจ, จิตใจ |
| ปลาย | สุดท้าย, จุดหมาย |
| เปลี่ยน | เริ่มใหม่, ก้าวต่อ |
| แปลง | เปลี่ยนแปลง |
| แกว่ง | โอน, เคลื่อน |

### กับดักที่ 2: วรรณยุกต์

AI มักออกเสียงวรรณยุกต์ผิดในคำที่ "ตัวอักษรใกล้เคียงกัน" เช่น ใ/ไ/ย, ะ/า

**คำที่ควรเลี่ยงในฮุก:**
- คำวรรณยุกต์เอก: "ใจ" (ออกผิดเป็นเสียงสามัญ)
- คำที่มีสระสั้น-ยาวคู่: "มา/มะ", "ดี/ดิ"
- คำที่สะกดคล้ายกันแต่ออกเสียงต่าง: "เก่า/เกา", "เก้า/เก้า"

### กับดักที่ 3: พยัญชนะท้ายที่ AI มักกลืน

AI มักกลืนพยัญชนะสะกด "ก", "ด", "บ" ในตำแหน่งท้ายคำโดยเฉพาะเมื่ออยู่ก่อนคำอื่น

**เทคนิค:** ถ้าคำสำคัญมีพยัญชนะสะกดดังกล่าว ให้วางไว้ก่อนจุดหยุดพัก (comma หรือ end of line) ไม่วางกลางกลุ่มคำ

### กับดักที่ 4: คำที่ AI ออกเป็นอังกฤษโดยอัตโนมัติ

| คำไทย | AI อาจออกเสียงว่า |
|-------|----------------|
| แอป | app (ออกเสียงอังกฤษ) |
| ออนไลน์ | online |
| เซ็นต์ | cent / set |
| โปรแกรม | program |

**แนวทาง:** ถ้าต้องใช้คำทับศัพท์ในเนื้อเพลง ให้วางไว้ใน verse ไม่วางในฮุก และเขียนแบบที่ Suno อาจ "อ่านเป็นอังกฤษ" ได้โดยไม่เสียความหมาย

## แบบฝึก: เขียน Chorus จาก Core Message

ใช้ Core Message จากแบบฝึก บท 4 แล้วขยายเป็น Chorus 4 บรรทัด

```
Core Message ของฉัน: _______________________________________

Chorus ร่าง:
บรรทัด 1: ________________________________________________
บรรทัด 2: ________________________________________________
บรรทัด 3 (ซ้ำ/ใกล้เคียงบรรทัด 1): __________________________
บรรทัด 4: ________________________________________________

ทดสอบ:
□ Core Message อยู่ท้ายบรรทัดหรือไม่?
□ มีคำที่ควบกล้ำซึ่งอาจออกเสียงผิดไหม?
□ ถ้าให้คนอื่นอ่านครั้งแรก เขาร้องตามได้ในครั้งที่ 2 ไหม?
```

## สรุปบท

- โครงสร้าง V–PC–C–B คือ "แผนผังสมอง" ที่ทำงานได้จริง ไม่ใช่แค่กฎ
- สูตรฮุก: ซ้ำ + คำง่าย + Core Message ท้ายบรรทัด
- 4 กับดักภาษาไทยใน AI: ควบกล้ำ, วรรณยุกต์, พยัญชนะสะกด, คำทับศัพท์
- เขียน Chorus ก่อน แล้วค่อย "ขยาย" เป็น Verse — ไม่ใช่ตรงกันข้าม
