# บท 4: STEP 1 — หาโจทย์

<span class="chapter-meta">ภาค 2 — กระบวนการ 7 ขั้น | ประมาณ 25 นาที</span>

โปรดิวเซอร์มืออาชีพไม่เคยเริ่มจาก "เดี๋ยวลอง generate ดูก่อน"

เขาเริ่มจากคำถาม ก่อนเสมอ

STEP 1 คือขั้นตอนที่ใช้เวลาน้อยที่สุด (10-15 นาที) แต่กำหนดผลลัพธ์ของทุกขั้นตอนที่เหลือ ถ้าคุณรู้ว่า "โจทย์คืออะไร" การเลือก genre, การเขียนเนื้อ, การสร้าง prompt ทั้งหมดจะตรงเป้ามากขึ้น 10 เท่า

---

## 3 คำถามทอง

### คำถามที่ 1: "งานนี้ต้องการให้คนรู้สึกอะไร?"

ไม่ใช่ "อยากให้คนรู้สึกดี" (คลุมเครือเกินไป) แต่คือ:
- ตื่นเต้น? ภูมิใจ? อบอุ่น? มั่นใจ? หวัง? ขอบคุณ?
- ความรู้สึกนี้จะเกิดขึ้น *ตอนไหน* ในงาน?
- มีความรู้สึกที่ *ต้องหลีกเลี่ยง* ไหม?

### คำถามที่ 2: "งานนี้ต้องการให้คนทำอะไร?"

เพลงควรผลักดัน behavior:
- ลุกขึ้นปรบมือ?
- นั่งฟังอย่างตั้งใจ?
- หยิบมือถือขึ้นมาถ่ายรูป?
- รู้สึก "ว้าว" แล้วโพสต์ลง social?

### คำถามที่ 3: "งานนี้ต้องการให้คนจำอะไร?"

เนื้อหาที่ต้องการให้ผู้ฟัง *ติดตัวกลับบ้าน*:
- ชื่อ campaign? ค่านิยมองค์กร? ชื่อผลิตภัณฑ์? ความรู้สึกเกี่ยวกับแบรนด์?

คำตอบของคำถามที่ 3 มักกลายเป็น **Core Message** ในเพลง

---

## เทคนิคสัมภาษณ์ผู้ฟัง

ถ้ามีเวลา ขอ 15 นาทีคุยกับ "ตัวแทนผู้ฟัง" 2-3 คนก่อน brief สรุป

**5 คำถามที่ใช้ได้ทันที:**

1. "ถ้าวันนี้คุณมาถึงงาน ดนตรีอะไรที่จะทำให้คุณรู้สึก 'ใช่เลย งานนี้เจ๋ง'?"
2. "เพลงแบบไหนที่คุณ *ไม่อยาก* ได้ยินในงานแบบนี้?"
3. "ถ้าให้พูดถึงงานนี้ในอนาคต คุณอยากให้คนอื่นรู้สึกยังไงเมื่อได้ยินชื่องาน?"
4. "มีเพลงหรือศิลปินที่คุณรู้สึกว่า 'อารมณ์ใกล้เคียงกับที่อยากได้' ไหม?"
5. "งานครั้งที่ผ่านมา ดนตรีช่วงไหนที่คุณชอบที่สุด? ทำไม?"

## เครื่องมือกลั่น Core Message ให้เหลือ 7 คำ

**กระบวนการกลั่น 3 ขั้น:**

**ขั้น 1** — อ่าน brief ทั้งหมด แล้วถามตัวเอง: "ถ้าคนได้ยินเพลงนี้แล้วจะจำได้แค่ 1 อย่าง — อยากให้จำอะไร?"

**ขั้น 2** — เขียน 3 version ของ Core Message:
- Version A: เป็นทางการ (เช่น "เราก้าวต่อไปด้วยกัน")
- Version B: อารมณ์ (เช่น "วันนี้ดีกว่าเมื่อวาน")
- Version C: ภาพ (เช่น "แสงที่ปลายอุโมงค์มาแล้ว")

**ขั้น 3** — ทดสอบ: ถามคนที่ไม่รู้บริบทงานว่า "ได้ยินประโยคนี้แล้วนึกถึงอะไร?" ถ้าตอบตรงกับที่อยากได้ → ใช้ได้

**ตัวอย่างการกลั่น:**

| Brief เดิม | Core Message (7 คำ) |
|-----------|-------------------|
| "ธนาคารต้องการให้เกษตรกรรู้ว่าเราอยู่เคียงข้างพวกเขาตลอดช่วงที่ยากลำบาก..." | "เราอยู่ตรงนี้เสมอ ไม่ทิ้งกัน" |
| "แอปใหม่จะช่วยให้ชีวิตการเงินของลูกค้าง่ายขึ้นอย่างที่ไม่เคยมีมาก่อน..." | "การเงินง่าย เริ่มต้นที่นี่" |
| "งานฉลองครบรอบ 20 ปีที่พนักงานทุกคนมีส่วนร่วมสร้างความสำเร็จ..." | "20 ปี ภูมิใจที่ได้ทำด้วยกัน" |

Core Message นี้จะกลายเป็น ฮุกหลักของเพลง, คีย์เวิร์ดใน Prompt และหัวข้อใช้ approve กับ stakeholder

## สรุปบท

- 3 คำถามทอง: รู้สึกอะไร / ทำอะไร / จำอะไร — ตอบก่อนทำทุกอย่าง
- สัมภาษณ์ผู้ฟังตัวแทน 2-3 คน ถ้ามีเวลา — ได้ insight ที่ดีกว่าการเดา
- Core Message ≤ 7 คำ — กลั่นจาก brief ยาว ให้เป็นหัวใจเพลง
- Worksheet นี้คือ "ใบขับขี่" ก่อน generate — ไม่มีแล้วไม่ไปต่อ
