## Export: เลือก Format ให้ถูกบริบท

### MP3 (320 kbps)

**ใช้เมื่อ:** ฝังใน PowerPoint, ส่งทาง email, เปิดบน Zoom/Teams, background music ห้องประชุม

**ข้อดี:** ไฟล์เล็ก (3–7 MB) เปิดได้ทุกอุปกรณ์ ฟังแทบไม่ต่างจาก WAV ในบริบทงานทั่วไป

### WAV (Lossless)

**ใช้เมื่อ:** ระบบเสียง PA มืออาชีพ, ส่ง sound engineer, งาน broadcast/record, ผสมกับ live vocal

**ข้อเสีย:** ไฟล์ใหญ่ (30–80 MB)

### Metadata ที่ควรกรอก

| Field | ตัวอย่าง |
|-------|---------|
| Title | ชื่อเพลง (ภาษาไทย) |
| Album | ชื่องาน + ปี |
| Comment | Suno Pro, วันที่สร้าง, Prompt สรุป |
| Genre | Thai Pop / Corporate |

## Audio Post: Fade และ Normalize

### Fade In/Out

Suno มักตัด audio แบบ hard cut ฟังดูกระโชก ต้องใส่ fade ด้วยซอฟต์แวร์ฟรี เช่น **Audacity**:

1. เปิดไฟล์ → เลือกช่วง 2 วิแรก → Effect → **Fade In**
2. เลือกช่วง 4 วิสุดท้าย → Effect → **Fade Out**
3. Export → MP3 320 kbps

### Normalize Loudness

เพลงหลายเพลงที่ generate ต่างวันมี loudness ต่างกัน ให้ normalize ทุกเพลงให้ตรงกัน:

| บริบท | ค่า Target |
|-------|-----------|
| ห้องประชุม / Zoom | **-14 LUFS** |
| ออกอากาศ TV / YouTube | **-16 LUFS** |
| concert / PA ใหญ่ | **-12 ถึง -10 LUFS** |

**ใน Audacity:** Effect → Loudness Normalization → ใส่ค่า → OK → Export

## ฝังเพลงใน PowerPoint อย่างถูกวิธี

### วิธีฝัง (ไม่ใช่ link)

1. Insert → Audio → **Audio on My PC** → เลือกไฟล์ MP3
2. คลิกขวาที่ icon เสียง → Audio Options → ตั้ง **Start: Automatically** + **Hide During Show**
3. File → Info → Optimize Media — ถ้าบอก "media linked" ให้ Embed ก่อน

### ทดสอบก่อนงาน

Copy ไฟล์ .pptx ใส่ USB → เปิดจาก USB บน laptop จริง → Slideshow → ตรวจว่าเสียงออก

ถ้าเสียงไม่ออก = ไฟล์ยัง link อยู่ ยังไม่ได้ embed จริง

## เปิดใน Zoom / Teams

1. Share Screen → เลือก **Share Computer Sound**
2. ทดสอบกับผู้เข้าร่วม test ก่อนงานจริงเสมอ
3. Mac: อาจต้องติดตั้ง Virtual Audio Driver เพิ่มเติม

## Checklist ก่อนขึ้นเวที 20 ข้อ

**ไฟล์และอุปกรณ์**
- [ ] ไฟล์เพลงอยู่ใน USB + Cloud (2 ที่)
- [ ] PowerPoint เปิดได้บน laptop ที่ใช้จริง
- [ ] ทดสอบเสียงออกจาก PowerPoint บน laptop จริง
- [ ] ไฟล์ WAV สำรองสำหรับ sound engineer (ถ้ามี)

**ระดับเสียง**
- [ ] ทุกเพลง Normalize ที่ -14 LUFS แล้ว
- [ ] ทดสอบในสถานที่จริง ระดับเสียง 60–70% เหมาะสม

**การเปิดในงาน**
- [ ] รู้ว่าเปิดเพลงไหน ตอนไหน ระยะเวลาเท่าไหร่
- [ ] ซ้อมกับ MC / presenter แล้ว
- [ ] มีคนรับผิดชอบกด play ชัดเจน

**คุณภาพเพลง**
- [ ] ผ่านการฟัง 3 รอบแล้ว
- [ ] ตารางตรวจ 7 ด้าน คะแนน ≥ 30
- [ ] ไม่มีเนื้อร้องที่ไม่เหมาะสม
- [ ] ความยาวเหมาะกับเวลา ไม่ตัดกลางเพลง

**สิทธิ์**
- [ ] สร้างด้วย Suno Pro / Premier
- [ ] บันทึก prompt + วันที่สร้างไว้แล้ว
- [ ] งาน broadcast — ตรวจกับฝ่ายกฎหมายแล้ว

**แผนสำรอง**
- [ ] มีเพลง backup ทุก slot
- [ ] รู้ว่าจะทำอะไรถ้าเสียงไม่ออกใน 30 วินาทีแรก

---

## สรุปบท

- MP3 320kbps สำหรับงานทั่วไป / WAV สำหรับงาน professional และ broadcast
- Fade In/Out + Normalize ที่ -14 LUFS ทุกครั้งก่อนนำไปใช้
- ฝัง embed เพลงใน PowerPoint และทดสอบจาก USB จริงก่อนงาน
- Checklist 20 ข้อ — ทำก่อนงานทุกครั้ง ไม่มีข้อยกเว้น
