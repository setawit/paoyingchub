# บท 6: STEP 2.5 — จังหวะ อารมณ์ และพลังงาน

<span class="chapter-meta">ภาค 2 — กระบวนการ 7 ขั้น | ประมาณ 20 นาที</span>

BPM ไม่ใช่ตัวเลขลอย ๆ ในช่อง "tempo" — มันคือ **อัตราการเต้นหัวใจของเพลง** สมองมนุษย์ synchronize จังหวะการหายใจและอัตราการเต้นหัวใจกับเพลงที่ได้ยินโดยอัตโนมัติ (Entrainment) เพลงช้าทำให้หายใจช้าลง ความวิตกกังวลลดลง เพลงเร็วทำให้ตื่นตัวและอยากเคลื่อนไหว

---

## BPM Map: แผนที่อารมณ์ตามจังหวะ

### 60–80 BPM — โซน "ไว้ใจและปิด"

**สภาวะผู้ฟัง:** ผ่อนคลาย, รู้สึกปลอดภัย, ใคร่ครวญ, อารมณ์ลึก

**ใช้เมื่อ:** ปิดงาน, เพลง tribute/ขอบคุณ, วิดีโอ emotional, ช่วงที่ต้องการให้ผู้ฟัง "ซึมซาบ"

**ตัวอย่าง:** เพลงลูกทุ่งช้า (72 BPM), ballad อะคูสติก (68 BPM)

**ระวัง:** ถ้าใช้หลังอาหารเที่ยงเมื่อคนเหนื่อยอยู่แล้ว อาจทำให้ง่วง

---

### 80–100 BPM — โซน "น่าเชื่อถือและมั่นคง"

**สภาวะผู้ฟัง:** สงบแต่ตื่นตัว, มีสมาธิ, รู้สึกมั่นคง

**ใช้เมื่อ:** Background music ระหว่าง session, VIP reception, ก่อนการนำเสนอสำคัญ, งานที่ต้องสื่อความ "มืออาชีพ"

**ตัวอย่าง:** Jazz lounge (88 BPM), ไทยป๊อปช้า (92 BPM)

---

### 90–115 BPM — โซน "จำได้และร่วมรู้สึก"

**สภาวะผู้ฟัง:** ตื่นตัวในระดับดี, อารมณ์ดี, อยากมีส่วนร่วม

**ใช้เมื่อ:** เพลงหลักของงาน (main theme), ช่วง award/highlight, เพลงที่ต้องการให้จำ

**ตัวอย่าง:** ไทยป๊อปกลาง (100 BPM), City Pop (105 BPM)

> **นี่คือ sweet spot สำหรับเพลงองค์กรส่วนใหญ่**

---

### 115–140 BPM — โซน "ปลุกและตื่นเต้น"

**สภาวะผู้ฟัง:** อยากเคลื่อนไหว, ตื่นเต้น, พลังงานสูง

**ใช้เมื่อ:** เปิดงาน, หลัง break, ช่วงกิจกรรม team building, งาน launch ที่ต้องการ "wow moment"

**ตัวอย่าง:** ลูกทุ่งเร็ว (118 BPM), EDM (128 BPM)

---

## กราฟ Energy Curve: 15 วินาทีแรกตัดสินทุกอย่าง

ผู้ฟังตัดสินใจ "ฟังต่อหรือข้าม" ภายใน 8–15 วินาทีแรก ในงาน event ถ้า intro เฉื่อยเกินไป แขกจะหันไปคุยกัน ถ้าโดดเข้าเร็วเกินไป คนยังไม่พร้อม

### Energy Curve สำหรับเพลง Opening (แนะนำ)

```
ระดับพลังงาน
100% |                         ████████████
 80% |              ████████████
 60% |   ████████████
 40% |███
     └──────────────────────────────────►
     0s  5s  10s  15s  20s  30s  45s  60s
```

- **0–5 วิ:** 40% — ให้คนได้ยินว่านี่คือเพลง
- **5–15 วิ:** build ขึ้น 60%
- **15–30 วิ:** เข้าสู่ main energy 80%
- **30 วิ+:** full energy พร้อม hook 100%

### Energy Curve สำหรับเพลง Close

```
ระดับพลังงาน
100% |████
 80% |    ████████
 60% |            ████████
 40% |                    ████████
 20% |                            ████████
     └──────────────────────────────────►
     0s      30s      60s      90s     120s
```

เริ่มแรง ค่อย ๆ ลดลงจนจบ — สร้างความรู้สึก "ลงจอดนุ่มนวล"

## แบบฝึกฟัง

เลือกเพลง 5 เพลงที่เคยได้ยินในงาน event ฟังแต่ละเพลงโดยไม่ทำอย่างอื่น แล้วกรอกตารางนี้:

| เพลง | BPM (เดา) | Energy ที่ 15 วิ | Energy จุดสูงสุด | งานแบบไหนที่เหมาะ |
|------|-----------|----------------|-----------------|-----------------|
| 1. | | | | |
| 2. | | | | |
| 3. | | | | |
| 4. | | | | |
| 5. | | | | |

**สิ่งที่จะสังเกตได้:** เพลงที่ hook เข้าเร็วมักเหมาะกับงานมากกว่าเพลงที่ intro ยาว และ BPM สูงไม่ได้แปลว่า energy สูงตลอด — dynamics สำคัญกว่า

---

## สรุปบท

- BPM ส่งผลต่อสรีรวิทยาของผู้ฟังโดยตรงผ่าน Entrainment
- 4 โซน: 60–80 (ปิด/ไว้ใจ), 80–100 (มั่นคง), 90–115 (จำได้ — sweet spot), 115–140 (ปลุก)
- ออกแบบ energy curve ของ intro ก่อนเสมอ — 15 วินาทีแรกตัดสินทุกอย่าง
- แบบฝึกฟัง 5 เพลง ทำครั้งเดียว เปลี่ยนวิธีมองเพลงไปตลอด
