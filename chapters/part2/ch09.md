# บท 9: STEP 5-6 — สร้าง คัด เลือก

ถ้า STEP 1-4 คือ "การออกแบบ" — STEP 5-6 คือ "การทำ" และ "การตัดสินใจ"

ใน 2 ขั้นตอนนี้คุณจะ: generate เพลงจาก prompt ที่เตรียมไว้ จากนั้นฟังและคัดเลือกอย่างเป็นระบบ ไม่ใช่ตาม "ความชอบ" ส่วนตัว แต่ตาม "หน้าที่" ของเพลง

## STEP 5: สร้าง — บริหารเครดิต Suno ฟรี

### ระบบเครดิตของ Suno

| แพ็กเกจ | เครดิต/เดือน | เพลง/วัน (ประมาณ) |
|---------|-------------|-----------------|
| Free | ~50 credits | 5 เพลง/วัน |
| Pro ($8) | 2,500 credits | ไม่จำกัดในทางปฏิบัติ |
| Premier ($24) | 10,000 credits | ไม่จำกัด |

การ generate เพลง 1 เพลง (2-4 นาที) ใช้ประมาณ 5 credits ใน Custom Mode (ใส่ lyric เอง) ใช้ประมาณ 5-10 credits

### กลยุทธ์บริหารเครดิตฟรี

**กลยุทธ์ 1: "Batch by Day"**
วางแผนล่วงหน้า — ถ้าต้องการ 4 เพลงสำหรับงาน 1 งาน ให้ generate วันละ 1 เพลง ทยอย 4 วัน ไม่ใช่ generate ทั้งหมดในวันเดียว

**กลยุทธ์ 2: "Refine Before Re-generate"**
ก่อน generate ครั้งใหม่ ให้ปรับ prompt ก่อนเสมอ ไม่ใช่ generate prompt เดิมซ้ำ ๆ (เพราะจะได้ผลใกล้เคียงเดิม เปลืองเครดิต)

**กลยุทธ์ 3: "Two Shots Per Prompt"**
Generate prompt หนึ่ง 2 ครั้ง (Suno generate 2 เพลงพร้อมกันในแต่ละครั้ง) เท่ากับได้ 2 ตัวเลือกต่อ prompt — เพียงพอสำหรับการ A/B

**กลยุทธ์ 4: "Upgrade ตอนจำเป็น"**
ถ้ามีงานใหญ่ที่ต้อง generate เยอะ (เช่น 15 เพลงใน 3 วัน) upgrade Pro ชั่วคราว 1 เดือน ($8) ประหยัดกว่าเสียเวลารอ

## STEP 6: คัด — วิธีฟัง A/B แบบโปร

ข้อผิดพลาดที่พบบ่อยที่สุดคือ ฟังเพลงแค่ครั้งเดียวแล้วตัดสิน

โปรดิวเซอร์มืออาชีพฟัง 3 รอบ แต่ละรอบสนใจคนละอย่าง

### รอบที่ 1: โครงสร้างและ Flow

**ฟังโดย:** ไม่สนใจเนื้อเพลง ไม่สนใจเสียงร้อง — แค่ฟัง "รูปทรง" ของเพลง

**ถามตัวเอง:**
- Intro ดึงความสนใจได้ภายใน 10 วินาทีไหม?
- มี build-up ที่ดีก่อน chorus ไหม?
- Chorus รู้สึก "ระเบิด" ไหม หรือแบนเท่า verse?
- จบเพลงรู้สึก "complete" ไหม หรือ "ตัดสั้น"?

---

### รอบที่ 2: เนื้อเพลงและเสียงร้อง

**ฟังโดย:** ตั้งใจฟังทุกคำที่ร้อง ไม่ทำอย่างอื่น

**ถามตัวเอง:**
- ได้ยินเนื้อชัดทุกคำไหม? หรือมีท่อนที่ฟังไม่ออก?
- เนื้อตรงกับที่เขียนไว้ไหม? มี word ที่ออกผิดไหม?
- ฮุกโดดเด่นพอไหม? ได้ยินครั้งแรกแล้วจำได้ไหม?
- วรรณยุกต์ถูกต้องหรือเปล่า? โดยเฉพาะในฮุก

---

### รอบที่ 3: อารมณ์และ Function

**ฟังโดย:** ลืมว่าคุณเป็นคนสร้าง — ฟังในฐานะผู้ฟังงาน

**ถามตัวเอง:**
- ถ้าเปิดเพลงนี้ตอนคนกำลังเดินเข้างาน พวกเขาจะรู้สึกอะไร?
- เพลงนี้ทำหน้าที่ที่วางไว้ใน brief ได้ไหม?
- ถ้าผู้บริหารได้ยินนาทีแรก เขาจะพูดว่าอะไร?

---

## ตารางตรวจ 7 ด้าน

ใช้ตารางนี้ประเมินเพลงแต่ละเพลงก่อนตัดสิน ให้คะแนน 1–5 แต่ละด้าน

| ด้าน | คำถาม | คะแนน (1–5) | หมายเหตุ |
|-----|-------|-----------|---------|
| **เนื้อเพี้ยน** | เนื้อที่ AI ร้องตรงกับที่เขียนไว้ไหม? | | |
| **หน้าที่** | เพลงทำหน้าที่ที่ระบุใน brief ได้ไหม? | | |
| **โครง** | โครงสร้าง V-C-B สมดุลไหม? ไม่ขาด ไม่เกิน? | | |
| **ฮุก** | ฮุกโดดเด่น จำได้ตั้งแต่ฟังครั้งแรกไหม? | | |
| **บาลานซ์** | เสียงร้อง เสียงดนตรี ได้ยินสมดุลกันไหม? | | |
| **ภาพลักษณ์** | เพลงนี้เหมาะกับภาพลักษณ์ขององค์กรไหม? | | |
| **สิทธิ์** | สร้างด้วยแพ็กเกจที่มีสิทธิ์เชิงพาณิชย์ไหม? | | |

**การตัดสิน:**
- คะแนนรวม 30–35: ผ่าน ใช้งานได้
- คะแนนรวม 22–29: ปรับ prompt แล้ว generate ใหม่
- คะแนนรวม ต่ำกว่า 22: ทบทวน brief + prompt ใหม่ทั้งหมด

**กฎพิเศษ:** ถ้าด้าน "สิทธิ์" ได้คะแนนต่ำกว่า 3 — **ห้ามใช้ทันที** ไม่ว่าคะแนนรวมจะสูงแค่ไหน

---

## Workflow การคัดเลือก

```
Generate Prompt → ได้ 2 เพลง (A และ B)
         ↓
  ฟัง A: 3 รอบ → กรอกตาราง 7 ด้าน
         ↓
  ฟัง B: 3 รอบ → กรอกตาราง 7 ด้าน
         ↓
  เปรียบเทียบ คะแนน A vs B
         ↓
  ถ้าคะแนนรวม ≥ 30 → Export
  ถ้าคะแนนรวม < 30 → ปรับ Prompt → Generate ใหม่
```

---

## เมื่อต้องตัดสินใจร่วมกับทีม

ถ้าต้องให้คนอื่นในทีมหรือผู้บริหาร "approve" เพลง แนะนำวิธีนี้:

1. **ส่งให้ฟัง 2 ตัวเลือก** เสมอ — ไม่ใช่ 1 เพลงให้เลือก "ใช่/ไม่ใช่" เพราะคนมักสะดวกใจกว่าเมื่อเปรียบเทียบ
2. **บอกหน้าที่ก่อนเปิดฟัง** — "เพลงนี้จะใช้ตอนเปิดงาน อยากให้คนรู้สึกตื่นเต้น" บอกก่อน แล้วค่อยเปิด
3. **ถามคำถามที่ถูก** — ไม่ใช่ "ชอบไหม?" แต่ "ถ้าคนได้ยินเพลงนี้ตอนเดินเข้างาน เขาจะรู้สึกอะไร?"

---

## สรุปบท

- บริหารเครดิตฟรีด้วย Batch by Day และ Refine Before Re-generate
- ฟัง 3 รอบ: โครง → เนื้อ/เสียงร้อง → อารมณ์/function
- ตารางตรวจ 7 ด้าน: เป้า 30+ คะแนน, ด้านสิทธิ์ต้องได้ 3+ เสมอ
- เมื่อ approve กับทีม: ส่ง 2 ตัวเลือก, บอกหน้าที่ก่อน, ถามคำถามที่ถูก
