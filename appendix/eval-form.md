# แบบฟอร์มประเมินเพลงโดยทีม

<span class="chapter-meta">ภาคผนวก | พิมพ์และใช้ได้ทันที</span>

แบบฟอร์มนี้ออกแบบให้ทีม 3–6 คนใช้ประเมินเพลงพร้อมกัน เพื่อให้การตัดสินใจโปร่งใสและมีเกณฑ์ที่ชัดเจน ไม่ใช่แค่ "ชอบ/ไม่ชอบ"

---

## วิธีใช้

1. พิมพ์แบบฟอร์มนี้ให้ครบตามจำนวนผู้ประเมิน
2. ให้ทุกคนฟังเพลงพร้อมกัน **โดยไม่คุยกันระหว่างฟัง**
3. กรอกคะแนนส่วนตัวก่อน แล้วค่อยเปิดเผยพร้อมกัน
4. คำนวณค่าเฉลี่ย และคุยกันเฉพาะด้านที่คะแนนต่างกันมาก

---

## แบบฟอร์มประเมินเพลง

```
================================================
แบบฟอร์มประเมินเพลง
================================================
ชื่อเพลง: _______________________________________
วันที่ประเมิน: ________________
ผู้ประเมิน: _________________ ตำแหน่ง: __________
ฟังรอบที่: ☐ 1  ☐ 2  ☐ 3

ชื่องานที่จะใช้: __________________________________
หน้าที่ของเพลงนี้: ________________________________
ผู้ฟังหลัก: _______________________________________

------------------------------------------------
SECTION A: ประเมินตามเกณฑ์ (1 = แย่มาก, 5 = ดีมาก)
------------------------------------------------

1. เนื้อเพลงถูกต้อง
   เนื้อที่ AI ร้องตรงกับที่เขียนไว้ ออกเสียงถูกต้อง
   ไม่มีคำแปลกปลอม วรรณยุกต์ถูกต้อง
   
   คะแนน: [ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ]
   
   หมายเหตุ: ________________________________________

2. ทำหน้าที่ได้
   เพลงนี้ทำสิ่งที่ระบุใน brief ได้จริงไหม
   เปิดในช่วงที่กำหนดแล้วผู้ฟังจะรู้สึกตามที่ต้องการ
   
   คะแนน: [ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ]
   
   หมายเหตุ: ________________________________________

3. โครงสร้างสมดุล
   Intro ดึงความสนใจได้ Verse-Chorus ชัดเจน
   Bridge (ถ้ามี) ทำงานได้ดี Outro จบสวย
   
   คะแนน: [ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ]
   
   หมายเหตุ: ________________________________________

4. ฮุกโดดเด่น
   ฟังครั้งเดียวแล้วจำได้ไหม
   Core Message ได้ยินชัดในฮุกไหม
   
   คะแนน: [ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ]
   
   หมายเหตุ: ________________________________________

5. บาลานซ์เสียง
   ได้ยินเสียงร้องชัดไหม ดนตรีไม่กลบเสียงร้อง
   เสียงดังพอสำหรับสถานที่จริงไหม
   
   คะแนน: [ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ]
   
   หมายเหตุ: ________________________________________

6. ภาพลักษณ์องค์กร
   เพลงนี้เหมาะกับภาพลักษณ์ขององค์กรไหม
   ถ้าลูกค้าภายนอกได้ยิน จะประทับใจหรือแปลกใจ
   
   คะแนน: [ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ]
   
   หมายเหตุ: ________________________________________

7. สิทธิ์ถูกต้อง
   สร้างด้วย Suno Pro/Premier ไหม
   มี documentation เก็บไว้ไหม
   
   คะแนน: [ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ]
   
   (ถ้าได้ต่ำกว่า 3 — ห้ามใช้ทันที)

------------------------------------------------
SECTION B: ประเมินรวม
------------------------------------------------

คะแนนรวม (เต็ม 35): _______

เกณฑ์:
  30–35 ✓ ผ่าน ใช้งานได้
  22–29 ◐ ปรับ prompt แล้ว generate ใหม่
  ต่ำกว่า 22 ✗ ทบทวน brief + prompt ใหม่

คำแนะนำส่วนตัว:
  ☐ ผ่าน — ใช้ได้เลย
  ☐ ผ่าน — แต่ควรปรับเล็กน้อยก่อน (ระบุด้านล่าง)
  ☐ Generate ใหม่
  ☐ ทบทวน brief ใหม่

สิ่งที่ควรปรับ (ถ้ามี):
___________________________________________________
___________________________________________________

------------------------------------------------
SECTION C: คำถามท้าย
------------------------------------------------

"ถ้าผู้บริหารระดับสูงได้ยินเพลงนี้โดยไม่รู้ที่มา
 เขาจะรู้สึกอย่างไร?"

คำตอบ: ____________________________________________
___________________________________________________

"ถ้าลูกค้า VIP ได้ยินตอนเดินเข้างาน 
 พวกเขาจะประทับใจหรือแปลกใจ?"

คำตอบ: ____________________________________________
___________________________________________________

================================================
ลายเซ็น: ___________________ วันที่: __________
================================================
```

## เคล็ดลับการใช้แบบฟอร์มร่วมกับทีม

**ก่อนประเมิน:**
- บอกทีมว่าเพลงนี้จะใช้ "ช่วงไหน" ของงาน และ "หน้าที่" คืออะไร
- ให้ทุกคนฟังในสภาพแวดล้อมเดียวกัน (ลำโพงเดียวกัน, ระดับเสียงเดียวกัน)

**ระหว่างประเมิน:**
- ห้ามคุยกันก่อนกรอกเสร็จ — ป้องกัน anchoring bias (คนแรกพูดแล้วคนอื่นตาม)

**หลังประเมิน:**
- เปิดเผยคะแนนพร้อมกัน
- คุยกันเฉพาะด้านที่คะแนน "ต่างกันมากกว่า 2 คะแนน"
- ด้านที่ทีมเห็นต่างคือจุดที่ต้องการเกณฑ์ชัดเจนกว่า — กลับไปดู brief

**กฎทองคำ:**
ถ้าคนที่ "รู้จักผู้ฟังจริง ๆ" ที่สุดในทีม (เช่น คนที่เคยพบลูกค้ากลุ่มนี้โดยตรง) ให้คะแนนต่ำในด้าน "ภาพลักษณ์องค์กร" — ให้น้ำหนักความเห็นของเขามากกว่าค่าเฉลี่ย
