# บทที่ 14 — หาข้อมูล / วิจัยเบื้องต้นก่อนประชุม

> **กลุ่มเสี่ยง:** ตรวจยาก · เสียหายมาก — **ช่อง ④**
> บทนี้กับบทที่ 8 คือสองบทที่อันตรายที่สุดในภาค 2

---

## 1. งานนี้คืออะไร ปกติทำอย่างไร ใช้เวลาเท่าไร

พรุ่งนี้ต้องประชุมเรื่องที่ยังไม่รู้จักดีพอ — อุตสาหกรรมที่ไม่คุ้น หน่วยงานที่ไม่เคยทำงานด้วย หัวข้อที่เพิ่งได้รับมอบหมาย

**เวลาที่ใช้แบบเดิม:** 2–6 ชั่วโมง ค้นหา อ่าน คัดกรอง สรุป

**เวลาที่ใช้เมื่อมี AI ช่วย:** ได้ภาพรวม 5 นาที + **ตรวจสอบและหาแหล่งจริง 1–3 ชั่วโมง**

กำไรของงานนี้ไม่ใช่เวลาที่ลดลงมาก แต่คือ **การรู้ว่าต้องหาอะไร** ซึ่งเป็นส่วนที่ยากที่สุดของการค้นคว้าเรื่องใหม่

## 2. AI ช่วยตรงไหนได้ ตรงไหนช่วยไม่ได้

| ช่วยได้ดี | ช่วยไม่ได้ — อันตราย |
|---|---|
| บอกว่าเรื่องนี้มีประเด็นอะไรบ้าง | บอกตัวเลขที่เชื่อถือได้ |
| บอกว่าควรไปหาข้อมูลจากที่ไหน | บอกว่าสถานการณ์ปัจจุบันเป็นอย่างไร |
| ตั้งคำถามที่เราควรถามในที่ประชุม | อ้างอิงแหล่งที่มีอยู่จริงเสมอ |
| อธิบายศัพท์เฉพาะที่เราไม่รู้จัก | รู้ว่าข้อมูลที่ให้มาเก่าแค่ไหน |
| จัดโครงว่าควรรู้อะไรบ้างก่อนประชุม | รู้เรื่องที่เกิดขึ้นในพื้นที่ |

### หลักที่สำคัญที่สุดของบทนี้

> ## **ใช้ AI เป็นแผนที่ ไม่ใช่เป็นแหล่งข้อมูล**

**แผนที่บอกว่าไปทางไหน แต่ไม่ได้บอกว่าปลายทางมีอะไร**

| ใช้เป็นแผนที่ (ปลอดภัย) | ใช้เป็นแหล่งข้อมูล (อันตราย) |
|---|---|
| "เรื่องนี้ควรรู้อะไรบ้างก่อนประชุม" | "สรุปสถานการณ์เรื่องนี้ให้หน่อย" |
| "หน่วยงานไหนเป็นคนเผยแพร่ข้อมูลนี้" | "ตัวเลขล่าสุดเท่าไร" |
| "คำถามที่ควรถามในที่ประชุมคืออะไร" | "คำตอบของเรื่องนี้คืออะไร" |
| "ศัพท์คำนี้แปลว่าอะไรในบริบทนี้" | "ตอนนี้แนวโน้มเป็นอย่างไร" |
| "ฉันน่าจะมองข้ามอะไรไปบ้าง" | "ใครเป็นผู้เล่นรายใหญ่ในตลาดนี้" |

คอลัมน์ซ้ายทั้งหมดมีคุณสมบัติร่วมกัน: **คำตอบที่ได้ไม่ใช่สิ่งที่เราจะเอาไปพูดต่อ แต่เป็นสิ่งที่พาเราไปหาของจริง**

### ขอ "คำถามที่ควรถาม" มากกว่า "คำตอบ"

นี่คือเทคนิคที่เปลี่ยนงานนี้จากช่อง ④ เป็นช่อง ③ ได้ทันที

*แทนที่จะถาม:* "ธุรกิจโรงสีข้าวมีโครงสร้างต้นทุนอย่างไร"
*ให้ถามว่า:* "ถ้าฉันจะประชุมกับเจ้าของโรงสีข้าวพรุ่งนี้ และฉันไม่เคยทำ sector นี้มาก่อน ฉันควรถามอะไรบ้างเพื่อให้เข้าใจธุรกิจเขา เรียงตามลำดับที่ควรถาม และบอกด้วยว่าคำตอบแบบไหนที่ควรทำให้ฉันถามต่อ"

**ทำไมดีกว่า:**
- คำถามที่ผิดไม่สร้างความเสียหาย เราแค่ถามแล้วได้คำตอบที่ไม่เกี่ยว
- คำตอบที่ผิดสร้างความเสียหาย เพราะเราเอาไปพูดต่อ
- และคนที่รู้จริงที่สุดในเรื่องนั้นกำลังนั่งอยู่ตรงหน้าเราในที่ประชุม — ถามเขาดีกว่าถาม AI

### เครื่องมือที่ค้นเว็บได้ vs ไม่ได้

ต้องรู้ว่าเครื่องมือที่ใช้อยู่เป็นแบบไหน เพราะความเสี่ยงต่างกัน

| | ค้นเว็บไม่ได้ | ค้นเว็บได้ |
|---|---|---|
| ข้อมูลมาจาก | ความจำจากการฝึก | เว็บที่ค้นเจอตอนนั้น |
| ความเก่า | เก่าถึงวันที่หยุดฝึก ไม่รู้ว่าเมื่อไร | ใหม่กว่า แต่ไม่รับประกัน |
| แหล่งอ้างอิง | **แต่งขึ้นมาได้ทั้งหมด** | มีลิงก์จริง แต่เนื้อหาอาจไม่ตรงกับที่สรุป |
| อันตรายหลัก | สร้างข้อมูลที่ไม่มีอยู่จริง | สรุปผิดจากแหล่งจริง หรืออ้างแหล่งที่ไม่น่าเชื่อถือ |
| วิธีตรวจ | ต้องหาแหล่งใหม่ทั้งหมดเอง | เปิดลิงก์ทุกลิงก์ อ่านเอง |

**ข้อสำคัญ:** เครื่องมือที่ค้นเว็บได้ **ไม่ได้ปลอดภัยกว่าโดยอัตโนมัติ** มันแค่เปลี่ยนชนิดความผิดพลาด จาก "แต่งขึ้นมา" เป็น "สรุปผิดจากของจริง" ซึ่งจับยากกว่าด้วยซ้ำ เพราะมีลิงก์ประกอบทำให้ดูน่าเชื่อถือ

## 3. Input ที่ต้องเตรียมก่อนสั่งงาน

```
1. บริบทการประชุม      คุยกับใคร เรื่องอะไร เราอยู่ในบทบาทไหน
2. สิ่งที่รู้แล้ว         เพื่อไม่ให้เสียเวลา
3. สิ่งที่ต้องตัดสินใจ    หรือสิ่งที่ต้องไม่พลาด
4. ระดับความลึกที่ต้องการ  พอคุยรู้เรื่อง / ต้องถกได้ / ต้องตัดสินใจได้
5. เอกสารที่มีอยู่แล้ว    ถ้ามี ให้วางลงไป (เปลี่ยนเป็นช่อง ② ทันที)
```

**ข้อ 5 คือทางลัดที่ดีที่สุด** — ถ้ามีเอกสารจริงอยู่ในมือ (รายงานอุตสาหกรรม เอกสารที่อีกฝ่ายส่งมา ข้อมูลที่เคยเก็บไว้) ให้วางลงไปแล้วให้ AI ทำงานกับมัน แทนที่จะให้ค้นเอง

## 4. กลุ่มความเสี่ยง

**ตรวจยาก** — เพราะเราไม่รู้เรื่องนี้ นั่นคือเหตุผลที่เราค้นตั้งแต่แรก เราจึงไม่มีความรู้พื้นฐานที่จะสะดุดเมื่อเจอของผิด

**เสียหายมาก** — สองชั้น

- **ชั้นที่ 1: พูดข้อมูลผิดในที่ประชุม** แล้วมีคนที่รู้จริงอยู่ในห้อง เสียความน่าเชื่อถือทั้งเรื่อง ไม่ใช่แค่จุดนั้น
- **ชั้นที่ 2: อ้างแหล่งที่ไม่มีอยู่จริง** เสียหายหนักกว่ามาก เพราะมันไม่ได้แปลว่าเราเข้าใจผิด แต่แปลว่าเราไม่ได้ตรวจสอบ

**ข้อสังเกต:** ความเสียหายของงานนี้ตกอยู่กับ **ความน่าเชื่อถือของตัวเรา** ซึ่งเป็นสิ่งที่สร้างยากและกู้คืนยากกว่าตัวเลขที่แก้ได้

## 5. วิธีตรวจ

### ขั้นที่ 1 — ทุกตัวเลข ทุกชื่อ ทุกวันที่ ต้องมีแหล่งที่เปิดดูได้ *(เวลาแล้วแต่ปริมาณ)*

ไล่ขีดเส้นใต้ในผลลัพธ์ทุกจุดที่เป็น

- ตัวเลข (ราคา ปริมาณ สัดส่วน อัตรา)
- ชื่อเฉพาะ (องค์กร บุคคล โครงการ กฎหมาย)
- วันที่และช่วงเวลา
- ข้อความที่ขึ้นต้นว่า "ปัจจุบัน" "ล่าสุด" "ในช่วงที่ผ่านมา"

**ทุกจุดที่ขีดเส้นใต้ ต้องมีแหล่งที่เราเปิดดูได้ด้วยตาตัวเอง ไม่งั้นตัดทิ้ง**

ไม่ใช่ "หาแหล่งไม่เจอแต่น่าจะจริง" — ตัดทิ้ง

### ขั้นที่ 2 — เปิดแหล่งที่อ้างมา ทุกแหล่ง *(10–30 นาที)*

สำหรับแต่ละแหล่งที่ AI อ้าง ตรวจสี่อย่าง

```
□ 1. แหล่งนี้มีอยู่จริงไหม        (เปิดไม่เจอ = ไม่มี)
□ 2. ชื่อเรื่อง ผู้เขียน ปี ตรงไหม  (มีอยู่จริงแต่รายละเอียดผิดได้)
□ 3. เนื้อหาข้างในพูดเรื่องนี้จริงไหม (สำคัญที่สุด)
□ 4. ข้อมูลในนั้นเป็นของปีไหน     (ไม่ใช่ปีที่เผยแพร่)
```

**ข้อ 3 คือข้อที่คนข้ามบ่อยที่สุดและสำคัญที่สุด**

เพราะสิ่งที่พบบ่อยไม่ใช่ "ลิงก์เสีย" แต่คือ **ลิงก์เปิดได้ เว็บมีอยู่จริง แต่ข้างในไม่ได้พูดเรื่องที่ AI สรุปมา** หรือพูดคนละความหมาย

**ข้อ 4 ก็สำคัญไม่แพ้กัน** — รายงานที่เผยแพร่ปี 2568 อาจใช้ข้อมูลปี 2565 ถ้าเราพูดว่า "ข้อมูลล่าสุดปี 2568" ทั้งที่ตัวเลขเป็นของสามปีก่อน คนที่รู้จะจับได้ทันที

### ขั้นที่ 3 — หาแหล่งที่สองยืนยัน *(15–30 นาที)*

สำหรับข้อมูลที่จะพูดในที่ประชุมจริง ต้องมีแหล่งที่สองที่เป็นอิสระจากแหล่งแรก

**"อิสระ" หมายถึง** ไม่ใช่เว็บที่คัดลอกมาจากแหล่งแรก — ข้อมูลผิดข้อเดียวสามารถกระจายไปหลายสิบเว็บได้ภายในไม่กี่วัน การเจอตัวเลขเดียวกันในห้าเว็บไม่ได้ยืนยันอะไรถ้าทั้งห้าเว็บอ้างต้นทางเดียวกัน

**ลำดับความน่าเชื่อถือของแหล่ง** (จากสูงไปต่ำ)

```
1. หน่วยงานที่เป็นเจ้าของข้อมูลนั้นโดยตรง
2. หน่วยงานราชการหรือองค์กรกำกับที่เผยแพร่เป็นประจำ
3. สมาคมอุตสาหกรรม หอการค้า
4. รายงานวิจัยที่ระบุวิธีเก็บข้อมูล
5. สื่อที่อ้างแหล่งชัดเจน
--- เส้นแบ่งความน่าเชื่อถือ ---
6. สื่อที่ไม่อ้างแหล่ง
7. บทความรวบรวม เว็บที่ไม่ระบุผู้เขียน
8. สิ่งที่ AI บอกโดยไม่มีแหล่ง
```

### ขั้นที่ 4 — ถามหาสิ่งที่ยังไม่รู้ *(5 นาที)*

ถามกลับ

> **"จากข้อมูลที่ให้มาทั้งหมด มีอะไรที่คุณไม่แน่ใจ ข้อมูลอาจล้าสมัย หรือเป็นเรื่องที่ต้องตรวจสอบกับแหล่งในประเทศไทยโดยเฉพาะ"**

และ

> **"ถ้าฉันเข้าประชุมโดยเชื่อข้อมูลชุดนี้ทั้งหมด ฉันเสี่ยงจะพลาดตรงไหนมากที่สุด"**

คำถามที่สองมักได้คำตอบที่มีประโยชน์มาก เพราะมันชี้จุดอ่อนของข้อมูลชุดนั้นเอง

### ขั้นที่ 5 — แยกสิ่งที่พูดได้กับพูดไม่ได้ *(5 นาที)*

ก่อนเข้าประชุม แบ่งข้อมูลที่เตรียมมาเป็นสามกอง

```
กอง 1 — พูดได้ ยืนยันแล้ว มีแหล่ง ตอบได้ว่ามาจากไหน
กอง 2 — ถามได้ ยังไม่แน่ใจ ใช้เป็นคำถามแทนการยืนยัน
         "ผมเข้าใจว่าประมาณ...ใช่ไหมครับ"
กอง 3 — ไม่พูด ยังหาแหล่งไม่ได้
```

**กอง 2 คือกองที่มีประโยชน์ที่สุด** — เปลี่ยนข้อมูลที่ไม่แน่ใจให้เป็นคำถาม ทำให้เราได้ข้อมูลจริงจากคนที่รู้ และดูเป็นคนที่เตรียมตัวมา แทนที่จะเสี่ยงพูดผิด

**รวมเวลาตรวจ: 40–75 นาที** ซึ่งมากกว่าเวลาที่ AI ใช้หลายสิบเท่า — และนั่นคือราคาของงานช่อง ④

## 6. จุดพลาดที่พบบ่อย

| จุดพลาด | ลักษณะ | วิธีกัน |
|---|---|---|
| **สร้างแหล่งอ้างอิงที่ไม่มีจริง** | ชื่อรายงานที่ฟังดูสมจริง หน่วยงานถูก แต่เอกสารไม่มีอยู่ | ขั้นตรวจที่ 2 — เปิดไม่เจอ = ไม่มี |
| **ลิงก์มีจริงแต่เนื้อหาไม่ตรง** | เปิดได้ แต่ข้างในไม่ได้พูดเรื่องนั้น | ขั้นตรวจที่ 2 ข้อ 3 — ต้องอ่านข้างใน |
| **ข้อมูลเก่าพูดเหมือนปัจจุบัน** | "ปัจจุบันราคาอยู่ที่..." ซึ่งเป็นราคาสามปีก่อน | ขั้นตรวจที่ 2 ข้อ 4 + ถามหาวันที่เสมอ |
| **ข้อมูลระดับโลกใช้กับตลาดไทย** | โครงสร้างต้นทุนของอุตสาหกรรมในต่างประเทศ | ขั้นตรวจที่ 4 + หาแหล่งในประเทศ |
| **ตัวเลขที่ปัดจนความหมายเปลี่ยน** | "ประมาณหนึ่งในสาม" จากตัวเลขจริง 28% | ขอตัวเลขดิบพร้อมแหล่งเสมอ |
| **เชื่อเพราะเห็นตรงกันหลายที่** | ห้าเว็บที่คัดลอกจากต้นทางเดียวกัน | ขั้นตรวจที่ 3 — แหล่งต้องอิสระจากกัน |
| **สรุปแนวโน้มจากข้อมูลจุดเดียว** | "ราคากำลังขาขึ้น" จากข้อมูลเดือนเดียว | ขอข้อมูลย้อนหลังหลายช่วงเวลา |

> อุตสาหกรรมนี้ในประเทศไทยมีมูลค่าตลาดประมาณ 45,000 ล้านบาท เติบโตเฉลี่ยปีละ 6.8% ในช่วง 5 ปีที่ผ่านมา โดยมีผู้ประกอบการรายใหญ่ 3 ราย ครองส่วนแบ่งตลาดรวมกันประมาณ 55%
>
> โครงสร้างต้นทุนโดยทั่วไป ประกอบด้วยวัตถุดิบ 60–65% ค่าแรง 12–15% พลังงาน 8–10% และอื่นๆ
>
> ความท้าทายสำคัญคือความผันผวนของราคาวัตถุดิบ และการแข่งขันจากสินค้านำเข้า
>
> **แหล่งอ้างอิง**
> - รายงานภาวะอุตสาหกรรมแปรรูปสินค้าเกษตร ปี 2567, [ชื่อหน่วยงาน]
> - บทวิเคราะห์อุตสาหกรรม, [ชื่อสถาบัน]

อ่านแล้วครบถ้วน มีตัวเลข มีโครงสร้างต้นทุน มีแหล่งอ้างอิงสองแหล่ง — พร้อมเข้าประชุม

### จับผิดอย่างไร

**ขั้นตรวจที่ 2 (เปิดแหล่งทุกแหล่ง)**

- **แหล่งที่ 1** — ค้นหาชื่อรายงานนี้ ไม่พบ ค้นในเว็บของหน่วยงานที่อ้าง ไม่มีรายงานชื่อนี้ มีรายงานชื่อใกล้เคียงแต่เป็นคนละเรื่องและคนละปี → **แหล่งนี้ไม่มีอยู่จริง**
- **แหล่งที่ 2** — สถาบันที่อ้างมีอยู่จริง แต่บทวิเคราะห์ชื่อนี้หาไม่เจอ มีบทวิเคราะห์เรื่องที่เกี่ยวข้องอยู่ แต่เป็นของปี 2565 และตัวเลขข้างในไม่ตรงกับที่สรุปมาเลย

**ผลคือ: ตัวเลขทุกตัวในย่อหน้าแรกไม่มีแหล่งรองรับ**

**ขั้นตรวจที่ 1 (ไล่ทุกตัวเลข)** — ขีดเส้นใต้ได้ 6 จุด: 45,000 ล้าน · 6.8% · 3 ราย · 55% · โครงสร้างต้นทุน 4 รายการ

ทั้ง 6 จุดตกอยู่ในสถานะเดียวกัน คือไม่มีแหล่งที่เปิดดูได้

**ขั้นตรวจที่ 4 (ถามหาสิ่งที่ไม่แน่ใจ)** — ถามว่า "มีอะไรที่คุณไม่แน่ใจบ้าง"

ได้คำตอบที่ตรงไปตรงมา:

> "ตัวเลขมูลค่าตลาดและอัตราการเติบโตเป็นการประมาณจากรูปแบบทั่วไปของอุตสาหกรรมประเภทนี้ ไม่ได้มาจากรายงานเฉพาะเจาะจง และข้อมูลส่วนแบ่งตลาดอาจไม่ตรงกับสถานการณ์ปัจจุบัน ควรตรวจสอบกับแหล่งข้อมูลในประเทศไทยโดยตรง"

**คำถามที่ตามมาคือ: ทำไมมันไม่บอกตั้งแต่แรก** คำตอบคือเราไม่ได้ถาม และมันไม่มีกลไกที่จะบอกเองว่าอะไรมั่นใจอะไรไม่มั่นใจ ทุกอย่างออกมาด้วยน้ำเสียงเดียวกัน — ซึ่งคือสิ่งที่บทที่ 1 เตือนไว้

**ขั้นตรวจที่ 3 (หาแหล่งจริง)** — ใช้เวลา 40 นาทีค้นหาแหล่งจริง พบ

- ข้อมูลสถิติจากหน่วยงานราชการที่เผยแพร่จริง แต่เป็นระดับหมวดใหญ่กว่า ไม่ได้แยกย่อยถึงอุตสาหกรรมนี้โดยเฉพาะ
- ข่าวจากสมาคมอุตสาหกรรม ที่ให้ภาพสถานการณ์ปีล่าสุด พร้อมตัวเลขบางส่วนที่อ้างอิงได้

### หลัง — เอกสารเตรียมประชุมที่ใช้ได้จริง

> **กอง 1 — พูดได้ (ยืนยันแล้ว)**
> - มูลค่าการส่งออกหมวด [X] ปี [ปี] = [ตัวเลข] — ที่มา: [หน่วยงาน] เผยแพร่ [วันที่] ✓ เปิดอ่านแล้ว
> - [ข้อมูลที่สอง] — ที่มา: [สมาคม] ✓
>
> **กอง 2 — ถามในที่ประชุม (ไม่ยืนยัน)**
> - "ผมเห็นตัวเลขระดับภาพรวมของหมวดใหญ่ แต่ไม่พบข้อมูลเฉพาะของอุตสาหกรรมนี้ พี่พอจะทราบไหมว่าขนาดตลาดจริงๆ ประมาณเท่าไร"
> - "โครงสร้างต้นทุนของธุรกิจนี้ วัตถุดิบคิดเป็นสัดส่วนประมาณเท่าไรครับ"
> - "ราคาวัตถุดิบช่วงนี้เทียบกับปีก่อนเป็นอย่างไรบ้าง"
>
> **กอง 3 — ไม่พูด**
> - ตัวเลขส่วนแบ่งตลาดและรายชื่อผู้เล่นรายใหญ่ (หาแหล่งไม่ได้)
> - อัตราการเติบโต 6.8% (ไม่มีที่มา)
>
> **คำถามที่เตรียมไว้ (จาก AI ในโหมดแผนที่)**
> 1. วัตถุดิบหลักมาจากไหน ฤดูกาลเป็นอย่างไร
> 2. ขายให้ใคร สัดส่วนในประเทศ/ส่งออกเท่าไร
> 3. เงินหมุนเวียนตึงช่วงไหนของปี
> 4. คู่แข่งหลักคือใคร แข่งกันที่อะไร
> 5. นโยบายรัฐที่กระทบธุรกิจนี้ตอนนี้คืออะไร

### ผลที่ต่างกัน

**ถ้าใช้ฉบับแรก:** เข้าประชุมแล้วพูดว่า "จากข้อมูลที่ผมดูมา ตลาดนี้มีมูลค่าประมาณ 45,000 ล้าน" — ถ้าคนในห้องรู้ว่าตัวเลขจริงคือ 12,000 ล้าน เราจะเสียความน่าเชื่อถือทั้งการประชุม และถ้าเขาถามต่อว่า "ดูจากที่ไหนครับ" เราตอบไม่ได้

**ถ้าใช้ฉบับที่สอง:** เข้าประชุมด้วยคำถามที่ดี ได้ข้อมูลจริงจากคนที่รู้จริง และดูเหมือนคนที่เตรียมตัวมา — ซึ่งเราเตรียมมาจริงๆ

**บทเรียน:** ในการประชุมเรื่องที่เราไม่รู้ **คำถามที่ดีมีค่ากว่าคำตอบที่ไม่แน่ใจ** เสมอ

**เวลาที่ใช้ตรวจสอบทั้งหมด: 1 ชั่วโมง 10 นาที**

## 8. Prompt ตั้งต้น

### แบบที่ 1 — โหมดแผนที่ (ใช้เป็นหลัก)

```
บทบาท: ผู้ช่วยเตรียมตัวก่อนประชุม

สถานการณ์: พรุ่งนี้ฉันต้องประชุมกับ [ใคร] เรื่อง [อะไร]
บทบาทของฉัน: [...]
สิ่งที่ฉันรู้แล้ว: [...]
สิ่งที่ฉันต้องตัดสินใจหรือต้องไม่พลาด: [...]

สิ่งที่ต้องการ — ห้ามให้ข้อมูลหรือตัวเลข ให้เฉพาะ 5 อย่างนี้:

1. ประเด็นที่ฉันควรรู้ก่อนเข้าประชุม เรียงตามความสำคัญ
   (บอกว่าเป็นประเด็นอะไร ไม่ต้องบอกคำตอบ)

2. คำถามที่ฉันควรถามในที่ประชุม เรียงตามลำดับที่ควรถาม
   แต่ละคำถามบอกด้วยว่า "คำตอบแบบไหนที่ควรทำให้ฉันถามต่อ"

3. หน่วยงานหรือแหล่งข้อมูลในประเทศไทยที่เผยแพร่ข้อมูลเรื่องนี้
   (ชื่อหน่วยงาน ไม่ต้องให้ตัวเลข)

4. ศัพท์เฉพาะที่น่าจะถูกใช้ในที่ประชุมนี้ พร้อมความหมาย

5. สิ่งที่คนที่ไม่เคยทำเรื่องนี้มักเข้าใจผิด

ข้อห้าม:
- ห้ามให้ตัวเลข สถิติ มูลค่าตลาด อัตราการเติบโต ส่วนแบ่งตลาด
- ห้ามระบุชื่อบริษัทหรือผู้ประกอบการรายใด
- ห้ามบอกว่า "สถานการณ์ปัจจุบันคือ..."
```

### แบบที่ 2 — เมื่อมีเอกสารจริงในมือ (ช่อง ②)

```
[แนบเอกสาร/รายงานที่มี]

จากเอกสารนี้เท่านั้น ห้ามใช้ความรู้จากที่อื่น:
1. สรุปประเด็นสำคัญ 5 ข้อ พร้อมระบุหน้าที่มา
2. ตัวเลขสำคัญทั้งหมด พร้อมหน้าและปีของข้อมูล
3. เรื่องที่เอกสารนี้ไม่ได้ตอบ แต่ฉันควรรู้ก่อนประชุม
4. คำถามที่ควรถามในที่ประชุม จากช่องว่างในข้อ 3
```

### แบบที่ 3 — คำถามตรวจสอบ (ถามทุกครั้งก่อนจบ)

```
1. จากทั้งหมดที่ให้มา อะไรที่คุณไม่แน่ใจ อะไรที่อาจล้าสมัย
   และอะไรที่เป็นการประมาณจากรูปแบบทั่วไป ไม่ใช่ข้อมูลเฉพาะเจาะจง

2. ถ้าฉันเข้าประชุมโดยเชื่อข้อมูลชุดนี้ทั้งหมด
   ฉันเสี่ยงจะพลาดตรงไหนมากที่สุด

3. ข้อมูลข้อไหนที่ต้องตรวจสอบกับแหล่งในประเทศไทยโดยเฉพาะ
   เพราะบริบทต่างจากต่างประเทศ
```

**คำถามชุดที่ 3 ควรทำให้เป็นนิสัย** — ถามทุกครั้งที่ใช้ AI ค้นคว้า ใช้เวลา 30 วินาที และเปลี่ยนข้อมูลที่ดูแน่นอนให้กลับมาอยู่ในสถานะที่ถูกต้อง คือยังไม่ยืนยัน
