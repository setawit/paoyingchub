# บทที่ 7 — ร่างบันทึกข้อความ หนังสือราชการ อีเมล

> **กลุ่มเสี่ยง:** ตรวจง่าย · เสียหายน้อย
> (ช่อง ① — ใช้ได้เต็มที่ นี่คืองานที่คุ้มที่สุดในเล่ม)

---

## 1. งานนี้คืออะไร ปกติทำอย่างไร ใช้เวลาเท่าไร

ต้องสื่อสารอะไรสักอย่างเป็นลายลักษณ์อักษร — ขออนุมัติ แจ้งเวียน ตอบข้อหารือ นัดหมาย ติดตามงาน ชี้แจง

**เวลาที่ใช้แบบเดิม:** 20–60 นาที ต่อฉบับ โดยที่ 70% ของเวลาหมดไปกับ **20% แรก** คือตอนที่ยังไม่รู้ว่าจะขึ้นต้นอย่างไร

**เวลาที่ใช้เมื่อมี AI ช่วย:** ร่าง 1 นาที + แก้และตรวจ 5–10 นาที

งานนี้คือจุดที่ AI ให้กำไรสุทธิสูงที่สุดในบรรดางานทั้งหมดในเล่ม เพราะเวลาตรวจเกือบเป็นศูนย์ — เราอ่านออกทันทีว่าประโยคไหนใช้ได้ ประโยคไหนใช้ไม่ได้

---

## 2. AI ช่วยตรงไหนได้ ตรงไหนช่วยไม่ได้

| ช่วยได้ดี | ช่วยไม่ได้ |
|---|---|
| ทำลายหน้ากระดาษเปล่า | รู้ว่าคนรับคนนี้ชอบอ่านแบบไหน |
| วางโครงตามประเภทหนังสือ | รู้ประวัติความสัมพันธ์ระหว่างสองหน่วยงาน |
| ปรับระดับความเป็นทางการ | รู้ว่าเรื่องนี้เคยมีปัญหากันมาก่อน |
| เขียนใหม่ 3 แบบให้เลือก | รู้ว่าอะไรพูดได้ อะไรพูดไม่ได้ในองค์กรนี้ |
| ทำให้สั้นลงโดยเก็บใจความ | รู้เลขที่หนังสือ รูปแบบฟอร์ม ผู้ลงนามที่ถูกต้อง |

### ข้อสำคัญ: ให้ร่างจาก "ประเด็น" ไม่ใช่จากศูนย์

นี่คือความต่างที่กำหนดคุณภาพงานทั้งชิ้น

**ผิด:** "เขียนหนังสือขออนุมัติจัดอบรมให้หน่อย"
→ ได้หนังสือที่มีแต่โครง เนื้อหาเป็นของกลางๆ ที่ใช้กับใครก็ได้ ต้องเขียนใหม่เกือบหมด

**ถูก:** "เขียนบันทึกขออนุมัติ โดยมีประเด็นที่ต้องสื่อดังนี้: (1) ขออนุมัติจัดอบรมหลักสูตร X ให้พนักงาน 25 คน (2) วันที่ 15-16 ต.ค. ที่ห้องประชุมชั้น 3 (3) งบประมาณ 48,000 บาท จากงบพัฒนาบุคลากรที่ตั้งไว้แล้ว (4) เหตุผล: ปีนี้มีพนักงานใหม่ 12 คนที่ยังไม่ผ่านหลักสูตรนี้ (5) ต้องการคำตอบภายใน 30 ก.ย. เพราะต้องจองวิทยากร"
→ ได้หนังสือที่ใช้ได้เลยหลังแก้เล็กน้อย

**หลักคือ: เราคิด AI เรียบเรียง** ถ้าเราให้มันคิดแทน มันจะคิดแบบกลางๆ ที่ไม่ตรงกับเรื่องของเรา

## 3. Input ที่ต้องเตรียมก่อนสั่งงาน

เตรียมหกอย่าง ใช้เวลาไม่เกิน 3 นาที และประหยัดเวลาแก้ได้มาก

```
1. ประเภทหนังสือ       บันทึกข้อความ / หนังสือภายนอก / อีเมล
2. ผู้รับ               ตำแหน่ง ระดับ ความสัมพันธ์
3. ประเด็นที่ต้องสื่อ    เขียนเป็น bullet ให้ครบ
4. สิ่งที่ต้องการให้เกิด  อนุมัติ / รับทราบ / ตอบกลับ / ดำเนินการ
5. กำหนดเวลา           ถ้ามี
6. โทน                 ทางการเต็ม / ทางการปกติ / กันเอง
```

### ตัวอย่างหนังสือแต่ละประเภท (โครงมาตรฐาน)

**บันทึกข้อความภายใน**
```
เรื่อง → เรียน → ความเป็นมา/เหตุผล → ข้อเท็จจริง
→ ข้อพิจารณา → ข้อเสนอ/ขออนุมัติ → จึงเรียนมาเพื่อ...
```

**หนังสือภายนอก**
```
ที่/วันที่ → เรื่อง → เรียน → อ้างถึง (ถ้ามี) → สิ่งที่ส่งมาด้วย (ถ้ามี)
→ ย่อหน้าเปิด (เหตุที่มีหนังสือ) → ย่อหน้าเนื้อหา
→ ย่อหน้าปิด (สิ่งที่ต้องการ) → ขอแสดงความนับถือ
```

**อีเมลงาน**
```
หัวเรื่องที่บอกเนื้อหาและการกระทำที่ต้องการ
→ ประโยคแรกบอกว่าต้องการอะไร (ไม่ใช่เกริ่น)
→ รายละเอียด → กำหนดเวลา → ปิด
```

> **หลักของอีเมล:** คนอ่านอีเมลบนมือถือ ประโยคแรกคือทั้งหมดที่เขาจะเห็น ถ้าประโยคแรกเป็น "เนื่องด้วยฝ่ายเราได้รับมอบหมาย..." แปลว่าเสียโอกาสไปแล้ว

### โทนภาษาราชการ vs ธุรกิจ

| | ราชการ | ธุรกิจ |
|---|---|---|
| ประธาน | มักละ หรือใช้หน่วยงาน | ใช้ "เรา" "ผม/ดิฉัน" ได้ |
| ความยาวประโยค | ยาว มีอนุประโยคซ้อน | สั้น ตรง |
| การขอ | "จึงเรียนมาเพื่อโปรดพิจารณา" | "รบกวนยืนยันกลับภายในวันศุกร์" |
| ความชัดของ deadline | มักคลุมเครือ | ต้องระบุวันที่ |

AI มักเขียนภาษาราชการได้ "ทางการเกินไป" คือมีคำเชื่อมและคำขยายเยอะจนใจความหาย ส่วนภาษาธุรกิจมักเขียนได้ "ตรงเกินไป" คือห้วนกว่าที่ควรในบริบทไทย ทั้งสองอย่างแก้ได้ในขั้นตอนตรวจ

## 4. กลุ่มความเสี่ยง

**ตรวจง่าย** — ผิดแล้วเห็นทันทีที่อ่าน ไม่ต้องเปิดแหล่งไหนเทียบ

**เสียหายน้อย** — ในกรณีทั่วไป แก้ได้ ส่งฉบับแก้ไขได้

**ยกเว้นสามกรณีที่ขยับขึ้นเป็นเสียหายมาก:**
- หนังสือที่มีข้อผูกพัน — ยืนยันเงื่อนไข ให้คำมั่น รับปาก
- หนังสือถึงหน่วยงานกำกับหรือหน่วยงานภายนอกที่จะเก็บเป็นหลักฐาน
- หนังสือที่มีตัวเลขซึ่งอีกฝ่ายจะใช้ตัดสินใจ

ในสามกรณีนี้ ให้ตรวจแบบช่อง ② คือไล่ทีละบรรทัดเรื่องข้อผูกพันและตัวเลข

## 5. วิธีตรวจ

### ขั้นที่ 1 — อ่านออกเสียง 1 รอบ *(2 นาที)*

นี่คือวิธีตรวจที่ทรงพลังที่สุดของงานเขียน และคนใช้น้อยที่สุด

**ทำไมได้ผล:** ประโยคที่ไม่ใช่ภาษาของเราจะสะดุดหูทันที ในขณะที่การอ่านในใจจะข้ามผ่านไป เพราะสมองเติมเต็มให้เอง

จุดที่มักสะดุด: คำเชื่อมที่ยาวเกิน · คำขยายที่ไม่จำเป็น · ประโยคที่ยาวจนต้องหายใจกลางประโยค · ศัพท์ที่เราไม่เคยใช้

ถ้าอยู่ในที่ที่อ่านออกเสียงไม่ได้ ให้อ่านช้าๆ แบบขยับปาก ได้ผลใกล้เคียงกัน

### ขั้นที่ 2 — ตรวจข้อมูลจำเพาะทุกตัว *(2 นาที)*

ไล่เช็คทีละอย่าง

```
□ ชื่อผู้รับ สะกดถูก ตำแหน่งถูก
□ ชื่อหน่วยงาน ชื่อเต็มถูกต้อง (AI ชอบย่อหรือเรียกผิด)
□ เลขที่หนังสือ
□ วันที่
□ ตัวเลขทุกตัว (จำนวนเงิน จำนวนคน จำนวนวัน)
□ ชื่อโครงการ ชื่อหลักสูตร ชื่อเอกสารอ้างอิง
□ คำนำหน้าและคำลงท้ายตรงกับระดับผู้รับ
```

**AI แต่งข้อมูลจำเพาะเก่งมาก** มันจะใส่เลขที่หนังสือที่ดูสมจริง วันที่ที่สมเหตุสมผล และชื่อหน่วยงานที่ใกล้เคียง — ทั้งหมดนี้ต้องตรวจ 100% ไม่ใช่สุ่ม

### ขั้นที่ 3 — หาข้อมูลที่เราไม่ได้บอก *(2 นาที)*

อ่านทีละย่อหน้า แล้วถามว่า **"ข้อมูลนี้ฉันบอกมันไปหรือเปล่า"**

AI ชอบเติมเหตุผลประกอบให้ดูสมบูรณ์ เช่น เราบอกแค่ว่าขออนุมัติจัดอบรม มันเติมมาว่า "เพื่อให้สอดคล้องกับแผนยุทธศาสตร์การพัฒนาบุคลากรประจำปี" — ซึ่งเราไม่รู้ด้วยซ้ำว่าแผนนั้นมีอยู่จริงไหม

### ขั้นที่ 4 — ตัดคำฟุ่มเฟือย *(2 นาที)*

คำที่ AI ชอบเติมและตัดได้เกือบทุกครั้ง

| คำที่ควรตัด | เขียนแทนว่า |
|---|---|
| "เนื่องด้วยในปัจจุบัน" | ตัดทิ้ง เริ่มที่ใจความเลย |
| "ทั้งนี้ เพื่อให้เป็นไปตาม..." | ตัดถ้าไม่ได้อ้างระเบียบจริง |
| "อย่างไรก็ตาม ในการนี้" | ตัดทิ้ง |
| "ซึ่งจะส่งผลให้เกิดประโยชน์อย่างยิ่ง" | ตัดทิ้ง หรือบอกประโยชน์ที่วัดได้ |
| "จึงใคร่ขอความอนุเคราะห์" | "จึงขอ" |
| "ดำเนินการในส่วนที่เกี่ยวข้องต่อไป" | บอกให้ชัดว่าต้องทำอะไร |

**เกณฑ์:** ลบประโยคนั้นออกแล้วความหมายเปลี่ยนไหม ถ้าไม่เปลี่ยน ลบ

### ขั้นที่ 5 — เช็คว่าคนอ่านรู้ไหมว่าต้องทำอะไร *(1 นาที)*

อ่านย่อหน้าสุดท้าย แล้วถามว่า **"ถ้าฉันเป็นคนรับ ฉันรู้ไหมว่าต้องทำอะไร ภายในเมื่อไร"**

ถ้าตอบไม่ได้ทั้งสองข้อ หนังสือฉบับนี้ยังไม่เสร็จ ไม่ว่าจะเขียนสวยแค่ไหน

**รวมเวลาตรวจ: 8–9 นาที**

## 6. จุดพลาดที่พบบ่อย

| จุดพลาด | อาการ | วิธีกัน |
|---|---|---|
| **สุภาพเกินจนไม่รู้ว่าต้องการอะไร** | อ่านจบแล้วยังไม่รู้ว่าให้ทำอะไร | ขั้นตรวจที่ 5 + สั่งให้เขียน "สิ่งที่ต้องการ" เป็นประโยคแรกของย่อหน้าสุดท้าย |
| **ใส่ข้อมูลที่เราไม่ได้บอก** | มีเหตุผล ตัวเลข หรือการอ้างอิงที่เราไม่รู้จัก | ขั้นตรวจที่ 3 + สั่ง "ห้ามเพิ่มข้อมูลที่ไม่ได้ให้" |
| **แต่งเลขที่หนังสือ/วันที่** | ดูสมจริงจนเผลอผ่าน | ขั้นตรวจที่ 2 — ตรวจ 100% |
| **โทนไม่ตรงความสัมพันธ์** | ทางการกับคนที่คุยกันทุกวัน หรือกันเองกับผู้ใหญ่ | บอกความสัมพันธ์ใน input ตั้งแต่แรก |
| **ยาวเกินจำเป็น** | 3 ย่อหน้าในเรื่องที่ 3 บรรทัดพอ | สั่งจำกัดความยาว + ขั้นตรวจที่ 4 |
| **อ้างระเบียบที่ไม่มี** | "ตามระเบียบว่าด้วย..." ที่ไม่เคยได้ยิน | ห้ามให้อ้างระเบียบเด็ดขาด ถ้าต้องอ้างให้เราใส่เอง |

## 7. เคสจริง 1 เคส

### สถานการณ์

ต้องเขียนอีเมลถึงหน่วยงานพันธมิตร เพื่อขอเลื่อนวันประชุมร่วมจากวันที่ 12 เป็นวันที่ 19 เพราะผู้บริหารติดภารกิจ

สิ่งที่บอก AI: "เขียนอีเมลขอเลื่อนประชุมจากวันที่ 12 เป็น 19 เพราะผู้บริหารติดภารกิจ ส่งถึงคุณ... ที่เป็นผู้ประสานงานของอีกฝ่าย"

### ก่อน — ร่างที่ได้มา

> **เรื่อง: ขอความอนุเคราะห์ในการพิจารณาปรับเปลี่ยนกำหนดการประชุม**
>
> เรียน คุณ...
>
> เนื่องด้วยในปัจจุบัน หน่วยงานของเราได้มีกำหนดการประชุมร่วมกับท่านในวันที่ 12 ตุลาคม 2568 นั้น
>
> ในการนี้ ด้วยผู้บริหารระดับสูงของเราติดภารกิจสำคัญเร่งด่วนที่ไม่อาจหลีกเลี่ยงได้ ประกอบกับเพื่อให้การประชุมดังกล่าวเป็นไปอย่างมีประสิทธิภาพและเกิดประโยชน์สูงสุดแก่ทั้งสองฝ่าย จึงใคร่ขอความอนุเคราะห์จากท่านในการพิจารณาปรับเปลี่ยนกำหนดการประชุมดังกล่าว
>
> ทั้งนี้ หากท่านมีข้อสงสัยประการใด สามารถติดต่อสอบถามได้ตามช่องทางที่สะดวก
>
> จึงเรียนมาเพื่อโปรดพิจารณา และขอขอบพระคุณเป็นอย่างสูงมา ณ โอกาสนี้

### จับผิดอย่างไร

**ขั้นที่ 1 (อ่านออกเสียง)** — สะดุดตั้งแต่ประโยคแรก "เนื่องด้วยในปัจจุบัน" ไม่มีความหมาย และทั้งฉบับไม่มีตรงไหนที่ฟังเหมือนเราพูด

**ขั้นที่ 3 (ข้อมูลที่ไม่ได้บอก)** — "ภารกิจสำคัญเร่งด่วนที่ไม่อาจหลีกเลี่ยงได้" เราไม่ได้บอกว่าเร่งด่วนหรือหลีกเลี่ยงไม่ได้ · "เพื่อให้การประชุมเป็นไปอย่างมีประสิทธิภาพ" เราไม่ได้บอกเหตุผลนี้ · ปีเป็น 2568 ที่ AI ใส่เอง ต้องเช็คว่าถูกไหม

**ขั้นที่ 5 (คนอ่านรู้ไหมว่าต้องทำอะไร)** — **จับได้จุดใหญ่ที่สุด: ไม่มีวันที่ 19 อยู่ในอีเมลเลย** ทั้งฉบับขอเลื่อนโดยไม่บอกว่าจะเลื่อนไปวันไหน คนรับต้องตอบกลับมาถามอยู่ดี

จุดนี้คือสิ่งที่เกิดขึ้นบ่อยมากและอันตรายเพราะ **ข้อความยิ่งสุภาพและยาว ยิ่งกลบใจความหลักที่หายไป**

### หลัง — ฉบับที่แก้แล้ว

> **เรื่อง: ขอเลื่อนประชุมร่วม จากวันที่ 12 เป็น 19 ต.ค.**
>
> เรียน คุณ...
>
> ขอเลื่อนการประชุมร่วมที่กำหนดไว้วันที่ 12 ตุลาคม ออกไปเป็น **วันที่ 19 ตุลาคม เวลาเดิม** เนื่องจากผู้บริหารติดภารกิจในวันดังกล่าว
>
> หากวันที่ 19 ไม่สะดวก รบกวนแจ้งวันที่ท่านสะดวกในสัปดาห์เดียวกัน เราปรับตามได้
>
> ขอบคุณครับ/ค่ะ

จาก 6 ย่อหน้าเหลือ 3 ย่อหน้า ใจความครบขึ้น และคนรับตอบกลับได้ทันทีด้วยคำเดียว

**เวลาที่ใช้แก้: 4 นาที** (เร็วกว่าเขียนเองจากศูนย์ประมาณ 15 นาที)

## 8. Prompt ตั้งต้น

```
บทบาท: ผู้ช่วยร่างหนังสือ

ประเภท: [บันทึกข้อความภายใน / หนังสือภายนอก / อีเมล]
ผู้รับ: [ตำแหน่ง ระดับ ความสัมพันธ์กับเรา]
โทน: [ทางการเต็ม / ทางการปกติ / กันเองแบบมืออาชีพ]

ประเด็นที่ต้องสื่อ (ต้องมีครบทุกข้อในหนังสือ):
1. ...
2. ...
3. ...

สิ่งที่ต้องการให้ผู้รับทำ: [อนุมัติ / ตอบกลับ / ดำเนินการ]
ภายในวันที่: [...]

รูปแบบ:
- ความยาวไม่เกิน [X] ย่อหน้า
- ย่อหน้าสุดท้ายต้องบอกชัดว่าต้องทำอะไร ภายในเมื่อไร
- หัวเรื่องต้องบอกทั้งเนื้อหาและการกระทำที่ต้องการ

ข้อห้าม:
- ห้ามเพิ่มเหตุผล ข้อมูล หรือตัวเลขที่ไม่ได้ให้ไว้ข้างบน
- ห้ามอ้างระเบียบ ประกาศ หรือแผนงานใดๆ
- ห้ามใส่เลขที่หนังสือหรือวันที่ ให้เว้นเป็น [เลขที่] [วันที่]
- ห้ามใช้ "เนื่องด้วยในปัจจุบัน" "ในการนี้" "ทั้งนี้"
  "เพื่อให้เกิดประโยชน์สูงสุด"

ทำ 2 แบบ: แบบสั้นที่สุดที่ยังครบ และแบบทางการกว่า
```

**เคล็ดลับ:** ขอ 2 แบบเสมอ แล้วเลือกแบบสั้นเป็นตัวตั้ง ค่อยหยิบประโยคจากแบบทางการมาเติมเฉพาะที่จำเป็น — วิธีนี้ได้หนังสือที่สั้นและครบ ซึ่งยากกว่าที่คิด
