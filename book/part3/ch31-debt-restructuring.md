# บทที่ 31 — Scenario ปรับโครงสร้างหนี้

> **กลุ่มเสี่ยง:** ตรวจง่าย (ตัวเลข) · **เสียหายมาก**
>
> *ตัวเลขและเคสในบทนี้เป็นตัวเลขสมมติ*

## 1. งานนี้คืออะไร ปกติทำอย่างไร ใช้เวลาเท่าไร

ลูกค้ามีปัญหาการชำระ ต้องหาว่ามีทางปรับเงื่อนไขอย่างไรที่ทำให้เขาชำระได้จริง และธนาคารรับได้

**เวลาที่ใช้แบบเดิม:** คำนวณเปรียบเทียบ 3–4 ทางเลือก 2–4 ชั่วโมง

**เวลาที่ใช้เมื่อมี AI ช่วย:** คำนวณ 15 นาที + ตรวจ 40 นาที

**หลักการที่ต้องยึดตลอดทั้งบท:**

> ## **ปรับโครงสร้างหนี้ที่ดี คือปรับให้ตรงกับความสามารถชำระที่แท้จริง ไม่ใช่ปรับให้ตัวเลขผ่านเกณฑ์**

ความแตกต่างนี้คือเส้นแบ่งระหว่างการแก้ปัญหากับการเลื่อนปัญหา และการเลื่อนปัญหามีต้นทุนสูงกว่าเสมอ เพราะเมื่อกลับมาอีกครั้ง หนี้จะสูงขึ้นและทางเลือกจะน้อยลง

## 2. AI ช่วยตรงไหนได้ ตรงไหนช่วยไม่ได้

| ช่วยได้ดี | ช่วยไม่ได้ |
|---|---|
| คำนวณตารางผ่อนใหม่ทุกทางเลือก | รู้ระเบียบการปรับโครงสร้างหนี้ของเรา |
| เปรียบเทียบผลของแต่ละทางเลือก | รู้ว่าลูกค้าจะทำได้จริงไหม |
| คำนวณดอกเบี้ยรวมตลอดสัญญา | รู้ผลต่อการจัดชั้นและการตั้งสำรอง |
| หาจุดที่ DSCR = 1 หลังปรับ | รู้ว่าอำนาจอนุมัติอยู่ระดับไหน |
| ทำตารางเปรียบเทียบให้อ่านง่าย | ประเมินว่าลูกค้าจริงใจแค่ไหน |

### ทางเลือกหลักในการปรับโครงสร้าง

| วิธี | ทำอะไร | ช่วยเมื่อ | ต้นทุนที่ตามมา |
|---|---|---|---|
| **ขยายระยะเวลา** | ยืดงวดออกไป งวดละน้อยลง | รายได้ลดลงถาวรแต่ยังมี | ดอกเบี้ยรวมสูงขึ้นมาก |
| **ลดจำนวนงวด / พักเงินต้น** | จ่ายเฉพาะดอกเบี้ยช่วงหนึ่ง | ปัญหาชั่วคราว รายได้จะกลับมา | เงินต้นไม่ลด ภาระหลังพ้นช่วงพักสูงขึ้น |
| **พักชำระทั้งหมด** | หยุดชำระชั่วคราว | ภัยพิบัติ เหตุสุดวิสัย | ดอกเบี้ยยังเดิน หนี้โตขึ้น |
| **ปรับตารางตามฤดูกาล** | ชำระหนักช่วงมีรายได้ | รายได้เป็นฤดูกาล | ต้องบริหารจัดการมากขึ้น |
| **ลดอัตราดอกเบี้ย** | ลดภาระดอกเบี้ย | ตามเกณฑ์ที่กำหนด | รายได้ธนาคารลดลง |
| **รวมสัญญา** | รวมหลายสัญญาเป็นหนึ่ง | มีหลายสัญญาที่บริหารยาก | ต้องดูผลต่อหลักประกัน |

**ทางเลือกที่คนมองข้ามบ่อยที่สุดคือ "ปรับตารางตามฤดูกาล"** ซึ่งในงานเกษตรมักเป็นทางเลือกที่ดีที่สุด เพราะปัญหาหลายกรณีไม่ใช่ว่าลูกค้าจ่ายไม่ไหวทั้งปี แต่เป็นว่างวดชำระตั้งไว้ผิดเดือน

### สามอย่างที่ต้องไม่ลืมในการคำนวณ

**1. ดอกเบี้ยค้าง**

ลูกค้าที่มีปัญหามักมีดอกเบี้ยค้างจ่ายอยู่แล้ว ซึ่งต้องจัดการด้วย ไม่ใช่คำนวณเฉพาะเงินต้นคงเหลือ

**2. ผลต่อการจัดชั้น**

การปรับโครงสร้างหนี้มีผลต่อการจัดชั้นลูกหนี้และการตั้งสำรอง ซึ่งเป็นเรื่องที่ต้องดูตามเกณฑ์ขององค์กร — **AI ไม่รู้เรื่องนี้เลย**

**3. ดอกเบี้ยรวมตลอดสัญญา**

การขยายระยะเวลาทำให้งวดลดลง แต่ดอกเบี้ยรวมเพิ่มขึ้นมาก ต้องแสดงตัวเลขนี้ให้ลูกค้าเห็นด้วย เพราะเขามีสิทธิ์รู้ว่าทางเลือกที่ดูเบาที่สุดมีต้นทุนเท่าไร

## 3. Input ที่ต้องเตรียมก่อนสั่งงาน

```
1. ยอดหนี้คงเหลือ แยกเงินต้น/ดอกเบี้ยค้าง ทุกสัญญา
2. เงื่อนไขปัจจุบัน              อัตราดอกเบี้ย งวด กำหนดชำระ
3. กระแสเงินสดที่แท้จริง          จากบทที่ 22-23 หลังหักทุกอย่าง
4. รูปแบบฤดูกาล                จาก statement
5. สาเหตุของปัญหา              ชั่วคราวหรือถาวร
6. สิ่งที่ลูกค้าเสนอ
7. หลักประกันที่มี
```

**ข้อ 5 กำหนดทางเลือกที่เหมาะสม**

| สาเหตุ | ทางเลือกที่เหมาะ |
|---|---|
| ภัยธรรมชาติปีเดียว | พักชำระชั่วคราว |
| ราคาตกต่อเนื่อง | ขยายระยะเวลา |
| ตารางชำระตั้งผิดฤดู | ปรับตารางตามฤดูกาล |
| ลงทุนเกินตัว | ขยายระยะเวลา + อาจต้องขายทรัพย์บางส่วน |
| ธุรกิจไม่ไปแล้ว | **ไม่ใช่การปรับโครงสร้าง — เป็นเรื่องอื่น** |

**แถวสุดท้ายสำคัญ** — ถ้าธุรกิจไม่มีทางกลับมาได้ การปรับโครงสร้างคือการยืดเวลาที่ทำให้ทุกฝ่ายเสียหายมากขึ้น

## 4. กลุ่มความเสี่ยง

**ตรวจง่าย (ตัวเลข)** — ตารางผ่อนคำนวณเองซ้ำได้

**เสียหายมาก** เพราะ

- ถ้าปรับแล้วลูกค้ายังชำระไม่ได้ เราเสียเวลาไปหนึ่งรอบและหนี้โตขึ้น
- **ทางเลือกที่สองมักแย่กว่าทางเลือกแรกเสมอ** — เมื่อปรับครั้งที่สอง ทางเลือกน้อยลงและเงื่อนไขแย่ลง
- มีผลต่อการจัดชั้นและการตั้งสำรอง
- เอกสารนี้จะถูกตรวจสอบย้อนหลังแน่นอน

**ข้อควรระวังที่สุด:** ความกดดันที่จะทำให้ตัวเลขผ่าน — ทั้งจากลูกค้าที่อยากได้ และจากตัวเราเองที่อยากช่วย จะทำให้เราเผลอใช้สมมติฐานที่มองโลกในแง่ดีเกินจริง

## 5. วิธีตรวจ

### ขั้นที่ 1 — คำนวณตารางผ่อนเองซ้ำ 1 scenario *(10 นาที)*

เลือก scenario ที่น่าจะเสนอ แล้วคำนวณเองด้วย Excel หรือเครื่องคิดเลข

ตรวจสามจุด
```
□ งวดชำระต่อเดือนตรงไหม
□ ดอกเบี้ยรวมตลอดสัญญาตรงไหม
□ ยอดคงเหลือ ณ งวดสุดท้ายเป็นศูนย์ไหม
```

**ถ้าตรง scenario อื่นค่อยเชื่อ ถ้าไม่ตรง ตรวจใหม่ทั้งหมด**

### ขั้นที่ 2 — ตรวจว่ากระแสเงินสดหลังปรับมาจากข้อมูลจริง *(10 นาที)*

**นี่คือขั้นตรวจที่สำคัญที่สุดของบทนี้**

ดูตัวเลขกระแสเงินสดที่ใช้ในการคำนวณว่าลูกค้าจะชำระได้ แล้วถามว่า **"ตัวเลขนี้มาจากไหน"**

| ที่มา | รับได้ไหม |
|---|---|
| จาก statement ย้อนหลัง 12 เดือน | ✓ รับได้ |
| จากงบการเงินที่ตรวจสอบแล้ว | ✓ รับได้ |
| จากประมาณการที่ลูกค้าทำ | △ ต้องตรวจสมมติฐาน |
| **จากการสมมติว่ารายได้จะฟื้นตัว** | ✗ **ห้ามใช้** |
| จากการสมมติว่าราคาจะดีขึ้น | ✗ ห้ามใช้ |

**กฎเหล็ก:**

> **ถ้าต้องสมมติว่าอนาคตจะดีขึ้นถึงจะผ่าน แปลว่ายังไม่ผ่าน**

การปรับโครงสร้างต้องทำให้ลูกค้าชำระได้ด้วย **กระแสเงินสดในระดับปัจจุบัน** ถ้ารายได้ฟื้นตัวจริงในภายหลัง นั่นคือส่วนเพิ่ม ไม่ใช่สมมติฐานตั้งต้น

### ขั้นที่ 3 — ตรวจว่ารวมดอกเบี้ยค้างและทุกสัญญาแล้วหรือยัง *(5 นาที)*

```
□ ดอกเบี้ยค้างจ่ายทั้งหมด รวมอยู่ในยอดที่ปรับหรือยัง
□ ทุกสัญญาที่ลูกค้ามีกับเรา รวมอยู่ในภาพหรือยัง
□ ภาระกับสถาบันอื่น รวมในการคำนวณความสามารถชำระหรือยัง
□ หนี้นอกระบบที่ลูกค้าแจ้ง นับรวมหรือยัง
```

**การปรับโครงสร้างสัญญาเดียวโดยไม่ดูภาระทั้งหมด คือการแก้ปัญหาที่มองไม่เห็นภาพรวม**

### ขั้นที่ 4 — เทียบกับระเบียบปรับโครงสร้างหนี้จริง *(20 นาที)*

```
□ วิธีที่เสนอ ทำได้ตามระเบียบข้อไหน
□ เงื่อนไขคุณสมบัติลูกค้าเข้าเกณฑ์ไหม
□ ระยะเวลาสูงสุดที่ขยายได้เท่าไร
□ ผลต่อการจัดชั้นลูกหนี้เป็นอย่างไร
□ ต้องตั้งสำรองเพิ่มหรือไม่
□ อำนาจอนุมัติอยู่ระดับไหน
□ เอกสารที่ต้องมีครบ
□ มีเงื่อนไขติดตามหลังปรับที่ระเบียบกำหนดไหม
```

**AI ไม่รู้ข้อใดข้อหนึ่งในนี้** — ทุกข้อต้องเปิดระเบียบดูเอง

### ขั้นที่ 5 — ตรวจว่าตารางใหม่สอดคล้องกับฤดูกาล *(5 นาที)*

วางตารางชำระใหม่ทับกับกระแสเงินสดรายเดือนจาก statement

```
□ งวดชำระอยู่ในเดือนที่มีเงินเข้าไหม
□ เดือนที่ยอดคงเหลือต่ำสุด มีงวดชำระหรือเปล่า
□ ถ้าฤดูกาลเลื่อน 1 เดือน ยังชำระได้ไหม
```

**ในหลายกรณี การแก้แค่เรื่องจังหวะเวลาก็เพียงพอ โดยไม่ต้องขยายระยะเวลาเลย** ซึ่งเป็นทางเลือกที่ดีที่สุดสำหรับทั้งสองฝ่าย

### ขั้นที่ 6 — ตรวจ scenario ที่แย่กว่านี้ *(5 นาที)*

ถามว่า **"ถ้าหลังปรับแล้วรายได้ยังลดลงอีก 10% ลูกค้าจะชำระได้ไหม"**

ถ้าคำตอบคือไม่ได้ แปลว่าการปรับครั้งนี้ไม่มีพื้นที่รองรับเลย และมีโอกาสสูงที่จะต้องกลับมาปรับอีกครั้ง

**ควรออกแบบให้มีพื้นที่รองรับอย่างน้อย 10–15%**

**รวมเวลาตรวจ: 55 นาที**

## 7. เคสจริง 1 เคส

*(ตัวเลขทั้งหมดเป็นของสมมติ)*

### สถานการณ์

ลูกค้าปลูกพืชไร่และมีลานรับซื้อขนาดเล็ก ค้างชำระ 3 งวด ขอปรับโครงสร้างหนี้

```
เงินต้นคงเหลือ                    3,200,000
ดอกเบี้ยค้างจ่าย                     185,000
งวดปัจจุบัน                      65,000/เดือน (คงที่ทุกเดือน)
ระยะเวลาคงเหลือ                   58 งวด
สาเหตุที่ลูกค้าแจ้ง                 "ปีที่แล้วราคาตก ปีนี้จะดีขึ้น"

กระแสเงินสดจาก statement 12 เดือน:
  เดือน ม.ค.-เม.ย. (ฤดูขาย)   เฉลี่ยเหลือใช้ 145,000/เดือน
  เดือน พ.ค.-ส.ค. (นอกฤดู)    เฉลี่ยเหลือใช้ 12,000/เดือน
  เดือน ก.ย.-ธ.ค. (ลงทุน+รับซื้อ) เฉลี่ยเหลือใช้ 38,000/เดือน
  รวมทั้งปี                      780,000
```

### ก่อน — scenario ที่ AI เสนอ

> **ทางเลือกในการปรับโครงสร้างหนี้**
>
> | ทางเลือก | งวดใหม่ | ระยะเวลา | ดอกเบี้ยรวม |
> |---|---|---|---|
> | A. ขยายเป็น 84 งวด | 48,000 | 84 เดือน | +512,000 |
> | B. ขยายเป็น 96 งวด | 43,500 | 96 เดือน | +684,000 |
> | C. พักเงินต้น 12 เดือน แล้วผ่อน 72 งวด | 12 เดือนแรก 14,000 จากนั้น 52,000 | 84 เดือน | +598,000 |
>
> **ข้อเสนอแนะ:** เสนอทางเลือก A เนื่องจากลูกค้ามีกระแสเงินสดเฉลี่ยเดือนละ 65,000 บาท ซึ่งเพียงพอต่อการชำระงวดละ 48,000 บาท และเมื่อรายได้ฟื้นตัวตามที่คาดการณ์ในปีถัดไป ลูกค้าจะมีความสามารถในการชำระเพิ่มขึ้น

### จับผิดอย่างไร

**ขั้นตรวจที่ 3 (ดอกเบี้ยค้าง)**

ทั้งสามทางเลือกคำนวณจากเงินต้น 3,200,000 เท่านั้น **ไม่มีทางเลือกไหนพูดถึงดอกเบี้ยค้าง 185,000 เลย**

ดอกเบี้ยค้างนี้ต้องจัดการ — จะรวมเข้าเป็นเงินต้น หรือให้ลูกค้าชำระก่อน หรือทยอยชำระ ต้องระบุให้ชัด ซึ่งกระทบตัวเลขทุกทางเลือก

**ขั้นตรวจที่ 2 (กระแสเงินสดมาจากไหน)** — **จับได้จุดที่ผิดที่สุด**

AI เขียนว่า "ลูกค้ามีกระแสเงินสดเฉลี่ยเดือนละ 65,000 บาท"

ตรวจกลับ: 780,000 ÷ 12 = 65,000 **ถูกต้องทางคณิตศาสตร์**

**แต่ใช้ไม่ได้เลยในทางปฏิบัติ** เพราะกระแสเงินสดของลูกค้ารายนี้ไม่ได้กระจายเท่ากันทุกเดือน

```
ม.ค.-เม.ย.:  145,000/เดือน   → ชำระ 48,000 ได้สบาย
พ.ค.-ส.ค.:    12,000/เดือน   → ชำระ 48,000 ไม่ได้เลย ขาด 36,000
ก.ย.-ธ.ค.:    38,000/เดือน   → ชำระ 48,000 ไม่ได้ ขาด 10,000
```

**ทางเลือก A จะทำให้ลูกค้าผิดนัด 8 เดือนจาก 12 เดือน** — ซึ่งแย่กว่าสถานการณ์ปัจจุบันด้วยซ้ำ

**ความผิดพลาดนี้เกิดจากการใช้ค่าเฉลี่ย** ซึ่งเป็นความผิดพลาดเดียวกับที่พบในบทที่ 25 — และเป็นความผิดพลาดที่พบบ่อยที่สุดในงานเกษตร

**ขั้นตรวจที่ 2 ต่อ (สมมติฐานรายได้ฟื้น)**

ประโยค "เมื่อรายได้ฟื้นตัวตามที่คาดการณ์ในปีถัดไป" — **มาจากคำพูดของลูกค้าที่ว่า "ปีนี้จะดีขึ้น"** ไม่ได้มาจากข้อมูลใดๆ

นี่คือการใช้สมมติฐานว่าอนาคตจะดีขึ้นมาทำให้ตัวเลขผ่าน ซึ่งเป็นสิ่งที่ห้ามไว้ในกฎเหล็กของขั้นตรวจที่ 2

**ขั้นตรวจที่ 5 (ฤดูกาล)**

ทั้งสามทางเลือกเป็นงวดคงที่เท่ากันทุกเดือน — **ไม่มีทางเลือกไหนคำนึงถึงฤดูกาลเลย** ทั้งที่นี่คือสาเหตุหลักของปัญหา

เมื่อดูสาเหตุที่แท้จริง พบว่าปัญหาไม่ใช่ว่าลูกค้าจ่ายไม่ไหวทั้งปี (780,000 ต่อปี เทียบกับภาระเดิม 780,000 ต่อปี — พอดีกัน) **แต่เป็นเรื่องจังหวะเวลาล้วนๆ**

**ขั้นตรวจที่ 6 (scenario ที่แย่กว่า)**

ทางเลือก A ใช้กระแสเงินสดเกือบเต็ม (48,000 จาก 65,000 = 74%) ไม่มีพื้นที่รองรับ

### หลัง — ทางเลือกที่แก้แล้ว

> **ข้อมูลตั้งต้นที่ถูกต้อง**
>
> ```
> เงินต้นคงเหลือ              3,200,000
> ดอกเบี้ยค้างจ่าย               185,000
> รวมภาระที่ต้องปรับ           3,385,000
>
> กระแสเงินสดรายเดือน (จาก statement 12 เดือน — ไม่ใช้ค่าเฉลี่ย):
>   ม.ค.-เม.ย.   145,000/เดือน  = 580,000
>   พ.ค.-ส.ค.     12,000/เดือน  =  48,000
>   ก.ย.-ธ.ค.     38,000/เดือน  = 152,000
>   รวมทั้งปี                     780,000
> ```
>
> **ทางเลือกที่เสนอ**
>
> | | **A — ปรับตามฤดูกาล** ⭐ | **B — ขยายระยะเวลา** | **C — พักเงินต้น 12 เดือน** |
> |---|---|---|---|
> | **รูปแบบงวด** | ม.ค.–เม.ย. 110,000<br>พ.ค.–ส.ค. 8,000<br>ก.ย.–ธ.ค. 30,000 | คงที่ 48,000 ทุกเดือน | 12 เดือนแรก 14,000<br>จากนั้น 52,000 |
> | **ชำระต่อปี** | 592,000 | 576,000 | 168,000 / 624,000 |
> | **ระยะเวลา** | ~72 เดือน | 84 เดือน | 84 เดือน |
> | **ดอกเบี้ยรวมเพิ่ม** | +398,000 | +542,000 | +631,000 |
> | **เดือนที่ชำระไม่ได้** | **0 จาก 12** | **8 จาก 12** ❌ | 0 ใน 12 เดือนแรก<br>**8 จาก 12** หลังจากนั้น ❌ |
> | **พื้นที่รองรับ** | 24% | −** | −** |
> | **ลดเงินต้นเร็วแค่ไหน** | เร็วที่สุด | ปานกลาง | ช้าที่สุด |
>
> *(คำนวณจากยอดรวม 3,385,000 ที่รวมดอกเบี้ยค้างแล้ว)*
>
> **ทำไมเสนอทางเลือก A**
>
> 1. **สาเหตุของปัญหาคือจังหวะเวลา ไม่ใช่ความสามารถชำระ**
>    กระแสเงินสดรวมทั้งปี 780,000 เทียบกับภาระเดิม 780,000 — ลูกค้าจ่ายไหวในภาพรวม แต่ตารางชำระแบบงวดคงที่ไม่ตรงกับรอบรายได้
> 2. **ชำระได้ทุกเดือนจริง** โดยไม่ต้องสมมติว่ารายได้จะดีขึ้น
> 3. **ดอกเบี้ยรวมต่ำที่สุดในสามทางเลือก** (ประหยัดกว่าทางเลือก B ประมาณ 144,000 บาท)
> 4. **เหลือพื้นที่รองรับ 24%** ของกระแสเงินสด หากปีถัดไปแย่ลงอีก
>
> **ทดสอบ scenario ที่แย่กว่า (ขั้นตรวจที่ 6)**
>
> ```
> ถ้ากระแสเงินสดลดลงอีก 10% ทุกเดือน:
>   ม.ค.-เม.ย. 130,500 → ชำระ 110,000 ได้ ✓
>   พ.ค.-ส.ค.  10,800 → ชำระ 8,000 ได้ ✓
>   ก.ย.-ธ.ค.  34,200 → ชำระ 30,000 ได้ ✓
> ยังชำระได้ทุกเดือน
>
> ถ้าลดลง 20%:
>   ก.ย.-ธ.ค. 30,400 → ชำระ 30,000 ได้แบบเฉียดฉิว
> → พื้นที่รองรับประมาณ 20%
> ```
>
> **ทดสอบฤดูกาลเลื่อน**
> ```
> ถ้าฤดูขายเลื่อนไป 1 เดือน (ก.พ.-พ.ค. แทน ม.ค.-เม.ย.):
> → เดือน ม.ค. จะมีงวด 110,000 แต่เงินยังไม่เข้า
> → **แก้: กำหนดงวดหนักเป็น ก.พ.-พ.ค. แทน**
>    และให้เดือน ม.ค. เป็นงวดเบา (30,000)
> ```
>
> **เงื่อนไขที่เสนอพร้อมการปรับ**
> 1. รายได้จากการขายผลผลิตเข้าบัญชีที่ธนาคาร
> 2. รายงานปริมาณและราคาขายหลังสิ้นฤดู (พ.ค. ของทุกปี)
> 3. RM เข้าพบก่อนเริ่มฤดูขาย (ธ.ค.) เพื่อประเมินว่าปีนั้นจะเป็นอย่างไร
> 4. หากปีใดชำระงวดฤดูขายไม่ครบ ให้ทบทวนทันที ไม่รอให้ค้าง 3 งวด
>
> **ประเด็นที่ต้องตรวจสอบกับระเบียบก่อนเสนอ**
> ```
> □ การกำหนดงวดไม่เท่ากันตามฤดูกาล ทำได้ตามระเบียบข้อไหน
> □ การรวมดอกเบี้ยค้างเข้าเป็นเงินต้น ทำได้หรือไม่ เงื่อนไขอย่างไร
> □ ระยะเวลา 72 เดือน อยู่ในกรอบหรือไม่
> □ ผลต่อการจัดชั้นลูกหนี้หลังปรับ
> □ ต้องตั้งสำรองเพิ่มหรือไม่
> □ อำนาจอนุมัติระดับใด
> □ เงื่อนไขติดตามหลังปรับที่ระเบียบกำหนด
> ```
>
> **ข้อมูลที่ยังต้องยืนยันกับลูกค้า**
> - สาเหตุที่แท้จริงของปัญหา — ลูกค้าบอกว่า "ราคาตก" แต่ต้องตรวจว่าปริมาณลดด้วยหรือไม่
> - ปีนี้คาดว่าปริมาณและราคาจะเป็นอย่างไร *(ใช้เป็นข้อมูลประกอบ ไม่ใช่สมมติฐานในการคำนวณ)*
> - มีภาระหนี้ที่อื่นหรือไม่

### บทเรียนจากเคสนี้

**ทางเลือกที่ดีที่สุดในเคสนี้ไม่ได้ทำให้ลูกค้าจ่ายน้อยลง** — เขาจ่าย 592,000 ต่อปี มากกว่าทางเลือก B ที่จ่าย 576,000

**แต่มันทำให้เขาจ่ายได้จริงทุกเดือน และประหยัดดอกเบี้ยรวมได้ 144,000 บาท**

ซึ่งชี้ให้เห็นว่า **การปรับโครงสร้างหนี้ที่ดีไม่ใช่การลดภาระให้มากที่สุด แต่เป็นการจัดภาระให้ตรงกับความสามารถจริง**

และในงานเกษตร ความสามารถจริงไม่ได้กระจายเท่ากันทุกเดือน — การใช้ค่าเฉลี่ยจึงเป็นความผิดพลาดที่ทำให้การปรับโครงสร้างล้มเหลวบ่อยที่สุด
