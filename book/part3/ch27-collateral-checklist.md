# บทที่ 27 — Checklist ตรวจหลักประกัน

> **กลุ่มเสี่ยง:** ตรวจง่าย · **เสียหายมาก**
>
> *ตัวอย่างในบทนี้เป็นของสมมติ*

## 1. งานนี้คืออะไร ปกติทำอย่างไร ใช้เวลาเท่าไร

ต้องไปตรวจหลักประกันที่ลูกค้าเสนอ — ที่ดิน อาคาร โรงเรือน หรือสินค้าคงคลัง — เพื่อยืนยันว่ามีอยู่จริง สภาพเป็นอย่างไร และประเมินได้เท่าไร

**เวลาที่ใช้แบบเดิม:** เตรียม 20–30 นาที + ตรวจหน้างาน 1–3 ชั่วโมง

**เวลาที่ใช้เมื่อมี AI ช่วย:** ทำ checklist 10 นาที + **เทียบกับระเบียบประเมิน 30 นาที**

**ข้อสำคัญที่สุดของบทนี้:**

> ## **มูลค่าที่ AI ประเมิน ใช้เป็นตุ๊กตาเท่านั้น ห้ามใส่ในเอกสารเด็ดขาด**

AI ไม่รู้ราคาที่ดินในพื้นที่ ไม่รู้เกณฑ์การประเมินของ ธ.ก.ส. ไม่รู้ว่าผู้ประเมินจะให้เท่าไร และไม่เคยเห็นทรัพย์สินชิ้นนั้น

สิ่งที่มันช่วยได้คือ **ทำให้เราไม่ลืมตรวจอะไร** ซึ่งเป็นคุณค่าที่แท้จริงของบทนี้

## 2. AI ช่วยตรงไหนได้ ตรงไหนช่วยไม่ได้

| ช่วยได้ดี | ช่วยไม่ได้ / ห้ามใช้ |
|---|---|
| ทำ checklist ตามประเภททรัพย์ | ประเมินมูลค่า |
| ชี้จุดที่ต้องถ่ายรูป/วัด/นับ | รู้เกณฑ์ LTV ของ ธ.ก.ส. |
| เตือนเรื่องที่คนมักลืมตรวจ | รู้ราคาซื้อขายในพื้นที่ |
| เสนอวิธีนับ/ชั่ง/วัดสต็อก | รู้ว่าเอกสารสิทธิ์ประเภทนี้รับได้ไหม |
| ทำแบบฟอร์มบันทึกผลตรวจ | ตรวจสอบภาระผูกพันแทนเราได้ |

### ความต่างของหลักประกันแต่ละประเภท

**1. ที่ดิน**

| ต้องตรวจ | ทำไม |
|---|---|
| ประเภทเอกสารสิทธิ์ (โฉนด / น.ส.3ก / ส.ป.ก. / อื่นๆ) | **แต่ละประเภทรับเป็นหลักประกันได้ไม่เท่ากัน — ต้องดูระเบียบ** |
| เลขที่ / เลขระวาง / เนื้อที่ ตรงกับเอกสาร | ป้องกันการดูผิดแปลง |
| **ภาระผูกพันหลังโฉนด** | **จุดที่ลืมบ่อยที่สุดและเสียหายหนักที่สุด** |
| ทางเข้า-ออก | ที่ดินที่ไม่มีทางเข้าออกมูลค่าต่างกันมาก |
| สภาพการใช้ประโยชน์จริง | ตรงกับที่แจ้งไหม |
| ผู้ครอบครองจริง | มีคนอื่นอยู่หรือเช่าอยู่ไหม |
| การเวนคืน / ผังเมือง / เขตป่า | กระทบการใช้ประโยชน์และมูลค่า |

**2. อาคารและโรงเรือน**

| ต้องตรวจ | ทำไม |
|---|---|
| ใบอนุญาตก่อสร้าง / ใบรับรองการก่อสร้าง | ไม่มี = มีความเสี่ยงทางกฎหมาย |
| แบบแปลนตรงกับที่สร้างจริงไหม | สร้างเกินแบบเป็นปัญหา |
| สร้างบนที่ดินของใคร | ถ้าไม่ใช่ที่ดินเดียวกันกับที่จำนอง ซับซ้อนมาก |
| สภาพโครงสร้าง | อายุ ร้าว ทรุด ซ่อมบำรุง |
| ระบบไฟฟ้า/น้ำ/ระบายน้ำ | โดยเฉพาะโรงเรือนเกษตร |
| การใช้งานจริง | ใช้อยู่หรือทิ้งร้าง |
| ประกันภัย | มีไหม ครอบคลุมไหม ผู้รับประโยชน์เป็นใคร |

**3. สินค้าคงคลัง (stock สินค้าเกษตร)**

ประเภทนี้ยากที่สุดเพราะ **เปลี่ยนแปลงตลอดเวลา และเสื่อมสภาพได้**

| ต้องตรวจ | ทำไม |
|---|---|
| ปริมาณจริง (นับ/ชั่ง/วัด) | ต้องมีวิธีที่ทำได้จริงในเวลาที่มี |
| คุณภาพและอายุ | ข้าวเก่า 2 ปีกับข้าวใหม่ราคาต่างกันมาก |
| ความชื้น | กระทบทั้งน้ำหนักและราคา |
| สภาพที่เก็บ | ป้องกันฝน/แมลง/หนู ได้ไหม |
| **ของนี้เป็นของลูกค้าจริงไหม** | **อาจเป็นของฝากขายหรือของคนอื่น** |
| มีการจำนำ/ค้ำประกันซ้ำไหม | สินค้าชิ้นเดียวค้ำหลายที่ |
| การหมุนเวียน | ถ้าขายออกไป หลักประกันหายไปด้วย |

**สองข้อที่สำคัญที่สุดของสต็อกคือ "เป็นของลูกค้าจริงไหม" และ "ค้ำซ้ำหรือเปล่า"** ซึ่งดูจากกองสินค้าไม่ได้เลย ต้องตรวจจากเอกสาร

## 3. Input ที่ต้องเตรียมก่อนสั่งงาน

```
1. ประเภทหลักประกัน (เจาะจง)
2. ข้อมูลเบื้องต้นที่มี          เลขที่เอกสาร เนื้อที่ ที่ตั้ง
3. ประเภทธุรกิจของลูกค้า
4. เวลาที่มีในการตรวจ
5. เครื่องมือที่พกไปได้         ตลับเมตร กล้อง เครื่องวัดความชื้น
6. คนที่ไปด้วย
```

> ### ⚠️ ห้ามให้ AI ประเมินมูลค่า
> สั่งชัดเจนว่า **"ห้ามระบุราคา มูลค่า หรือช่วงราคาใดๆ"**
>
> ถ้ามันประเมินมาให้ ให้ลบทิ้ง — ไม่ใช่เก็บไว้เป็นข้อมูลอ้างอิง เพราะตัวเลขที่เห็นแล้วจะติดอยู่ในหัวและมีอิทธิพลต่อการตัดสินใจโดยไม่รู้ตัว

## 4. กลุ่มความเสี่ยง

**ตรวจง่าย** — checklist ทดสอบได้ด้วยการเอาไปใช้จริง

**เสียหายมาก** เพราะหลักประกันคือทางออกสุดท้ายเมื่อทุกอย่างผิดพลาด ถ้าหลักประกันมีปัญหา เราจะรู้ตอนที่แก้อะไรไม่ได้แล้ว

**ความเสียหายสามแบบ**
1. **หลักประกันไม่มีอยู่จริงหรือไม่ใช่ของลูกค้า** — พบตอนบังคับหลักประกัน
2. **มีภาระผูกพันอยู่ก่อน** — เราอยู่ลำดับหลัง ได้เงินไม่ครบ
3. **มูลค่าต่ำกว่าที่ประเมิน** — หลักประกันไม่คุ้มหนี้

**แบบที่ 2 คือแบบที่ป้องกันง่ายที่สุดแต่เกิดบ่อยที่สุด** เพราะเป็นการตรวจเอกสารที่ใช้เวลาไม่นาน แต่คนข้ามเพราะคิดว่าไม่น่ามี

## 5. วิธีตรวจ

### ขั้นที่ 1 — เทียบ checklist กับระเบียบประเมินจริง *(20–30 นาที)*

**ขั้นนี้ห้ามข้าม**

```
□ ประเภทเอกสารสิทธิ์นี้ รับเป็นหลักประกันได้ไหม ตามระเบียบข้อไหน
□ เกณฑ์การประเมินมูลค่าใช้วิธีไหน ตามระเบียบข้อไหน
□ สัดส่วนวงเงินต่อมูลค่าหลักประกันเท่าไร
□ ใครเป็นผู้มีอำนาจประเมิน
□ ต้องใช้ผู้ประเมินภายนอกในกรณีไหน
□ เอกสารที่ต้องมีครบก่อนเสนอ
□ ระยะเวลาที่ผลประเมินใช้ได้
□ กรณีสต็อก มีเงื่อนไขพิเศษอะไร
```

AI ไม่รู้ข้อใดข้อหนึ่งในนี้เลย — **ทุกข้อต้องเปิดระเบียบดูเอง**

### ขั้นที่ 2 — ตรวจภาระผูกพันบนเอกสารสิทธิ์ *(10 นาที)*

> **จุดที่ลืมบ่อยที่สุดและเสียหายหนักที่สุด**

```
□ ดูหลังโฉนดทุกหน้า ไม่ใช่แค่หน้าแรก
□ มีการจดทะเบียนจำนอง/ขายฝาก/ภาระจำยอมไหม
□ มีการอายัดไหม
□ มีข้อกำหนดห้ามโอนไหม (โดยเฉพาะที่ดินที่ได้จากการจัดสรรของรัฐ)
□ ตรวจกับสำนักงานที่ดินอีกครั้ง ไม่ใช่ดูจากสำเนาที่ลูกค้าให้มา
```

**ข้อสุดท้ายสำคัญมาก** — สำเนาที่ลูกค้าให้มาอาจเป็นสำเนาเก่าที่ยังไม่มีภาระผูกพันที่เพิ่งจดล่าสุด

### ขั้นที่ 3 — สต็อก: วิธีนับต้องทำได้จริงในเวลาที่มี *(5 นาที)*

ตรวจว่าวิธีที่ AI เสนอทำได้จริงหรือไม่

*ตัวอย่างวิธีที่เสนอมาแล้วทำไม่ได้:*
- "นับจำนวนกระสอบทั้งหมด" — กองสูง 4 เมตร นับไม่ได้
- "ชั่งน้ำหนักตัวอย่างสุ่ม 50 จุด" — ไม่มีเครื่องชั่งและไม่มีเวลา
- "ตรวจสอบเอกสารการซื้อทุกรายการ" — มีเป็นร้อยรายการ

*วิธีที่ทำได้จริง*
- วัดขนาดกอง (กว้าง × ยาว × สูง) แล้วคูณด้วยน้ำหนักต่อลูกบาศก์เมตรโดยประมาณ
- นับจำนวนกระสอบในแถวหน้าและจำนวนแถว แล้วประมาณ
- ถ่ายรูปพร้อมของอ้างอิงขนาด (คน/ไม้เมตร) ไว้เทียบ
- ขอดูสมุดบันทึกการรับ-จ่ายสินค้า เทียบกับที่เห็น

**ระบุในเอกสารเสมอว่าใช้วิธีประมาณการแบบไหน** ไม่ใช่เขียนตัวเลขลอยๆ เหมือนนับมาจริง

### ขั้นที่ 4 — ทดสอบ checklist กับหน้างานจริง 1 ครั้ง *(1 รอบ)*

เหมือนบทที่ 16 — checklist ที่ยังไม่เคยใช้จริงคือร่าง

ใช้แล้วจดว่าข้อไหนทำไม่ได้ ข้อไหนขาด

### ขั้นที่ 5 — ลบทุกตัวเลขมูลค่าที่ AI ให้มา *(1 นาที)*

ไล่อ่านแล้วลบทุกจุดที่มีราคา มูลค่า หรือช่วงราคา

**แม้จะเขียนกำกับว่า "ประมาณการ" ก็ต้องลบ** เพราะเมื่ออยู่ในเอกสารแล้ว คนอ่านจะให้น้ำหนักกับมัน

**รวมเวลาตรวจ: 36–46 นาที + 1 รอบทดสอบหน้างาน**

| จุดพลาด | ผลที่ตามมา | วิธีกัน |

| **สต็อก: ไม่ตรวจว่าเป็นของลูกค้าจริง** | ยึดของคนอื่น | ตรวจเอกสารซื้อ/ใบรับฝาก |
| **สต็อก: ไม่ตรวจการค้ำซ้ำ** | ของชิ้นเดียวค้ำหลายที่ | ตรวจทะเบียนและสอบถาม |

| **อาคาร: ไม่ตรวจใบอนุญาตก่อสร้าง** | ความเสี่ยงทางกฎหมาย | ใส่ใน checklist |
| **ไม่ถ่ายรูป** | ไม่มีหลักฐานว่าตรวจแล้วเห็นอะไร | ระบุรายการรูปที่ต้องถ่าย |

## 7. เคสจริง 1 เคส

*(ตัวอย่างสมมติ)*

### สถานการณ์

ลูกค้าเสนอสต็อกข้าวเปลือกในโกดังเป็นหลักประกันเพิ่มเติม ต้องไปตรวจ

### ก่อน — checklist ที่ AI ให้มา

> **Checklist การตรวจสอบสินค้าคงคลัง (ข้าวเปลือก)**
>
> 1. ตรวจสอบปริมาณข้าวเปลือกโดยการชั่งน้ำหนักทั้งหมด
> 2. ตรวจสอบคุณภาพข้าวเปลือก ได้แก่ ความชื้น สิ่งเจือปน และเปอร์เซ็นต์ต้นข้าว
> 3. ตรวจสอบสภาพสถานที่จัดเก็บ
> 4. ประเมินมูลค่าโดยใช้ราคาตลาดปัจจุบัน ซึ่งข้าวเปลือกเจ้าความชื้น 15% ปัจจุบันมีราคาประมาณ 9,000–9,500 บาทต่อตัน
> 5. คำนวณมูลค่าหลักประกัน = ปริมาณ × ราคาตลาด × อัตราส่วนที่ธนาคารกำหนด (โดยทั่วไป 60–70% สำหรับสินค้าคงคลัง)
> 6. จัดทำรายงานผลการตรวจสอบ

### จับผิดอย่างไร

**ขั้นตรวจที่ 5 (ลบตัวเลขมูลค่า)** — ข้อ 4 และ 5 มีตัวเลขที่ต้องลบทั้งหมด

- **"ราคาประมาณ 9,000–9,500 บาทต่อตัน"** — AI ไม่รู้ราคาปัจจุบันและไม่รู้ราคาในพื้นที่นี้ ตัวเลขนี้อาจผิดไปหลายพันบาทต่อตัน
- **"อัตราส่วนโดยทั่วไป 60–70%"** — AI ไม่รู้เกณฑ์ของ ธ.ก.ส. **นี่คือตัวเลขที่อันตรายที่สุด** เพราะถ้าเชื่อแล้วคำนวณวงเงินไว้ล่วงหน้า แล้วเกณฑ์จริงต่างจากนี้ จะต้องกลับไปคุยกับลูกค้าใหม่ทั้งหมด

**ขั้นตรวจที่ 3 (วิธีนับทำได้จริงไหม)**

**ข้อ 1 "ชั่งน้ำหนักทั้งหมด"** — ทำไม่ได้ ข้าวเปลือกในโกดังหลายร้อยตัน ถ้าจะชั่งต้องขนออกมาทั้งหมดแล้วขนกลับ ใช้เวลาหลายวัน

**ข้อ 2 "ตรวจเปอร์เซ็นต์ต้นข้าว"** — ต้องใช้เครื่องมือเฉพาะและความชำนาญที่ RM ทั่วไปไม่มี

**ขั้นตรวจที่ 1 (เทียบกับระเบียบ)** — checklist นี้ไม่ได้ระบุเลยว่า

- ธ.ก.ส. รับสต็อกสินค้าเกษตรเป็นหลักประกันได้ในกรณีใดบ้าง
- ต้องมีเอกสารอะไรประกอบ
- ใครเป็นผู้ประเมิน
- ต้องมีการควบคุมสต็อกอย่างไร (ผู้เก็บรักษา / การตรวจสอบเป็นระยะ)

**ขั้นตรวจที่ 2 และประเด็นที่หายไปทั้งหมด** — **checklist นี้ไม่มีข้อที่ตรวจว่าข้าวเป็นของลูกค้าจริงหรือไม่ และไม่มีข้อที่ตรวจการค้ำซ้ำเลย**

ซึ่งเป็นสองประเด็นที่สำคัญที่สุดของหลักประกันประเภทสต็อก

### หลัง — checklist ที่ใช้ได้จริง

> # ตรวจหลักประกัน: สต็อกข้าวเปลือก
> **วันที่ตรวจ:** ______ **ผู้ตรวจ:** ______ **สถานที่:** ______
>
> ---
> ### 🔴 ส่วนที่ 1 — ตรวจเอกสารก่อนออกจากสำนักงาน
> *(ถ้าส่วนนี้ไม่ผ่าน ไม่ต้องไปตรวจหน้างาน)*
>
> ```
> □ 1.1 สต็อกสินค้าเกษตรรับเป็นหลักประกันได้ตามระเบียบ [เลขที่] ข้อ [___]
>       เงื่อนไขที่ระบุ: ______________________
> □ 1.2 เอกสารแสดงกรรมสิทธิ์ในสินค้า
>       □ ใบเสร็จ/ใบกำกับภาษีการซื้อ
>       □ ใบรับซื้อจากเกษตรกร
>       □ สมุดบันทึกการรับซื้อ
> □ 1.3 ตรวจว่ามีการจำนำ/ค้ำประกันกับสถาบันอื่นหรือไม่
>       □ สอบถามลูกค้าโดยตรง
>       □ ตรวจจากข้อมูลเครดิต
>       □ ตรวจสัญญาที่มีอยู่
> □ 1.4 สินค้านี้เป็นของฝากขายหรือของผู้อื่นหรือไม่
>       □ ขอดูสัญญารับฝาก (ถ้ามี)
> □ 1.5 กรมธรรม์ประกันภัยสินค้า — มี/ไม่มี
>       ถ้ามี: ผู้รับประโยชน์คือ ______ วงเงิน ______
> ```
>
> ### 🟡 ส่วนที่ 2 — ตรวจปริมาณหน้างาน
>
> **วิธีประมาณการ (เลือกวิธีที่ทำได้ แล้วระบุในรายงาน)**
> ```
> □ วิธี A — กองเปิด: วัดขนาดกอง
>          กว้าง ____ ม. × ยาว ____ ม. × สูงเฉลี่ย ____ ม.
>          = ____ ลบ.ม. × น้ำหนักต่อ ลบ.ม. โดยประมาณ ____ = ____ ตัน
> □ วิธี B — บรรจุกระสอบ: นับแถวหน้า ____ กระสอบ
>          × จำนวนแถว ____ × จำนวนชั้น ____
>          = ____ กระสอบ × น้ำหนักต่อกระสอบ ____ กก. = ____ ตัน
> □ วิธี C — เทียบกับสมุดบันทึก
>          ยอดรับเข้าสะสม ____ − ยอดจ่ายออกสะสม ____ = ____ ตัน
>
> □ เทียบผลจาก 2 วิธีขึ้นไป ต่างกันเกิน 15% หรือไม่
>   ถ้าต่างมาก → บันทึกไว้และหาสาเหตุ
> □ ระบุในรายงานว่าใช้วิธีประมาณการแบบใด
>   **ห้ามเขียนตัวเลขโดยไม่ระบุวิธี**
> ```
>
> ### 🟡 ส่วนที่ 3 — ตรวจคุณภาพ
> ```
> □ 3.1 ความชื้น — วัดได้ ____ % (ถ้ามีเครื่องวัด)
>       ถ้าไม่มีเครื่อง: บันทึกว่า "ไม่ได้วัด" ห้ามประมาณ
> □ 3.2 อายุข้าว — ข้าวปีไหน ____ (ถามลูกค้า + ดูสมุดบันทึก)
> □ 3.3 สภาพภายนอก
>       □ สี (ปกติ / คล้ำ / มีเชื้อรา)
>       □ กลิ่น (ปกติ / อับ / เหม็น)
>       □ สิ่งเจือปนที่มองเห็น
>       □ ร่องรอยแมลง/หนู
> □ 3.4 แยกกองตามเกรด/ปีหรือไม่ หรือกองรวมกัน
> ```
>
> ### 🟡 ส่วนที่ 4 — ตรวจสถานที่เก็บ
> ```
> □ หลังคารั่วหรือไม่ (ดูร่องรอยน้ำบนพื้นและผนัง)
> □ พื้นยกสูงจากดินหรือไม่ / มีแผ่นรองหรือไม่
> □ การระบายอากาศ
> □ การป้องกันสัตว์รบกวน
> □ ความปลอดภัย (ประตู กุญแจ กล้อง ยาม)
> □ ใครถือกุญแจ — ลูกค้าคนเดียวหรือมีคนอื่น
> □ สถานที่นี้เป็นของลูกค้าหรือเช่า
>   ถ้าเช่า: สัญญาเช่าเหลืออายุ ____ เดือน
> ```
>
> ### 📷 ส่วนที่ 5 — รูปที่ต้องถ่าย
> ```
> □ ภาพรวมกองสินค้า พร้อมของอ้างอิงขนาด (คน/ไม้เมตร)
> □ ระยะใกล้ให้เห็นสภาพเมล็ด
> □ สภาพหลังคาและพื้น
> □ ป้ายชื่อโกดัง/ที่ตั้ง (ยืนยันสถานที่)
> □ เครื่องวัดความชื้นขณะวัด (ถ้ามี)
> □ สมุดบันทึกการรับ-จ่ายหน้าล่าสุด
> ```
>
> ### ⚫ ส่วนที่ 6 — ข้อควรระวังของหลักประกันประเภทนี้
> ```
> □ สต็อกหมุนเวียนได้ — ถ้าลูกค้าขายออกไป หลักประกันหายไปด้วย
>   → ต้องมีเงื่อนไขควบคุม: ระบุในข้อเสนอว่าจะควบคุมอย่างไร
>   □ ตรวจสต็อกทุก ____ เดือน
>   □ รายงานปริมาณคงเหลือทุก ____
>   □ กำหนดปริมาณขั้นต่ำที่ต้องคงไว้
> □ ข้าวเสื่อมสภาพตามเวลา — มูลค่าลดลงทุกเดือน
> □ ราคาผันผวนตามฤดูกาล
> ```
>
> ---
> ### ❌ สิ่งที่ห้ามทำ
> ```
> ✗ ห้ามระบุมูลค่าหรือราคาประเมินในรายงานนี้
>   → ส่งข้อมูลปริมาณและคุณภาพให้ผู้มีอำนาจประเมินตามระเบียบ
> ✗ ห้ามเขียนปริมาณโดยไม่ระบุวิธีประมาณการ
> ✗ ห้ามเขียนค่าความชื้นถ้าไม่ได้วัดด้วยเครื่อง
> ```
>
> ### 📋 สรุปผลการตรวจ
> ```
> ปริมาณโดยประมาณ ____ ตัน (วิธี: ____)
> ประเด็นที่พบ: ______________________
> ประเด็นที่ยังไม่ได้ข้อมูล: ______________________
> ส่งข้อมูลให้ผู้ประเมินเมื่อ ______
> ```

### สิ่งที่เปลี่ยนไป

| | ฉบับแรก | ฉบับแก้ |
|---|---|---|
| จำนวนข้อ | 6 | 40+ |
| ตัวเลขมูลค่า/ราคา | มี 2 จุด | 0 |
| ตรวจกรรมสิทธิ์ | ไม่มี | 3 ข้อ |
| **ตรวจการค้ำซ้ำ** | **ไม่มี** | **3 ข้อ** |
| วิธีนับที่ทำได้จริง | ไม่มี (ชั่งทั้งหมด) | 3 วิธี + การเทียบ |
| อ้างอิงระเบียบ | ไม่มี | มีช่องให้กรอกข้อ |
| รายการรูปที่ต้องถ่าย | ไม่มี | 6 รายการ |
| เงื่อนไขควบคุมสต็อก | ไม่มี | 3 ข้อ |
| ทำได้จริงในเวลาที่มี | ไม่ | ใช่ |

**ข้อสังเกตสำคัญ:** checklist ฉบับแรกมี 6 ข้อและดูกระชับ แต่ **ข้อที่สำคัญที่สุดสองข้อ (ของใครและค้ำซ้ำไหม) ไม่มีอยู่เลย** ขณะที่ข้อที่มีอยู่กลับทำไม่ได้จริง

นี่คือลักษณะทั่วไปของ checklist ที่ AI สร้างจากความรู้ทั่วไป — มันครอบคลุมสิ่งที่ "ควรตรวจตามตำรา" แต่ไม่ครอบคลุมสิ่งที่ "ทำให้เสียหายจริง"

**เวลาที่ใช้ทำและตรวจ: 45 นาที** (ครั้งเดียว ใช้ได้ตลอด)

## 8. Prompt ตั้งต้น

```
บทบาท: ผู้ช่วยจัดทำ checklist ตรวจหลักประกัน

ประเภทหลักประกัน: [ที่ดิน / อาคาร-โรงเรือน / สต็อกสินค้าเกษตร — ระบุเจาะจง]
ข้อมูลเบื้องต้นที่มี: [...]
ประเภทธุรกิจของลูกค้า: [...]
เวลาที่มีในการตรวจ: [X] ชั่วโมง
เครื่องมือที่พกไปได้: [ตลับเมตร / กล้อง / เครื่องวัดความชื้น / ไม่มี]
ไปคนเดียวหรือมีคนช่วย: [...]

**ข้อห้ามที่สำคัญที่สุด:**
- **ห้ามระบุราคา มูลค่า ช่วงราคา หรืออัตราส่วนวงเงินต่อหลักประกันใดๆ**
  คุณไม่รู้ราคาในพื้นที่และไม่รู้เกณฑ์ของธนาคารที่ฉันทำงานอยู่
- ห้ามระบุเกณฑ์ LTV หรือ "โดยทั่วไปธนาคารให้ X%"
- ห้ามอ้างระเบียบหรือเกณฑ์ใดๆ ให้เว้นเป็น [ระบุข้อจากระเบียบ ___]

สิ่งที่ต้องการ — แยกเป็นส่วน:

**ส่วน 1 — ตรวจเอกสารก่อนออกจากสำนักงาน**
รวมถึง:
- การตรวจว่าทรัพย์นี้เป็นของลูกค้าจริงหรือไม่
- **การตรวจภาระผูกพัน/การค้ำประกันซ้ำ** (ข้อนี้ต้องมี)
- เอกสารที่ต้องมีครบ

**ส่วน 2 — ตรวจหน้างาน**
- แต่ละข้อต้องทำได้จริงในเวลาและด้วยเครื่องมือที่ระบุข้างบน
- **ถ้าวิธีใดทำไม่ได้ในเวลาที่มี ห้ามเสนอ**
- สำหรับการวัดปริมาณ ให้เสนอ 2-3 วิธีประมาณการที่ทำได้จริง
  พร้อมสูตรคำนวณ และวิธีเทียบผลระหว่างวิธี

**ส่วน 3 — รายการรูปที่ต้องถ่าย**
พร้อมบอกว่าแต่ละรูปใช้เป็นหลักฐานเรื่องอะไร

**ส่วน 4 — ข้อควรระวังเฉพาะของหลักประกันประเภทนี้**
โดยเฉพาะ: อะไรที่ทำให้หลักประกันนี้หายไปหรือเสื่อมค่าได้
และควรมีเงื่อนไขควบคุมอะไร

**ส่วน 5 — รายการที่ฉันต้องไปเปิดระเบียบตรวจเอง**
ทำเป็น checklist ว่ามีเรื่องอะไรบ้างที่ต้องตรวจกับระเบียบ
ก่อนจะใช้ checklist นี้ได้จริง

รูปแบบ: ทำเป็นช่องติ๊ก □ พร้อมช่องว่างให้กรอกค่าที่วัดได้
ให้พิมพ์ออกมาพกไปหน้างานได้

ข้อกำหนดเพิ่ม:
- ทุกข้อต้องเป็นสิ่งที่ "ทำแล้วรู้ผลทันที" ไม่ใช่ "ตรวจสอบความเหมาะสม"
- ข้อไหนที่ต้องใช้ความชำนาญเฉพาะทาง ให้ระบุว่าต้องใช้ผู้เชี่ยวชาญ
  ไม่ใช่ให้ RM ทำเอง
```
