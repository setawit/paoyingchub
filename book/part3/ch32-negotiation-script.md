# บทที่ 32 — เตรียมบทเจรจากับลูกค้าที่จ่ายช้า

> **กลุ่มเสี่ยง:** ตรวจง่าย · เสียหายปานกลาง
>
> *ตัวอย่างในบทนี้เป็นของสมมติ*

---

## 1. งานนี้คืออะไร ปกติทำอย่างไร ใช้เวลาเท่าไร

ต้องคุยกับลูกค้าที่ค้างชำระหรือเริ่มมีปัญหา เพื่อหาทางออกที่ทั้งสองฝ่ายรับได้ โดยไม่ทำลายความสัมพันธ์จนคุยกันไม่ได้อีก

**เวลาที่ใช้แบบเดิม:** มักไม่ได้เตรียม เข้าไปคุยแล้วว่ากันตามสถานการณ์

**เวลาที่ใช้เมื่อมี AI ช่วย:** เตรียม 20 นาที + ซ้อม 15 นาที

**ทำไมต้องเตรียม:** การเจรจาเรื่องหนี้ต่างจากการคุยทั่วไป เพราะ

- อีกฝ่ายอยู่ในภาวะกดดันและอาจตั้งรับ
- สิ่งที่เราพูดในวันนั้นอาจถูกอ้างในภายหลัง
- **เรามีอำนาจจำกัด และการเผลอเสนอเกินอำนาจสร้างปัญหาที่แก้ยาก**
- ถ้าคุยพัง ครั้งต่อไปยากกว่าเดิมมาก

## 2. AI ช่วยตรงไหนได้ ตรงไหนช่วยไม่ได้

| ช่วยได้ดี | ช่วยไม่ได้ |
|---|---|
| เสนอแนวทางเจรจาหลายแบบ | รู้ว่าลูกค้าคนนี้เป็นอย่างไร |
| เล่นบทลูกค้าให้เราซ้อม | รู้ว่าอะไรเป็นเรื่องอ่อนไหวสำหรับเขา |
| หาคำพูดที่ตรงแต่ไม่แรง | อ่านสถานการณ์หน้างาน |
| เตือนสิ่งที่ไม่ควรพูด | รู้ว่าเราเสนออะไรได้จริง |
| ช่วยคิดคำตอบสำหรับข้อโต้แย้ง | ตัดสินใจแทนเราในห้อง |

### หลักที่ 1 — ขีดเส้นอำนาจให้ชัดก่อนเสมอ

**นี่คือข้อที่สำคัญที่สุดของบทนี้**

ก่อนสั่งงาน ต้องเขียนสามอย่างให้ชัด

```
1. สิ่งที่เราเสนอได้เอง         ในอำนาจของเรา
2. สิ่งที่เสนอได้ถ้าขออนุมัติ     ต้องบอกลูกค้าว่าต้องขออนุมัติ
3. สิ่งที่เสนอไม่ได้เด็ดขาด
```

**ถ้าไม่บอก AI จะเสนอสิ่งที่ฟังดูสมเหตุสมผลแต่เราให้ไม่ได้** และเมื่อเราเผลอพูดออกไปในห้อง ลูกค้าจะยึดถือว่าเราสัญญาแล้ว

> **คำพูดที่หลุดออกไปในการเจรจาเรื่องหนี้ ถอนคืนยากมาก**

### หลักที่ 2 — เป้าหมายจริงมักไม่ใช่ "ให้เขาจ่าย"

เป้าหมายที่แท้จริงของการเจรจาครั้งแรกมักเป็น

```
1. เข้าใจว่าเกิดอะไรขึ้นจริง       ← สำคัญที่สุด
2. ประเมินว่าลูกค้ายังอยากแก้ปัญหาไหม
3. ได้ข้อตกลงที่เป็นรูปธรรม แม้จะเล็ก
4. รักษาช่องทางการติดต่อไว้
```

**ข้อ 1 สำคัญที่สุด** เพราะถ้าเรายังไม่รู้สาเหตุจริง ข้อเสนอใดๆ ก็เป็นการเดา

และ **ลูกค้าที่รู้สึกว่าเราเข้ามาเพื่อฟังก่อน มักเล่าความจริงมากกว่าลูกค้าที่รู้สึกว่าเราเข้ามาทวง**

### หลักที่ 3 — ขอ 2–3 แนวทางที่ต่างกันที่ผลลัพธ์

| แนวทาง | ท่าที | เหมาะเมื่อ |
|---|---|---|
| **เข้าใจก่อน** | ฟังสถานการณ์ ยังไม่เสนออะไร | ยังไม่รู้สาเหตุ / ครั้งแรกที่คุย |
| **ร่วมแก้ปัญหา** | เสนอทางเลือกที่มี ให้เขาเลือก | รู้สาเหตุแล้ว ลูกค้ายังมีศักยภาพ |
| **ชัดเจนเรื่องผลที่ตามมา** | บอกตรงๆ ว่าถ้าไม่มีอะไรเปลี่ยน จะเกิดอะไร | เคยคุยมาแล้วหลายครั้ง ไม่มีความคืบหน้า |

**อย่าข้ามไปแนวทางที่สามเร็วเกินไป** — แต่ก็อย่าค้างอยู่ที่แนวทางแรกนานเกินไปจนไม่มีอะไรเกิดขึ้น

## 3. Input ที่ต้องเตรียมก่อนสั่งงาน

```
1. สถานะหนี้                  ค้างกี่งวด เท่าไร มาแล้วกี่เดือน
2. ประวัติการติดต่อ             คุยมากี่ครั้ง ผลเป็นอย่างไร
3. สิ่งที่ลูกค้าเคยรับปาก         และทำได้หรือไม่
4. ท่าทีของลูกค้า              ให้ความร่วมมือ / เลี่ยง / โกรธ
5. สิ่งที่เราเสนอได้เอง
6. สิ่งที่ต้องขออนุมัติ
7. สิ่งที่เสนอไม่ได้เด็ดขาด
8. เป้าหมายของการคุยครั้งนี้
```

**ปิดชื่อและปัดตัวเลขถ้าใช้เครื่องมือนอกระบบ** — บทเจรจาทำงานกับโครงของสถานการณ์ ไม่ต้องรู้ชื่อลูกค้า

## 4. กลุ่มความเสี่ยง

**ตรวจง่าย** — อ่านบทแล้วรู้ว่าใช้ได้หรือไม่ได้

**เสียหายปานกลาง แต่มีสองจุดที่ขยับเป็นเสียหายมาก**

1. **เสนอเงื่อนไขที่นอกอำนาจ** — สร้างความคาดหวังที่เราทำไม่ได้ และทำให้การเจรจาครั้งต่อไปเริ่มจากจุดที่แย่กว่าเดิม
2. **พูดสิ่งที่อาจมีผลทางกฎหมาย** — คำพูดที่อาจตีความว่าเป็นการผ่อนผันหรือให้คำมั่น

**ข้อควรระวัง:** อย่าใช้บทที่เตรียมมาเป็นสคริปต์ที่ต้องพูดตาม ให้ใช้เป็นแนวทางและจุดที่ต้องไม่พลาด — การพูดตามบทจะฟังออกทันทีและทำลายบรรยากาศ

## 5. วิธีตรวจ

### ขั้นที่ 1 — ตรวจว่าทุกข้อเสนออยู่ในอำนาจจริง *(5 นาที)*

ไล่ทุกประโยคที่เป็นข้อเสนอ แล้วจัดเป็นสามกลุ่ม

```
✓ เสนอได้เอง           → พูดได้เลย
△ ต้องขออนุมัติ         → ต้องพูดว่า "ผมจะขออนุมัติให้"
                          ไม่ใช่ "ได้ครับ"
✗ นอกอำนาจ            → ตัดออก
```

**ความแตกต่างระหว่าง "ได้ครับ" กับ "ผมจะขออนุมัติให้" คือความแตกต่างที่สำคัญที่สุดในบทนี้**

### ขั้นที่ 2 — ตรวจว่าเป็นภาษาที่เราพูดกับลูกค้ารายนี้จริง *(5 นาที)*

อ่านออกเสียง ถ้าฟังเหมือนอ่านจากกระดาษ ต้องเขียนใหม่

**AI มักเขียนบทเจรจาที่เป็นทางการเกินไป** ซึ่งในบริบทการทวงหนี้จะทำให้ลูกค้ารู้สึกว่าเรื่องนี้เข้าสู่กระบวนการทางการแล้ว และจะตั้งรับทันที

| AI มักเขียน | ควรพูด |
|---|---|
| "ทางธนาคารขอเรียนแจ้งว่าท่านมีภาระหนี้ค้างชำระ" | "พี่ครับ งวดสองสามเดือนที่ผ่านมายังไม่ได้เข้ามา ผมเลยมาดูว่าเกิดอะไรขึ้น" |
| "ท่านมีความประสงค์จะดำเนินการอย่างไร" | "พี่คิดว่าจะเอายังไงดีครับ" |
| "หากไม่ดำเนินการภายในกำหนด ธนาคารจำเป็นต้อง..." | "ถ้าปล่อยไว้แบบนี้ต่อไป มันจะเข้าขั้นตอนที่ผมช่วยอะไรไม่ได้แล้วนะครับ" |

### ขั้นที่ 3 — ซ้อมกับ AI ที่เล่นบทลูกค้าแบบยากที่สุด *(10 นาที)*

**นี่คือส่วนที่มีค่าที่สุดของบทนี้**

สั่งให้ AI เล่นบทลูกค้าที่

- ตั้งรับ ไม่ยอมรับว่ามีปัญหา
- โยนความผิดให้คนอื่นหรือให้ธนาคาร
- ขอสิ่งที่เราให้ไม่ได้
- เงียบ ไม่ตอบ
- โกรธ

แล้วเราซ้อมตอบ

**ดูสามอย่าง**
```
□ เราเผลอสัญญาอะไรที่ทำไม่ได้ไหม
□ เราเสียการควบคุมบทสนทนาตรงไหน
□ มีคำถามไหนที่เราตอบไม่ได้
```

### ขั้นที่ 4 — เตรียมคำตอบสำหรับข้อโต้แย้งที่พบบ่อย *(5 นาที)*

| ลูกค้าพูด | เตรียมตอบว่า |
|---|---|
| "เดี๋ยวเดือนหน้าจ่ายแน่" | "เดือนหน้าเงินจะมาจากไหนครับ" *(ขอความเฉพาะเจาะจง)* |
| "ธนาคารอื่นเขาไม่เข้มงวดแบบนี้" | ไม่เถียง กลับไปที่เรื่องของเรา |
| "ก็เพราะธนาคารให้วงเงินน้อยไง" | รับฟัง แล้วถามว่าตอนนี้จะแก้อย่างไร |
| "ผมไม่มีจริงๆ" | "แล้วตอนนี้พอจ่ายได้เดือนละเท่าไรครับ" *(หาตัวเลขที่เป็นไปได้)* |
| "ขอพักไปก่อน 6 เดือน" | "ผมรับเรื่องไว้ได้ แต่ต้องดูตามเกณฑ์ก่อน ยังบอกไม่ได้ว่าได้หรือไม่ได้" |

**หลักในการตอบ: อย่าเถียง อย่าสัญญา ถามหาความเฉพาะเจาะจง**

### ขั้นที่ 5 — กำหนดสิ่งที่ต้องได้กลับมาจากการคุย *(3 นาที)*

ก่อนเข้าไป ต้องรู้ว่าอย่างน้อยที่สุดต้องได้อะไร

```
□ รู้สาเหตุที่แท้จริง
□ ได้ตัวเลขที่ลูกค้าจ่ายได้จริง (ไม่ใช่ตัวเลขที่เขาอยากให้เราพอใจ)
□ ได้วันที่ที่เฉพาะเจาะจง ไม่ใช่ "เร็วๆ นี้"
□ ได้ข้อตกลงเล็กๆ ที่วัดได้ แม้จะไม่ใช่การชำระเต็มจำนวน
□ นัดครั้งถัดไปไว้แล้ว
```

**ข้อตกลงเล็กที่ทำได้จริง มีค่ากว่าคำสัญญาใหญ่ที่ทำไม่ได้** เพราะมันสร้างหลักฐานว่าลูกค้ายังให้ความร่วมมือ

**รวมเวลาเตรียมและตรวจ: 28 นาที**

## 6. จุดพลาดที่พบบ่อย

| จุดพลาด | ผลที่ตามมา | วิธีกัน |
|---|---|---|
| **เสนอเงื่อนไขที่นอกอำนาจ RM** | ความคาดหวังที่ทำไม่ได้ | ขั้นตรวจที่ 1 + ระบุขอบอำนาจใน input |
| **บทสุภาพเกินจนไม่มีน้ำหนัก** | ลูกค้าไม่รู้สึกว่าเรื่องนี้จริงจัง | ขั้นตรวจที่ 2 |
| **ภาษาทางการเกินไป** | ลูกค้าตั้งรับทันที | ขั้นตรวจที่ 2 |
| **พูดว่า "ได้" ทั้งที่ต้องขออนุมัติ** | ถ้าไม่อนุมัติ เสียความเชื่อถือ | แยก "ได้" กับ "จะขออนุมัติให้" |
| **มุ่งแต่จะให้จ่าย ไม่ได้ฟังสาเหตุ** | ไม่รู้ปัญหาจริง แก้ผิดจุด | ตั้งเป้าหมายให้ถูก (หลักที่ 2) |
| **รับตัวเลขที่ลูกค้าบอกลอยๆ** | "เดือนหน้าจ่ายแน่" ที่ไม่มีที่มา | ขั้นตรวจที่ 4 — ถามว่าเงินจะมาจากไหน |
| **ไม่นัดครั้งถัดไป** | เรื่องค้าง ไม่มีกำหนด | ขั้นตรวจที่ 5 |
| **ใช้บทเป็นสคริปต์** | ฟังออกว่าอ่านมา | ใช้เป็นแนวทาง ไม่ใช่บทพูด |

## 7. เคสจริง 1 เคส

*(ตัวอย่างสมมติ)*

### สถานการณ์

ลูกค้าค้างชำระ 2 งวด เคยโทรไปแล้ว 2 ครั้ง ครั้งแรกบอกว่า "เดี๋ยวจัดการ" ครั้งที่สองไม่รับสาย ตอนนี้จะไปพบที่กิจการ

**ขอบอำนาจ**
```
เสนอได้เอง:    รับเรื่อง ผ่อนผันการเรียกเก็บ 1 งวดเพื่อรอเอกสาร
ต้องขออนุมัติ:  การปรับโครงสร้างหนี้ทุกรูปแบบ
เสนอไม่ได้:    ลดดอกเบี้ย ยกดอกเบี้ยค้าง พักชำระเกิน 1 งวด
```

### ก่อน — บทที่ AI ให้มา

> **บทสนทนาสำหรับการเจรจาหนี้**
>
> **เปิดการสนทนา:**
> "สวัสดีครับคุณ... ผมมาจากธนาคาร วันนี้มาเพื่อหารือเกี่ยวกับภาระหนี้ที่ค้างชำระ ซึ่งขณะนี้มีจำนวน 2 งวด คิดเป็นเงินต้นและดอกเบี้ยรวม... บาท"
>
> **นำเสนอทางออก:**
> "ทางธนาคารเข้าใจถึงสถานการณ์ที่ท่านกำลังเผชิญ และมีความยินดีที่จะพิจารณาแนวทางการปรับโครงสร้างหนี้ที่เหมาะสม โดยสามารถขยายระยะเวลาการผ่อนชำระออกไปได้ หรือพักชำระเงินต้นเป็นการชั่วคราว เพื่อบรรเทาภาระของท่าน"
>
> **ปิดการสนทนา:**
> "หากท่านสนใจ ทางเราจะดำเนินการจัดทำเอกสารให้ในสัปดาห์หน้า และท่านจะได้รับเงื่อนไขใหม่ที่ผ่อนปรนมากขึ้น"

### จับผิดอย่างไร

**ขั้นตรวจที่ 1 (อำนาจ)** — **พบปัญหาร้ายแรง**

```
"มีความยินดีที่จะพิจารณาแนวทางการปรับโครงสร้างหนี้"
  → ✗ นอกอำนาจ RM — ต้องขออนุมัติ

"สามารถขยายระยะเวลาการผ่อนชำระออกไปได้ หรือพักชำระเงินต้น"
  → ✗ พูดเหมือนเสนอได้เลย ทั้งที่ยังไม่รู้ว่าจะอนุมัติไหม
  → และ "พักชำระเงินต้น" เกินขอบอำนาจ

"ทางเราจะดำเนินการจัดทำเอกสารให้ในสัปดาห์หน้า"
  → ✗ สัญญาว่าจะได้ ทั้งที่ยังไม่รู้ผล

"ท่านจะได้รับเงื่อนไขใหม่ที่ผ่อนปรนมากขึ้น"
  → ✗ **สัญญาผลลัพธ์ที่ควบคุมไม่ได้เลย**
```

**ถ้าพูดตามบทนี้แล้วสุดท้ายไม่อนุมัติ สถานการณ์จะแย่กว่าไม่ไปคุยเลย** เพราะลูกค้าจะรู้สึกว่าถูกหลอก และครั้งต่อไปจะไม่เชื่ออะไรที่เราพูดอีก

**ขั้นตรวจที่ 2 (ภาษา)** — ทั้งบทเป็นภาษาราชการ ถ้าพูดแบบนี้กับเจ้าของกิจการในพื้นที่ เขาจะรู้สึกทันทีว่า "เรื่องเข้ากระบวนการแล้ว" และจะตั้งรับ

**หลักที่ 2 (เป้าหมาย)** — **บทนี้ข้ามขั้นตอนสำคัญที่สุดไปเลย**

ทั้งบทไม่มีคำถามแม้แต่ข้อเดียวที่ถามว่า **เกิดอะไรขึ้น**

เรายังไม่รู้ว่าลูกค้ามีปัญหาอะไร แต่บทกระโดดไปเสนอทางแก้ทันที — ซึ่งหมายความว่าเรากำลังเสนอทางแก้ให้ปัญหาที่เราไม่รู้

**ขั้นตรวจที่ 5 (สิ่งที่ต้องได้กลับมา)** — บทไม่มีการนัดครั้งถัดไป ไม่มีการขอตัวเลขที่ลูกค้าจ่ายได้ ไม่มีข้อตกลงที่วัดได้

### หลัง — บทที่แก้แล้ว

> ## แนวทางการคุย *(ไม่ใช่บทที่ต้องพูดตาม)*
>
> ### 🎯 เป้าหมายของการคุยครั้งนี้ — เรียงตามความสำคัญ
> ```
> 1. รู้ว่าเกิดอะไรขึ้นจริง
> 2. ได้ตัวเลขที่เขาจ่ายได้จริงตอนนี้ (ไม่ใช่ตัวเลขที่เขาคิดว่าเราอยากได้ยิน)
> 3. ได้ข้อตกลงที่วัดได้ แม้จะเล็ก
> 4. นัดครั้งถัดไป
> ```
>
> ### 1️⃣ เปิด — สั้น ไม่กล่าวหา *(2 นาที)*
>
> > "พี่ครับ สองสามเดือนมานี้งวดยังไม่ได้เข้ามา ผมโทรไปสองครั้งไม่ติด เลยแวะมาดูว่าเกิดอะไรขึ้นครับ"
>
> **แล้วหยุด รอให้เขาพูด**
>
> ⚠️ **ห้ามพูดตัวเลขยอดค้างในประโยคแรก** — เขารู้อยู่แล้วว่าค้าง การพูดตัวเลขทันทีทำให้บทสนทนากลายเป็นการทวงตั้งแต่วินาทีแรก
>
> ### 2️⃣ ฟัง — ส่วนที่ยาวที่สุด *(15-20 นาที)*
>
> **คำถามที่ต้องถามให้ได้**
> ```
> □ "ช่วงนี้เป็นยังไงบ้างครับ ธุรกิจเดินปกติไหม"
> □ "ปัญหามันเริ่มตั้งแต่เมื่อไรครับ"
> □ "แล้วตอนนี้เงินเข้ายังเข้าอยู่ไหม เดือนละประมาณเท่าไร"
> □ "มีที่อื่นที่ต้องผ่อนอีกไหมครับ"
> □ "แล้วพี่วางแผนไว้ยังไงครับ"
> ```
>
> 🔑 **สิ่งที่ต้องฟังให้ได้:** ปัญหาเป็นเรื่องชั่วคราวหรือถาวร · ธุรกิจยังเดินอยู่ไหม · มีหนี้ที่อื่นเพิ่มหรือเปล่า · เขายังอยากแก้ปัญหาไหม
>
> ⚠️ **ห้ามขัด ห้ามรีบเสนอทางแก้ในช่วงนี้**
>
> ### 3️⃣ หาตัวเลขที่เป็นไปได้จริง *(10 นาที)*
>
> > "เข้าใจครับ ทีนี้ผมอยากรู้ว่า ตอนนี้จริงๆ พี่พอจ่ายได้เดือนละประมาณเท่าไรครับ"
>
> **ถ้าเขาบอกตัวเลขที่สูงเกินจริง:**
> > "พี่ครับ ผมอยากได้ตัวเลขที่พี่จ่ายได้จริงๆ มากกว่าตัวเลขที่ฟังดูดี เพราะถ้าตกลงแล้วทำไม่ได้ มันจะยากกว่าเดิมนะครับ"
>
> **ถ้าเขาบอกว่าไม่มีเลย:**
> > "แล้วเงินที่เข้ามาแต่ละเดือน หมดไปกับอะไรบ้างครับ พอจะเหลือส่วนไหนได้บ้างไหม"
>
> ### 4️⃣ บอกสิ่งที่เราทำได้ — ให้ชัดว่าอะไรได้ อะไรต้องขอ *(5 นาที)*
>
> > "ผมบอกตรงๆ นะครับว่าผมทำอะไรได้บ้าง
> >
> > **สิ่งที่ผมทำได้เลย** คือผ่อนผันการเรียกเก็บงวดนี้ไว้ก่อน เพื่อให้พี่รวบรวมเอกสาร
> >
> > **สิ่งที่ผมทำเองไม่ได้** คือการปรับเงื่อนไขการผ่อน อันนั้นผมต้องทำเรื่องเสนอขึ้นไป ซึ่ง**ผมยังบอกไม่ได้ว่าจะได้หรือไม่ได้** ขึ้นอยู่กับเกณฑ์และข้อมูลที่เราส่งขึ้นไป
> >
> > แต่ถ้าพี่อยากให้ผมลองเสนอดู ผมต้องการข้อมูลจากพี่ก่อน"
>
> ✅ **จุดสำคัญ:** แยก "ทำได้เลย" กับ "ต้องขออนุมัติ" ให้ชัด และ**พูดตรงๆ ว่ายังบอกไม่ได้ว่าจะได้หรือไม่ได้**
>
> ### 5️⃣ ปิด — ต้องได้ข้อตกลงที่วัดได้ *(5 นาที)*
>
> > "งั้นเอาแบบนี้นะครับ
> > 1. พี่ส่ง [เอกสาร] ให้ผมภายในวันที่ [ระบุวัน]
> > 2. เดือนนี้พี่จ่ายเข้ามา [ตัวเลขที่ตกลงกัน] ภายในวันที่ [ระบุวัน]
> > 3. ผมจะทำเรื่องเสนอขึ้นไป แล้วจะแจ้งผลให้ทราบภายใน [ระบุวัน]
> > 4. ผมจะโทรหาพี่วันที่ [ระบุวัน] นะครับ
> >
> > ตกลงไหมครับ"
>
> **แล้วจดไว้ทันที และทวนให้เขาฟังอีกครั้ง**
>
> ---
> ### ❌ ห้ามพูดเด็ดขาด
> ```
> ✗ "ได้ครับ" กับเรื่องที่ต้องขออนุมัติ
> ✗ "จะได้เงื่อนไขที่ผ่อนปรนมากขึ้น"
> ✗ "ไม่ต้องห่วง เดี๋ยวจัดการให้"
> ✗ "ธนาคารเข้าใจ" (ลอยเกินไป ไม่มีความหมาย)
> ✗ คำพูดใดๆ ที่อาจตีความว่าเป็นการผ่อนผันอย่างเป็นทางการ
> ```
>
> ### 💬 ถ้าลูกค้าพูดแบบนี้
> | เขาพูด | ตอบ |
> |---|---|
> | "เดี๋ยวเดือนหน้าจ่ายแน่" | "เดือนหน้าเงินจะมาจากไหนครับ" |
> | "ขอพัก 6 เดือน" | "ผมรับเรื่องไว้ได้ แต่ต้องดูตามเกณฑ์ ยังบอกไม่ได้ว่าได้หรือไม่ได้ครับ" |
> | "ธนาคารอื่นเขาไม่เข้มงวดแบบนี้" | *(ไม่เถียง)* "ครับ ทีนี้ของเรา ตอนนี้พี่พอจ่ายได้เท่าไรครับ" |
> | "ผมไม่มีจริงๆ" | "ผมเข้าใจครับ แล้วถ้าเป็นเดือนละห้าพันพอไหวไหมครับ" *(หาตัวเลขที่เป็นไปได้)* |
> | *(เงียบ)* | *(รอ อย่ารีบพูดแทน)* |
>
> ### 📝 หลังคุยเสร็จ — ทำทันที
> ```
> □ บันทึก Call Report ทันที ระบุสิ่งที่ตกลงกันให้ชัด
> □ แยกให้ชัดว่าอะไรที่เราพูดว่า "ทำได้" อะไรที่พูดว่า "ต้องขออนุมัติ"
> □ ส่งข้อความสรุปสิ่งที่ตกลงให้ลูกค้า (เป็นหลักฐานร่วมกัน)
> ```

**ความต่างไม่ได้อยู่ที่เราใจดีขึ้น แต่อยู่ที่เราจะรู้ปัญหาจริงหรือไม่** — และถ้าไม่รู้ ข้อเสนอที่ตามมาก็เป็นการเดา ซึ่งมีโอกาสสูงที่จะต้องกลับมาแก้อีกรอบ

## 8. Prompt ตั้งต้น

```
บทบาท: ผู้ช่วยเตรียมแนวทางการเจรจากับลูกค้าที่มีปัญหาการชำระหนี้

สถานการณ์:
- ค้างชำระ: [กี่งวด เป็นเงินเท่าไร] (ปัดตัวเลขได้)
- ระยะเวลาที่เริ่มมีปัญหา: [...]
- ประวัติการติดต่อ: [คุยมากี่ครั้ง ผลเป็นอย่างไร]
- สิ่งที่ลูกค้าเคยรับปาก และทำได้หรือไม่: [...]
- ท่าทีของลูกค้า: [ให้ความร่วมมือ / เลี่ยง / โกรธ / เงียบ]
- ลักษณะการพูดคุยของลูกค้าคนนี้: [ตรงไปตรงมา / อ้อม / ชอบเถียง]

**ขอบอำนาจของฉัน (สำคัญที่สุด — ห้ามเสนอเกินนี้):**
- สิ่งที่ฉันเสนอได้เอง: [...]
- สิ่งที่ต้องขออนุมัติ: [...]
- **สิ่งที่เสนอไม่ได้เด็ดขาด: [...]**

เป้าหมายของการคุยครั้งนี้ (เรียงตามความสำคัญ):
1. [...]
2. [...]

สิ่งที่ต้องการ:

**A. แนวทางการคุย 3 แบบ ที่ต่างกันที่ผลลัพธ์ ไม่ใช่แค่ความสุภาพ**
1. เข้าใจสถานการณ์ก่อน (ยังไม่เสนออะไร)
2. ร่วมแก้ปัญหา (เสนอทางเลือกที่มี)
3. ชัดเจนเรื่องผลที่ตามมา

แต่ละแบบบอกว่าเหมาะกับสถานการณ์ไหน และมีความเสี่ยงอะไร

**B. สำหรับแบบที่เหมาะที่สุด ให้ทำเป็นแนวทางที่มี:**
- ประโยคเปิด (สั้น ไม่กล่าวหา)
- **คำถามที่ต้องถามให้ได้** เพื่อเข้าใจสาเหตุจริง
- วิธีหาตัวเลขที่ลูกค้าจ่ายได้จริง
- วิธีบอกสิ่งที่เราทำได้ **โดยแยกชัดระหว่าง
  "ทำได้เลย" กับ "ต้องขออนุมัติ"**
- ข้อตกลงที่ต้องได้ก่อนจบการคุย (ต้องวัดได้และมีวันที่)

**C. รายการ "ห้ามพูด"**
คำพูดที่อาจถูกตีความว่าเป็นการให้คำมั่นหรือผ่อนผัน

**D. การรับมือข้อโต้แย้ง**
ตารางว่าถ้าลูกค้าพูดแบบนี้ ควรตอบอย่างไร
รวมกรณี: ผัดผ่อน / เปรียบเทียบกับธนาคารอื่น / โทษธนาคาร /
บอกว่าไม่มีเลย / เงียบไม่ตอบ

**E. สิ่งที่ต้องทำทันทีหลังคุยเสร็จ**

ข้อกำหนดเรื่องภาษา:
- **ใช้ภาษาพูดจริง ไม่ใช่ภาษาเขียน**
  ห้ามใช้ "ท่าน" "ทางธนาคารขอเรียนแจ้ง"
  "มีความประสงค์" "ดำเนินการ"
- ประโยคสั้น เหมือนที่คนคุยกันจริง

ข้อห้ามเด็ดขาด:
- **ห้ามเสนอสิ่งที่อยู่ในรายการ "เสนอไม่ได้เด็ดขาด"**
- **ห้ามใช้คำที่ทำให้ลูกค้าเข้าใจว่าได้แล้ว
  สำหรับเรื่องที่ต้องขออนุมัติ**
- ห้ามสัญญาผลลัพธ์ที่ควบคุมไม่ได้
- ห้ามอ้างระเบียบหรือเกณฑ์ของธนาคาร
- ห้ามข้ามขั้นตอนการฟังสาเหตุไปเสนอทางแก้ทันที
```

**รอบที่สอง — ซ้อม:**

```
ตอนนี้คุณเล่นเป็นลูกค้ารายนี้ ในแบบที่ยากที่สุด:

ผมจะเริ่มคุย คุณตอบในบทบาทลูกค้า

3. คำถามไหนที่ผมตอบไม่ดี
ห้ามชม ให้บอกเฉพาะจุดที่ยังไม่ดี
```
