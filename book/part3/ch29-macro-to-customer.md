# บทที่ 29 — เชื่อม macro → ลูกค้ารายนั้น

> **กลุ่มเสี่ยง:** ตรวจยาก · เสียหายปานกลาง (เป็นมุมมอง ไม่ใช่ตัวเลขที่ใช้อนุมัติโดยตรง)
>
> *ตัวอย่างในบทนี้เป็นของสมมติ*

---

## 1. งานนี้คืออะไร ปกติทำอย่างไร ใช้เวลาเท่าไร

ข่าวบอกว่าน้ำมันขึ้น ค่าเงินอ่อน ปุ๋ยแพง ดอกเบี้ยขึ้น — คำถามคือ **ลูกค้ารายนี้ของเรากระทบไหม ทางไหน แรงแค่ไหน และเมื่อไร**

**เวลาที่ใช้แบบเดิม:** มักไม่ได้ทำเป็นระบบ ใช้ความรู้สึกว่า "น่าจะกระทบ"

**เวลาที่ใช้เมื่อมี AI ช่วย:** ไล่ห่วงโซ่ 10 นาที + ตรวจและแปลงเป็นตัวเลข 30 นาที

**คุณค่าหลักของงานนี้:** เปลี่ยนความกังวลลอยๆ เป็นตัวเลขที่ตัดสินใจได้

ข่าวมหภาคทำให้เรากังวลได้ทุกวัน แต่ความกังวลที่ไม่มีตัวเลขกำกับนำไปสู่การกระทำสองแบบที่ผิดทั้งคู่ — ตื่นตระหนกกับเรื่องที่ไม่กระทบ และเฉยกับเรื่องที่กระทบจริง

## 2. AI ช่วยตรงไหนได้ ตรงไหนช่วยไม่ได้

| ช่วยได้ดี | ช่วยไม่ได้ |
|---|---|
| ไล่ห่วงโซ่ผลกระทบทีละขั้น | รู้ตัวเลขปัจจุบันของตัวแปรมหภาค |
| ชี้ทางที่เราไม่ได้คิดถึง | รู้โครงสร้างต้นทุนจริงของลูกค้า |
| แยกผลกระทบทางตรง/ทางอ้อม | รู้ว่าลูกค้าปรับตัวได้แค่ไหน |
| ชี้ว่าใครได้ประโยชน์บ้าง | รู้ว่าสัญญากับคู่ค้าเป็นอย่างไร |
| ตั้งคำถามเรื่องระยะเวลา | ตัดสินว่าอันไหนสำคัญพอต้องทำอะไร |

### หลักที่ 1 — ให้ไล่ห่วงโซ่ ไม่ใช่ให้ข้อสรุป

**ผิด:** "น้ำมันขึ้นกระทบลูกค้าเกษตรอย่างไร"
→ ได้คำตอบทั่วไปที่ใช้กับใครก็ได้

**ถูก:** "น้ำมันดีเซลขึ้น 15% ช่วยไล่ห่วงโซ่ผลกระทบทีละขั้นว่ามันเดินทางมาถึงกิจการ[ประเภทนี้]ได้ทางไหนบ้าง แต่ละขั้นใช้เวลากี่เดือน และจุดไหนที่ผลกระทบอาจถูกดูดซับไปก่อนถึงลูกค้า"

**ตัวอย่างห่วงโซ่ที่ได้**

```
น้ำมันดีเซล +15%
  │
  ├─ ทางตรง (0-1 เดือน)
  │   └─ ค่าน้ำมันรถขนส่งของกิจการเอง
  │       → กระทบทันทีเต็มจำนวน
  │
  ├─ ทางอ้อมผ่านค่าขนส่งจ้าง (1-2 เดือน)
  │   └─ ผู้รับจ้างขนส่งปรับราคา
  │       → ปรับได้แค่ไหน ขึ้นกับการแข่งขันในพื้นที่
  │
  ├─ ทางอ้อมผ่านต้นทุนเกษตรกร (3-6 เดือน)
  │   └─ ค่าไถ ค่าเกี่ยว ค่าสูบน้ำแพงขึ้น
  │       → เกษตรกรขอราคาสูงขึ้น / ลดพื้นที่ปลูก
  │       → กระทบปริมาณและราคาต้นทางของกิจการ
  │
  ├─ ทางอ้อมผ่านปุ๋ยและเคมี (6-12 เดือน)
  │   └─ ต้นทุนการผลิตปุ๋ยสูงขึ้น
  │       → กระทบฤดูถัดไป
  │
  └─ ทางที่อาจได้ประโยชน์
      └─ ถ้าคู่แข่งที่พึ่งพาการขนส่งระยะไกลกระทบหนักกว่า
          → กิจการที่อยู่ใกล้แหล่งวัตถุดิบได้เปรียบขึ้น
```

**ประโยชน์ของการไล่แบบนี้:** เห็นว่าผลกระทบไม่ได้มาพร้อมกัน และช่องทางที่แรงที่สุดมักไม่ใช่ช่องทางที่ชัดที่สุด

### หลักที่ 2 — AI มักข้ามเรื่องเวลา ต้องถามเสมอ

**นี่คือจุดอ่อนที่เป็นระบบของ AI ในงานนี้**

มันจะบอกว่า "จะส่งผลให้ต้นทุนสูงขึ้น" โดยไม่บอกว่าสูงขึ้นเมื่อไร ซึ่งทำให้เราคิดว่าทุกอย่างเกิดพร้อมกัน

**ถามทุกครั้ง:** *"ห่วงโซ่แต่ละขั้นใช้เวลากี่เดือนกว่าจะกระทบ"*

**ทำไมเรื่องเวลาสำคัญ:**
- ผลกระทบที่มาใน 1 เดือน ต้องรับมือทันที
- ผลกระทบที่มาใน 6 เดือน มีเวลาปรับตัว และอาจไม่เกิดจริงเพราะสถานการณ์เปลี่ยน
- และที่สำคัญ: **ต้องรู้ว่าผลกระทบจะมาถึงก่อนหรือหลังงวดชำระหนี้**

### หลักที่ 3 — แปลงเป็นตัวเลขต้นทุนจริง แล้วดูว่าเป็นกี่ % ของต้นทุนรวม

> **นี่คือขั้นตอนที่เปลี่ยนความกังวลเป็นข้อมูล**

*ตัวอย่าง*

```
ข่าว: ค่าขนส่งขึ้น 20%

ลูกค้า A (ลานรับซื้อ):
  ค่าขนส่งคิดเป็น 3% ของต้นทุนรวม
  → ขึ้น 20% = ต้นทุนรวมเพิ่ม 0.6%
  → กำไรขั้นต้น 8% เหลือ 7.4%
  → กระทบ แต่ไม่วิกฤต

ลูกค้า B (กิจการขนส่งผลผลิต):
  ค่าขนส่ง (น้ำมัน+ค่าแรงคนขับ) คิดเป็น 55% ของต้นทุนรวม
  → ขึ้น 20% = ต้นทุนรวมเพิ่ม 11%
  → กำไรขั้นต้น 14% เหลือ 3%
  → วิกฤต ต้องคุยทันที
```

**ข่าวเดียวกัน ผลต่างกัน 18 เท่า**

**กฎที่ใช้ได้จริง:** ผลกระทบที่ "ฟังดูใหญ่" แต่คิดเป็นน้อยกว่า 2% ของต้นทุนรวม **ไม่ต้องตื่น** แต่ควรบันทึกไว้เฝ้าดู

และในทางกลับกัน ผลกระทบที่ฟังดูเล็กแต่กระทบรายการต้นทุนที่ใหญ่ที่สุดของลูกค้า ต้องให้ความสำคัญทันที

### หลักที่ 4 — อย่าลืมว่าลูกค้าอาจได้ประโยชน์

AI มักเห็นแต่ด้านลบ เพราะเราถามในเชิงความเสี่ยง

*ตัวอย่างที่ลูกค้าได้ประโยชน์*
- **ค่าเงินอ่อน** → ผู้ส่งออกและผู้ที่ขายให้ผู้ส่งออกได้ประโยชน์
- **ราคาวัตถุดิบตก** → ผู้ที่ซื้อวัตถุดิบนั้นได้ประโยชน์ (แม้ผู้ผลิตจะเสีย)
- **ดอกเบี้ยขึ้น** → คู่แข่งที่มีหนี้มากกว่ากระทบหนักกว่า
- **ต้นทุนขนส่งสูง** → กิจการที่อยู่ใกล้ตลาดได้เปรียบ

**ถามเสมอ:** *"ลูกค้ารายนี้อาจได้ประโยชน์จากสถานการณ์นี้ทางไหนบ้าง"*

## 3. Input ที่ต้องเตรียมก่อนสั่งงาน

```
1. ตัวแปรมหภาคที่สนใจ         พร้อมตัวเลขจริงและวันที่ (เราหาเอง)
2. ประเภทธุรกิจลูกค้า (เจาะจง)
3. โครงสร้างต้นทุนของลูกค้า     แต่ละรายการเป็นกี่ % ของต้นทุนรวม
4. ลูกค้าขายให้ใคร ซื้อจากใคร
5. สัญญาและเงื่อนไขที่มี        ราคาคงที่หรือลอยตัว
6. งวดชำระหนี้                เพื่อดูว่าผลกระทบมาก่อนหรือหลัง
```

**ข้อ 1 — ตัวเลขมหภาคต้องเราหาเอง** AI ไม่รู้ราคาน้ำมัน ค่าเงิน หรืออัตราดอกเบี้ยปัจจุบัน (ช่อง ④ จากบทที่ 2)

**ข้อ 3 คือข้อที่ทำให้งานนี้มีค่า** — ถ้าไม่มีโครงสร้างต้นทุน จะแปลงเป็นตัวเลขไม่ได้ และจะได้แค่คำอธิบายทั่วไป

## 4. กลุ่มความเสี่ยง

**ตรวจยาก** — ห่วงโซ่ผลกระทบพิสูจน์ไม่ได้ด้วยข้อมูลที่มี ต้องใช้การประมาณและวิจารณญาณ

**เสียหายปานกลาง** — เพราะผลลัพธ์ของงานนี้เป็น **มุมมอง** ไม่ใช่ตัวเลขที่ใช้อนุมัติโดยตรง

**แต่มีความเสี่ยงสองแบบที่ต้องระวัง**
1. **ตื่นตระหนกเกินไป** → เข้มงวดกับลูกค้าที่ไม่ได้กระทบจริง สร้างภาระโดยไม่จำเป็น
2. **ประมาทเกินไป** → ไม่เห็นผลกระทบที่กำลังมา และไปรู้ตอนที่ลูกค้าผิดนัดแล้ว

**ข้อควรระวังสำคัญ:** ห้ามนำผลจากงานนี้ไปเขียนในเมโมเป็นตัวเลขยืนยัน ให้เขียนเป็น "ประมาณการผลกระทบภายใต้สมมติฐาน X" เสมอ

## 5. วิธีตรวจ

### ขั้นที่ 1 — ถามเรื่องเวลาทุกขั้นของห่วงโซ่ *(5 นาที)*

สำหรับทุกขั้น ถาม **"กี่เดือนถึงจะกระทบ"**

แล้วทำตารางเวลา

```
เดือนที่ 0-1:  [ผลกระทบที่มาทันที]
เดือนที่ 1-3:  [...]
เดือนที่ 3-6:  [...]
เดือนที่ 6-12: [...]
```

**แล้ววางทับกับปฏิทินการชำระหนี้ของลูกค้า** — ถ้าผลกระทบหนักที่สุดมาถึงพอดีกับงวดชำระใหญ่ นั่นคือสิ่งที่ต้องจัดการล่วงหน้า

### ขั้นที่ 2 — แปลงทุกช่องทางเป็นตัวเลข *(15 นาที)*

```
ช่องทาง | รายการต้นทุนที่กระทบ | % ของต้นทุนรวม | การเปลี่ยนแปลง | ผลต่อต้นทุนรวม
```

**ทุกแถวต้องมีตัวเลขในคอลัมน์สุดท้าย** ถ้าคำนวณไม่ได้ ให้ระบุว่าต้องการข้อมูลอะไรเพิ่ม

### ขั้นที่ 3 — เรียงลำดับใหม่ตามขนาดผลกระทบ *(5 นาที)*

**AI มักเรียงตามความชัดเจนของเหตุผล ไม่ใช่ตามขนาดผลกระทบ**

เรียงใหม่ตามคอลัมน์สุดท้ายของตารางในขั้นที่ 2 แล้วตัดทุกช่องทางที่ต่ำกว่า 0.5% ของต้นทุนรวมออกจากรายการที่ต้องติดตาม (แต่บันทึกไว้)

### ขั้นที่ 4 — ถามหาด้านที่ได้ประโยชน์ *(3 นาที)*

ถามคำถามในหลักที่ 4 แล้วดูว่ามีข้อไหนที่จริงสำหรับลูกค้ารายนี้

### ขั้นที่ 5 — ตรวจว่าลูกค้าปรับตัวได้แค่ไหน *(5 นาที)*

ผลกระทบที่คำนวณได้เป็น **กรณีที่ลูกค้าไม่ทำอะไรเลย** ซึ่งไม่เคยเกิดขึ้นจริง

ถามว่า
```
□ ลูกค้าส่งต่อต้นทุนไปยังราคาขายได้ไหม ได้แค่ไหน ช้าแค่ไหน
□ มีสัญญาราคาคงที่ที่ป้องกันไว้ไหม
□ เปลี่ยนแหล่งวัตถุดิบได้ไหม
□ ลดปริมาณการผลิตได้ไหมโดยไม่ขาดทุนมากกว่าเดิม
□ เคยเจอสถานการณ์แบบนี้มาก่อนไหม ตอนนั้นทำอย่างไร
```

**ข้อสุดท้ายมีค่าที่สุด** — ถ้าลูกค้าเคยผ่านสถานการณ์คล้ายกันมาแล้วและรอดมาได้ นั่นคือหลักฐานที่หนักแน่นกว่าการคำนวณใดๆ

### ขั้นที่ 6 — ตัดสินว่าต้องทำอะไร *(2 นาที)*

```
> 5% ของต้นทุนรวม    → คุยกับลูกค้าภายในเดือนนี้ + ทบทวนวงเงิน
2-5%                 → เพิ่มในรายการติดตาม + ถามในการเข้าพบครั้งหน้า
< 2%                 → บันทึกไว้ ไม่ต้องทำอะไร
ได้ประโยชน์           → อาจเป็นโอกาส (ดูบทที่ 34)
```

**รวมเวลาตรวจ: 35 นาที**

## 6. จุดพลาดที่พบบ่อย

| จุดพลาด | ลักษณะ | วิธีกัน |
|---|---|---|
| **ผลกระทบทุกอย่างดูรุนแรงเท่ากัน** | ไม่มีการเรียงลำดับ | ขั้นตรวจที่ 2 และ 3 |
| **ข้ามเรื่องเวลา** | คิดว่าทุกอย่างเกิดพร้อมกัน | ขั้นตรวจที่ 1 |
| **ลืมว่าลูกค้าอาจได้ประโยชน์** | มองแต่ด้านลบ | ขั้นตรวจที่ 4 |
| **ไม่คำนึงถึงการปรับตัว** | คำนวณกรณีที่ลูกค้าไม่ทำอะไรเลย | ขั้นตรวจที่ 5 |
| **ใช้ตัวเลขมหภาคที่ AI ให้มา** | ราคาน้ำมัน ค่าเงินที่ไม่ใช่ปัจจุบัน | หาตัวเลขเอง (ช่อง ④) |
| **เหมารวมลูกค้าทั้งพอร์ต** | ผลกระทบต่างกันมากแม้ sector เดียวกัน | คำนวณรายเคสจากโครงสร้างต้นทุนจริง |
| **ตื่นตระหนกกับตัวเลขที่ฟังดูใหญ่** | "ขึ้น 30%" ที่คิดเป็น 0.4% ของต้นทุน | ขั้นตรวจที่ 2 |
| **เอาไปเขียนในเมโมเป็นตัวเลขยืนยัน** | ประมาณการกลายเป็นข้อเท็จจริง | เขียนเป็น "ประมาณการภายใต้สมมติฐาน" |

## 7. เคสจริง 1 เคส

*(ตัวเลขสมมติ)*

### สถานการณ์

ราคาอาหารสัตว์ (ข้าวโพดและกากถั่วเหลือง) ปรับขึ้นอย่างมีนัยสำคัญ ต้องประเมินผลกระทบต่อลูกค้าในพอร์ต 3 ราย

```
ลูกค้า A — ฟาร์มเลี้ยงไก่ไข่ 
           อาหารสัตว์ = 68% ของต้นทุนรวม
ลูกค้า B — ลานรับซื้อข้าวโพด
           ไม่ได้ซื้ออาหารสัตว์ แต่ขายข้าวโพดให้โรงงานอาหารสัตว์
ลูกค้า C — โรงสีข้าว 
           ขายรำและปลายข้าวให้โรงงานอาหารสัตว์ (12% ของรายได้)
```

### ก่อน — ผลที่ AI ให้มา

> **ผลกระทบจากราคาอาหารสัตว์ที่สูงขึ้น**
>
> การปรับตัวสูงขึ้นของราคาวัตถุดิบอาหารสัตว์จะส่งผลกระทบต่อภาคปศุสัตว์อย่างมีนัยสำคัญ เนื่องจากต้นทุนอาหารสัตว์คิดเป็นสัดส่วนหลักของต้นทุนการผลิต ผู้ประกอบการจะเผชิญกับแรงกดดันด้านต้นทุนที่เพิ่มขึ้น
>
> ผลกระทบต่อผู้ประกอบการรายย่อยจะรุนแรงกว่าผู้ประกอบการรายใหญ่ เนื่องจากมีอำนาจต่อรองในการจัดซื้อน้อยกว่า
>
> **ข้อเสนอแนะ:** ควรติดตามสถานการณ์อย่างใกล้ชิด และประเมินความสามารถในการชำระหนี้ของลูกค้ากลุ่มปศุสัตว์

### จับผิดอย่างไร

**ขั้นตรวจที่ 2 (แปลงเป็นตัวเลข)** — ผลวิเคราะห์เดิมไม่มีตัวเลขเลย ทำให้เอาไปใช้ตัดสินใจไม่ได้

คำนวณเอง สมมติราคาอาหารสัตว์ขึ้น 18%

**ลูกค้า A (ฟาร์มไก่ไข่)**
```
อาหารสัตว์ = 68% ของต้นทุนรวม
ขึ้น 18% → ต้นทุนรวมเพิ่ม = 68% × 18% = 12.2%
กำไรก่อนดอกเบี้ยเดิม 11% ของรายได้
→ ถ้าส่งต่อราคาไม่ได้เลย: ขาดทุน 1.2%
→ DSCR จาก 1.35 เหลือ ติดลบ
```
**วิกฤต — ต้องคุยทันที**

**ลูกค้า B (ลานรับซื้อข้าวโพด)**

ที่นี่คือจุดที่การวิเคราะห์เดิมพลาดที่สุด

**ขั้นตรวจที่ 4 (ด้านที่ได้ประโยชน์)** — ถามว่า "ใครได้ประโยชน์จากราคาอาหารสัตว์สูงขึ้น"

ได้คำตอบ:

> "ผู้ที่ขายวัตถุดิบอาหารสัตว์ได้ประโยชน์ — ได้แก่ เกษตรกรผู้ปลูกข้าวโพด ลานรับซื้อข้าวโพด และผู้ผลิตวัตถุดิบทดแทน เนื่องจากราคาอาหารสัตว์ที่สูงขึ้นมักสะท้อนราคาวัตถุดิบต้นทางที่สูงขึ้นด้วย"

```
ลูกค้า B: ราคาข้าวโพดสูงขึ้นตาม
→ มูลค่าต่อหน่วยที่ผ่านลานสูงขึ้น
→ **แต่ต้องใช้เงินทุนหมุนเวียนมากขึ้นเพื่อซื้อปริมาณเท่าเดิม**
→ ประมาณ +18% ของความต้องการเงินทุนหมุนเวียน
```

**ผลกระทบของลูกค้า B ไม่ใช่เรื่องกำไร แต่เป็นเรื่องสภาพคล่อง** — เขาอาจกำไรดีขึ้น แต่เงินไม่พอซื้อของ ซึ่งนำไปสู่การเสียปริมาณให้คู่แข่ง

**นี่คือผลกระทบที่การวิเคราะห์เดิมมองไม่เห็นเลย และเป็นโอกาสทางธุรกิจด้วย** (เพิ่มวงเงินหมุนเวียน — ดูบทที่ 34)

**ลูกค้า C (โรงสี)**
```
รำและปลายข้าว = 12% ของรายได้ ราคาขึ้นตามราคาอาหารสัตว์
ขึ้น 18% → รายได้เพิ่ม = 12% × 18% = 2.2%
→ ได้ประโยชน์เล็กน้อย
→ ไม่ต้องทำอะไร บันทึกไว้
```

**ขั้นตรวจที่ 1 (เรื่องเวลา)**

ถามว่าแต่ละผลกระทบใช้เวลากี่เดือน

```
ลูกค้า A: 0-1 เดือน (ซื้ออาหารสัตว์ทุกสัปดาห์ กระทบทันที)
          ราคาไข่ปรับตาม: 2-4 เดือน (ช้ากว่าต้นทุน)
          → **มีช่วง 2-4 เดือนที่ขาดทุน ก่อนที่ราคาขายจะปรับตาม**
ลูกค้า B: 0-1 เดือน (ความต้องการเงินทุนเพิ่มทันทีในฤดูรับซื้อ)
ลูกค้า C: 1-2 เดือน
```

**วางทับกับปฏิทินชำระหนี้:** ลูกค้า A มีงวดชำระใหญ่ในอีก 2 เดือน — **ตรงกับช่วงที่ขาดทุนพอดี**

**ขั้นตรวจที่ 5 (การปรับตัว)** — สำหรับลูกค้า A

```
□ ส่งต่อราคาได้ไหม → ได้ แต่ช้า 2-4 เดือน และขึ้นกับตลาดไข่
□ เปลี่ยนสูตรอาหารได้ไหม → ได้บางส่วน แต่กระทบผลผลิตไข่
□ ลดจำนวนไก่ได้ไหม → ได้ แต่ต้นทุนคงที่ต่อตัวจะสูงขึ้น
□ เคยเจอมาก่อนไหม → **เคย ในปี [X] และผ่านมาได้โดยลดจำนวนไก่ชั่วคราว
                      และเจรจาขอผ่อนผันงวดชำระ**
```

ข้อสุดท้ายสำคัญมาก — มันบอกว่าลูกค้ามีประสบการณ์รับมือ และบอกว่าเราควรเสนออะไร

### หลัง — ผลวิเคราะห์ที่ใช้ได้จริง

> **ประมาณการผลกระทบจากราคาอาหารสัตว์ +18%**
> *(ภายใต้สมมติฐาน: ลูกค้าไม่ปรับตัวในช่วง 3 เดือนแรก และโครงสร้างต้นทุนตามงบปี [X])*
>
> | ลูกค้า | ช่องทางที่กระทบ | ผลต่อต้นทุน/รายได้ | เวลาที่กระทบ | ระดับ |
> |---|---|---|---|---|
> | **A** ฟาร์มไก่ไข่ | อาหารสัตว์ 68% ของต้นทุน | **ต้นทุนรวม +12.2%** | 0–1 เดือน | 🔴 **วิกฤต** |
> | | ราคาไข่ปรับตาม | รายได้ +? | 2–4 เดือน (ช้ากว่า) | |
> | **B** ลานข้าวโพด | ราคาข้าวโพดสูงขึ้นตาม | **ต้องใช้เงินทุนหมุนเวียน +18%** | 0–1 เดือน | 🟡 **สภาพคล่อง** |
> | | มูลค่าต่อหน่วยสูงขึ้น | กำไรอาจดีขึ้น | | *(อาจเป็นโอกาส)* |
> | **C** โรงสี | รำ/ปลายข้าว 12% ของรายได้ | **รายได้ +2.2%** | 1–2 เดือน | 🟢 ได้ประโยชน์ |
>
> **ลูกค้า A — สิ่งที่ต้องทำภายในเดือนนี้**
>
> - **ช่วงเสี่ยงคือ 2–4 เดือนข้างหน้า** ซึ่งต้นทุนขึ้นแล้วแต่ราคาขายยังไม่ปรับตาม
> - **งวดชำระใหญ่ในอีก 2 เดือน ตรงกับช่วงที่ขาดทุนพอดี** → ต้องจัดการล่วงหน้า
> - เข้าพบภายในสัปดาห์นี้ เพื่อ:
>   - ยืนยันตัวเลขต้นทุนอาหารสัตว์จริงที่เขาซื้ออยู่
>   - ถามว่าราคาไข่ที่ขายได้ปรับขึ้นหรือยัง เท่าไร
>   - ถามว่าปี [X] ที่เคยเจอ ตอนนั้นทำอย่างไร
>   - หารือการปรับตารางชำระชั่วคราว (ดูบทที่ 31)
>
> **ลูกค้า B — โอกาสและความเสี่ยงพร้อมกัน**
>
> - ความต้องการเงินทุนหมุนเวียนเพิ่ม ~18% ในฤดูรับซื้อที่กำลังจะมาถึง
> - ถ้าวงเงินไม่พอ จะเสียปริมาณให้คู่แข่ง
> - **แนะนำ: ทบทวนวงเงินหมุนเวียนก่อนเข้าฤดู** (ดูบทที่ 25)
>
> **ลูกค้า C — ไม่ต้องทำอะไร**
>
> - บันทึกไว้ ติดตามตามปกติ
>
> **ข้อจำกัดของการประมาณการนี้**
> - ใช้ตัวเลขราคาอาหารสัตว์จาก [แหล่ง + วันที่]
> - โครงสร้างต้นทุนจากงบปี [X] อาจเปลี่ยนไปแล้ว
> - **ไม่ได้คำนึงถึงการปรับตัวของลูกค้า ซึ่งจะทำให้ผลกระทบจริงน้อยกว่านี้**
> - ต้องยืนยันตัวเลขกับลูกค้าก่อนใช้ในเอกสารใดๆ

### สิ่งที่เปลี่ยนไป

| | ฉบับแรก | ฉบับแก้ |
|---|---|---|
| ตัวเลขผลกระทบ | ไม่มี | ทุกรายมีตัวเลข |
| แยกรายลูกค้า | ไม่ | แยก 3 ราย ผลต่างกันโดยสิ้นเชิง |
| ลูกค้าที่ได้ประโยชน์ | ไม่พบ | พบ 2 ราย (B บางส่วน, C) |
| เรื่องเวลา | ไม่มี | มี + วางทับปฏิทินชำระหนี้ |
| การปรับตัวของลูกค้า | ไม่คำนึงถึง | ตรวจ 5 ข้อ รวมประสบการณ์ในอดีต |
| สิ่งที่ต้องทำ | "ติดตามอย่างใกล้ชิด" | ระบุชัดรายลูกค้า พร้อมกำหนดเวลา |
| โอกาสทางธุรกิจ | ไม่เห็น | เห็น (ลูกค้า B ต้องการวงเงินเพิ่ม) |

**บทเรียนสำคัญ:** ข่าวมหภาคเดียวกัน กระทบลูกค้าสามรายในทิศทางที่ **ต่างกันโดยสิ้นเชิง** — รายหนึ่งวิกฤต รายหนึ่งเป็นโอกาส รายหนึ่งไม่ต้องทำอะไร

การวิเคราะห์ที่เหมารวมทั้งพอร์ตจึงไม่มีประโยชน์ และอาจทำให้เราทำสิ่งที่ผิดกับลูกค้าที่ไม่ควรถูกทำ

**เวลาที่ใช้ทั้งหมด: 40 นาที สำหรับ 3 ราย**

## 8. Prompt ตั้งต้น

```
บทบาท: ผู้ช่วยวิเคราะห์ผลกระทบของปัจจัยมหภาคต่อธุรกิจเฉพาะราย

ปัจจัยมหภาค: [ระบุพร้อมตัวเลขจริงและวันที่ — ฉันหามาเอง]
เช่น "ราคาวัตถุดิบอาหารสัตว์ปรับขึ้น 18% จาก [แหล่ง] ณ [วันที่]"

ลูกค้า:
- ประเภทธุรกิจ: [เจาะจง]
- **โครงสร้างต้นทุน** (สำคัญที่สุด):
  | รายการ | % ของต้นทุนรวม |
  |---|---|
  | ... | ... |
- รายได้มาจาก: [ขายอะไร ให้ใคร สัดส่วนเท่าไร]
- ซื้อวัตถุดิบจาก: [...]
- สัญญาที่มี: [ราคาคงที่ / ลอยตัว / ไม่มีสัญญา]
- กำไรก่อนดอกเบี้ย: [X]% ของรายได้
- งวดชำระหนี้: [เดือนไหน จำนวนเท่าไร]

สิ่งที่ต้องการ:

**A. ไล่ห่วงโซ่ผลกระทบ**
วาดเป็นแผนผัง แยกเป็น:
- ทางตรง
- ทางอ้อม (แต่ละช่องทาง)
- **ทางที่ลูกค้าอาจได้ประโยชน์** (ข้อนี้ต้องมี)

**ทุกขั้นต้องระบุ "กี่เดือนกว่าจะกระทบ"**

**B. แปลงเป็นตัวเลข**
ตารางที่มีคอลัมน์:
| ช่องทาง | รายการต้นทุน/รายได้ที่กระทบ | % ของต้นทุนหรือรายได้รวม |
| การเปลี่ยนแปลง % | **ผลต่อต้นทุนรวม/รายได้รวม %** | เวลาที่กระทบ |

ถ้าคำนวณไม่ได้ ให้ระบุว่าต้องการข้อมูลอะไรเพิ่ม

**C. เรียงลำดับตามขนาดผลกระทบ**
ไม่ใช่ตามความชัดเจนของเหตุผล
ตัดช่องทางที่ต่ำกว่า 0.5% ของต้นทุนรวมออกจากรายการหลัก

**D. ปฏิทินผลกระทบ**
เดือนที่ 0-1 / 1-3 / 3-6 / 6-12
**แล้วเทียบกับงวดชำระหนี้ข้างบนว่าตรงกันหรือไม่**

**E. การปรับตัวที่เป็นไปได้**
- ส่งต่อต้นทุนไปยังราคาขายได้ไหม ช้าแค่ไหน
- เปลี่ยนแหล่งวัตถุดิบได้ไหม
- ปรับปริมาณการผลิตได้ไหม
- ผลกระทบสุทธิหลังปรับตัวน่าจะเป็นเท่าไร

**F. คำถามที่ควรถามลูกค้า**
เพื่อยืนยันตัวเลขและดูว่าเขาปรับตัวอย่างไรแล้ว
รวมถึง: "เคยเจอสถานการณ์แบบนี้มาก่อนไหม ตอนนั้นทำอย่างไร"

ข้อห้าม:
- **ห้ามให้ตัวเลขมหภาคใดๆ** (ราคาน้ำมัน ค่าเงิน ดอกเบี้ย ราคาสินค้า)
  ใช้เฉพาะตัวเลขที่ฉันให้มาข้างบน
- ห้ามสรุปว่าลูกค้าจะมีปัญหาหรือไม่มี
- **ห้ามข้ามเรื่องเวลา** ทุกผลกระทบต้องระบุว่ากี่เดือน
- ห้ามมองแต่ด้านลบ ต้องมีส่วน "อาจได้ประโยชน์" เสมอ
- ห้ามใช้คำว่า "อย่างมีนัยสำคัญ" โดยไม่มีตัวเลขกำกับ
```
