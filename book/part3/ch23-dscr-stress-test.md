# บทที่ 23 — DSCR / Stress test / Sensitivity

> **กลุ่มเสี่ยง:** ตรวจง่าย · **เสียหายมาก** — ช่อง ②
>
> *ตัวเลขและเคสในบทนี้เป็นตัวเลขสมมติ*

## 1. งานนี้คืออะไร ปกติทำอย่างไร ใช้เวลาเท่าไร

คำนวณว่าลูกค้ามีความสามารถชำระหนี้แค่ไหน และถ้าสถานการณ์แย่ลงจะยังชำระได้ไหม

**เวลาที่ใช้แบบเดิม:** คำนวณ base case + 3–4 scenario ใน Excel 1–2 ชั่วโมง

**เวลาที่ใช้เมื่อมี AI ช่วย:** 10 นาที + ตรวจ 20 นาที

**ข้อสำคัญที่สุดของบทนี้:**

> ## **สมมติฐานเป็นของเรา การคำนวณเป็นของ AI**

ถ้าสลับกัน — ให้ AI ตั้งสมมติฐานแล้วเราตรวจแค่การคำนวณ — เราจะได้ตัวเลขที่ถูกต้องทางคณิตศาสตร์ทุกตัว บนสมมติฐานที่ไม่มีใครรับผิดชอบ

## 2. AI ช่วยตรงไหนได้ ตรงไหนช่วยไม่ได้

| ช่วยได้ดี | ช่วยไม่ได้ |
|---|---|
| คำนวณเร็วและไม่ผิดเลข | รู้ว่าสมมติฐานไหนสมเหตุสมผล |
| ทำตารางหลาย scenario | รู้ว่าราคาลงได้แค่ไหนในความจริง |
| แสดงสูตรทุกขั้น | รู้ว่าตัวแปรไหนเกี่ยวโยงกัน |
| หาจุดที่ DSCR = 1 | รู้ว่าลูกค้าถอนเงินไปใช้ส่วนตัวเท่าไร |
| ทำ sensitivity table | รู้ว่าตัวเลขตั้งต้นเชื่อถือได้แค่ไหน |

### ตั้งสมมติฐานเอง — ต้องระบุอะไรบ้าง

```
1. กระแสเงินสดสำหรับชำระหนี้     มาจากไหน คำนวณอย่างไร
2. ภาระชำระหนี้ทั้งปี             เงินต้น + ดอกเบี้ย ของทุกสัญญา
3. รายการหักที่ต้องไม่ลืม         ภาษี เงินถอนเจ้าของ ลงทุนซ่อมบำรุง
4. ช่วงเวลาที่ใช้                รอบปี หรือรอบฤดูกาล
5. ตัวแปรที่จะทดสอบ             และช่วงที่จะทดสอบ
```

**ข้อ 3 คือจุดที่พลาดบ่อยที่สุดในทางปฏิบัติ**

ในกิจการเจ้าของคนเดียวหรือครอบครัว **เจ้าของถอนเงินไปใช้ส่วนตัว** เป็นรายการที่ไม่อยู่ในงบกำไรขาดทุนแต่มีอยู่จริง ถ้าไม่หัก DSCR จะสูงกว่าความเป็นจริงมาก

*ตัวอย่าง:* กิจการมีกำไร 2.4 ล้าน/ปี ภาระชำระ 1.8 ล้าน/ปี → DSCR = 1.33 ดูผ่าน
แต่ถ้าเจ้าของถอนไปใช้ส่วนตัวปีละ 800,000 → เหลือ 1.6 ล้าน → DSCR = 0.89 **ไม่ผ่าน**

### Scenario ที่ต้องทดสอบในงานเกษตร

| scenario | ทดสอบอะไร | ช่วงที่ควรใช้ |
|---|---|---|
| **ราคาผลผลิตลง** | รายได้ลด ต้นทุนคงเดิม | −10% / −20% / −30% |
| **ต้นทุนขึ้น** | ปุ๋ย อาหารสัตว์ น้ำมัน ค่าแรง | +10% / +20% |
| **ดอกเบี้ยขึ้น** | ภาระชำระเพิ่ม | +1% / +2% |
| **ผลผลิตหาย** | ปริมาณลด ต้นทุนที่จ่ายไปแล้วไม่คืน | −20% / −40% |
| **คู่ค้าหลักหาย** | รายได้หายไปตามสัดส่วน | ตามสัดส่วนคู่ค้ารายใหญ่ |
| **ชำระเงินช้าลง** | เงินทุนหมุนเวียนตึง | +30 วัน |

**scenario ที่คนลืมบ่อยที่สุดคือสองอันสุดท้าย** ทั้งที่ในทางปฏิบัติเกิดบ่อยกว่าราคาลง 30%

### ขอตารางที่เปลี่ยนตัวแปรทีละตัว

ทำ sensitivity table ที่แสดงว่า **ตัวแปรไหนกระทบ DSCR แรงที่สุด**

```
              DSCR
base case     1.42
ราคา -10%     1.18   ← กระทบ 0.24
ราคา -20%     0.94
ต้นทุน +10%   1.31   ← กระทบ 0.11
ต้นทุน +20%   1.20
ดอกเบี้ย +2%  1.36   ← กระทบ 0.06
```

ตารางแบบนี้บอกทันทีว่า **ราคาคือตัวแปรที่ต้องเฝ้าระวังที่สุด** ซึ่งนำไปสู่การออกแบบเงื่อนไขและการติดตามที่ตรงจุด

## 3. Input ที่ต้องเตรียมก่อนสั่งงาน

```
1. ตัวเลขฐานจากบทที่ 21 และ 22   ที่ตรวจสอบแล้ว
2. ภาระหนี้ทุกสัญญา              เงินต้น ดอกเบี้ย กำหนดชำระ
3. รายการหักทั้งหมด              ภาษี เงินถอนเจ้าของ ลงทุนประจำ
4. โครงสร้างต้นทุน               ต้นทุนผันแปร vs คงที่ (สำคัญมาก)
5. สัดส่วนคู่ค้ารายใหญ่
6. scenario ที่ต้องการทดสอบ       และช่วง
```

**ข้อ 4 จำเป็นสำหรับ stress test ที่ถูกต้อง** เพราะเมื่อรายได้ลด 20% กำไรไม่ได้ลด 20% — มันลดมากกว่านั้น ในสัดส่วนที่ขึ้นกับว่าต้นทุนคงที่มีเท่าไร

## 4. กลุ่มความเสี่ยง

**ตรวจง่าย** — เป็นคณิตศาสตร์ คำนวณเองซ้ำได้

**เสียหายมาก** — DSCR คือตัวเลขที่ผู้อนุมัติดูเป็นอันดับแรก และเป็นตัวเลขที่ถูกอ้างในเมโมโดยตรง

**ลักษณะพิเศษ:** ความผิดพลาดของงานนี้มักไม่ได้อยู่ที่การคำนวณ (AI คำนวณแทบไม่ผิด) แต่อยู่ที่ **สมมติฐานที่ไม่ได้ระบุ** และ **รายการหักที่ลืม** — ซึ่งทั้งสองอย่างมองไม่เห็นในผลลัพธ์ที่ออกมาสวยงาม

## 5. วิธีตรวจ

### ขั้นที่ 1 — คำนวณ base case ด้วยมือ 1 รอบ *(5 นาที)*

> **ถ้า base case ตรง scenario อื่นค่อยเชื่อ**
> **ถ้า base case ไม่ตรง ทุกอย่างที่เหลือใช้ไม่ได้**

ใช้เครื่องคิดเลขคำนวณ DSCR base case เองทีละขั้น เทียบกับที่ AI ให้มา

**สิ่งที่ต้องดูไม่ใช่แค่ผลลัพธ์ แต่คือตัวเลขที่ใช้ในแต่ละช่อง** — ตัวเศษคือตัวไหน ตัวส่วนรวมอะไรบ้าง

### ขั้นที่ 2 — ตรวจรายการหักให้ครบ *(3 นาที)*

```
□ ภาษีเงินได้
□ เงินถอนของเจ้าของ / เงินใช้ส่วนตัว        ← ลืมบ่อยที่สุด
□ ค่าใช้จ่ายลงทุนประจำ (ซ่อมบำรุง เปลี่ยนอุปกรณ์)
□ ภาระหนี้ทุกสัญญา รวมสถาบันอื่น            ← ลืมบ่อย
□ ภาระหนี้นอกระบบที่ลูกค้าแจ้ง               ← ลืมบ่อย
□ หนี้การค้าที่ต้องชำระประจำ
□ ดอกเบี้ยค้างจ่าย
```

**สามข้อที่ทำเครื่องหมายไว้คือข้อที่ทำให้ DSCR สูงกว่าความจริงมากที่สุด**

### ขั้นที่ 3 — บังคับให้แสดงสูตรทุกช่อง *(5 นาที)*

**ห้ามรับตัวเลขลอยๆ ทุกช่องในตารางต้องมีสูตรและที่มา**

ถ้าตารางมี 20 ช่อง ต้องมี 20 สูตร ไล่ดูว่ามันหยิบตัวเลขจากที่ถูกต้องหรือไม่

*สิ่งที่มักพบ:* ใช้กำไรสุทธิแทนกระแสเงินสด · ลืมบวกค่าเสื่อมราคากลับ · ใช้ภาระชำระเฉพาะสัญญาใหม่ไม่รวมสัญญาเดิม

### ขั้นที่ 4 — ทดสอบความสมเหตุสมผลของ stress *(5 นาที)*

**นี่คือขั้นตรวจที่จับความผิดพลาดเชิงตรรกะได้ดีที่สุด**

ถามตัวเองว่า **"ถ้าราคาลง 20% กำไรควรลงเท่าไร"** แล้วเทียบกับที่ AI คำนวณ

*วิธีคิด:*
```
กิจการมีรายได้ 100 ต้นทุนผันแปร 80 ต้นทุนคงที่ 12 กำไร 8

ถ้าราคาขายลง 20% (ต้นทุนผันแปรคงเดิมเพราะซื้อวัตถุดิบราคาเดิม):
รายได้ 80 − ต้นทุนผันแปร 80 − ต้นทุนคงที่ 12 = กำไร -12

กำไรไม่ได้ลด 20% แต่ลดจาก +8 เป็น -12 คือพลิกเป็นขาดทุน
```

**ถ้า AI คำนวณว่าราคาลง 20% แล้วกำไรลง 20% แสดงว่ามันคิดผิด** — มันลดทั้งรายได้และต้นทุนตามสัดส่วน ซึ่งไม่ตรงกับความจริงในธุรกิจที่มีต้นทุนคงที่

ธุรกิจที่มีต้นทุนคงที่สูง (โรงสี โรงงาน) จะอ่อนไหวต่อราคามากกว่าที่ตัวเลขแรกดูเหมือน

### ขั้นที่ 5 — เช็คว่าตัวแปรที่เกี่ยวกันขยับตามหรือไม่ *(5 นาที)*

**ความผิดพลาดที่สำคัญที่สุดของ stress test คือการ stress ตัวแปรเดียวโดยไม่ขยับตัวแปรที่เกี่ยวข้อง**

*ตัวอย่างความสัมพันธ์ที่ต้องคำนึงถึง*

| ถ้า stress ตัวนี้ | ตัวที่ต้องขยับตาม |
|---|---|
| ราคาผลผลิตลง | ปริมาณรับซื้ออาจเพิ่ม (เกษตรกรเร่งขาย) / ต้นทุนวัตถุดิบลงด้วย |
| ผลผลิตหาย | ราคามักขึ้น (อุปทานน้อย) — บรรเทาผลกระทบบางส่วน |
| ดอกเบี้ยขึ้น | ต้นทุนของคู่ค้าขึ้นด้วย อาจกระทบเงื่อนไขการค้า |
| ต้นทุนอาหารสัตว์ขึ้น | ราคาเนื้อ/นม มักปรับตามในภายหลัง (แต่ช้ากว่า) |

**คำถามที่ต้องถามเสมอ:** "ในความเป็นจริง สถานการณ์นี้เกิดขึ้นพร้อมกับอะไรอีก"

สิ่งที่ควรทำเพิ่ม: ทำ scenario ที่แย่หลายอย่างพร้อมกัน (combined stress) เพราะในความเป็นจริงปัญหามักมาพร้อมกัน

### ขั้นที่ 6 — หาจุดที่ DSCR = 1 *(2 นาที)*

ถามว่า **"ราคาต้องลงกี่ % ถึงจะทำให้ DSCR = 1"**

ตัวเลขนี้มีค่ามากกว่า DSCR ตัวเดียว เพราะมันบอกว่า **ลูกค้ามีพื้นที่รองรับความผันผวนแค่ไหน** และเปรียบเทียบได้ว่าความผันผวนขนาดนั้นเคยเกิดขึ้นจริงในอดีตหรือไม่

**รวมเวลาตรวจ: 25 นาที**

## 6. จุดพลาดที่พบบ่อย

| จุดพลาด | ผลที่ตามมา | วิธีกัน |
|---|---|---|
| **ลืมหักเงินถอนเจ้าของ** | DSCR สูงกว่าจริงมาก | ขั้นตรวจที่ 2 |
| **ลืมหักภาษี** | DSCR สูงกว่าจริง | ขั้นตรวจที่ 2 |
| **ลืมภาระหนี้สถาบันอื่น** | ประเมินภาระต่ำเกินไป | ขั้นตรวจที่ 2 |
| **stress ตัวแปรเดียวแบบแยกส่วน** | ภาพไม่ตรงความจริง | ขั้นตรวจที่ 5 |
| **ลดรายได้และต้นทุนตามสัดส่วนเท่ากัน** | ประเมินผลกระทบต่ำเกินไปในธุรกิจต้นทุนคงที่สูง | ขั้นตรวจที่ 4 + ให้แยกต้นทุนผันแปร/คงที่ |
| **ใช้กำไรสุทธิแทนกระแสเงินสด** | ไม่บวกค่าเสื่อมกลับ ประเมินต่ำเกินไป | ขั้นตรวจที่ 3 |
| **ใช้ตัวเลขฐานที่ยังไม่ตรวจ** | ผิดตั้งแต่ต้น ทุกอย่างที่ตามมาผิดหมด | ตรวจบทที่ 21-22 ให้เสร็จก่อน |
| **ไม่คิดเรื่องจังหวะเวลา** | DSCR ทั้งปีผ่าน แต่เงินไม่พอในเดือนที่ต้องชำระ | ทำ cash flow รายเดือนเพิ่ม |

**จุดพลาดข้อสุดท้ายสำคัญมากในงานเกษตร** — DSCR รายปี 1.4 ดูดี แต่ถ้ารายได้เข้ามา 4 เดือนและงวดชำระอยู่ในเดือนที่ไม่มีรายได้ ลูกค้าก็ยังผิดนัดอยู่ดี

## 7. เคสจริง 1 เคส

*(ตัวเลขทั้งหมดเป็นของสมมติ)*

### สถานการณ์

กิจการเลี้ยงสุกรขุน ขอสินเชื่อระยะยาว 8 ล้านบาท เพื่อขยายโรงเรือน ต้องคำนวณ DSCR และทำ stress test

**ข้อมูลฐาน (ตรวจสอบจากบทที่ 21-22 แล้ว)**

```
รายได้ต่อปี              24,000,000
ต้นทุนผันแปร (อาหารสัตว์ ลูกสุกร ยา)  18,600,000  (77.5%)
ต้นทุนคงที่ (ค่าแรง ค่าเสื่อม สาธารณูปโภค)  3,200,000
กำไรก่อนดอกเบี้ยและภาษี    2,200,000
ค่าเสื่อมราคา (รวมอยู่ในต้นทุนคงที่)  900,000

ภาระหนี้เดิม              720,000/ปี
ภาระหนี้ใหม่ (8 ล้าน 7 ปี)  1,420,000/ปี
รวมภาระชำระ              2,140,000/ปี
```

### ก่อน — ผลที่ AI คำนวณมา

> **การวิเคราะห์ความสามารถในการชำระหนี้**
>
> กระแสเงินสดสำหรับชำระหนี้ = กำไรก่อนดอกเบี้ยและภาษี + ค่าเสื่อมราคา
> = 2,200,000 + 900,000 = **3,100,000 บาท**
>
> ภาระชำระหนี้ทั้งปี = **2,140,000 บาท**
>
> **DSCR = 3,100,000 ÷ 2,140,000 = 1.45**
>
> **ผลการทดสอบภาวะวิกฤต**
>
> | Scenario | กระแสเงินสด | DSCR |
> |---|---|---|
> | Base case | 3,100,000 | 1.45 |
> | ราคาสุกรลง 10% | 2,790,000 | 1.30 |
> | ราคาสุกรลง 20% | 2,480,000 | 1.16 |
> | ต้นทุนอาหารสัตว์ขึ้น 10% | 2,790,000 | 1.30 |
> | ดอกเบี้ยขึ้น 2% | 3,100,000 | 1.38 |
>
> **สรุป:** DSCR อยู่ในระดับที่ยอมรับได้ทุก scenario ไม่ต่ำกว่า 1.15 กิจการมีความสามารถในการรองรับความผันผวนได้ดี เห็นควรสนับสนุน

ตารางสวย ตัวเลขครบ ทุก scenario ผ่าน

### จับผิดอย่างไร

**ขั้นตรวจที่ 1 (คำนวณ base case เอง)**

```
3,100,000 ÷ 2,140,000 = 1.449 ✓ เลขถูก
```

การคำนวณไม่ผิด — ปัญหาอยู่ที่อื่น

**ขั้นตรวจที่ 2 (รายการหัก)** — **พบสองรายการที่หายไป**

```
□ ภาษีเงินได้                   ❌ ไม่ได้หัก
□ เงินถอนของเจ้าของ              ❌ ไม่ได้หัก
```

ถามลูกค้าและดูจาก statement พบว่า
- ภาษีเงินได้ประมาณปีละ 280,000
- **เจ้าของถอนไปใช้ส่วนตัวเฉลี่ยเดือนละ 55,000 = ปีละ 660,000**

```
กระแสเงินสดที่ใช้ได้จริง = 3,100,000 − 280,000 − 660,000 = 2,160,000
DSCR ที่ถูกต้อง = 2,160,000 ÷ 2,140,000 = 1.01
```

**DSCR จริงคือ 1.01 ไม่ใช่ 1.45** — ต่างกันมหาศาล และ 1.01 แปลว่าแทบไม่มีพื้นที่รองรับอะไรเลย

**ขั้นตรวจที่ 4 (ความสมเหตุสมผลของ stress)** — **พบความผิดพลาดเชิงตรรกะ**

ดู scenario "ราคาสุกรลง 10%" ที่ AI คำนวณ: กระแสเงินสดลดจาก 3,100,000 เป็น 2,790,000 คือลด 10% พอดี

**แต่นี่ผิด** ลองคิดเอง

```
ราคาลง 10% → รายได้ = 24,000,000 × 0.9 = 21,600,000
ต้นทุนผันแปร ไม่เปลี่ยน (ซื้ออาหารสัตว์ราคาเดิม เลี้ยงจำนวนเดิม) = 18,600,000
ต้นทุนคงที่ ไม่เปลี่ยน = 3,200,000

กำไรก่อนดอกเบี้ยและภาษี = 21,600,000 − 18,600,000 − 3,200,000 = -200,000
บวกค่าเสื่อมกลับ = -200,000 + 900,000 = 700,000
```

**กระแสเงินสดคือ 700,000 ไม่ใช่ 2,790,000**

AI ลดกระแสเงินสดลง 10% ตามรายได้ ทั้งที่ควรลดลงตามกำไร ซึ่งเป็นตัวเลขที่เล็กกว่ามาก ผลคือ **ประเมินผลกระทบต่ำกว่าความจริงเกือบ 4 เท่า**

ธุรกิจที่มีอัตรากำไรบาง (กำไรก่อนดอกเบี้ย 2.2 ล้านจากรายได้ 24 ล้าน = 9.2%) จะอ่อนไหวต่อราคาอย่างรุนแรง

**คำนวณ scenario ใหม่ทั้งหมด**

```
ราคาลง 10%:
กระแสเงินสด = 700,000 − ภาษี 0 − เงินถอน 660,000 = 40,000
DSCR = 40,000 ÷ 2,140,000 = 0.02   ← ชำระไม่ได้

ราคาลง 20%:
รายได้ = 19,200,000
กำไรก่อนดอกเบี้ย = 19,200,000 − 18,600,000 − 3,200,000 = -2,600,000
กระแสเงินสด = -2,600,000 + 900,000 − 660,000 = -2,360,000
DSCR = ติดลบ   ← ขาดทุนและต้องเอาเงินจากที่อื่นมาใส่

ต้นทุนอาหารสัตว์ขึ้น 10% (อาหารสัตว์คิดเป็น ~70% ของต้นทุนผันแปร):
ต้นทุนผันแปรเพิ่ม = 18,600,000 × 0.7 × 0.1 = 1,302,000
กำไรก่อนดอกเบี้ย = 2,200,000 − 1,302,000 = 898,000
กระแสเงินสด = 898,000 + 900,000 − 660,000 = 1,138,000
DSCR = 0.53   ← ชำระไม่ได้
```

**ขั้นตรวจที่ 5 (ตัวแปรที่เกี่ยวกัน)**

ถามว่า "ในความเป็นจริง ราคาสุกรลงมักเกิดพร้อมกับอะไร"

ได้คำตอบที่สำคัญ:

> "ราคาสุกรตกมักเกิดจากอุปทานล้นตลาด ซึ่งในช่วงเดียวกันราคาอาหารสัตว์อาจไม่ได้ลดตาม (เพราะขึ้นกับราคาข้าวโพดและถั่วเหลืองโลก) นอกจากนี้ในภาวะราคาตก เกษตรกรมักเร่งขายสุกรก่อนน้ำหนักถึงเกณฑ์ ทำให้ราคาต่อตัวยิ่งต่ำลงอีก
>
> scenario ที่ควรทดสอบเพิ่ม: ราคาลง 15% พร้อมกับต้นทุนอาหารสัตว์ขึ้น 5% ในเวลาเดียวกัน"

**ขั้นตรวจที่ 6 (จุดที่ DSCR = 1)**

```
ราคาลงได้เพียง 1.2% ก่อนที่ DSCR จะต่ำกว่า 1
```

**ตัวเลขนี้คือข้อสรุปที่แท้จริงของเคสนี้** — ลูกค้าแทบไม่มีพื้นที่รองรับความผันผวนเลย

และเมื่อดูข้อมูลย้อนหลัง ราคาสุกรในรอบ 5 ปีผันผวนเกิน 20% หลายครั้ง

> - พิจารณาลดวงเงินหรือขยายระยะเวลา เพื่อลดภาระชำระต่อปี
> - พิจารณาเงื่อนไขที่ผูกกับราคาผลผลิต

### ถ้าไม่จับผิด จะเกิดอะไร

เมโมจะระบุ DSCR 1.45 และ stress test ที่ผ่านทุก scenario ผู้อนุมัติอนุมัติ 8 ล้าน

เมื่อราคาสุกรลง 10% ในปีถัดไป (ซึ่งเกิดขึ้นเป็นปกติ) กิจการจะชำระไม่ได้ และเคสจะกลายเป็นหนี้มีปัญหาภายในปีแรก

**ความผิดพลาดสองจุด — ลืมหักเงินถอนเจ้าของ และคำนวณ stress ผิดวิธี — รวมกันทำให้ภาพผิดจากความจริงประมาณ 40 เท่า** (DSCR ที่ราคาลง 10%: 1.30 vs 0.02)
