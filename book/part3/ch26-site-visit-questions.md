# บทที่ 26 — เตรียมคำถามก่อนลง site visit

> **กลุ่มเสี่ยง:** ตรวจง่าย · เสียหายน้อย — **ช่อง ①**
> บทนี้คือการใช้ AI ในโหมดที่ปลอดภัยที่สุด: ผลิต **คำถาม** ไม่ใช่ **คำตอบ**
>
> *ตัวอย่างในบทนี้เป็นของสมมติ*

---

## 1. งานนี้คืออะไร ปกติทำอย่างไร ใช้เวลาเท่าไร

พรุ่งนี้ต้องลงพื้นที่พบลูกค้า มีเวลาอยู่กับเขา 1–2 ชั่วโมง ต้องได้ข้อมูลที่ต้องการให้ครบ

**เวลาที่ใช้แบบเดิม:** 15–30 นาที หรือไม่ได้เตรียมเลย ใช้ความจำและประสบการณ์

**เวลาที่ใช้เมื่อมี AI ช่วย:** 10 นาที + ปรับเอง 10 นาที

**ทำไมการเตรียมคำถามคุ้มค่า:** เวลาที่อยู่กับลูกค้ามีจำกัด และ **คำถามที่ลืมถามในวันนั้น มีต้นทุนสูงมาก** — ต้องโทรตาม ต้องเดินทางไปใหม่ หรือแย่ที่สุดคือทำเมโมโดยไม่มีข้อมูลนั้น

**ความเสี่ยงต่ำเป็นพิเศษ:** ถ้าคำถามไม่ดี เราก็แค่ไม่ถาม ไม่มีอะไรเสียหาย ต่างจากงานที่ AI ผลิตคำตอบซึ่งความผิดพลาดไหลเข้าเอกสาร

## 2. AI ช่วยตรงไหนได้ ตรงไหนช่วยไม่ได้

| ช่วยได้ดี | ช่วยไม่ได้ |
|---|---|
| แปลงข้อสงสัยจากงบเป็นคำถาม | รู้ว่าลูกค้าคนนี้พูดคุยแบบไหน |
| เสนอสิ่งที่ควรดูด้วยตา | รู้ว่าเรื่องไหนถามแล้วเสียความสัมพันธ์ |
| ชี้คำถามที่คนมักลืมถาม | รู้ว่าหน้างานจริงมีอะไรให้ดู |
| จัดลำดับคำถาม | รู้ภาษาที่ลูกค้าเข้าใจ |
| บอกว่าคำตอบแบบไหนควรถามต่อ | อ่านสีหน้าและท่าทาง |

### หลักที่ 1 — ให้คำถามเจาะเคสนี้ ไม่ใช่คำถามทั่วไป

**ต้องป้อนสิ่งที่เราสงสัยจากงบและ statement เข้าไป** ไม่งั้นจะได้คำถามที่ใช้กับใครก็ได้ ซึ่งไม่มีค่า

| คำถามทั่วไป (ไม่มีค่า) | คำถามเจาะเคส (มีค่า) |
|---|---|
| "ธุรกิจเป็นอย่างไรบ้าง" | "ปีที่แล้วสินค้าคงเหลือปลายปีเพิ่มขึ้นเกือบเท่าตัว ตอนนี้ระบายไปได้เท่าไรแล้ว" |
| "มีคู่ค้ากี่ราย" | "เห็นในบัญชีว่ารายรับส่วนใหญ่มาจากรายเดียว ถ้าเขาลดปริมาณลง พี่มีทางไปที่ไหนบ้าง" |
| "มีปัญหาอะไรไหม" | "เดือน ก.ค. ปีที่แล้วยอดในบัญชีเหลือน้อยมาก ช่วงนั้นผ่านมาได้ยังไง" |

**คำถามเจาะเคสทำสองอย่างพร้อมกัน** — ได้ข้อมูลที่ต้องการ และแสดงให้ลูกค้าเห็นว่าเราอ่านเอกสารของเขาจริง ซึ่งเปลี่ยนคุณภาพของบทสนทนาทั้งหมด

### หลักที่ 2 — ขอคำถามที่ "ถ้าตอบไม่ได้ = สัญญาณ"

นี่คือเทคนิคที่ทรงพลังที่สุดของบทนี้

สั่งว่า

> **"เสนอคำถามที่เจ้าของกิจการที่ดำเนินธุรกิจนี้จริงต้องตอบได้ทันที และถ้าตอบไม่ได้หรือตอบไม่ตรง แสดงว่ามีอะไรที่ต้องดูต่อ"**

*ตัวอย่างคำถามประเภทนี้*
- "ต้นทุนต่อหน่วยตอนนี้เท่าไร" — คนที่ทำธุรกิจจริงตอบได้ทันที
- "ซื้อจากใครบ้าง ราคาต่างกันไหม" — ถ้าตอบไม่ได้ แปลว่าไม่ได้บริหารต้นทุนเอง
- "ถ้าเดือนหน้าราคาลง 10% พี่จะทำยังไง" — คำตอบบอกว่าเขาคิดเรื่องความเสี่ยงไว้ไหม
- "ลูกค้ารายไหนจ่ายช้าที่สุด" — คนที่ติดตามหนี้เองตอบได้ทันที

**สิ่งที่เราดูไม่ใช่แค่คำตอบ แต่คือ "ตอบได้เร็วแค่ไหน" และ "ตอบด้วยตัวเลขหรือด้วยความรู้สึก"**

### หลักที่ 3 — ขอสิ่งที่ควรดูด้วยตา ไม่ใช่แค่ถาม

**สิ่งที่เห็นเชื่อถือได้มากกว่าสิ่งที่ได้ยิน** และการดูใช้เวลาน้อยกว่าถาม

*ตัวอย่างสิ่งที่ควรดู*
- สภาพเครื่องจักร — ใช้งานอยู่จริงไหม มีฝุ่นจับไหม
- ปริมาณสต็อก — ตรงกับที่บอกไหม สภาพเป็นอย่างไร เก่าเกินไปไหม
- จำนวนคนทำงาน — ตรงกับที่แจ้งไหม
- ป้ายทะเบียนรถ — เป็นของกิจการหรือเช่า
- สมุดบันทึกหน้างาน — มีการบันทึกจริงไหม ล่าสุดเมื่อไร
- สภาพอาคาร — ซ่อมบำรุงหรือปล่อยทิ้ง
- รถขนส่งของคู่ค้า — เป็นเจ้าที่ลูกค้าบอกไหม

**สิ่งที่ควรถ่ายรูปไว้เสมอ:** สภาพสต็อก · เครื่องจักรสำคัญ · หลักประกัน · ป้ายชื่อกิจการ (เพื่อยืนยันสถานที่)

### หลักที่ 4 — อย่าลืมคนอื่นนอกจากเจ้าของ

ข้อมูลที่มีค่าที่สุดมักไม่ได้มาจากเจ้าของ

| ถามใคร | ได้อะไร |
|---|---|
| **ลูกจ้าง** | ทำงานมานานไหม ค่าจ้างจ่ายตรงเวลาไหม ช่วงไหนงานหนัก |
| **คู่ค้าที่มาส่งของ** | ลูกค้าจ่ายตรงไหม สั่งของบ่อยแค่ไหน |
| **เพื่อนบ้าน/ร้านค้าใกล้เคียง** | กิจการเดินจริงไหม มีเรื่องอะไรในพื้นที่ |
| **คนในตลาดเดียวกัน** | ชื่อเสียงในวงการ |

**ไม่ต้องถามเป็นทางการ** — คุยธรรมดาระหว่างรอหรือระหว่างเดิน ก็ได้ข้อมูลแล้ว

## 3. Input ที่ต้องเตรียมก่อนสั่งงาน

```
1. ประเภทธุรกิจ (เจาะจง)
2. สิ่งที่สงสัยจากงบ/statement    ระบุเป็นข้อๆ พร้อมตัวเลข
3. วัตถุประสงค์การเข้าพบ
4. เวลาที่มี
5. เคยเจอลูกค้ามาก่อนไหม / ความสัมพันธ์
6. เรื่องติดตามค้างจาก Call Report ครั้งก่อน
```

**ถ้าใช้เครื่องมือนอกระบบ ให้ปิดชื่อและปัดตัวเลข** — คำถามที่ได้จะใช้ได้เหมือนกัน เพราะคำถามทำงานกับโครงของปัญหา ไม่ใช่กับตัวตนของลูกค้า

## 4. กลุ่มความเสี่ยง

**ตรวจง่าย · เสียหายน้อย** — คำถามที่ไม่ดีเราแค่ไม่ถาม

**ความเสี่ยงเดียวที่ต้องระวัง:** คำถามที่ทำให้ลูกค้ารู้สึกถูกสอบสวน หรือคำถามที่ไม่เหมาะกับบริบท

*ตัวอย่างที่ต้องปรับ:* คำถามที่เขียนเป็นภาษาราชการหรือภาษาวิชาการ เมื่อถามชาวบ้านจะฟังดูเหมือนการซักถาม

| AI มักเขียนว่า | ควรถามว่า |
|---|---|
| "ท่านมีการบริหารจัดการความเสี่ยงด้านราคาอย่างไร" | "ถ้าราคาตกแบบปีที่แล้วอีก พี่จะทำยังไงครับ" |
| "โครงสร้างต้นทุนของกิจการเป็นอย่างไร" | "ต้นทุนต่อตันตอนนี้ประมาณเท่าไรครับ" |
| "ท่านมีแผนการขยายธุรกิจในอนาคตหรือไม่" | "ปีหน้ามีอะไรที่คิดจะทำเพิ่มไหมครับ" |

## 5. วิธีตรวจ

### ขั้นที่ 1 — ตรวจว่าเจาะเคสนี้ไหม *(3 นาที)*

อ่านคำถามทีละข้อ ถามว่า **"คำถามนี้ใช้กับลูกค้ารายอื่นได้ไหม"**

- ใช้ได้กับใครก็ได้ → **ตัดทิ้ง** หรือแก้ให้เจาะจง
- ใช้ได้เฉพาะรายนี้ → เก็บไว้

**เกณฑ์:** ควรมีคำถามที่อ้างอิงตัวเลขหรือข้อเท็จจริงเฉพาะของลูกค้ารายนี้อย่างน้อยครึ่งหนึ่ง

### ขั้นที่ 2 — แปลงเป็นภาษาที่เราพูดจริง *(5 นาที)*

อ่านออกเสียงทุกคำถาม ถ้าฟังแล้วไม่เหมือนที่เราพูด ให้เขียนใหม่

**เกณฑ์:** คำถามที่ดีควรสั้น ไม่มีคำเชื่อมซับซ้อน และใช้คำที่ลูกค้าใช้

### ขั้นที่ 3 — เรียงลำดับใหม่ตามการเดินจริง *(5 นาที)*

**AI เรียงคำถามตามหมวดหมู่เชิงตรรกะ (การเงิน → การผลิต → การตลาด) ซึ่งไม่ตรงกับลำดับที่เราจะเดิน**

ให้เรียงใหม่ตามนี้

```
1. คำถามเปิด (สร้างบรรยากาศ)         นั่งคุย 10 นาทีแรก
2. คำถามที่ต้องดูของประกอบ            ระหว่างเดินดูหน้างาน
3. คำถามละเอียดเรื่องตัวเลข           กลับมานั่งคุย
4. คำถามที่อ่อนไหว                   ท้ายสุด เมื่อบรรยากาศดีแล้ว
5. คำถามกับคนอื่น                    ระหว่างเดิน/รอ
```

**คำถามที่อ่อนไหวต้องอยู่ท้ายเสมอ** — เรื่องหนี้นอกระบบ เรื่องคดีความ เรื่องความขัดแย้งในครอบครัว ถ้าถามตอนต้นจะทำให้บทสนทนาที่เหลือเปลี่ยนไปทั้งหมด

### ขั้นที่ 4 — ตัดให้เหลือเท่าที่ถามไหว *(2 นาที)*

**คำถามที่ถามไหวใน 1 ชั่วโมง: ประมาณ 12–15 ข้อ** (รวมเวลาฟังคำตอบและคุยนอกเรื่อง)

ถ้า AI ให้มา 30 ข้อ ต้องตัด ให้เลือกด้วยเกณฑ์: **"ถ้าไม่ได้คำตอบข้อนี้ เมโมจะเขียนไม่ได้ไหม"**

### ขั้นที่ 5 — เตรียมคำถามสำรอง *(2 นาที)*

เผื่อกรณีลูกค้าตอบสั้นหรือเลี่ยง ให้เตรียมคำถามต่อไว้

*ตัวอย่าง:* ถามว่า "ยอดขายเดือนละเท่าไร" ตอบว่า "ก็แล้วแต่เดือน" → ถามต่อว่า "เดือนที่ดีที่สุดปีนี้ประมาณเท่าไรครับ แล้วเดือนที่แย่ที่สุดล่ะ"

**รวมเวลาตรวจ: 17 นาที**

## 6. จุดพลาดที่พบบ่อย

| จุดพลาด | ลักษณะ | วิธีกัน |
|---|---|---|
| **คำถามยาวเป็นทางการเกินจะถามชาวบ้าน** | ฟังเหมือนอ่านจากกระดาษ | ขั้นตรวจที่ 2 |
| **คำถามทั่วไปที่ใช้กับใครก็ได้** | ไม่ได้ข้อมูลที่ต้องการ | ขั้นตรวจที่ 1 + ป้อนข้อสงสัยที่เจาะจง |
| **ลืมคำถามที่ต้องถามคนอื่น** | ได้แต่มุมของเจ้าของ | สั่งให้เสนอคำถามสำหรับลูกจ้าง/คู่ค้า/เพื่อนบ้าน |
| **ไม่มีรายการสิ่งที่ต้องดูด้วยตา** | ไปถึงแล้วลืมดู | สั่งให้แยกเป็นรายการต่างหาก |
| **คำถามเยอะเกินเวลา** | ถามไม่ครบ ข้อสำคัญตกท้าย | ขั้นตรวจที่ 4 |
| **คำถามอ่อนไหวอยู่ต้น** | บรรยากาศเสียตั้งแต่แรก | ขั้นตรวจที่ 3 |
| **ไม่ได้เตรียมคำถามต่อ** | ลูกค้าตอบสั้นแล้วจบ | ขั้นตรวจที่ 5 |
| **ถามคำถามที่รู้คำตอบอยู่แล้ว** | เสียเวลา | ระบุ "สิ่งที่รู้แล้ว" ใน input |

## 7. เคสจริง 1 เคส

*(ตัวอย่างสมมติ)*

### สถานการณ์

จะไปพบลูกค้าฟาร์มเลี้ยงโคนม เวลา 1.5 ชั่วโมง ไม่เคยไปมาก่อน

**ข้อสงสัยจากการวิเคราะห์เอกสาร**
1. ปริมาณน้ำนมที่ขายตามงบ ลดลง 12% แต่รายได้ลดแค่ 4%
2. มีรายการซื้อทรัพย์สินในงบปีที่แล้ว 1.8 ล้าน แต่ไม่รู้ว่าซื้ออะไร
3. statement มีรายการโอนออกให้บุคคลรายหนึ่งสม่ำเสมอเดือนละ 45,000
4. ค่าอาหารสัตว์ในงบสูงขึ้น 22% ในขณะที่จำนวนโคเท่าเดิม

### ก่อน — คำถามที่ AI ให้มาครั้งแรก (ไม่ได้ป้อนข้อสงสัย)

> 1. ท่านดำเนินธุรกิจฟาร์มโคนมมาเป็นระยะเวลานานเท่าใด
> 2. ปัจจุบันมีจำนวนโคนมทั้งหมดกี่ตัว แบ่งเป็นโครีดนมกี่ตัว
> 3. ผลผลิตน้ำนมเฉลี่ยต่อวันเป็นเท่าใด
> 4. ท่านจำหน่ายน้ำนมให้แก่ผู้ใดบ้าง
> 5. โครงสร้างต้นทุนการผลิตเป็นอย่างไร
> 6. ท่านมีการบริหารจัดการความเสี่ยงด้านราคาอาหารสัตว์อย่างไร
> 7. ท่านมีแผนการขยายกิจการในอนาคตหรือไม่
> 8. ท่านประสบปัญหาอุปสรรคใดในการดำเนินธุรกิจบ้าง

**ขั้นตรวจที่ 1** — ทั้ง 8 ข้อใช้กับฟาร์มโคนมรายไหนก็ได้ ไม่มีข้อไหนเจาะเคสนี้

**ขั้นตรวจที่ 2** — ทุกข้อเป็นภาษาเขียน ถ้าถามออกไปจริงจะฟังเหมือนสัมภาษณ์ราชการ

**ไม่มีข้อไหนตอบข้อสงสัย 4 ข้อของเราเลย**

> 1. "ฟาร์มนี้ทำมากี่ปีแล้วครับ" *(เปิดบทสนทนา)*
> 2. "ตอนนี้มีโคกี่ตัว รีดนมได้กี่ตัวครับ"
> 3. **"ปีที่แล้วน้ำนมออกน้อยลงหน่อยใช่ไหมครับ เกิดอะไรขึ้นหรือเปล่า"**
>    → *ข้อสงสัยที่ 1 — ถ้าตอบว่าโคป่วย/โคแก่ ต้องถามต่อว่าตอนนี้เป็นยังไง*
> 4. **"ราคาน้ำนมที่ได้ต่อกิโล ปีนี้กับปีที่แล้วต่างกันไหมครับ"**
>    → *ข้อสงสัยที่ 1 — ถ้าราคาขึ้น จะอธิบายว่าทำไมรายได้ลดน้อยกว่าปริมาณ*
>
> ### 👀 ช่วงเดินดูฟาร์ม (40 นาที)
>
> **สิ่งที่ต้องดูด้วยตา**
> ```
> □ จำนวนโคจริง เทียบกับที่บอก (นับคร่าวๆ)
> □ สภาพโค — ผอม/สมบูรณ์ / มีตัวที่ป่วยไหม
> □ โรงเรือน — สภาพ ซ่อมบำรุงไหม มีส่วนที่ไม่ได้ใช้ไหม
> □ อุปกรณ์รีดนม — สภาพ ใช้งานอยู่จริงไหม ใหม่หรือเก่า
> □ ถังเก็บนม/ถังทำความเย็น — ขนาด สภาพ
> □ ที่เก็บอาหารสัตว์ — มีสต็อกเท่าไร ยี่ห้ออะไร
> □ แปลงหญ้า — มีไหม ขนาดเท่าไร ดูแลดีไหม
> □ สมุดบันทึกการรีดนม — มีจริงไหม บันทึกล่าสุดเมื่อไร
> □ ถ่ายรูป: โรงเรือน / อุปกรณ์รีดนม / สต็อกอาหาร
> ```
>
> **คำถามระหว่างเดิน**
>
> 5. **"อุปกรณ์ตัวนี้ซื้อมานานหรือยังครับ"** *(ถามตรงจุดที่เห็นของใหม่)*
>    → *ข้อสงสัยที่ 2 — หาว่า 1.8 ล้านคืออะไร โดยไม่ต้องถามตรงๆ*
> 6. **"อาหารสัตว์ใช้ยี่ห้อนี้ตลอดเลยไหมครับ ราคาขึ้นเยอะไหมปีนี้"**
>    → *ข้อสงสัยที่ 4*
> 7. **"ซื้อจากร้านเดียวหรือหลายร้านครับ ราคาต่างกันไหม"**
>    → *ข้อสงสัยที่ 4 — และเป็นคำถามที่ "ถ้าตอบไม่ได้ = สัญญาณ"*
> 8. "วันนี้รีดได้กี่กิโลครับ" *(คนที่ทำเองตอบได้ทันที)*
>
> **คำถามกับลูกจ้าง** *(ถามระหว่างเดิน แบบคุยธรรมดา)*
> 9. "ทำงานที่นี่มานานไหมครับ"
> 10. "ช่วงไหนงานหนักที่สุดครับ"
>
> ### 📊 ช่วงกลับมานั่งคุย (25 นาที)
>
> 11. **"ค่าอาหารสัตว์ปีนี้สูงขึ้นเยอะเลยนะครับ ดูจากตัวเลขแล้วขึ้นประมาณ 20% ทั้งที่โคเท่าเดิม เป็นเพราะราคาอย่างเดียวหรือให้อาหารเยอะขึ้นด้วยครับ"**
>     → *ข้อสงสัยที่ 4 — ถามตรงโดยอ้างตัวเลข แสดงว่าเราอ่านงบเขามาจริง*
> 12. **"ปีที่แล้วเห็นมีซื้อของเข้ามาประมาณล้านแปด ซื้ออะไรบ้างครับ"**
>     → *ข้อสงสัยที่ 2 — ถามตรง*
> 13. "ต้นทุนต่อกิโลน้ำนมตอนนี้ประมาณเท่าไรครับ"
>     → *คำถามที่ "ถ้าตอบไม่ได้ = สัญญาณ"*
> 14. "ถ้าราคาอาหารสัตว์ขึ้นอีก 10% พี่จะทำยังไงครับ"
>     → *ดูว่าคิดเรื่องความเสี่ยงไว้ไหม*
>
> ### 🔒 ช่วงท้าย เมื่อบรรยากาศดีแล้ว (10 นาที)
>
> 15. **"เห็นในบัญชีมีโอนออกทุกเดือนประมาณสี่หมื่นห้า อันนี้เป็นค่าอะไรครับ"**
>     → *ข้อสงสัยที่ 3 — คำถามอ่อนไหว ต้องอยู่ท้าย*
>     → *คำถามต่อถ้าตอบไม่ชัด: "เป็นค่าจ้าง ค่าเช่า หรือผ่อนอะไรหรือเปล่าครับ"*
> 16. "มีภาระที่ต้องผ่อนที่อื่นอีกไหมครับ"
>
> ### 🔄 คำถามสำรอง (ถ้าตอบสั้น)
>
> | ถ้าตอบว่า | ถามต่อว่า |
> |---|---|
> | "ก็แล้วแต่เดือน" | "เดือนที่ดีที่สุดปีนี้ได้เท่าไร เดือนที่แย่สุดล่ะครับ" |
> | "ไม่มีปัญหาอะไร" | "แล้วช่วงไหนของปีที่เหนื่อยที่สุดครับ" |
> | "จำไม่ได้" | "พอจะมีสมุดจดไว้ไหมครับ ขอดูได้ไหม" |

### สิ่งที่เปลี่ยนไป

| | ฉบับแรก | ฉบับแก้ |
|---|---|---|

| ตอบข้อสงสัยจากเอกสาร | 0 จาก 4 ข้อ | 4 จาก 4 ข้อ |
| ภาษา | ภาษาเขียนราชการ | ภาษาพูด |

| คำถามกับคนอื่น | ไม่มี | 2 ข้อ |
| ลำดับ | ตามหมวดหมู่ | ตามการเดินจริง |
| คำถามอ่อนไหว | ปนอยู่ | แยกไว้ท้าย |
| คำถามสำรอง | ไม่มี | 3 กรณี |

**ข้อสังเกตที่สำคัญที่สุด:** คำถามข้อ 11, 12, 15 อ้างอิงตัวเลขจากเอกสารของลูกค้าโดยตรง

การถามแบบนี้ให้ผลสองอย่างที่การถามลอยๆ ให้ไม่ได้
1. **ได้คำตอบที่เจาะจง** — ลูกค้ารู้ว่าเราถามเรื่องอะไร ตอบตรงจุด
2. **ลูกค้ารู้ว่าเราอ่านเอกสารเขาจริง** — ซึ่งเปลี่ยนคุณภาพของบทสนทนาทั้งหมด และทำให้คำตอบที่ได้ตรงไปตรงมาขึ้น

## 8. Prompt ตั้งต้น

```
บทบาท: ผู้ช่วยเตรียมคำถามสำหรับการลงพื้นที่พบลูกค้าสินเชื่อ

ข้อมูล:
- ประเภทธุรกิจ: [เจาะจง]
- วัตถุประสงค์การเข้าพบ: [...]
- เวลาที่มี: [X] ชั่วโมง
- เคยพบลูกค้ามาก่อนไหม: [...]

**ข้อสงสัยจากเอกสารที่ต้องหาคำตอบให้ได้** (สำคัญที่สุด):
1. [ระบุพร้อมตัวเลข เช่น "ปริมาณขายลด 12% แต่รายได้ลดแค่ 4%"]
2. ...
3. ...

สิ่งที่รู้อยู่แล้ว ไม่ต้องถาม: [...]
เรื่องติดตามค้างจากครั้งก่อน: [...]

สิ่งที่ต้องการ — แยก 4 ส่วน:

**ส่วน A — คำถามที่ตอบข้อสงสัยข้างบนโดยตรง**
- แต่ละข้อระบุว่าตอบข้อสงสัยข้อไหน
- **ใช้ภาษาพูดที่ถามชาวบ้านได้** ไม่ใช่ภาษาเขียน
  ประโยคสั้น ไม่มีคำเชื่อมซับซ้อน
- แต่ละข้อบอกด้วยว่า "ถ้าตอบแบบไหน ควรถามต่ออย่างไร"

**ส่วน B — คำถามที่ "ถ้าตอบไม่ได้ = สัญญาณ"**
คำถามที่คนทำธุรกิจนี้จริงต้องตอบได้ทันที
ระบุว่าถ้าตอบไม่ได้ แปลว่าอะไร

**ส่วน C — สิ่งที่ควรดูด้วยตา ไม่ใช่ถาม**
- รายการสิ่งที่ควรสังเกตหน้างาน
- แต่ละอย่างบอกว่า "ถ้าเห็นแบบไหน แปลว่าอะไร"
- รายการสิ่งที่ควรถ่ายรูปไว้

**ส่วน D — คำถามสำหรับคนอื่นนอกจากเจ้าของ**
- ลูกจ้าง / คู่ค้าที่มาส่งของ / เพื่อนบ้าน
- ใช้ภาษาคุยธรรมดา ไม่ใช่การสอบถาม

**การจัดลำดับ:** เรียงตามลำดับที่จะเดินจริง
1. นั่งคุยตอนแรก (คำถามเปิด)
2. ระหว่างเดินดูหน้างาน (คำถามที่ต้องมีของประกอบ)
3. กลับมานั่งคุย (คำถามตัวเลข)
4. ท้ายสุด (คำถามอ่อนไหว — เรื่องหนี้ เรื่องส่วนตัว)

**จำนวน:** ไม่เกิน [เวลา × 10] ข้อ
เพราะต้องมีเวลาฟังคำตอบและคุยนอกเรื่อง

ข้อห้าม:
- **ห้ามเสนอคำถามที่ใช้กับลูกค้ารายไหนก็ได้**
  ("ธุรกิจเป็นอย่างไรบ้าง" / "มีปัญหาอะไรไหม")
- ห้ามใช้คำว่า "ท่าน" หรือภาษาราชการ
- ห้ามถามเรื่องที่ระบุว่ารู้อยู่แล้ว
- ห้ามให้คำตอบหรือข้อมูลเกี่ยวกับธุรกิจนี้
  ให้เฉพาะคำถามเท่านั้น
```
