# บทที่ 36 — สรุปว่าสัปดาห์นี้ควรเข้าพบใครก่อน

> **กลุ่มเสี่ยง:** ตรวจง่าย · เสียหายน้อย — **ช่อง ①**
> บทนี้รวมผลจากบทที่ 30 และ 34 เข้ากับความเป็นจริงของการเดินทาง
>
> *ตัวอย่างในบทนี้เป็นของสมมติ*

---

## 1. งานนี้คืออะไร ปกติทำอย่างไร ใช้เวลาเท่าไร

เช้าวันจันทร์ มีลูกค้าในพอร์ต 110 ราย มีเวลาลงพื้นที่ 3 วัน ต้องเลือกว่าไปหาใคร และเรียงอย่างไรให้คุ้มการเดินทาง

**เวลาที่ใช้แบบเดิม:** วางแผนตามความเร่งด่วนที่นึกออก มักจบลงด้วยการไปหาคนที่โทรมาหาเราล่าสุด

**เวลาที่ใช้เมื่อมี AI ช่วย:** 15 นาที + ปรับเอง 15 นาที

**ปัญหาที่แท้จริงของงานนี้:** ต้องรวมสามเรื่องที่ไม่เกี่ยวกันเข้าด้วยกัน

```
1. ความเสี่ยง      ใครที่ต้องไปดูก่อนที่ปัญหาจะลุกลาม (บทที่ 30)
2. โอกาส          ใครที่ควรไปคุยเรื่องบริการเพิ่ม (บทที่ 34)
3. เส้นทาง        ไปยังไงให้ไม่เสียเวลาบนถนนทั้งวัน
```

**เรื่องที่สามคนมักไม่คิดตอนวางแผน แล้วเสียเวลาไปครึ่งหนึ่งกับการขับรถ**

## 2. AI ช่วยตรงไหนได้ ตรงไหนช่วยไม่ได้

| ช่วยได้ดี | ช่วยไม่ได้ |
|---|---|
| รวมหลายเกณฑ์เข้าด้วยกัน | รู้ว่าถนนเส้นไหนใช้ได้ |
| จัดกลุ่มตามพื้นที่ | รู้ว่าลูกค้าอยู่บ้านช่วงไหน |
| เสนอลำดับพร้อมเหตุผล | รู้ว่าใครที่เราควรไปเพราะความสัมพันธ์ |
| เตือนสิ่งที่อาจลืม | รู้ว่าช่วงนี้เขาอยู่ในนาหรือในบ้าน |
| ประมาณว่าเวลาพอไหม | รู้ข้อมูลที่อยู่ในหัวเรา |

### หลักที่ 1 — เวลาของลูกค้าไม่เท่ากันทุกช่วง

**ข้อจำกัดที่สำคัญที่สุดในงานเกษตร และเป็นข้อที่ AI ไม่รู้เลย**

```
ช่วงเก็บเกี่ยว      → ลูกค้าอยู่ในแปลง ไม่มีเวลาคุย
ช่วงรับซื้อ         → ลานคึกคัก เจ้าของยุ่งมาก
ช่วงหลังขายผลผลิต  → มีเวลา มีเงิน เป็นจังหวะที่ดีที่สุด
เช้าตรู่            → เกษตรกรออกไปทำงานแล้ว
ช่วงบ่ายแก่         → กลับมาแล้ว คุยได้
วันพระ / วันสำคัญ   → ต้องเช็คก่อน
```

**การไปในเวลาที่เขาไม่ว่าง = เสียทั้งเที่ยวและเสียความรู้สึก**

### หลักที่ 2 — เหตุผลของแต่ละรายต้องอธิบายได้ในประโยคเดียว

เกณฑ์ตรวจตัวเอง: **"ถ้าหัวหน้าถามว่าทำไมไปหาคนนี้ ตอบได้ในประโยคเดียวไหม"**

| เหตุผลที่ใช้ไม่ได้ | เหตุผลที่ใช้ได้ |
|---|---|
| "ถึงรอบทบทวนแล้ว" | "เลยกำหนดทบทวนมา 2 เดือน และเป็นรายที่วงเงินใหญ่ที่สุดในกลุ่ม" |
| "ไม่ได้ไปนาน" | "ไม่ได้ไป 8 เดือน และเพิ่งเห็นใน statement ว่ายอดคงเหลือต่ำผิดปกติ 3 เดือนติด" |
| "อยู่ใกล้ทางผ่าน" | "อยู่ระหว่างทางไปหารายที่ 1 เลยแวะส่งเอกสารที่ค้างอยู่" *(เหตุผลนี้ใช้ได้ ถ้าเป็นการเสริม ไม่ใช่เหตุผลหลัก)* |

### หลักที่ 3 — อย่าจัดตามความเสี่ยงอย่างเดียว

**นี่คือความผิดพลาดที่พบบ่อยที่สุดของงานนี้**

ถ้าจัดตามความเสี่ยงล้วนๆ จะได้ตารางที่ไปหาแต่ลูกค้าที่มีปัญหา ซึ่งมีผลข้างเคียงสามอย่าง

1. **ลูกค้าดีไม่เคยเจอเรา** — จนวันที่เขาต้องการอะไร เขาไปหาธนาคารอื่น
2. **ลูกค้าเริ่มสังเกตว่าเราไปหาเฉพาะตอนมีปัญหา** — พอเห็นเราขับรถเข้ามาก็รู้สึกไม่ดีตั้งแต่ต้น
3. **เราไม่เห็นโอกาส** เพราะไปเจอแต่ปัญหา

**สัดส่วนที่แนะนำ**
```
60%  ความเสี่ยง (จากบทที่ 30)
25%  โอกาสและความสัมพันธ์ (จากบทที่ 34)
15%  งานตามรอบ (ทบทวน / ต่ออายุ / ตรวจหลักประกัน)
```

## 3. Input ที่ต้องเตรียมก่อนสั่งงาน

```
1. รายชื่อลูกค้าที่พิจารณา (ใช้รหัส)   พร้อมคะแนนเสี่ยงจากบทที่ 30
2. ลูกค้าที่มีโอกาสเสนอบริการ (บทที่ 34)
3. วันครบกำหนดต่างๆ                ทบทวน ต่ออายุ ตรวจหลักประกัน
4. ที่ตั้งโดยประมาณ                 อำเภอ/ตำบล ไม่ต้องละเอียด
5. เวลาที่มี                        กี่วัน วันไหนบ้าง
6. ฤดูกาลและความพร้อมของลูกค้า      สำคัญมาก
7. เรื่องที่ค้างต้องตามจาก Call Report ครั้งก่อน
```

**ใช้รหัสแทนชื่อเสมอ** — ตารางนี้มีข้อมูลลูกค้าหลายรายพร้อมกัน

## 4. กลุ่มความเสี่ยง

**ตรวจง่าย · เสียหายน้อย** — แผนที่ไม่ดีเราปรับได้ระหว่างสัปดาห์

**ความเสี่ยงเดียว: เชื่อแผนมากกว่าสัญชาตญาณ**

ถ้ารู้สึกว่าต้องไปหาใครสักคน แต่เขาไม่อยู่ในแผน — **ไป** แล้วค่อยหาว่าทำไมแผนไม่จับเขา (ซึ่งจะทำให้เกณฑ์ในบทที่ 30 ดีขึ้น)

## 5. วิธีตรวจ

### ขั้นที่ 1 — อธิบายเหตุผลแต่ละรายในประโยคเดียว *(5 นาที)*

ไล่ทุกรายในแผน แล้วเขียนเหตุผลหนึ่งประโยค

**ถ้าเขียนไม่ได้ ให้ตัดออก** และเอาคนที่เขียนได้มาแทน

### ขั้นที่ 2 — หาลูกค้าที่ควรไปแต่ AI ไม่รู้ *(5 นาที)*

**นี่คือขั้นตรวจที่สำคัญที่สุด**

นึกดูว่ามีใครที่เรารู้สึกว่าควรไป แต่ไม่อยู่ในแผน

**เหตุผลที่ AI ไม่รู้**
```
- สิ่งที่เห็นตอนไปครั้งล่าสุดแต่ไม่ได้บันทึก
- เรื่องที่ได้ยินจากคนในพื้นที่
- ความสัมพันธ์ที่ต้องรักษา
- ลูกค้าที่รับปากไว้ว่าจะไป
- เรื่องส่วนตัวของลูกค้า (เจ็บป่วย งานบุญ งานศพ)
```

**เรื่องสุดท้ายสำคัญมากในงานพื้นที่** — การไปร่วมงานสำคัญของลูกค้าสร้างความสัมพันธ์ที่ใช้ได้ยาวกว่าการเข้าพบเชิงธุรกิจสิบครั้ง

**เติมเข้าไปในแผน และบันทึกไว้ว่าสัญญาณนี้ควรเพิ่มในเกณฑ์บทที่ 30 หรือไม่**

### ขั้นที่ 3 — ตรวจเส้นทางและเวลา *(10 นาที)*

```
□ ลูกค้าในวันเดียวกันอยู่ในทิศทางเดียวกันไหม
□ เวลาเดินทางรวมเท่าไร เทียบกับเวลาคุย
□ นัดแรกของวันอยู่ไกลที่สุดหรือใกล้ที่สุด
□ มีเวลาเผื่อสำหรับความล่าช้าไหม
```

**กฎที่ใช้ได้จริง:** เวลาเดินทางไม่ควรเกิน 40% ของเวลาทำงานในวันนั้น

**เทคนิคการจัดเส้นทาง:** ไปให้ไกลที่สุดก่อนในตอนเช้า แล้วทยอยกลับ — จะได้ไม่ติดปัญหาว่ากลับไม่ทันตอนเย็น

### ขั้นที่ 4 — ตรวจว่าลูกค้าจะว่างไหม *(5 นาที)*

```
□ ช่วงนี้เป็นฤดูที่เขายุ่งไหม
□ เวลาที่จะไปตรงกับเวลาที่เขาอยู่ไหม
□ ได้โทรนัดล่วงหน้าหรือยัง
□ มีวันสำคัญในพื้นที่ที่ควรเลี่ยงไหม
```

**การโทรนัดล่วงหน้าเปลี่ยนอัตราการเจอตัวจากประมาณ 60% เป็นเกือบ 100%** ซึ่งคุ้มกว่าการประหยัดเวลาโทร

### ขั้นที่ 5 — ตรวจสัดส่วนของแผน *(3 นาที)*

```
ความเสี่ยง:  ___ ราย (___%)
โอกาส:      ___ ราย (___%)
งานตามรอบ:  ___ ราย (___%)
```

**ถ้าความเสี่ยงเกิน 80% ให้ปรับ** ตามหลักที่ 3

### ขั้นที่ 6 — เตรียมเป้าหมายของแต่ละการเข้าพบ *(5 นาที)*

สำหรับทุกราย เขียนว่า **"ครั้งนี้ต้องได้อะไรกลับมา"**

ถ้าเขียนไม่ได้ แปลว่ายังไม่ควรไป — หรือต้องคิดก่อนว่าไปทำไม

**รวมเวลาตรวจ: 33 นาที**

## 6. จุดพลาดที่พบบ่อย

| จุดพลาด | ผลที่ตามมา | วิธีกัน |
|---|---|---|
| **จัดตามความเสี่ยงอย่างเดียว** | ลูกค้าดีไม่เคยเจอเรา เสียโอกาส | ขั้นตรวจที่ 5 + สัดส่วน 60/25/15 |
| **ลืมลูกค้าที่ AI ไม่รู้** | ข้อมูลในหัวเราไม่ได้ถูกใช้ | ขั้นตรวจที่ 2 |
| **ไม่คิดเรื่องเส้นทาง** | เสียเวลาครึ่งวันบนถนน | ขั้นตรวจที่ 3 |
| **ไปในเวลาที่ลูกค้าไม่ว่าง** | เสียทั้งเที่ยว | ขั้นตรวจที่ 4 |
| **ไม่โทรนัดล่วงหน้า** | ไปถึงแล้วไม่เจอ | ขั้นตรวจที่ 4 |
| **ไม่มีเป้าหมายของการไป** | ไปคุยเรื่อยเปื่อย ไม่ได้ข้อมูลที่ต้องการ | ขั้นตรวจที่ 6 |
| **วางแผนแน่นเกินไป** | รายแรกช้า พังทั้งวัน | เผื่อเวลา 30% |
| **ลืมเรื่องที่ค้างจากครั้งก่อน** | ลูกค้ารู้สึกว่าเราไม่ติดตาม | ใส่เรื่องค้างใน input |

## 7. เคสจริง 1 เคส

*(ตัวอย่างสมมติ)*

### สถานการณ์

มีเวลาลงพื้นที่ 3 วัน (อังคาร–พฤหัสบดี) พอร์ต 110 ราย กระจายใน 4 อำเภอ

### ก่อน — แผนที่ AI เสนอครั้งแรก

> **แผนการเข้าพบลูกค้าประจำสัปดาห์**
>
> | วัน | ลำดับ | ลูกค้า | เหตุผล |
> |---|---|---|---|
> | อังคาร | 1 | A-045 | คะแนนเสี่ยงสูงสุด (42) |
> | | 2 | A-112 | คะแนนเสี่ยง 38 |
> | | 3 | A-023 | คะแนนเสี่ยง 35 |
> | พุธ | 4 | A-078 | คะแนนเสี่ยง 33 |
> | | 5 | A-091 | คะแนนเสี่ยง 31 |
> | | 6 | A-007 | คะแนนเสี่ยง 29 |
> | พฤหัส | 7 | A-056 | คะแนนเสี่ยง 28 |
> | | 8 | A-134 | คะแนนเสี่ยง 27 |
> | | 9 | A-019 | คะแนนเสี่ยง 26 |

### จับผิดอย่างไร

**ขั้นตรวจที่ 3 (เส้นทาง)** — **ปัญหาที่ใหญ่ที่สุด**

ดูที่ตั้งของลูกค้าแต่ละราย

```
วันอังคาร:
  A-045  อำเภอ ก. (ห่างจากสาขา 35 กม.)
  A-112  อำเภอ ค. (ห่าง 52 กม. คนละทิศกับ ก.)
  A-023  อำเภอ ก. (กลับมาทางเดิม)

→ ระยะทางรวมประมาณ 190 กม.
→ เวลาเดินทางประมาณ 4.5 ชั่วโมง
→ เวลาคุยเหลือ 3 ชั่วโมง สำหรับ 3 ราย
```

**เวลาเดินทาง 60% ของวัน** — เกินเกณฑ์ 40% มาก

**สาเหตุ:** AI เรียงตามคะแนนความเสี่ยงล้วนๆ โดยไม่ได้จัดกลุ่มตามพื้นที่ เพราะเราไม่ได้ให้ข้อมูลที่ตั้ง

**ขั้นตรวจที่ 5 (สัดส่วน)**

```
ความเสี่ยง:  9 ราย (100%)
โอกาส:      0 ราย (0%)
งานตามรอบ:  0 ราย (0%)
```

**ทั้งสัปดาห์ไปหาแต่ลูกค้าที่มีปัญหา** ซึ่งตามหลักที่ 3 มีผลข้างเคียงสามอย่าง

และมีผลอีกอย่างที่ไม่ได้พูดถึง: **สามวันเต็มที่เจอแต่ปัญหา ส่งผลต่อสภาพจิตใจของคนทำงานด้วย**

**ขั้นตรวจที่ 2 (ลูกค้าที่ AI ไม่รู้)**

นึกดูแล้วพบสามราย

```
B-034 — รับปากไว้เมื่อ 3 สัปดาห์ก่อนว่าจะไปดูโรงเรือนใหม่
        → ถ้าไม่ไปอีกจะเสียความน่าเชื่อถือ
        (AI ไม่รู้เพราะเป็นคำรับปากด้วยวาจา ไม่ได้บันทึก)

B-067 — ได้ยินจากคนในพื้นที่ว่าคู่ค้าหลักของเขาปิดกิจการ
        → เป็นข้อมูลสำคัญที่ยังไม่มีในระบบ
        (AI ไม่รู้เพราะยังไม่ได้บันทึกที่ไหน)

B-089 — พ่อของเจ้าของเสียชีวิต มีงานสวดสัปดาห์นี้
        → ควรไปร่วมงาน
        (AI ไม่รู้ และไม่มีทางรู้)
```

**ทั้งสามรายไม่อยู่ในแผน และรายที่สองอาจสำคัญกว่าลูกค้าอันดับ 1 ในแผนด้วยซ้ำ**

**ขั้นตรวจที่ 4 (ลูกค้าจะว่างไหม)**

```
A-045 และ A-023 เป็นลานรับซื้อ — ตอนนี้เป็นกลางฤดูรับซื้อ
→ เจ้าของยุ่งมาก คุยได้ไม่เกิน 20 นาที
→ ถ้าจะคุยเรื่องยาว ควรเลื่อนไปหลังฤดู
→ แต่ถ้าเป็นเรื่องเร่งด่วน ควรไปช่วงเช้ามืดหรือเย็น
```

### บทเรียนจากเคสนี้

**ลูกค้าที่สำคัญที่สุดในสัปดาห์นี้ (B-067) ไม่อยู่ในแผนที่ AI ทำเลย**

เพราะข้อมูลที่ทำให้เขาสำคัญ — คู่ค้าหลักปิดกิจการ — เป็นข้อมูลที่ได้ยินจากคนในพื้นที่ ยังไม่ได้บันทึกที่ไหน และยังไม่ปรากฏใน statement

> **ข้อมูลที่มีค่าที่สุดในงาน RM มักเป็นข้อมูลที่ยังไม่ได้อยู่ในระบบ**

ซึ่งนำไปสู่ข้อสรุปสองอย่าง
1. **AI ช่วยจัดการสิ่งที่อยู่ในระบบได้ดี แต่เราต้องเป็นคนเติมสิ่งที่อยู่นอกระบบเสมอ**
2. **ถ้าเราบันทึกสิ่งที่ได้ยินจากพื้นที่ลงในระบบมากขึ้น เครื่องมือก็จะช่วยเราได้มากขึ้น** — ซึ่งย้อนกลับไปที่บทที่ 20 เรื่องการบันทึก Call Report ให้ครบ

**เวลาที่ใช้ทั้งหมด: 32 นาที**

## 8. Prompt ตั้งต้น

```
บทบาท: ผู้ช่วยวางแผนการลงพื้นที่

**ใช้รหัสลูกค้า ไม่ใช้ชื่อ**

เวลาที่มี: [กี่วัน วันไหนบ้าง เวลาเริ่ม-เลิก]
จุดเริ่มต้น: [สาขา]

**รายชื่อลูกค้าที่พิจารณา:**
| รหัส | อำเภอ | ระยะทางจากสาขา | ประเภทธุรกิจ | เหตุผลที่ควรไป | ระดับ |
|---|---|---|---|---|---|
| A-045 | ก. | 35 กม. | ลานรับซื้อ | [เหตุผลที่เป็นข้อเท็จจริง ไม่ใช่คะแนน] | เสี่ยง |
| C-018 | ข. | 20 กม. | พืชไร่ | [...] | โอกาส |
| ... | | | | | |

**ฤดูกาลและความพร้อมของลูกค้าตอนนี้:**
- ลานรับซื้อ: กลางฤดูรับซื้อ เจ้าของยุ่งมาก คุยได้ไม่เกิน 20 นาที
  ควรไปช่วง [เวลา]
- เกษตรกร: [...]
- [กลุ่มอื่น]: [...]

เรื่องที่ค้างจาก Call Report ครั้งก่อน: [...]
วันสำคัญในพื้นที่สัปดาห์นี้: [...]

สิ่งที่ต้องการ:

**A. จัดตารางรายวัน โดย:**
1. **จัดกลุ่มตามพื้นที่ก่อน** — ลูกค้าในวันเดียวกันต้องอยู่ทิศทางเดียวกัน
2. **เวลาเดินทางรวมต้องไม่เกิน 40% ของเวลาทำงานในวันนั้น**
3. วันที่ไปไกล ให้ไปจุดไกลที่สุดตอนเช้า แล้วทยอยกลับ
4. คำนึงถึงเวลาที่ลูกค้าแต่ละกลุ่มว่าง ตามข้อมูลฤดูกาลข้างบน

**B. สัดส่วนของแผน:**
- ความเสี่ยง ประมาณ 60%
- โอกาสและความสัมพันธ์ ประมาณ 25%
- งานตามรอบ ประมาณ 15%
**ห้ามจัดแผนที่เป็นลูกค้าความเสี่ยงล้วน**

**C. แต่ละรายระบุ:**
- **เหตุผลในประโยคเดียวที่อธิบายหัวหน้าได้**
  (ต้องบอกว่าเกิดอะไรขึ้น ไม่ใช่บอกคะแนน)
- **สิ่งที่ต้องได้กลับมาจากการเข้าพบครั้งนี้**
- เวลาที่ควรใช้

**D. รายที่ควรเลื่อน พร้อมเหตุผล**
โดยเฉพาะรายที่ตอนนี้ไม่ใช่จังหวะที่ดี

**E. Checklist สิ่งที่ต้องเตรียมก่อนออก**
แยกรายลูกค้า (เอกสาร เครื่องมือ ข้อมูลที่ต้องค้นก่อน)

**F. คำถาม: มีข้อมูลประเภทไหนที่ฉันน่าจะมีอยู่ในหัว
แต่ไม่ได้ใส่ในรายการข้างบน ซึ่งควรนำมาพิจารณาด้วย**

ข้อห้าม:
- ห้ามเรียงตามคะแนนความเสี่ยงอย่างเดียวโดยไม่ดูพื้นที่
- ห้ามใช้คะแนนเป็นเหตุผลในการไป
  ให้เขียนเหตุผลที่เป็นข้อเท็จจริง
- ห้ามวางแผนแน่นเกิน 70% ของเวลาที่มี
- ห้ามจัดลูกค้าในวันเดียวกันที่อยู่คนละทิศทาง
```

**ข้อ F คือส่วนที่สำคัญที่สุด** — มันบังคับให้เราหยุดคิดว่ามีอะไรที่รู้แต่ไม่ได้ป้อน ซึ่งในเคสข้างบนคือสิ่งที่ทำให้พบลูกค้าที่สำคัญที่สุดของสัปดาห์
