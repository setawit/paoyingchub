# บทที่ 35 — แปลศัพท์การเงินให้ลูกค้าเกษตรกรเข้าใจ

> **กลุ่มเสี่ยง:** ตรวจง่าย · เสียหายปานกลาง (เข้าใจผิด = ปัญหาตามมา)
>
> *ตัวอย่างในบทนี้เป็นของสมมติ*

---

## 1. งานนี้คืออะไร ปกติทำอย่างไร ใช้เวลาเท่าไร

ต้องอธิบายเรื่องการเงินให้ลูกค้าที่ไม่ได้เรียนมาทางนี้เข้าใจ — DSCR, วงเงินหมุนเวียน, หลักประกัน, ดอกเบี้ยลอยตัว, การจัดชั้น, เงื่อนไขในสัญญา

**เวลาที่ใช้แบบเดิม:** อธิบายไปเรื่อยๆ ในห้อง แล้วหวังว่าเขาเข้าใจ

**เวลาที่ใช้เมื่อมี AI ช่วย:** เตรียมคำอธิบาย 15 นาที + ทดสอบ 10 นาที

**ทำไมเรื่องนี้สำคัญกว่าที่คิด:**

ลูกค้าที่ไม่เข้าใจเงื่อนไข จะไม่ปฏิบัติตามเงื่อนไข — ไม่ใช่เพราะไม่อยากทำ แต่เพราะไม่รู้ว่าต้องทำ

และเมื่อเกิดปัญหา คำถามที่ตามมาคือ **"ตอนทำสัญญา RM อธิบายหรือเปล่า"** ซึ่งเป็นคำถามที่ตอบยากถ้าเราไม่มั่นใจว่าเขาเข้าใจจริง

---

## 2. AI ช่วยตรงไหนได้ ตรงไหนช่วยไม่ได้

| ช่วยได้ดี | ช่วยไม่ได้ |
|---|---|
| เสนอวิธีอธิบายหลายแบบ | รู้ว่าลูกค้าคนนี้เข้าใจแค่ไหน |
| คิดอุปมาจากอาชีพลูกค้า | รู้ภาษาถิ่นและคำที่เขาใช้ |
| ทำให้สั้นลงโดยเก็บใจความ | อ่านสีหน้าว่าเข้าใจหรือไม่ |
| ชี้จุดที่อาจเข้าใจผิด | รู้เงื่อนไขจริงในสัญญาของเรา |
| ทำตัวอย่างตัวเลขประกอบ | รับผิดชอบถ้าอธิบายผิด |

### หลักที่ 1 — ง่ายจนผิด คือปัญหาที่ใหญ่กว่ายากจนไม่เข้าใจ

> ## **คำอธิบายที่ง่ายแต่ผิด อันตรายกว่าคำอธิบายที่ยากแต่ถูก**

เพราะลูกค้าที่ไม่เข้าใจจะถามต่อ แต่ลูกค้าที่เข้าใจผิดจะไม่ถาม และจะไปทำตามความเข้าใจที่ผิดนั้น

**ตัวอย่างการทำให้ง่ายจนผิด**

| คำอธิบายที่ง่ายแต่ผิด | ทำไมผิด |
|---|---|
| "ดอกเบี้ยลอยตัวคือดอกเบี้ยที่ขึ้นลงได้" | ไม่ผิด แต่ไม่พอ — ลูกค้าไม่รู้ว่ามันขึ้นได้แค่ไหน และงวดผ่อนจะเปลี่ยนตามไหม |
| "หลักประกันคือของที่เอามาค้ำไว้ ถ้าไม่จ่ายธนาคารก็ยึด" | ทำให้เข้าใจว่ายึดแล้วจบ ทั้งที่ถ้าขายได้ไม่พอ ยังเป็นหนี้ส่วนที่เหลืออยู่ |
| "วงเงินหมุนเวียนคือเงินที่เบิกใช้ได้เรื่อยๆ" | ทำให้เข้าใจว่าไม่ต้องคืน ทั้งที่ต้องคืนตามรอบ |
| "จ่ายขั้นต่ำก็ได้" | ไม่ได้บอกว่าเงินต้นไม่ลดและดอกเบี้ยเดินต่อ |

**แถวที่สองและสามเป็นความเข้าใจผิดที่สร้างปัญหาจริงบ่อยที่สุด**

### หลักที่ 2 — อุปมาต้องใช้จากอาชีพลูกค้า และต้องไม่ทำให้เข้าใจผิดเรื่องภาระ

อุปมาที่ดีทำให้เข้าใจเร็ว อุปมาที่ผิดทำให้เข้าใจผิดถาวร

**อุปมาที่ต้องระวังเป็นพิเศษ**

| อุปมา | ปัญหา |
|---|---|
| "วงเงินหมุนเวียนก็เหมือนกระเป๋าเงินสำรอง" | ทำให้รู้สึกว่าเป็นเงินของเรา ไม่ใช่หนี้ที่ต้องคืนพร้อมดอกเบี้ย |
| "หลักประกันก็เหมือนของฝากไว้" | ของฝากได้คืนแน่นอน หลักประกันอาจถูกบังคับขาย |
| "ดอกเบี้ยก็เหมือนค่าเช่าเงิน" | ดีพอสมควร แต่ต้องเสริมว่าค่าเช่านี้เปลี่ยนได้ถ้าเป็นอัตราลอยตัว |

**เกณฑ์ตรวจอุปมา:** ถามว่า *"ถ้าลูกค้าเชื่ออุปมานี้ 100% เขาจะเข้าใจผิดเรื่องอะไรได้บ้าง"*

### หลักที่ 3 — ตัวเลขจริงชนะคำอธิบายเสมอ

คำอธิบายที่ดีที่สุดมักไม่ใช่การเปรียบเทียบ แต่เป็น **ตัวอย่างตัวเลขที่เป็นของเขาเอง**

| แทนที่จะอธิบายว่า | ให้แสดงว่า |
|---|---|
| "ดอกเบี้ยลอยตัวคืออะไร" | "ตอนนี้พี่ผ่อนเดือนละ 12,000 ถ้าดอกเบี้ยขึ้น 1% จะเป็นเดือนละ 12,800 ถ้าขึ้น 2% เป็น 13,600" |
| "DSCR คืออะไร" | "เงินที่พี่มีเหลือจ่ายหนี้ได้เดือนละ 45,000 งวดที่ต้องจ่าย 35,000 เหลือ 10,000 เป็นเผื่อไว้" |
| "ทำไมต้องมีหลักประกัน" | "ถ้าถึงจุดที่จ่ายไม่ได้จริงๆ ธนาคารจะต้องขายที่แปลงนี้ ขายได้เท่าไรก็หักหนี้ ถ้าไม่พอ ส่วนที่เหลือพี่ยังต้องรับผิดชอบอยู่" |

## 3. Input ที่ต้องเตรียมก่อนสั่งงาน

```
1. ศัพท์หรือเงื่อนไขที่ต้องอธิบาย
2. ความหมายที่ถูกต้องตามสัญญา/ระเบียบ  ← เราต้องใส่เอง
3. อาชีพและบริบทของลูกค้า
4. ระดับความคุ้นเคยกับเรื่องการเงิน
5. ตัวเลขจริงของเคสนี้              (ปัดได้)
6. สิ่งที่ถ้าเข้าใจผิดจะเกิดปัญหา       ← สำคัญที่สุด
```

**ข้อ 2 ต้องเราใส่เอง** — AI ไม่รู้เงื่อนไขในสัญญาของเรา ถ้าให้มันอธิบายจากความรู้ทั่วไป มันจะอธิบายแบบธนาคารพาณิชย์ทั่วไป ซึ่งอาจต่างจากของเรา

## 4. กลุ่มความเสี่ยง

**ตรวจง่าย** — ทดสอบได้ด้วยการให้คนฟังเล่ากลับ

**เสียหายปานกลาง** แต่เป็นความเสียหายที่ **ปรากฏช้า**

- ลูกค้าเข้าใจผิดวันนี้ ปัญหาเกิดในอีก 1–2 ปี
- เมื่อเกิดปัญหา ความสัมพันธ์เสียหายมากเพราะลูกค้ารู้สึกว่าถูกหลอก
- และเป็นคำถามในการตรวจสอบว่าได้อธิบายครบถ้วนหรือไม่

**ข้อควรระวัง:** การอธิบายด้วยคำพูดอย่างเดียวไม่มีหลักฐาน — ถ้าเป็นเรื่องสำคัญ ควรมีเอกสารประกอบที่ลูกค้าเก็บไว้ได้

## 5. วิธีตรวจ

### ขั้นที่ 1 — ตรวจว่าง่ายแล้วยังถูกไหม *(10 นาที)*

**นี่คือขั้นตรวจหลักของบทนี้**

สำหรับทุกคำอธิบาย เทียบกับเงื่อนไขจริงในสัญญา แล้วถาม

```
□ มีเงื่อนไขอะไรที่ถูกตัดออกเพื่อให้ง่ายขึ้นไหม
□ เงื่อนไขที่ตัดออกนั้น สำคัญไหม
□ ถ้าลูกค้าเชื่อคำอธิบายนี้ 100% เขาจะเข้าใจผิดเรื่องอะไรได้บ้าง
```

**ข้อสุดท้ายคือคำถามที่ทรงพลังที่สุด** ถามกับ AI ก็ได้ ถามตัวเองก็ได้

### ขั้นที่ 2 — ตรวจอุปมา *(5 นาที)*

สำหรับทุกอุปมา ถามว่า **"อุปมานี้ทำให้เข้าใจผิดเรื่องภาระหรือความรับผิดชอบไหม"**

*จุดที่อุปมามักทำให้เข้าใจผิด*
- ทำให้หนี้ดูเหมือนไม่ใช่หนี้
- ทำให้ความเสี่ยงดูน้อยกว่าจริง
- ทำให้เข้าใจว่ามีทางออกที่ง่ายกว่าจริง

### ขั้นที่ 3 — ทดสอบด้วยการให้เล่ากลับ *(10 นาที)*

**วิธีที่ได้ผลที่สุด: อธิบายให้คนที่ไม่ใช่คนแบงก์ฟัง แล้วให้เขาเล่ากลับ**

ถ้าไม่มีคน ให้ใช้ AI

```
"ผมจะอธิบายเรื่อง [X] ให้ฟัง
คุณเป็นเกษตรกรที่ไม่เคยกู้เงินธนาคารมาก่อน
ฟังแล้วเล่ากลับมาว่าคุณเข้าใจว่าอะไร
แล้วบอกด้วยว่ามีตรงไหนที่ยังไม่เข้าใจ
หรือตรงไหนที่คุณเดาเอาเอง"
```

**สิ่งที่ต้องดูในการเล่ากลับ**
- เขาเข้าใจภาระของตัวเองถูกไหม
- เขารู้ไหมว่าต้องทำอะไร เมื่อไร
- เขารู้ไหมว่าถ้าไม่ทำจะเกิดอะไร
- มีตรงไหนที่เขาเข้าใจเกินกว่าที่เราพูด (เติมเอง)

### ขั้นที่ 4 — เช็คว่ามีเรื่องที่ต้องบอกแต่ยังไม่ได้บอกไหม *(5 นาที)*

ไล่ดูเงื่อนไขในสัญญาทั้งหมด แล้วเช็คว่าเรื่องที่ **ถ้าเข้าใจผิดจะเกิดปัญหา** ได้ถูกอธิบายครบไหม

**เรื่องที่ต้องอธิบายเสมอ แม้ลูกค้าไม่ถาม**
```
□ งวดผ่อนเปลี่ยนได้ไหม ในกรณีไหน
□ ถ้าจ่ายช้าจะเกิดอะไร (ค่าปรับ ผลต่อประวัติ)
□ หลักประกันจะถูกบังคับเมื่อไร และถ้าขายไม่พอจะเป็นอย่างไร
□ เงื่อนไขที่ลูกค้าต้องทำ (ส่งเอกสาร รายงาน)
□ อะไรที่ทำให้ธนาคารเรียกคืนหนี้ก่อนกำหนดได้
```

### ขั้นที่ 5 — ให้ลูกค้ามีอะไรกลับไปอ่าน *(5 นาที)*

คำอธิบายด้วยปากลืมได้ภายในสัปดาห์เดียว

**ทำเอกสารสรุป 1 หน้า** ที่มี
- จำนวนเงิน งวด วันที่ครบกำหนด
- สิ่งที่ลูกค้าต้องทำ พร้อมกำหนด
- เบอร์ติดต่อ
- เรื่องที่ต้องระวัง 2–3 ข้อ

**ให้เป็นภาษาเดียวกับที่เราอธิบาย ไม่ใช่ภาษาสัญญา**

**รวมเวลาตรวจ: 35 นาที**

## 7. เคสจริง 1 เคส

*(ตัวอย่างสมมติ)*

### สถานการณ์

ต้องอธิบายให้ลูกค้าเกษตรกรที่กู้ครั้งแรกเข้าใจ 3 เรื่อง

```
1. วงเงินหมุนเวียน — ต้องชำระคืนเต็มจำนวนภายใน 31 พ.ค. ทุกปี
2. ดอกเบี้ยลอยตัว — อ้างอิงอัตราที่ธนาคารประกาศ
3. หลักประกัน — ที่ดิน 1 แปลง
```

### ก่อน — คำอธิบายที่ AI เสนอ

> **1. วงเงินหมุนเวียน**
>
> "วงเงินหมุนเวียนก็เหมือนกระเป๋าเงินสำรองของเรา เวลาต้องการใช้ก็หยิบออกมาใช้ได้ พอมีเงินเข้ามาก็ใส่กลับเข้าไป ใช้ได้เรื่อยๆ ไม่ต้องขอใหม่ทุกครั้ง"
>
> **2. ดอกเบี้ยลอยตัว**
>
> "ดอกเบี้ยลอยตัวก็คือดอกเบี้ยที่ขึ้นลงได้ตามสถานการณ์ บางช่วงอาจถูกลง บางช่วงอาจแพงขึ้น เหมือนราคาข้าวที่ขึ้นลงตามตลาด"
>
> **3. หลักประกัน**
>
> "หลักประกันก็คือที่ดินที่เราเอามาค้ำไว้กับธนาคาร เหมือนเป็นหลักฐานว่าเราจะจ่ายคืนแน่นอน ถ้าเราจ่ายครบตามกำหนด ที่ดินก็เป็นของเราเหมือนเดิม"

อ่านแล้วเข้าใจง่ายมาก ใช้อุปมาที่เกษตรกรคุ้นเคย — **และทั้งสามข้อมีปัญหา**

### จับผิดอย่างไร

**ขั้นตรวจที่ 1 (ง่ายแล้วยังถูกไหม)**

**ข้อ 1 — ผิดจุดสำคัญที่สุด**

คำอธิบายบอกว่า "ใช้ได้เรื่อยๆ" แต่ **ไม่ได้บอกเลยว่าต้องชำระคืนเต็มจำนวนภายใน 31 พ.ค. ทุกปี** ซึ่งเป็นเงื่อนไขหลักของวงเงินนี้

ถ้าลูกค้าเชื่อตามนี้ เขาจะไม่เตรียมเงินไว้ล้างยอดในเดือนพฤษภาคม และจะผิดเงื่อนไขโดยไม่รู้ตัว

**นี่คือตัวอย่างชัดของ "ละเงื่อนไขสำคัญเพื่อให้ง่าย"**

**ข้อ 2 — ไม่ผิดแต่ไม่พอ**

บอกว่าดอกเบี้ยขึ้นลงได้ แต่ไม่ได้บอกสองเรื่องที่ลูกค้าต้องรู้
- **ขึ้นแล้วงวดผ่อนจะเปลี่ยนไหม หรือระยะเวลาจะยาวขึ้น**
- **ขึ้นได้แค่ไหน และถ้าขึ้นจะกระทบเขาเท่าไร**

**ข้อ 3 — ผิดในทางที่อันตรายที่สุด**

`"ถ้าเราจ่ายครบตามกำหนด ที่ดินก็เป็นของเราเหมือนเดิม"`

ประโยคนี้ถูกต้องตามตัวอักษร แต่ **พูดแต่ด้านบวก และไม่ได้บอกด้านที่ลูกค้าต้องรู้จริงๆ**

- ถ้าจ่ายไม่ครบจะเกิดอะไร — ไม่ได้บอก
- **ถ้าบังคับขายแล้วได้ไม่พอ ลูกค้ายังต้องรับผิดชอบส่วนที่เหลือ** — ไม่ได้บอก

**ขั้นตรวจที่ 2 (ตรวจอุปมา)**

`"วงเงินหมุนเวียนก็เหมือนกระเป๋าเงินสำรองของเรา"`

ถามว่า "อุปมานี้ทำให้เข้าใจผิดเรื่องภาระไหม"

**ใช่** — "กระเป๋าเงินสำรองของเรา" ทำให้รู้สึกว่าเป็นเงินของตัวเอง ไม่ใช่หนี้ที่ต้องคืนพร้อมดอกเบี้ย และไม่มีอะไรในอุปมานี้ที่บ่งบอกว่าต้องล้างยอดตามรอบ

**ขั้นตรวจที่ 3 (ทดสอบให้เล่ากลับ)**

ให้ AI เล่นบทเกษตรกรที่ไม่เคยกู้ ฟังคำอธิบายทั้งสามข้อแล้วเล่ากลับ

ได้คำตอบ:

> "เข้าใจว่า ธนาคารให้วงเงินไว้ก้อนหนึ่ง เราหยิบใช้ได้ตามต้องการ มีเงินก็ใส่คืน ไม่มีก็ไม่เป็นไร ใช้ไปเรื่อยๆ
>
> ดอกเบี้ยขึ้นลงได้ แต่คงไม่ต่างกันมาก
>
> ที่ดินเอามาค้ำไว้เฉยๆ ถ้าจ่ายครบก็ได้คืน
>
> ที่ยังไม่เข้าใจ: ต้องจ่ายเมื่อไร เท่าไร"

**การเล่ากลับนี้เผยความเข้าใจผิด 4 จุด**
```
1. "ไม่มีก็ไม่เป็นไร"           → ไม่รู้ว่าต้องล้างยอดตามรอบ
2. "คงไม่ต่างกันมาก"           → ไม่รู้ผลกระทบของดอกเบี้ยที่ขึ้น
3. "เอามาค้ำไว้เฉยๆ"           → ไม่รู้ว่าถูกบังคับขายได้
4. "ไม่เข้าใจว่าต้องจ่ายเมื่อไร" → เรื่องพื้นฐานที่สุดยังไม่ชัด
```

### หลัง — คำอธิบายที่แก้แล้ว

> ### 1️⃣ วงเงินหมุนเวียน
>
> *(พูด)*
>
> "วงเงินหมุนเวียน 3 ล้านนี่ พี่เบิกมาใช้ได้ตามที่ต้องการในช่วงที่ต้องซื้อของ **แต่มีข้อสำคัญอยู่ข้อหนึ่ง**
>
> **ทุกปี พอถึงวันที่ 31 พฤษภาคม พี่ต้องคืนเงินให้ครบทั้งก้อนก่อน** ยอดต้องเป็นศูนย์ แล้วรอบใหม่ค่อยเบิกใหม่ได้
>
> เหตุผลที่ต้องเป็นแบบนี้ เพราะเงินก้อนนี้มีไว้ให้พี่ใช้ซื้อของขายของในรอบปีหนึ่ง พอขายของเสร็จ เงินก็ควรกลับมาแล้ว ถ้ามันไม่กลับมา แปลว่าเงินไปติดอยู่ที่ไหนสักที่ ซึ่งเป็นสัญญาณว่ามีอะไรผิดปกติ
>
> **ถ้าถึงวันที่ 31 พฤษภาคมแล้วยังคืนไม่ครบ** วงเงินนี้จะไม่ต่ออายุให้รอบหน้า และจะกลายเป็นหนี้ค้างที่ต้องจ่ายคืน"
>
> **ตัวอย่างเป็นตัวเลข:**
> ```
> พ.ย.  เบิก 1.5 ล้าน ไปซื้อของ
> ธ.ค.  เบิกเพิ่ม 1 ล้าน  (ใช้ไป 2.5 ล้าน เหลือวงเงิน 5 แสน)
> ก.พ.  ขายของได้ คืน 1.5 ล้าน  (เหลือหนี้ 1 ล้าน)
> เม.ย. คืนอีก 1 ล้าน  (ยอดเป็นศูนย์ ✓)
> 31 พ.ค. — ยอดต้องเป็นศูนย์ ✓ ผ่าน
> มิ.ย.  รอบใหม่เริ่ม เบิกได้อีก
> ```
>
> ⚠️ **ห้ามใช้อุปมา "กระเป๋าเงินสำรอง"**
>
> ---
> ### 2️⃣ ดอกเบี้ยลอยตัว
>
> *(พูด)*
>
> "ดอกเบี้ยที่พี่จ่าย ไม่ได้ตายตัวตลอดสัญญา ธนาคารประกาศอัตราใหม่เป็นระยะ ถ้าอัตราขึ้น ดอกที่พี่จ่ายก็ขึ้นตาม ถ้าลง ก็ลงตาม
>
> **สิ่งที่พี่ต้องรู้คือ ถ้าดอกขึ้น งวดที่พี่ต้องจ่ายจะเป็นเท่าไร**"
>
> **ตัวอย่างเป็นตัวเลขของเขาเอง:**
> ```
> ตอนนี้ผ่อนเดือนละ            12,000 บาท
> ถ้าดอกเบี้ยขึ้น 1%  → เดือนละ 12,800 บาท  (+800)
> ถ้าดอกเบี้ยขึ้น 2%  → เดือนละ 13,600 บาท  (+1,600)
> ```
>
> *(พูดต่อ)*
>
> "ปีละ 800 บาท อาจฟังดูไม่เยอะ แต่ถ้าขึ้น 2% ก็ประมาณเดือนละพันหก ปีหนึ่งเกือบสองหมื่น พี่ลองคิดดูว่ารับได้ไหม
>
> ผมแนะนำว่าเวลาวางแผน ให้คิดเผื่อไว้ว่าอาจต้องจ่ายเดือนละหมื่นสาม ไม่ใช่หมื่นสอง"
>
> ---
> ### 3️⃣ หลักประกัน
>
> *(พูด — ข้อนี้ต้องพูดให้ครบ แม้จะฟังดูหนัก)*
>
> "ที่ดินแปลงนี้ที่พี่เอามาเป็นหลักประกัน ผมต้องอธิบายให้ครบทั้งสองด้านนะครับ
>
> **ด้านที่หนึ่ง** ตราบใดที่พี่จ่ายตามกำหนด ที่ดินยังเป็นของพี่ ทำกินได้ตามปกติ ธนาคารแค่จดจำนองไว้ พี่แค่ขายหรือโอนไม่ได้จนกว่าจะปลดจำนอง
>
> **ด้านที่สอง — อันนี้สำคัญ ต้องบอกให้ชัด**
>
> ถ้าถึงจุดที่พี่จ่ายไม่ได้จริงๆ และแก้ปัญหากันไม่ได้แล้ว ธนาคารมีสิทธิ์บังคับขายที่ดินแปลงนี้เพื่อเอาเงินมาใช้หนี้
>
> **และถ้าขายได้ไม่พอกับหนี้ที่ค้างอยู่ ส่วนที่ขาด พี่ยังต้องรับผิดชอบอยู่**
>
> คือไม่ใช่ว่ายึดที่ไปแล้วจบนะครับ ถ้าที่ขายได้ 2 ล้าน แต่หนี้ 2.5 ล้าน ส่วนที่เหลือ 5 แสน พี่ยังเป็นหนี้อยู่"
>
> *(พูดต่อ)*
>
> "ผมบอกเรื่องนี้ไม่ได้ขู่นะครับ แต่ผมอยากให้พี่รู้ทั้งหมดก่อนตัดสินใจ **และถ้าวันไหนพี่เริ่มรู้สึกว่าจะจ่ายไม่ไหว ให้บอกผมเร็วที่สุด** เพราะยิ่งบอกเร็ว ทางแก้ยิ่งเยอะ ถ้าปล่อยจนค้างหลายงวด ทางเลือกจะเหลือน้อยลงมาก"
>
> ⚠️ **ห้ามใช้อุปมา "ของฝากไว้"**

### เอกสารสรุปที่ให้ลูกค้ากลับไป (1 หน้า)

> ```

### ทดสอบซ้ำ — ให้เล่ากลับอีกครั้ง

> "เข้าใจว่า ได้วงเงิน 3 ล้าน เบิกใช้ได้ **แต่ทุกปีพอถึงสิ้นเดือนพฤษภาคมต้องคืนให้หมดก่อน** ถ้าคืนไม่หมดปีหน้าจะไม่ได้ใช้อีก
>
> ดอกเบี้ยตอนนี้เดือนละหมื่นสอง แต่มันขึ้นได้ ควรเผื่อไว้ว่าอาจเป็นหมื่นสาม
>
> ที่ดินที่เอามาค้ำ **ถ้าจ่ายไม่ไหวจนถูกขาย แล้วขายได้ไม่พอ ก็ยังเป็นหนี้ส่วนที่เหลืออยู่**
>
> แล้วต้องส่งเอกสารทุกสามเดือน
>
> ถ้ามีปัญหาให้โทรบอกเร็วๆ"

**ครบทุกประเด็นสำคัญ และไม่มีความเข้าใจผิดที่พบในรอบแรก**

### สิ่งที่เปลี่ยนไป

| | คำอธิบายแรก | คำอธิบายที่แก้ |
|---|---|---|
| เงื่อนไขล้างยอด 31 พ.ค. | **ไม่ได้บอกเลย** | บอกชัด + ตัวอย่างตัวเลข |
| ผลของดอกเบี้ยที่ขึ้น | "ขึ้นลงได้" | ตัวเลขจริงของเขา 3 ระดับ |
| ด้านลบของหลักประกัน | ไม่ได้บอก | บอกครบ รวมส่วนที่ขายไม่พอ |
| อุปมาที่ทำให้เข้าใจผิด | 2 จุด | 0 |
| ความเข้าใจผิดจากการเล่ากลับ | 4 จุด | 0 |
| เอกสารให้กลับไปอ่าน | ไม่มี | 1 หน้า |
| ความยาว | สั้นมาก | ยาวกว่า แต่ครบ |

### บทเรียนจากเคสนี้

**คำอธิบายที่แก้แล้วยาวกว่าและฟังดูหนักกว่า** โดยเฉพาะข้อ 3 ที่ต้องบอกว่าถ้าขายหลักประกันไม่พอ ลูกค้ายังเป็นหนี้อยู่

มีแรงกดดันตามธรรมชาติที่จะไม่พูดเรื่องนี้ เพราะมันทำให้บรรยากาศไม่ดี และเพราะลูกค้าอาจลังเล

**แต่การไม่พูดคือการโยนปัญหาไปให้ตัวเราในอนาคต** — ในวันที่ลูกค้ามีปัญหาและบอกว่า "ไม่มีใครบอกผมเลย"

> **หน้าที่ของเราไม่ใช่ทำให้ลูกค้ารู้สึกดีในวันที่เซ็นสัญญา แต่คือทำให้เขาตัดสินใจโดยรู้ทั้งหมด**

**เวลาที่ใช้เตรียมและทดสอบ: 40 นาที**

```

เรื่องที่ต้องอธิบาย: [ศัพท์/เงื่อนไข]

**ความหมายที่ถูกต้องตามสัญญาของเรา (ต้องยึดตามนี้เท่านั้น
ห้ามใช้ความรู้ทั่วไปเกี่ยวกับผลิตภัณฑ์ธนาคาร):**
- [เขียนเงื่อนไขจริงให้ครบ]
- [รวมเงื่อนไขที่ลูกค้าต้องทำ และผลถ้าไม่ทำ]

ลูกค้า:
- อาชีพ: [...]
- ความคุ้นเคยกับเรื่องการเงิน: [ไม่เคยกู้มาก่อน / เคยกู้แล้ว]
- ภาษาที่ใช้: [...]

ตัวเลขจริงของเคสนี้ (ปัดแล้ว): [...]

**สิ่งที่ถ้าลูกค้าเข้าใจผิดจะเกิดปัญหา (สำคัญที่สุด
ต้องอธิบายให้ครบทุกข้อ):**
1. [...]
2. [...]

สิ่งที่ต้องการ:

**A. คำอธิบาย 2-3 แบบ** ที่ต่างกันที่วิธีอธิบาย

**B. สำหรับแต่ละแบบ ต้องบอกด้วยว่า:**
- **ถ้าลูกค้าเชื่อคำอธิบายนี้ 100% เขาจะเข้าใจผิดเรื่องอะไรได้บ้าง**
- มีเงื่อนไขไหนที่ถูกตัดออกเพื่อให้ง่ายขึ้น

**C. ตัวอย่างตัวเลข**
ใช้ตัวเลขจริงของเคสนี้ แสดงให้เห็นผลในหลายสถานการณ์

- สิ่งที่ต้องทำ พร้อมกำหนดเวลา
- สิ่งที่ต้องระวัง
- ใช้ภาษาเดียวกับที่อธิบาย ไม่ใช่ภาษาสัญญา

- **ต้องอธิบายด้านลบด้วย** ไม่ใช่เฉพาะด้านบวก
  โดยเฉพาะ: ถ้าจ่ายไม่ได้จะเกิดอะไร
