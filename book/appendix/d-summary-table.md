
## หลักตรวจ 6 ข้อ (บทที่ 3)

| # | หลัก | ประโยคที่ต้องจำ |
|---|---|---|
| 1 | ห้ามใช้ในเรื่องที่ไม่รู้เลย | ขอบเขตการใช้ = ขอบเขตความรู้ |
| 2 | ตัวเลขทุกตัวตรวจเอง | **ผิดจุดเดียว สงสัยทั้งชุด** |
| 3 | ขอที่มา แล้วไปดูของจริง | **เปิดไม่เจอ = ไม่มี** |
| 4 | ถามซ้ำแบบกลับด้าน | ถ้าพลิกง่าย แสดงว่าเดิมก็ไม่มั่น |
| 5 | ป้อนข้อมูลเอง | ของจริงตรงหน้า ดีกว่าความจำของมัน |
| 6 | ชื่อเราเซ็น = รับผิดชอบ 100% | **"AI เขียนมา" ไม่ใช่คำแก้ตัว** |

**ถ้าจำหกข้อไม่ไหว จำสองข้อพอ: ข้อ 5 และ ข้อ 6** — สองข้อนี้ลากอีกสี่ข้อตามมาเอง

## เวลาที่ใช้จริงต่อสัปดาห์ (ประมาณการ)

สำหรับ RM ที่ใช้ AI กับงานในเล่มนี้อย่างครบถ้วน

```
เวลาที่ประหยัดได้จากการร่าง      ~8-12 ชั่วโมง/สัปดาห์
เวลาที่เพิ่มขึ้นจากการตรวจ        ~3-5 ชั่วโมง/สัปดาห์
                               ─────────────────────
กำไรสุทธิ                       ~5-7 ชั่วโมง/สัปดาห์
```

**และกำไรนี้จะกลายเป็นขาดทุนทันทีถ้าข้ามขั้นตอนตรวจ** เพราะความผิดพลาดที่หลุดออกไปหนึ่งครั้ง กินเวลาแก้มากกว่าเวลาตรวจทั้งเดือน

## หน้าสุดท้าย

> **มั่นใจใน AI ไม่ได้ ต้องมั่นใจในวิธีตรวจของตัวเอง**

```
เครื่องมือเปลี่ยน       → วิธีตรวจไม่เปลี่ยน
รุ่นใหม่เก่งขึ้น        → ความรับผิดชอบยังเป็นของเรา
งานเร็วขึ้น           → ไม่ได้แปลว่าถูกขึ้น
```

**สิ่งเดียวที่ควรสะสม: บันทึกจุดพลาด**
