# ภาคผนวก ก — Prompt ตั้งต้น 31 งาน

> **วิธีใช้:** ภาคผนวกนี้เป็น **ดัชนี** ชี้ไปยัง prompt ฉบับเต็มในแต่ละบท พร้อมสรุปข้อห้ามสำคัญและสัญญาณเตือนของแต่ละงาน
>
> **อย่าลอกไปใช้ทั้งดุ้น** — ใช้เป็นจุดตั้งต้น แล้วปรับข้อห้ามตามบันทึกจุดพลาดของตัวเอง (บทที่ 38–39)

---

## โครง prompt กลาง (ใช้ได้กับทุกงาน)

```
บทบาท: [ผู้ช่วย...]

บริบท:
- สถานการณ์: [...]
- ผู้รับ/ผู้อ่าน: [...]
- ข้อจำกัด: [...]
- สิ่งที่ฉันรู้อยู่แล้ว ไม่ต้องบอกซ้ำ: [...]

ข้อมูล:
[วางของจริง]

สิ่งที่ต้องการ:
[อธิบายให้ชัด]

รูปแบบ:
- [โครงสร้าง / ความยาว / สิ่งที่ต้องมีในทุกข้อ]

ข้อห้าม:
- ห้ามเพิ่มข้อมูลที่ไม่มีในสิ่งที่ให้ไป
- ถ้าข้อมูลไม่พอ ให้ระบุว่าไม่พอ ห้ามเดา
- ห้ามอ้างระเบียบหรือเอกสารที่ฉันไม่ได้ให้
- [ข้อห้ามเฉพาะงาน]

ท้ายผลลัพธ์ ให้ระบุ:
A. จุดที่ข้อมูลที่ฉันให้ไม่เพียงพอ
B. จุดที่คุณไม่มั่นใจ
C. สิ่งที่ฉันควรตรวจเป็นอันดับแรก
```

**สามบรรทัดท้าย (A–B–C) ใช้เวลาพิมพ์ 15 วินาที และควรมีในทุก prompt**

## ข้อห้ามมาตรฐาน — เลือกใช้ตามงาน

```
【 ข้อมูล 】
□ ห้ามเพิ่มข้อมูล ตัวเลข หรือเหตุผลที่ไม่มีในสิ่งที่ให้ไป
□ ถ้าข้อมูลไม่พอ ให้ระบุว่าไม่พอ ห้ามเดา
□ ห้ามอ้างระเบียบ ประกาศ กฎหมาย หรือเอกสารที่ฉันไม่ได้ให้
□ ห้ามใส่ความรู้ทั่วไปเกี่ยวกับอุตสาหกรรมนี้

【 ตัวเลข 】
□ ทุกตัวเลขต้องระบุที่มา
□ ตัวเลขที่เป็นช่วง ต้องคงเป็นช่วง ห้ามทำเป็นค่าเดียว
□ ห้ามคำนวณตัวเลขใหม่ที่ไม่ได้ขอ
□ เปอร์เซ็นต์ต้องมีตัวเลขดิบกำกับ เช่น "35% (7 จาก 20 ราย)"
□ ห้ามเทียบกับค่าเฉลี่ยอุตสาหกรรมใดๆ

【 ภาษา 】
□ ห้ามใช้ "มีศักยภาพ" "มีแนวโน้มที่ดี" "อย่างมีนัยสำคัญ"
  "มีความสัมพันธ์ที่ดี" โดยไม่มีตัวเลขในบรรทัดเดียวกัน
□ ห้ามเปลี่ยน "ควร" เป็น "ต้อง" หรือกลับกัน
□ ห้ามรวบความเห็นต่างเป็นข้อสรุปเดียว
□ ห้ามใช้ภาษาราชการเมื่อสั่งให้เขียนภาษาพูด

【 ขอบเขต 】
□ ห้ามให้ข้อสรุปหรือข้อเสนอแนะ ถ้าฉันขอแค่ข้อเท็จจริง
□ ห้ามตัดสินใจแทนฉัน
□ ห้ามเสนอชื่อผลิตภัณฑ์ของธนาคาร
□ ห้ามระบุมูลค่า ราคา หรือเกณฑ์วงเงิน
```

# ภาค 3 — งาน RM ธ.ก.ส.

> ⚠️ **ทุกงานในภาคนี้ใช้เครื่องมือในระบบองค์กรเท่านั้น** เว้นแต่ระบุว่าใช้ข้อมูลที่ปิดชื่อและปัดตัวเลขแล้ว

## 20. Call Report → [บทที่ 20](../part3/ch20-call-report.md#8-prompt-ตั้งต้น)

**โครงสำคัญ:** จดโน้ตด้วยสัญลักษณ์ `[พูด] [เห็น] [คิด] [?] [ทำ]`

**ข้อห้ามที่ขาดไม่ได้**
```
□ ข้อมูลจาก [พูด] ต้องขึ้นต้นด้วย "ลูกค้าแจ้งว่า" ทุกข้อ
□ ตัวเลขที่เป็นช่วง ต้องคงเป็นช่วง
□ ห้ามคำนวณตัวเลขใหม่ที่ไม่มีในโน้ต
□ ห้ามใส่ความรู้ทั่วไปเกี่ยวกับธุรกิจประเภทนี้
□ ห้ามตัด [คิด] และ [?] ออก
□ ห้ามใช้ "มีศักยภาพ" "มีแนวโน้มที่ดี" "มีความสัมพันธ์ที่ดี"
```

## 21. อ่านงบการเงิน → [บทที่ 21](../part3/ch21-financial-statements.md#8-prompt-ตั้งต้น)

## 24. Credit Memo → [บทที่ 24](../part3/ch24-credit-memo.md#8-prompt-ตั้งต้น)

```

```
**ต้องขอรายงาน:** ประโยคที่ไม่มีหลักฐาน · ความยาวส่วนจุดแข็ง vs ความเสี่ยง · ความเสี่ยงที่ไม่มีเงื่อนไขรองรับ
