## ฉบับที่ 2 — แบบตาราง (ใช้ในไฟล์)

> สร้างเป็นไฟล์เดียวในเครื่ององค์กร แล้วเติมไปเรื่อยๆ

| วันที่ | งาน | AI พลาดอะไร | ★ เราจับได้อย่างไร | ป้องกันครั้งหน้า | เสียหาย | แก้ prompt แล้ว |
|---|---|---|---|---|---|---|
| | | | | | | |
| | | | | | | |
| | | | | | | |

### คอลัมน์เพิ่มเติมถ้าทำในตารางคำนวณ

```
- ประเภทความผิดพลาด  (เติมข้อมูล / คำนวณผิด / ตีความผิด /
                      อ่านผิด / ภาษา / ขอบเขต)
- กลุ่ม               (A: แก้ prompt ได้ / B: ต้องตรวจถาวร / C: เลิกใช้)
- เกิดซ้ำครั้งที่       (นับว่าความผิดพลาดแบบนี้เกิดกี่ครั้งแล้ว)
```

**คอลัมน์ "เกิดซ้ำครั้งที่" มีค่ามาก** — พอถึงครั้งที่ 3 ก็รู้ทันทีว่านี่คือนิสัยของเครื่องมือ ไม่ใช่ความบังเอิญ

## ฉบับที่ 3 — แบบย่อ (จดเร็วระหว่างทำงาน)

> ใช้เมื่อกำลังรีบ แล้วค่อยมาขยายทีหลัง

```
[วันที่] [งาน] — พลาด: ___ | จับได้โดย: ___ | แก้: ___
```

*ตัวอย่าง*
```
3 ก.ย. สรุปประชุม — พลาด: เปลี่ยนข้อเสนอเป็นมติ | จับได้โดย: ค้นคำว่า "มติ" ย้อนหาในโน้ต | แก้: เพิ่มข้อห้าม
```

**30 วินาทีต่อครั้ง** — และมีค่ากว่าการตั้งใจจะเขียนละเอียดแล้วไม่ได้เขียนเลย

## แบบฟอร์มร่วมของทีม (บทที่ 40)

> ไฟล์เดียว ทุกคนเติมได้ ทบทวนร่วมกันทุกเดือน

| วันที่ | ผู้บันทึก | งาน | AI พลาดอะไร | จับได้อย่างไร | ป้องกัน | ทีมรับทราบ |
|---|---|---|---|---|---|---|
| | | | | | | ✓ |

### กติกาของไฟล์ร่วม

```
□ ทุกคนเติมได้ ไม่ต้องขออนุญาต
□ ห้ามใส่ชื่อลูกค้าหรือข้อมูลที่ระบุตัวได้
□ ห้ามใช้ไฟล์นี้ในการประเมินผลงานใคร
□ การบันทึกจุดพลาดของตัวเอง = การช่วยทีม ไม่ใช่การยอมรับความผิด
□ ทบทวนร่วมกันทุกเดือน 1 ชั่วโมง
```

**กติกาข้อที่สามสำคัญที่สุด** — ถ้าไฟล์นี้ถูกใช้ประเมินคน จะไม่มีใครบันทึกอะไรอีก และทีมจะเสียเครื่องมือที่มีค่าที่สุดไป

## ตัวอย่างบันทึกที่กรอกแล้ว

| วันที่ | งาน | AI พลาดอะไร | ★ จับได้อย่างไร | ป้องกัน | เสียหาย |
|---|---|---|---|---|---|
| 3 ก.ย. | สรุปประชุม | เขียนว่า "ที่ประชุมมีมติให้เลื่อน" ทั้งที่โน้ตเขียนว่า "มีผู้เสนอให้เลื่อน" | ค้นคำว่า "มติ" ทุกจุด ย้อนหาในโน้ต — ไม่มีคำนี้ในโน้ตเลย | ข้อห้าม: ห้ามใช้คำว่ามติเว้นแต่ระบุชัดในโน้ต | ปานกลาง |
| 18 ก.ย. | สูตร Excel | สูตรอ้าง A2:A1000 แต่ข้อมูลมี 1,847 แถว → 847 แถวไม่ถูกนับ ไม่มี error | เทียบผลรวมตารางสรุปกับ SUM ข้อมูลดิบ ต่าง 26% | (1) อ้างทั้งคอลัมน์เสมอ (2) ใส่เซลล์ตรวจสอบถาวรในไฟล์ | มาก |
| 24 ก.ย. | วิเคราะห์งบ | เทียบกำไรขั้นต้นกับค่าเฉลี่ย "อุตสาหกรรม" ที่ไม่ใช่ sector เดียวกัน และไม่มีแหล่ง | สงสัยตัวเลข benchmark เลยถามหาแหล่ง → ไม่มี | ข้อห้าม: ห้ามเทียบกับค่าเฉลี่ยอุตสาหกรรมใดๆ | มาก |
| 9 ต.ค. | DSCR | ไม่หักเงินถอนเจ้าของ → DSCR สูงกว่าจริง 44% | ไล่ checklist รายการหัก 7 ข้อ | ใส่รายการหักครบใน input + ทำ checklist ติดโต๊ะ | มาก |
| 15 ต.ค. | สรุปประชุม | ตัดข้อท้วงติงออก เหลือแต่ข้อเสนอ | นึกย้อนว่าในห้องมีใครค้าน → ไม่มีในสรุป | **เกิดซ้ำกลุ่มเดียวกับ 3 ก.ย.** → ขั้นตรวจถาวร: "ในห้องมีใครเห็นต่างบ้าง และอยู่ในสรุปไหม" | ปานกลาง |

## เริ่มวันนี้

```
□ สร้างไฟล์ "บันทึกจุดพลาด" ในเครื่ององค์กร
□ ใส่หัวตาราง 5 ช่อง
□ ย้อนนึกความผิดพลาดที่จำได้ในเดือนที่ผ่านมา กรอก 3 แถว
□ ตั้งเตือนในปฏิทิน: ทบทวน 30 นาที ทุกสิ้นเดือน
```

> **บันทึกที่มี 5 แถวและได้ใช้จริง มีค่ากว่าระบบที่สมบูรณ์แบบที่ยังไม่ได้เริ่ม**
