# ภาคผนวก ข — Checklist ตรวจ 31 งาน (ฉบับพกพา)

> **วิธีใช้:** 1 งาน ไม่เกิน 5 ข้อ ติ๊กได้ใน 3 นาที
>
> **รหัสสี**
> 🔵 **ตรวจก่อนใช้** — ทำก่อนเริ่มสั่งงาน
> 🟠 **ตรวจก่อนส่ง** — ทำก่อนงานออกจากมือเรา
> 🔴 **ตรวจก่อนเซ็น** — ทำก่อนเอาชื่อเราไปผูก
>
> พิมพ์หน้านี้ออกมาแปะไว้ที่โต๊ะ หรือถ่ายรูปเก็บในมือถือ

## ⚡ checklist ที่ใช้ได้กับทุกงาน (30 วินาที)

```
🔵 ก่อนกด Enter — ข้อมูล
□ 1. มีชื่อคน เลขบัตร เลขบัญชี เลขสัญญา ที่อยู่ หลงเหลืออยู่ไหม
□ 2. ปิดชื่อแล้ว ข้อมูลที่เหลือยังระบุตัวได้อยู่ไหม
□ 3. เครื่องมือนี้อยู่ในระบบองค์กรหรือนอกระบบ
□ 4. ถ้าข้อความนี้ขึ้นหน้าหนังสือพิมพ์พรุ่งนี้ อธิบายได้ไหม
□ 5. ไฟล์แนบ/รูป เปิดดูทุกหน้าแล้วหรือยัง

🔴 ก่อนเซ็น — ความรับผิดชอบ
□ 1. ถ้าถูกถามว่าตัวเลขนี้มาจากไหน ตอบได้ไหม
□ 2. ถ้าถูกถามว่าทำไมถึงสรุปแบบนี้ อธิบายได้ไหม
□ 3. มีประโยคไหนในเอกสารนี้ที่พิสูจน์ไม่ได้
```

# ภาค 2 — งานออฟฟิศทั่วไป

## บทที่ 6 · สรุปประชุม
```
🔵 □ ได้รับความยินยอมก่อนอัดหรือยัง (ถ้าใช้ไฟล์เสียง)
🟠 □ ไล่คำว่า "มติ/อนุมัติ/เห็นชอบ" ทุกจุด ย้อนหาในโน้ต
🟠 □ ชื่อคนในตารางสิ่งที่ต้องทำ ตรงกับงานไหม
🟠 □ ตัวเลขและวันที่ทุกตัว มีในโน้ตไหม
🟠 □ เรื่องที่พูดสั้นแต่สำคัญ อยู่ในสรุปไหม
```

## บทที่ 7 · ร่างหนังสือ อีเมล
```
🟠 □ อ่านออกเสียง 1 รอบ มีประโยคไหนสะดุด
🟠 □ ชื่อ ตำแหน่ง เลขที่ วันที่ ตัวเลข — ตรวจ 100%
🟠 □ มีข้อมูลหรือเหตุผลที่เราไม่ได้บอกไหม
🟠 □ ตัดคำฟุ่มเฟือยแล้วหรือยัง
🟠 □ คนอ่านรู้ไหมว่าต้องทำอะไร ภายในเมื่อไร
```

## บทที่ 8 · ย่อเอกสารยาว
```
🔵 □ มีเอกสารจริงในมือ (ไม่ใช่ถามลอยๆ)
🟠 □ สุ่มเปิดเทียบ 3 จุด (สำคัญสุด / ชัดเจนสุด / มีตัวเลข)
🟠 □ ถามแล้วว่า "มีข้อยกเว้นอะไรที่สรุปตัดออกไป"
🟠 □ ไล่คำ "ต้อง/ควร" เทียบกับต้นฉบับ
🔴 □ ประเด็นที่จะอ้างต่อ อ่านต้นฉบับจุดนั้นเองแล้ว
```

## บทที่ 9 · แปลงเป็นสไลด์
```
🔵 □ ขอโครงก่อน ยังไม่ทำไฟล์
🟠 □ อ่านชื่อสไลด์เรียงกัน ลำดับตรงกับที่จะพูดไหม
🟠 □ ตัวเลขบนสไลด์ทุกตัว เทียบต้นทางแล้ว
🟠 □ แผ่นไหนเกิน 5 บรรทัด
🟠 □ เปิดดูบนจอจริงแล้ว
```

## บทที่ 10 · งาน Excel
```
🔵 □ บอกโครงตาราง + ตัวอย่างที่มีแถวปัญหาแล้ว
🟠 □ ทดสอบ 3 แถว: ปกติ / สุดขั้ว / ค่าว่าง
🟠 □ ผลรวม pivot = ผลรวมข้อมูลดิบ
🟠 □ ล้างข้อมูล: นับแถวก่อน-หลัง หายกี่แถว เพราะอะไร
🟠 □ เลื่อนดูแถวสุดท้าย สูตรครอบคลุมครบไหม
```

## บทที่ 11 · หา pattern
```
🔵 □ ตั้งคำถามก่อนโยนข้อมูลแล้ว
🟠 □ ทุก pattern ดูแล้วว่ามาจากกี่แถว (< 10 แถว = ตัด)
🟠 □ ทุกเปอร์เซ็นต์ตรวจฐานแล้ว
🟠 □ ถามแล้วว่า "อาจเกิดจากอะไรอื่นได้บ้าง"
🟠 □ แบ่งข้อมูลครึ่งหนึ่งแล้วถามใหม่ — pattern ยังอยู่ไหม
```

## บทที่ 12 · dashboard / กราฟ
```
🟠 □ แกน Y ของกราฟแท่ง เริ่มที่ 0
🟠 □ สุ่มอ่านค่าจากกราฟ 2-3 จุด เทียบตาราง
🟠 □ กราฟที่วางคู่กัน สเกลเท่ากันไหม
🟠 □ มอง 5 วินาทีแล้วได้คำตอบไหม
🟠 □ ค่าที่หายไป วาดเป็น 0 หรือเว้นว่าง
```

## บทที่ 13 · เขียนข้อความยาก
```
🔵 □ ระบุสิ่งที่เสนอได้ / เสนอไม่ได้ ใน input แล้ว
🟠 □ อ่านในบทบาทคนรับ — เขารู้ไหมว่าคำตอบคืออะไร
🟠 □ ไล่คำ "จะ/ได้/รับรอง/ดำเนินการให้" — ผูกมัดอะไรบ้าง
🟠 □ ไม่ได้อ้างระเบียบหรือนโยบายที่ไม่มีจริง
🟠 □ ทิ้งไว้ 10 นาทีแล้วอ่านใหม่
```

## บทที่ 14 · หาข้อมูล / วิจัย
```
🔵 □ ใช้โหมดแผนที่ (ขอประเด็นและคำถาม ไม่ใช่คำตอบ)
🟠 □ ขีดเส้นใต้ทุกตัวเลข ชื่อ วันที่ — มีแหล่งที่เปิดดูได้ไหม
🟠 □ เปิดลิงก์ทุกลิงก์ เนื้อหาข้างในตรงกับที่สรุปไหม
🟠 □ ข้อมูลเป็นของปีไหน (ไม่ใช่ปีที่เผยแพร่)
🔴 □ แยกเป็น 3 กอง: พูดได้ / ถามได้ / ไม่พูด
```

## บทที่ 15 · ตรวจทานภาษา
```
🔵 □ สั่งทีละรอบ รอบละด้าน + ให้รายการศัพท์ที่ห้ามเปลี่ยน
🟠 □ ทุกจุดที่ AI ชี้ — เราตัดสินเองว่าผิดจริงไหม
🟠 □ ตัวเลขที่ขัดกัน — กลับไปที่แหล่งต้นทาง อย่าเดา
🟠 □ ถ้าให้แก้ ต้องเทียบก่อน-หลังทุกจุด
🟠 □ ตรวจเองเพิ่ม: ชื่อบนหน้าปก / ปีที่อ้าง / สิ่งที่ขาดหาย
```

## บทที่ 16 · ทำ SOP / checklist
```
🔵 □ เล่างานที่ทำจริง ไม่ใช่งานที่ควรทำ
🟠 □ ทุกขั้นตอบได้ว่า "ถ้าข้ามจะเกิดอะไร"
🟠 □ หาขั้นที่ AI เติมเอง ("จัดทำรายงานสรุป...")
🟠 □ เทียบกับระเบียบจริง (อำนาจ / เอกสาร / เวลา)
🔴 □ ให้คนที่ไม่รู้งานลองทำตาม 1 รอบ
```

## บทที่ 17 · จัดลำดับงาน
```
🔵 □ ใส่ "ผลกระทบถ้าช้า" ทุกงาน ไม่ใช่แค่ deadline
🟠 □ ดูงาน 3 อันดับสุดท้าย มีอันไหนที่จริงๆ สำคัญ
🟠 □ อธิบายลำดับให้หัวหน้าฟังได้ในประโยคเดียว
🟠 □ เวลารวมไม่เกิน 70% ของเวลาว่าง
🟠 □ ถามหางานที่ลืมใส่
```

## บทที่ 18 · ซ้อมนำเสนอ
```
🔵 □ เขียนบทบาทผู้ฟังละเอียด 5-6 ข้อ
🟠 □ คำถามที่ได้ เหมือนที่คนจริงเคยถามไหม
🟠 □ ตอบทุกข้อออกเสียงจริง — ตอบไม่ได้กี่ข้อ (3+ = เลื่อน)
🟠 □ ตอบไม่ได้ → หาข้อมูล ไม่ใช่แก้คำตอบ
🟠 □ ซ้อมคำถามที่ไม่เกี่ยวกับเนื้อหาด้วย
```

## บทที่ 19 · แปลไทย-อังกฤษ
```
🔵 □ ให้รายการศัพท์เฉพาะที่องค์กรใช้แล้ว
🟠 □ แปลกลับ ในบทสนทนาใหม่ แล้วเทียบต้นฉบับ
🟠 □ ตัวเลข หน่วย สกุลเงิน วันที่ — โดยเฉพาะ พ.ศ./ค.ศ.
🟠 □ ศัพท์เฉพาะ 5 คำสำคัญ เทียบกับที่องค์กรใช้จริง
🟠 □ ถามว่า "มีจุดไหนที่คุณไม่มั่นใจ / ต้นฉบับกำกวมตรงไหน"
```

# ภาค 3 — งาน RM ธ.ก.ส.

> ⚠️ ทุกงานในภาคนี้ — **เครื่องมือในระบบองค์กรเท่านั้น**

## บทที่ 20 · Call Report
```
🟠 □ ทุกตัวเลขในรายงาน มีในโน้ตไหม
🟠 □ ทุกประโยค "ลูกค้าแจ้งว่า" เป็นสิ่งที่เขาพูดจริง
🟠 □ มีข้อมูลธุรกิจทั่วไปที่ AI เติมเข้ามาไหม
🟠 □ น้ำเสียงตรงกับที่รู้สึกหน้างานไหม (บวกเกินไหม)
🔴 □ เรื่องติดตามครบ มีใคร/อะไร/เมื่อไร
```

## บทที่ 21 · อ่านงบการเงิน
```
🔵 □ พิมพ์ตัวเลขเอง ไม่ใช่ให้อ่านจากรูป
🟠 □ งบดุลต้องดุลทุกปี (ถ้าไม่ดุล หยุด)
🟠 □ คำนวณอัตราส่วนหลัก 3 ตัวด้วยมือซ้ำ
🟠 □ ทุกข้อสังเกต ให้ชี้บรรทัดในงบ แล้วเปิดดูเอง
🔴 □ ถามคำอธิบายทางเลือกเรื่องฤดูกาล + benchmark ที่ใช้ไม่ได้
```

## บทที่ 22 · อ่าน statement
```
🟠 □ รวมยอดเข้า-ออกเองซ้ำ ตรงกับที่สรุปไหม
🔴 □ ไล่รายการเข้าก้อนใหญ่ทุกรายการ — มาจากไหน
🔴 □ หักโอนระหว่างบัญชีตัวเอง / เงินกู้ / ที่ไม่ทราบที่มา ออกแล้ว
🟠 □ ทุก red flag เปิด statement ดูรายการจริง
🟠 □ เทียบ 3 ทาง: statement / ลูกค้าเล่า / งบ
```

## บทที่ 23 · DSCR / stress test
```
🟠 □ คำนวณ base case ด้วยมือซ้ำ 1 รอบ
🔴 □ หักครบไหม: ภาษี / เงินถอนเจ้าของ / หนี้ทุกสัญญา / หนี้ที่อื่น
🟠 □ ทุกช่องในตารางมีสูตรและการแทนค่า
🔴 □ stress: ราคาลง X% แล้วกำไรลงมากกว่า X% ไหม (ถ้าเท่ากัน = ผิด)
🟠 □ ตัวแปรที่เกี่ยวกันขยับตามหรือไม่ + จุดที่ DSCR = 1
```

## บทที่ 24 · Credit Memo
```
🔴 □ ทุกตัวเลข ย้อนไปหาต้นทางได้
🔴 □ ทุกข้อสรุป มีหลักฐานในย่อหน้าก่อนหน้า
🟠 □ อ่านในบทบาทผู้อนุมัติ — จุดไหนจะถูกถาม
🔴 □ ตัดประโยคที่ "ฟังดูดี" แต่พิสูจน์ไม่ได้
🔴 □ ความยาวส่วนความเสี่ยง เทียบกับส่วนจุดแข็ง
```

## บทที่ 25 · โครงสร้างวงเงิน
```
🔴 □ เทียบกับระเบียบผลิตภัณฑ์จริงทุกข้อ
🟠 □ คำนวณจากช่วงฤดูกาล ไม่ใช่ค่าเฉลี่ยทั้งปี
🟠 □ วงเงินที่เสนอ ÷ ความต้องการ ≤ 1.2
🟠 □ ตารางชำระไม่ตรงกับเดือนที่เงินตึง
🔴 □ ทุกเงื่อนไข: ใครตรวจ / ตรวจอย่างไร / ไม่ทำแล้วเกิดอะไร
```

## บทที่ 26 · คำถามก่อน site visit
```
🔵 □ ป้อนข้อสงสัยจากเอกสารพร้อมตัวเลขแล้ว
🟠 □ คำถามเจาะเคสนี้ ไม่ใช่ใช้กับใครก็ได้
🟠 □ อ่านออกเสียง — เป็นภาษาที่เราพูดจริงไหม
🟠 □ เรียงใหม่ตามลำดับที่จะเดินจริง (อ่อนไหวไว้ท้าย)
🟠 □ มีรายการ "สิ่งที่ต้องดูด้วยตา" และ "คำถามกับคนอื่น"
```

## บทที่ 27 · Checklist หลักประกัน
```
🔴 □ เทียบกับระเบียบประเมินจริง (ประเภทเอกสารสิทธิ์ / เกณฑ์ / อำนาจ)
🔴 □ ตรวจภาระผูกพันหลังโฉนดทุกหน้า + ตรวจกับสำนักงานที่ดิน
🔴 □ (สต็อก) ตรวจว่าเป็นของลูกค้าจริง + ไม่ได้ค้ำซ้ำ
🟠 □ วิธีนับ/ชั่ง/วัด ทำได้จริงในเวลาที่มี
🔴 □ ลบทุกตัวเลขมูลค่าที่ AI ให้มา
```

## บทที่ 28 · วิเคราะห์ sector
```
🟠 □ ทุกราคาและตัวเลข มีแหล่ง + วันที่ + เงื่อนไข (เช่น ความชื้น)
🔴 □ เทียบกับความรู้พื้นที่ — ทำเครื่องหมาย ✓ ✗ ?
🟠 □ ถามหาปัจจัยที่ไม่ได้พูดถึง + ความเข้าใจผิดที่พบบ่อย
🟠 □ ตรวจว่าใช้ข้อมูลระดับโลกกับตลาดท้องถิ่นไหม
🟠 □ ตรวจนโยบายรัฐกับแหล่งจริง
```

## บทที่ 29 · macro → ลูกค้า
```
🔵 □ ตัวเลขมหภาคหาเอง พร้อมแหล่งและวันที่
🟠 □ ทุกขั้นของห่วงโซ่ระบุ "กี่เดือนถึงจะกระทบ"
🔴 □ แปลงเป็น % ของต้นทุนรวม (< 2% = ไม่ต้องตื่น)
🟠 □ ถามหาด้านที่ลูกค้าอาจได้ประโยชน์
🟠 □ ตรวจว่าลูกค้าปรับตัวได้แค่ไหน + เคยเจอมาก่อนไหม
```

## บทที่ 30 · Early warning
```
🔵 □ AI ทำเกณฑ์เท่านั้น — ไม่ป้อนข้อมูลลูกค้า
🟠 □ 3 อันดับแรก — เราเห็นด้วยจากประสบการณ์ไหม
🔴 □ ลูกค้าที่เราไม่สบายใจแต่คะแนนต่ำ — สัญญาณอะไรที่ไม่ได้ป้อน
🟠 □ ทุกสัญญาณเทียบกับช่วงเดียวกันปีก่อน (ไม่ใช่เดือนก่อน)
🟠 □ จำนวนที่ถูกจัดเป็นเสี่ยงสูง = จำนวนที่เข้าไปดูไหว
```

## บทที่ 31 · ปรับโครงสร้างหนี้
```
🟠 □ คำนวณตารางผ่อนเองซ้ำ 1 scenario
🔴 □ กระแสเงินสดมาจากข้อมูลจริง ไม่ใช่สมมติว่ารายได้จะฟื้น
🔴 □ รวมดอกเบี้ยค้าง + ทุกสัญญา + ภาระที่อื่นแล้ว
🔴 □ เทียบกับระเบียบปรับโครงสร้างจริง + ผลต่อการจัดชั้น
🟠 □ ตารางใหม่สอดคล้องฤดูกาล + เหลือพื้นที่รองรับ 10-15%
```

## บทที่ 32 · บทเจรจา
```
🔵 □ เขียนขอบอำนาจ 3 ระดับให้ชัดใน input
🔴 □ ทุกข้อเสนออยู่ในอำนาจจริง (แยก "ได้" กับ "จะขออนุมัติ")
🟠 □ อ่านออกเสียง — เป็นภาษาที่พูดกับลูกค้ารายนี้จริงไหม
🟠 □ ซ้อมกับ AI ที่เล่นบทลูกค้าแบบยากที่สุด
🟠 □ กำหนดสิ่งที่ต้องได้กลับมา (ตัวเลข + วันที่ + นัดครั้งหน้า)
```

## บทที่ 33 · Red team
```
🔵 □ ป้อนเมโมทั้งฉบับ + บทบาทผู้อนุมัติละเอียด + คำถามที่เคยถูกถาม
🟠 □ คำถามที่ได้ เหมือนที่เคยถูกถามจริงไหม
🔴 □ ตอบทุกข้อออกเสียง — ตอบไม่ได้ 3+ ข้อ = เลื่อนการเสนอ
🔴 □ คำตอบที่ตอบได้ อยู่ในเมโมหรืออยู่ในหัวเรา
🟠 □ ตรวจความสอดคล้องทั้งฉบับ (ตัวเลข / ความเสี่ยง vs เงื่อนไข)
```

## บทที่ 34 · cross-sell
```
🔵 □ ป้อนปัญหาที่ลูกค้าเคยเล่า (ยกคำพูดมาตรงๆ)
🔴 □ ทุกข้อ ตอบได้ไหมว่า "ลูกค้าได้ประโยชน์อะไรจริง" (1 ประโยค)
🔴 □ เทียบกับผลิตภัณฑ์ที่มีจริง + ลูกค้าเข้าเกณฑ์ไหม
🟠 □ ตรวจว่าลูกค้ามีอยู่แล้ว หรือเคยปฏิเสธไปแล้วไหม
🟠 □ จังหวะเวลาเหมาะไหม + เสนอทีละ 1 เรื่อง
```

## บทที่ 35 · แปลศัพท์ให้ลูกค้า
```
🔵 □ ใส่ความหมายที่ถูกต้องตามสัญญาของเรา (ไม่ใช่ความรู้ทั่วไป)
🔴 □ ง่ายแล้วยังถูกไหม — มีเงื่อนไขไหนถูกตัดออก
🔴 □ อุปมาทำให้เข้าใจผิดเรื่องภาระไหม
🔴 □ ทดสอบ: ให้เล่ากลับ + ถามว่า "มีตรงไหนที่เดาเอาเอง"
🟠 □ มีเอกสารสรุป 1 หน้าให้ลูกค้ากลับไปอ่าน
```

## บทที่ 36 · แผนเข้าพบรายสัปดาห์
```
🟠 □ ทุกรายอธิบายเหตุผลได้ในประโยคเดียว (ไม่ใช่ "คะแนนเสี่ยง X")
🔴 □ มีใครที่ควรไปแต่ AI ไม่รู้ (ข้อมูลในหัวเรา)
🟠 □ เวลาเดินทาง ≤ 40% ของเวลาทำงาน
🟠 □ ลูกค้าจะว่างไหม (ฤดูกาล / เวลาในวัน) + โทรนัดแล้ว
🟠 □ สัดส่วน: เสี่ยง ~60% / โอกาส ~25% / ตามรอบ ~15%
```

## 📌 ห้าข้อที่ควรจำถ้าจำอย่างอื่นไม่ไหว

```
1. ตัวเลขทุกตัว ตรวจเอง — ผิดจุดเดียว สงสัยทั้งชุด
2. เปิดไม่เจอ = ไม่มี
3. ป้อนของจริงเอง ดีกว่าให้มันหาเอง
4. ถ้าข้อสรุปพลิกง่ายเมื่อถามกลับด้าน แปลว่าเดิมก็ไม่มั่น
5. ชื่อเราเซ็น = รับผิดชอบ 100%
```
