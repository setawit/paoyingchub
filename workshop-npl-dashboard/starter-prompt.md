# Starter Prompt — สร้าง NPL Dashboard ของสาขาตัวเอง

> **วิธีใช้:** copy ข้อความในกล่องด้านล่างทั้งหมด (ตั้งแต่ "ผมต้องการ..." ถึง "...ไฟล์ลูกค้าจริง")
> วางในหน้าคุยกับ Claude แล้วเติมช่องว่าง `[ ]` ให้ตรงกับไฟล์ข้อมูลของสาขาตัวเองก่อนกดส่ง

---

```
ผมต้องการเครื่องมือ dashboard สำหรับติดตามงานหนี้/NPL ของสาขา ธ.ก.ส.
เป็นไฟล์ HTML ไฟล์เดียว เปิดด้วยการดับเบิลคลิก ไม่ต้องต่ออินเทอร์เน็ต
ไม่ต้องติดตั้งโปรแกรมอะไรเพิ่ม เพราะผมเปิดใช้ในสาขาที่บางทีไม่มีสัญญาณ

สิ่งที่ต้องการให้ทำได้:
1. เลือกไฟล์ Excel หรือ CSV ของสาขาตัวเอง แล้วอ่านข้อมูลเข้ามา
2. หน้าจอให้ผมจับคู่คอลัมน์เอง (เผื่อชื่อคอลัมน์ในไฟล์ผมไม่ตรงกับที่ระบบเดา)
3. แสดงแดชบอร์ดสรุปงานหนี้ พร้อมตัวกรอง "สาขา" และ "ช่วงเวลา"

ไฟล์ของผมมีคอลัมน์ประมาณนี้ (ผมจะเติมชื่อคอลัมน์จริงในไฟล์ผมให้ครบ):
- ชื่อสาขา: [ เติมชื่อคอลัมน์ในไฟล์ผม เช่น "สาขา" ]
- งวดข้อมูล/เดือน: [ เติมชื่อคอลัมน์ เช่น "เดือน" หรือ "งวด" ]
- ชั้นหนี้ปัจจุบัน: [ เติมชื่อคอลัมน์ เช่น "ชั้นหนี้" ]
- ชั้นหนี้งวดก่อน (ถ้ามี): [ เติมชื่อคอลัมน์ หรือเขียนว่า "ไม่มีคอลัมน์นี้" ]
- ยอดหนี้คงเหลือ: [ เติมชื่อคอลัมน์ เช่น "ยอดคงเหลือ" ]
- จำนวนวันค้างชำระ (ถ้ามี): [ เติมชื่อคอลัมน์ หรือเขียนว่า "ไม่มีคอลัมน์นี้" ]
- ยอดชำระในงวด (ถ้ามี): [ เติมชื่อคอลัมน์ หรือเขียนว่า "ไม่มีคอลัมน์นี้" ]
- สถานะปรับโครงสร้างหนี้ (ถ้ามี): [ เติมชื่อคอลัมน์ หรือเขียนว่า "ไม่มีคอลัมน์นี้" ]
- ผู้รับผิดชอบ/พนักงานสินเชื่อ (ถ้ามี): [ เติมชื่อคอลัมน์ หรือเขียนว่า "ไม่มีคอลัมน์นี้" ]

ข้อกำหนดสำคัญที่ต้องทำตามเป๊ะๆ:
- ห้ามใช้ CDN ทุกกรณี — โค้ดทั้งหมดต้องอยู่ในไฟล์ HTML ไฟล์เดียว เปิดได้แม้ไม่มีอินเทอร์เน็ต
- ห้ามใช้ backend / server / ฐานข้อมูลภายนอกใดๆ ทั้งสิ้น
- ห้ามใช้ localStorage หรือ browser storage ใดๆ — ให้ข้อมูลอยู่ในหน่วยความจำระหว่างเปิดหน้าเท่านั้น
- ข้อมูลลูกหนี้ต้องไม่ถูกส่งออกจากเครื่องผมเด็ดขาด (ห้ามยิง API ออกไปที่ไหนทั้งสิ้น)
- ต้องมีปุ่ม "โหลดข้อมูลตัวอย่าง" ในตัว เพื่อให้ผมเช็คได้ว่าตัวเครื่องมือเองปกติหรือไม่
- ถ้าข้อมูลบางคอลัมน์ที่ผมบอกว่า "ไม่มีคอลัมน์นี้" ให้ปิดการแสดงผลเฉพาะส่วนที่เกี่ยวข้อง
  พร้อมข้อความอธิบายว่าขาดคอลัมน์อะไร แทนที่จะทำให้ทั้งหน้าใช้งานไม่ได้

**คำเตือนสำคัญ: ผมจะแนบเฉพาะไฟล์ข้อมูลตัวอย่างที่ปิดบังชื่อลูกค้าจริงแล้วเท่านั้น
ห้ามผมแนบไฟล์ข้อมูลลูกค้าจริงเข้ามาในแชทนี้เด็ดขาด**
```

## หมายเหตุถึง AI ที่มาช่วยซ่อมทีหลัง

Prompt ก้อนนี้จะถูกฝังไว้เป็น HTML comment ท้ายไฟล์ `npl-dashboard.html` เสมอ
เพราะเมื่อผู้ใช้ (ซึ่งเขียนโค้ดไม่เป็น) เจอปัญหา วิธีซ่อมของเขาคือ **"ส่งไฟล์ทั้งอันกลับไปให้ AI พร้อมอาการที่เจอ"**
ถ้ามี prompt เดิมติดไปในไฟล์ด้วย AI ตัวที่มาซ่อมจะเข้าใจเจตนาเดิม โครงสร้างคอลัมน์ และข้อจำกัด (ห้าม CDN, ห้าม backend ฯลฯ) ได้ทันทีโดยไม่ต้องเดาใหม่หรือถามผู้ใช้ซ้ำ
