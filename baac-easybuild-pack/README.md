# BAAC EasyBuild — Copilot Dashboard Pack (v2)

ชุดไฟล์สำหรับ **วางใน GitHub Copilot Chat** เพื่อให้ Copilot เขียนโค้ด
Dashboard HTML ที่สมบูรณ์ออกมาให้ในครั้งเดียว

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ | ต้องแก้ก่อนใช้? |
|------|---------|----------------|
| `00_MASTER_PROMPT.md` | คำสั่งหลัก — บอก Copilot ว่าต้องสร้างอะไร ส่งมอบอะไร | ไม่ต้อง |
| `01_REQUIREMENTS.md` | แบบฟอร์มความต้องการ — **กรอกคำตอบของคุณลงไป** | ✅ ต้องกรอก |
| `02_DESIGN_SPEC.md` | สเปกดีไซน์ BAAC: รหัสสี ฟอนต์ เลย์เอาต์ คอมโพเนนต์ | ไม่ต้อง |
| `03_SECURITY_SPEC.md` | สเปกระบบ Login / Role / Audit Log (แบบ mock ใน prototype) | ไม่ต้อง |
| `04_CODE_CONTRACT.md` | กติกาทางเทคนิค + Checklist ตรวจรับงาน | ไม่ต้อง |

## วิธีใช้ (3 ขั้นตอน)

1. **กรอก** `01_REQUIREMENTS.md` — ตอบคำถามในช่อง `>` ทุกข้อ
   (ข้อไหนไม่รู้ ให้เขียนว่า `ใช้ค่าเริ่มต้น` — Copilot จะใช้ค่า default ที่กำหนดไว้)
2. **วางไฟล์ทั้ง 5 ไฟล์** ลงใน Copilot Chat (แนบไฟล์ หรือ copy เนื้อหาต่อกัน
   โดยเริ่มจาก `00_MASTER_PROMPT.md` เสมอ) แล้วกดส่ง
3. **ตรวจรับงาน** ด้วย Checklist ท้ายไฟล์ `04_CODE_CONTRACT.md`
   ถ้าข้อไหนไม่ผ่าน ให้พิมพ์บอก Copilot ว่า "ข้อ X ใน checklist ยังไม่ผ่าน แก้ให้ด้วย"

## ผลลัพธ์ที่จะได้

ไฟล์ `index.html` ไฟล์เดียว เปิดได้ทันทีด้วยการดับเบิลคลิก (ไม่ต้องติดตั้งอะไร)
ประกอบด้วย หน้า Login, Dashboard พร้อม KPI / กราฟ / ตาราง, Import/Export,
Dark Mode, และ Audit Log ตามสเปก BAAC
