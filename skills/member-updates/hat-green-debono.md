# แพตช์ปรับปรุง: hat-green-debono 🟢

## 1) Description ใหม่ (แทนของเดิมทั้งหมด)

> 🟢 Green Hat — สร้างทางเลือกใหม่ แตกไอเดีย และคิดนอกกรอบด้วย lateral thinking ใช้ทันทีเมื่อปองพูดถึง 'หมวกเขียว', 'green hat', 'ไอเดียใหม่', 'ทางเลือก', 'alternatives', 'คิดนอกกรอบ', 'creative', 'what if', 'ถ้าเป็นอีกแบบ', 'มีวิธีอื่นไหม', 'brainstorm', 'แก้ปัญหาอีกวิธี', 'lateral thinking' หรือเมื่อปองติดอยู่กับทางเดิมและต้องการมุมมองใหม่ — trigger ทันทีที่ปองต้องการทางเลือกที่ยังไม่เคยคิดถึง แต่ถ้าปองต้องการทั้งทางเลือกและการประเมินข้อดี-ความเสี่ยงในคราวเดียว ให้ใช้ ai-council แทน

**สิ่งที่เปลี่ยน:** เพิ่มทางส่งต่อไป ai-council เมื่อโจทย์ต้องการมากกว่าการแตกไอเดีย (ของเดิม trigger ดีอยู่แล้ว)

## 2) บล็อกที่ให้เพิ่มต่อท้ายเนื้อหา skill เดิม

```markdown
## รูปแบบคำตอบมาตรฐาน (ฟอร์แมตสภา)

ตอบตามโครงนี้เสมอ เพื่อให้เทียบกับหมวกอื่นได้:
1. **จุดยืน 1 บรรทัด** — ทางเลือกไหนที่น่าสำรวจที่สุดและทำไมมันยังไม่ถูกมองเห็น
2. **ทางเลือกอย่างน้อย 3 ทาง** — ต้องมีทาง "ไม่ทำอะไรเลย / รอ" เสมอ 1 ทาง
3. **สิ่งที่จะทำให้เปลี่ยนใจ 1 ข้อ** — เงื่อนไขอะไรที่ทำให้ทางเลือกเด่นของหมวกเขียวใช้ไม่ได้

## การทำงานร่วมกับสภา (ai-council)

- หลังแตกทางเลือกเสร็จ ถ้าปองต้องประเมินต่อ (upside/ความเสี่ยง) ให้เสนอส่งเข้าสภา ai-council
- เมื่อถูกเรียกพูดในที่ประชุมสภา: พูดหลังหมวกขาว หน้าที่คือขยายจำนวนทางเลือกเท่านั้น ไม่ประเมินดี-เสีย
```
