## สิ่งที่ระบบใหม่ทำได้

1. **ประชุมสภา** — พูดว่า "ประชุมสภา" หรือ "ขอความเห็นสภา" แล้วประธานจะเลือกองค์ประชุม
   ให้หมวกแต่ละใบพูดตามลำดับ ⚪→🟢→🟡→⚫→🔴→📐 แล้วสรุปเป็นมติฟอร์แมตเดียว
2. **4 โหมด** — ด่วน (3 เสียง) / เต็มสภา / ดีเบต (🟡ปะทะ⚫) / เฉพาะกิจ (เลือกสมาชิกเอง)
3. **มติสภามีเงื่อนไขล้มมติ** — ทุกมติระบุสัญญาณที่บอกว่าตัดสินใจผิด และนัดวันทบทวนผล
4. **สมุดมติ** — บันทึกมติลง Google Drive โฟลเดอร์ `AI Council – สมุดมติ` อัตโนมัติ
5. **ทบทวนมติ** — พูดว่า "ทบทวนมติ" แล้ว Dalio จะนำ post-mortem แบบ Pain + Reflection

## วิธีติดตั้ง

### (A) ติดตั้ง skill ใหม่ ai-council

นำเนื้อหา `ai-council/SKILL.md` ไปสร้างเป็น skill ใหม่บน claude.ai
(Settings → Capabilities → Skills → สร้าง/อัปโหลด skill)
โดยใช้บรรทัด `description:` ใน frontmatter เป็นคำอธิบาย skill

### (B) อัปเดต skill สมาชิกเดิม

แต่ละไฟล์ใน `member-updates/` มี 2 ส่วน:

1. **Description ใหม่** — ก๊อปไปแทนคำอธิบาย skill เดิมทั้งหมด (แก้ปัญหา trigger ชนกัน)
2. **บล็อกเพิ่มท้าย** — ก๊อปไปต่อท้ายเนื้อหา skill เดิม (ฟอร์แมตคำตอบมาตรฐาน + วิธีทำงานร่วมกับสภา)

จุดที่แก้สำคัญสุด: **hat-black-munger** เดิม trigger คำว่า "ความเสี่ยง/ตรวจสอบ/เคสสินเชื่อ"
ซึ่งชนกับ credit-master และ skill งานธนาคาร — เวอร์ชันใหม่แยกเส้นชัดแล้ว

### ลำดับที่แนะนำ

1. ติดตั้ง ai-council ก่อน แล้วลองสั่ง "ประชุมสภา" กับโจทย์จริงสัก 1 เรื่อง
2. ถ้าเสียงสมาชิกโอเค ค่อยทยอยอัปเดต description สมาชิกทีละตัว (เริ่มจากหมวกดำ)
3. หลังใช้ครบ 2-3 มติ ลอง "ทบทวนมติ" เพื่อทดสอบสมุดมติ + post-mortem
