# ภาคผนวก C — เทมเพลต

> เทมเพลตทุกแบบในภาคผนวกนี้ออกแบบให้เขียนด้วยมือหรือพิมพ์ลงโน้ตส่วนตัวได้ ไม่ต้องใช้ระบบใด ๆ ห้ามบันทึกชื่อลูกค้า เลขบัญชี หรือข้อมูลที่ระบุตัวบุคคลลงในเทมเพลตเหล่านี้ ให้เขียนเป็นเหตุการณ์กว้าง ๆ เช่น "ลูกค้ารายหนึ่ง" แทน

## C1 Check-in sheet

ใช้ก่อนเริ่มรอบ Session Flow ในบทที่ 8 ใช้เวลาไม่เกินหนึ่งนาที

```
วันที่: ______________

วันนี้ฉันรู้สึก:  ☐ พร้อม   ☐ เหนื่อยแต่ไหว   ☐ หนักมาก (เลือกเรื่องเบาที่สุด)

เรื่องที่จะฝึกวันนี้ (หนึ่งเรื่องจากงานจริง):
____________________________________________

ทักษะที่เกี่ยวข้อง:  ☐ SDM   ☐ OSD   ☐ DO   ☐ TDU

เวลาที่มี:  ☐ รอบเต็ม 8 ขั้น   ☐ เวอร์ชันสองนาที
```

## C3 Log Line

ใช้ทุกวัน แม้วันที่ไม่มีเวลาทำอย่างอื่น เขียนหนึ่งบรรทัดในรูปแบบใดรูปแบบหนึ่ง

```
รูปแบบ 1 (สิ่งที่เรียนรู้):   วันนี้ฉันเห็นว่า ______________________
รูปแบบ 2 (ถ้าทำใหม่):        ถ้าทำใหม่ ฉันจะ ________________________ ต่างหนึ่งอย่าง
รูปแบบ 3 (เรียกชื่อวิธีคิด):  วันนี้ฉันใช้วิธีคิดแบบ ______________________
```

ตาราง Log Line รายสัปดาห์ สำหรับดูรูปแบบที่ซ้ำ

| วัน | ทักษะ | Log Line |
| --- | --- | --- |
| จันทร์ | | |
| อังคาร | | |
| พุธ | | |
| พฤหัสบดี | | |
| ศุกร์ | | |

ปลายสัปดาห์ อ่านทั้งห้าบรรทัดต่อกันและตอบ รูปแบบอะไรที่ซ้ำ และก้าวถัดไปหนึ่งก้าวคืออะไร

## C4 Coaching sheet

ใช้กับ Coaching Loop ในบทที่ 9 หัวหน้าหรือผู้โค้ชกรอกหลังบทสนทนา ไม่ใช่ระหว่างคุย และไม่ใช้เป็นเอกสารประเมินผล

```
วันที่: ______________     ทักษะหลัก: ☐ SDM ☐ OSD ☐ DO ☐ TDU

STOP       ฉันอยากบอกคำตอบอะไร (และหยุดได้หรือไม่):
           ____________________________________________

           ____________________________________________

STRUCTURE  สิ่งที่น้องรู้แน่ / สิ่งที่เดา / ทางเลือกที่เห็น:
           ____________________________________________

REFLECT    น้องบอกว่าเรียนรู้อะไรเกี่ยวกับวิธีคิดของตัวเอง:
           ____________________________________________

ASSIGN     งานหนึ่งอย่างที่ตกลงกัน:  ______________________
           วันนัดฟังผล:  ______________

บอกคำตอบตรง ๆ หรือไม่?  ☐ ไม่    ☐ ใช่ เพราะ ☐ ความปลอดภัย ☐ กฎระเบียบ ☐ เวลา ☐ ยังไม่มีพื้นฐาน
ถ้าใช่ ทบทวนกับน้องแล้วหรือยัง: ☐ แล้ว  ☐ ยัง
```
