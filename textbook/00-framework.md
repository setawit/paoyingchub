# Future Skills Engine — Framework อ้างอิง (Source of Truth)

> ไฟล์นี้เป็น "ตัวตั้ง" ที่ทุกบทต้องยึด ห้ามแก้ 4 ทักษะ ห้ามเพิ่มทักษะที่ 5 ห้ามเปลี่ยนชื่อ loop
> ถ้าเนื้อบทไหนขัดกับไฟล์นี้ ให้แก้บท ไม่ใช่แก้ไฟล์นี้

## ตำรานี้เชื่ออะไร (Core Philosophy)

1. ตำรานี้ไม่ใช่คู่มือทฤษฎี แต่เป็นคู่มือเปลี่ยนพฤติกรรม — ทุกบทต้องตอบ "อ่านแล้วทำอะไรได้ทันที"
2. ทักษะเกิดจากพฤติกรรมที่ทำซ้ำ ไม่ใช่จากการสอน — ทุกบทต้องมี drill
3. Tacit knowledge ถ่ายทอดผ่านเคสจริง ไม่ใช่ผ่านนิยาม
4. คนเปลี่ยนพฤติกรรมเพราะอัตลักษณ์ ไม่ใช่เพราะกฎ
5. การอบรมกับ Daily Sharpening เสริมกัน ไม่ใช่แทนที่กัน — ห้ามด่าระบบอบรม ห้ามทำให้ HRD รู้สึกถูกโจมตี

## 4 Future Skills (ห้ามแก้)

ตัวย่อในตำรา (SDM/OSD/DO/TDU) = ชื่อทักษะจริงของ ธ.ก.ส.

### SDM — Strategic Decision-Making (ตัดสินใจอย่างรอบคอบ)
ใช้ข้อมูล หลักฐาน และการวิเคราะห์ ประกอบยุทธศาสตร์องค์กร เพื่อตัดสินใจอย่างมีเหตุผล บริหารความเสี่ยง และใช้ทรัพยากรให้คุ้มค่า
แก่น: มองภาพรวม/ความเชื่อมโยง · ใช้ข้อมูลมากกว่าความรู้สึก · ชั่งผลดีผลเสียและความเสี่ยง · กล้าตัดสินใจแม้ไม่แน่นอน · ประเมินผลกระทบสั้น–ยาว

### OSD — Opportunity Seeking & Differentiation (มองหาโอกาสและสร้างความแตกต่าง)
ค้นหา วิเคราะห์ และใช้โอกาสทางธุรกิจ เพื่อสร้างคุณค่าใหม่และความได้เปรียบ
แก่น: หา insight จากข้อมูลใน–นอก · มองแนวโน้มเศรษฐกิจ/ตลาด/ลูกค้า/คู่แข่ง/เทคโนโลยี · คิดนวัตกรรม · ผูกโอกาสเข้ากับยุทธศาสตร์

### DO — Data Optimization (บริหารงานด้วยข้อมูล)
ใช้ข้อมูลที่ถูกต้อง น่าเชื่อถือ และเป็นระบบ เพื่อสนับสนุนการตัดสินใจ การวางแผน และการบริหารความเสี่ยง
แก่น: Data Governance · Data Analysis · Insight · Data-driven Decision Making

### TDU — Technology & Digital Utilization (บูรณาการงานด้วยเทคโนโลยีดิจิทัล)
เลือกและประยุกต์ใช้เทคโนโลยีดิจิทัลอย่างเหมาะสม เพื่อเพิ่มประสิทธิภาพและสร้างคุณค่าให้องค์กร
แก่น: Digital Mindset · Continuous Learning · Digital Transformation · Technology Adoption · Cyber Awareness

## 5 ระดับพฤติกรรม (ใช้กับทุกทักษะ)

| ระดับ | ชื่อ | ใจความ |
|------|------|--------|
| Level 1 | Executor | ทำงานตัวเองให้ได้มาตรฐาน ใช้ข้อมูล/เครื่องมือพื้นฐาน รับผิดชอบผลงาน |
| Level 2 | Coach | เทียบทางเลือก ตัดสินบนข้อเท็จจริง เสนอแนวคิดใหม่ ช่วยคนอื่นได้ |
| Level 3 | Role Model | คิดเชิงระบบ สร้าง insight/ของใหม่ เป็นแบบอย่างและถ่ายทอด |
| Level 4 | Architect | เชื่อมงานกับกลยุทธ์ ออกแบบระบบ/กระบวนการ บริหารทรัพยากรระดับองค์กร |
| Level 5 | Shaper | วางนโยบาย สร้างมาตรฐาน/วัฒนธรรม กำหนดทิศทางระยะยาว |

> หมายเหตุ: ระดับสูงไม่ได้แปลว่า "ตำแหน่งสูง" เท่านั้น พนักงานสาขาก็ไต่ระดับในทักษะของตัวเองได้ ตำราเน้นให้แต่ละคนรู้ว่าตอนนี้อยู่ระดับไหนและขยับขึ้นยังไง

## เครื่องยนต์การสอน (จาก System Instruction — ห้ามเปลี่ยน/เพิ่ม)

**Loop การเก่งขึ้น:** Trigger → Thinking → Action → Feedback → Repeat

**Session Flow (การลับคมหนึ่งรอบ):** Check-in → Diagnosis → Teach → Force Thinking → Feedback → Today's One Thing → Log Line → Repeat

**5 Non-Negotiable Rules:**
1. Ask before answer — ถามก่อนบอกคำตอบ
2. One action only — ให้ลงมือทีละอย่างเดียว
3. No fluff — ไม่มีน้ำ
4. Name the thinking — เรียกชื่อวิธีคิดออกมา
5. Do it today — ทำวันนี้

**Coaching Loop (สำหรับหัวหน้า):** STOP → ASK → STRUCTURE → REFLECT → ASSIGN

## ผู้อ่าน (ทุกบทต้องพูดกับคนเหล่านี้ได้)

พนักงานสาขา (teller, ลูกค้าสัมพันธ์) · พนักงานสินเชื่อ (RM, นิติกร, ประเมินหลักประกัน) · หัวหน้าหน่วย/ผจก.สาขา/BCM · เจ้าหน้าที่กิจการสาขา/สนญ. · ผู้บริหาร
ทุกบทต้องมีเคสครอบคลุมอย่างน้อย 2 สายงานที่ต่างกัน

## กติกาการเขียน (ย่อ)

โทน "พี่เล่าให้น้องฟัง" · ใช้ "เรา/คุณ" ไม่ใช้ "ท่าน" · ประโยคสั้น ภาษาไทยธรรมชาติ · เลี่ยงศัพท์ HR/consulting กลวง · ทุกหลักการมีเคส · ทุกบทมี drill · เปลี่ยนคนผ่านอัตลักษณ์ · ไม่อวยผู้อ่าน · ไม่ citation เยอะ · heading ไม่ซ้อนเกิน 2 ระดับ · bold เฉพาะ key concept ครั้งแรก · prose มากกว่า bullet

## โครงบังคับทุกบท (7 ส่วน)

1. Hook เปิดบท (เคส/คำถาม/สถานการณ์จริง ≤1 หน้า)
2. Why this matters (≤1 หน้า)
3. Core content (แบ่ง section ย่อย)
4. Cases — 2 เคสจาก 2 สายงาน (มี dialogue, จบด้วย insight)
5. Drill (ทำได้ทุกวัน/สัปดาห์นี้)
6. Reflection questions (3–5 ข้อ)
7. Key takeaways (3–5 ข้อ)
