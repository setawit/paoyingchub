# ภาคผนวก A — ตารางพฤติกรรม 4 ทักษะ × 5 ระดับ

> ตารางนี้เป็นกรอบเรียนรู้ที่เขียนขึ้นสำหรับตำรานี้ เพื่อใช้ประเมินตัวเองและวางแผนฝึก ไม่ใช่เกณฑ์ประเมินผลงาน การเลื่อนตำแหน่ง หรือสมรรถนะอย่างเป็นทางการของธนาคาร ถ้าธนาคารมีนิยามสมรรถนะที่ประกาศใช้ ให้ยึดเอกสารทางการนั้นเป็นหลัก

## วิธีใช้ตาราง

อ่านตารางไปพร้อมกับบทที่ 10 เลือกทักษะที่งานของคุณเรียกใช้บ่อยที่สุด แล้วอ่านจากระดับ 1 ขึ้นไป หยุดที่ช่องสุดท้ายที่คุณนึกเหตุการณ์จริงในช่วงสามเดือนที่ผ่านมาได้ นั่นคือระดับโดยประมาณของคุณในทักษะนั้น และช่องถัดไปคือก้าวถัดไป

กฎการอ่านสามข้อ ข้อแรก ตัดสินจากเหตุการณ์ที่เกิดขึ้นจริง ไม่ใช่จากสิ่งที่ "น่าจะทำได้" ข้อสอง ระดับสูงต้องมีพฤติกรรมของระดับก่อนหน้าครบ ข้อสาม ระดับไม่ได้เท่ากับตำแหน่ง พนักงานสาขาไต่ระดับในทักษะของตัวเองได้

## ตารางพฤติกรรม

| ระดับ | SDM ตัดสินใจอย่างรอบคอบ | OSD มองหาโอกาสและสร้างความแตกต่าง |
| --- | --- | --- |
| **1 Executor** | ตัดสินใจเรื่องในงานตัวเองบนข้อมูลและเหตุผลที่มี แยกสิ่งที่รู้ออกจากสิ่งที่เดา รับผิดชอบผลที่ตามมา | สังเกตและจดสิ่งที่เกิดซ้ำในงาน เช่น คำถามหรือปัญหาของลูกค้าที่ซ้ำกัน และเล่าให้หัวหน้าฟัง |
| **2 Coach** | เทียบทางเลือกพร้อมความเสี่ยงของแต่ละทาง ตกลงสัญญาณเปลี่ยนใจล่วงหน้า และช่วยเพื่อนร่วมงานตัดสินใจเรื่องของเขาได้ดีขึ้น | ถามหาสาเหตุที่อยู่หลังสิ่งที่เกิดซ้ำ ลองทดลองเล็กกับลูกค้าจำนวนน้อย และช่วยให้คนอื่นเห็นสิ่งที่เขาเคยมองผ่าน |
| **3 Role Model** | คิดเชิงระบบ เห็นผลกระทบสั้นและยาว วิธีตัดสินของคุณถูกทีมนำไปใช้เอง โดยไม่ต้องมีคุณอยู่ | สร้างข้อเสนอที่มีหลักฐานจากการทดลอง ทำให้ทีมเห็นและลองทำตาม ผูกโอกาสเข้ากับเป้าหมายของหน่วย |
| **4 Architect** | ออกแบบแนวทางหรือกระบวนการตัดสินใจที่ใช้ทั้งสาขาหรือหน่วยงาน เชื่อมการตัดสินใจเข้ากับกลยุทธ์ขององค์กร และบริหารทรัพยากรให้คุ้มค่า | ออกแบบวิธีหาและทดสอบโอกาสอย่างเป็นระบบ จัดสรรทรัพยากรให้ไอเดียที่ผูกกับยุทธศาสตร์ และเชื่อมกับหลายหน่วยงาน |
| **5 Shaper** | วางหลักการและวัฒนธรรมการตัดสินใจที่คงอยู่ข้ามตัวบุคคล กำหนดทิศทางการบริหารความเสี่ยงระยะยาว | วางนโยบายและวัฒนธรรมที่เปิดให้ทดลองและเรียนรู้ กำหนดทิศทางสร้างความแตกต่างระยะยาวขององค์กร |

| ระดับ | DO บริหารงานด้วยข้อมูล | TDU บูรณาการงานด้วยเทคโนโลยีดิจิทัล |
| --- | --- | --- |
| **1 Executor** | ใช้ข้อมูลพื้นฐานในงานตัวเองได้ถูกต้อง รู้ที่มาของตัวเลขที่ใช้ และดูแลข้อมูลลูกค้าตามกฎขององค์กร | ใช้เครื่องมือพื้นฐานของงานได้คล่องและปลอดภัย ใช้เฉพาะเครื่องมือที่องค์กรอนุญาตกับข้อมูลลูกค้า |
| **2 Coach** | ตีความข้อมูลเป็นข้อเสนอ เทียบกับอะไรสักอย่างเพื่อให้ตัวเลขมีความหมาย ช่วยคนอื่นอ่านข้อมูลให้เป็น | เลือกเครื่องมือให้เหมาะกับงาน วัดก่อนหลังว่าดีขึ้นจริงหรือไม่ และสอนคนอื่นใช้ได้ |
| **3 Role Model** | สร้างวิธีมองและตรวจข้อมูลที่ทีมนำไปใช้ต่อ ลดอคติในการอ่านข้อมูล และตั้งคำถามกับข้อมูลที่ไม่ชัด | พัฒนาวิธีทำงานด้วยเครื่องมือที่ทีมนำไปใช้ต่อ ถามว่าขั้นตอนจำเป็นไหมก่อนใส่ลงระบบ และเป็นแบบอย่างด้านความปลอดภัย |
| **4 Architect** | ออกแบบวิธีเก็บ ดูแล และใช้ข้อมูลที่เชื่อมกับกลยุทธ์ กำหนดนิยามตัวชี้วัดให้ตรงกันทั้งหน่วยงาน | ออกแบบวิธีทำงานดิจิทัลที่เชื่อมกับกลยุทธ์ ประเมินความคุ้มค่าและความเสี่ยงของเทคโนโลยีใหม่ก่อนนำมาใช้ในวงกว้าง |
| **5 Shaper** | วางมาตรฐานคุณภาพข้อมูลและวัฒนธรรมการตัดสินใจด้วยข้อมูลขององค์กร | วางทิศทางและมาตรฐานด้านดิจิทัลและความปลอดภัยที่คนทั้งองค์กรยึดถือในระยะยาว |

## ตัวอย่างหลักฐานที่ใช้ยืนยันแต่ละระดับ

หลักฐานที่ดีคือสิ่งที่คนอื่นตรวจเห็นได้ ไม่ใช่ความรู้สึกของคุณ ตัวอย่างเช่น

| ระดับ | ตัวอย่างหลักฐาน |
| --- | --- |
| **1 Executor** | บันทึกเหตุผลของการตัดสินใจที่จดไว้, รายงานที่ระบุที่มาของตัวเลข, สมุด Log Line ที่ต่อเนื่อง |
| **2 Coach** | เพื่อนร่วมงานที่เล่าได้ว่าเคยเรียนรู้อะไรจากคุณ, บันทึกการโค้ชที่ใช้ Coaching Loop, ผลการทดลองเล็กที่มีตัวเลขก่อนหลัง |
| **3 Role Model** | เอกสารหรือวิธีทำที่ทีมใช้เองเมื่อคุณไม่อยู่, คนอื่นที่ทำตามวิธีของคุณแล้วได้ผล |
| **4 Architect** | กระบวนการหรือแนวทางที่ใช้ข้ามทีม และมีตัวชี้วัดที่ตกลงร่วมกัน |
| **5 Shaper** | นโยบายหรือมาตรฐานที่ยังใช้ต่อแม้ผู้เขียนเปลี่ยนตำแหน่งไปแล้ว |

## ข้อควรระวังเมื่อใช้ตาราง

อย่าใช้ตารางนี้ให้คะแนนเพื่อนร่วมงานหรือลูกน้อง เพราะมันถูกออกแบบมาให้แต่ละคนอ่านตัวเอง อย่าเอาไปเทียบกับระบบประเมินผลที่ธนาคารมี และอย่ายึดตายตัวกับถ้อยคำของแต่ละช่อง ถ้าพฤติกรรมของคุณไม่ตรงกับตัวอย่างพอดีแต่เจตนาตรงกัน ให้ถือว่าอยู่ในระดับนั้นได้ ใช้วิจารณญาณและขอความเห็นจากคนที่ไว้ใจหนึ่งคน
