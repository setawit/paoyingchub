# บทที่ 3 — Loop ของการเก่งขึ้น

> เคสทุกเรื่องในตำรานี้เป็นตัวอย่างสมมติที่เขียนขึ้นเพื่อประกอบการเรียนรู้ ไม่ใช่เหตุการณ์หรือลูกค้าจริง

## เปิดบท

มีคนสองกลุ่มที่ทำงานมาสิบปีเท่ากัน กลุ่มแรกเก่งขึ้นทุกปี กลุ่มที่สองทำงานคล่องขึ้นแต่ไม่ได้เก่งขึ้น เป็นสิบปีของปีแรกซ้ำสิบรอบ

ความต่างไม่ได้อยู่ที่ความฉลาด หรือความขยัน คนกลุ่มที่สองก็ขยันไม่แพ้กัน ความต่างอยู่ที่ว่า หลังทำงานเสร็จแต่ละครั้ง มีอะไรบางอย่างย้อนกลับมาเปลี่ยนวิธีคิดของครั้งต่อไปหรือไม่ บทนี้คือวิธีทำให้สิ่งนั้นเกิดขึ้นเป็นนิสัย

## ทำไมเรื่องนี้สำคัญกับคุณ

ในบทที่ 1 เราบอกว่าทักษะเกิดจากพฤติกรรมที่ทำซ้ำ แต่ทำซ้ำเฉย ๆ ยังไม่พอ ถ้าทำซ้ำโดยไม่เรียนรู้อะไรจากรอบก่อน เราแค่ซ้อมความเคยชินเดิมให้แน่นขึ้น บทนี้ให้โครงสร้างที่ทำให้การทำซ้ำกลายเป็นการเก่งขึ้นจริง และกฎห้าข้อที่ทำให้โครงสร้างนั้นหมุนได้ ไม่ค้างอยู่แค่ความตั้งใจ

บทนี้เป็นบทหัวใจของทั้งเล่ม ทุกบทที่เหลือคือการเอา loop นี้ไปใช้กับทักษะต่าง ๆ

## Loop ห้าขั้น

การเก่งขึ้นหมุนเป็นวงกลม ห้าขั้น

**Trigger** คือจุดที่เหตุการณ์ในงานจริงมาถึง อาจเป็นลูกค้าถามคำถามที่ไม่คาด แฟ้มที่ตัวเลขดูแปลก หรือหัวหน้าถามว่า "ทำไมถึงเลือกแบบนี้" ทุกวันมี trigger หลายสิบจุด เรามักปล่อยมันผ่านไปเพราะรีบ ขั้นแรกของการลับคมคือเลือกจับหนึ่งจุด

**Thinking** คือช่วงที่เรานึกออกเสียงหรือในใจว่าเรากำลังคิดอะไรอยู่ ก่อนลงมือ ข้อนี้เป็นขั้นที่ถูกข้ามบ่อยที่สุด เพราะคนที่ชำนาญแล้วจะคิดเร็วจนไม่รู้ตัวว่าคิด แต่ถ้าไม่เห็นความคิดของตัวเอง ก็แก้ไขมันไม่ได้

**Action** คือลงมือทำจริง ทำสิ่งเดียวที่ชัดเจน ไม่ใช่ตั้งใจจะทำหลายอย่าง

**Feedback** คือสิ่งที่ย้อนกลับมาบอกเราว่าผลเป็นอย่างไร อาจมาจากลูกค้า จากผลลัพธ์ในงาน จากหัวหน้า หรือจากการทบทวนของเราเอง ถ้าไม่มี feedback การทำซ้ำก็ไม่มีทิศทาง

**Repeat** คือการวนกลับไปที่ trigger ครั้งต่อไป พร้อมสิ่งที่เรียนรู้จากรอบก่อน ไม่ใช่เริ่มจากศูนย์

ลองดูว่า loop นี้อยู่ในชีวิตจริงอย่างไร ลูกค้าถามคำถามที่เราตอบไม่ได้ทันที (trigger) เราหยุดคิดว่าจะหาข้อมูลจากไหน (thinking) แล้วไปหาและตอบกลับ (action) ลูกค้าบอกว่า "ตรงนี้ยังไม่ชัด" (feedback) ครั้งหน้าเราเริ่มด้วยการถามก่อนว่าลูกค้าอยากรู้ระดับไหน (repeat)

## กฎห้าข้อที่ทำให้ loop หมุนจริง

คนส่วนใหญ่รู้จัก loop แบบนี้อยู่แล้วในหัว แต่ไม่ค่อยหมุนจริง เพราะมีแรงที่ดึงให้หลุดวง ตำรานี้จึงมีกฎห้าข้อ ที่เรียกว่า Non-Negotiable คือต่อรองไม่ได้ เพราะถ้ายอมผ่อนข้อไหน loop จะหยุด

**1) ถามก่อนบอก (Ask before answer)** เมื่อมีคนมาขอความช่วยเหลือ หรือเมื่อเราจะช่วยตัวเองคิด ให้ถามก่อน ไม่รีบบอกคำตอบ เพราะคำตอบที่ได้มาฟรีมักไม่ติดตัว คนที่ถูกถามต้องคิดเอง ส่วนที่คิดเองคือส่วนที่ทักษะเติบโต

**2) ลงมือทีละอย่าง (One action only)** จบแต่ละรอบด้วยการลงมือเพียงเรื่องเดียว คนที่ตั้งใจจะเปลี่ยนห้าเรื่องพร้อมกันมักไม่ได้เปลี่ยนเรื่องไหนเลย เรื่องเดียวที่ทำจริงดีกว่าห้าเรื่องที่ตั้งใจ

**3) ไม่มีน้ำ (No fluff)** ไม่เติมคำพูดสวยหรู ไม่ปลอบใจโดยไม่มีสาระ ไม่ยกทฤษฎีที่ไม่ได้ใช้ ทุกประโยคต้องพาไปสู่การคิดหรือการทำ

**4) เรียกชื่อวิธีคิด (Name the thinking)** เมื่อเราใช้วิธีคิดแบบหนึ่งได้ดี ให้เรียกชื่อมันออกมา เช่น "เมื่อกี้ฉันเทียบสามทางเลือก" เพราะสิ่งที่เรียกชื่อได้จะถูกเรียกใช้ซ้ำได้ ส่วนสิ่งที่ทำแบบไม่รู้ตัว จะหายไปเมื่อสถานการณ์เปลี่ยน

**5) ทำวันนี้ (Do it today)** ทุกรอบจบด้วยสิ่งที่ลงมือได้วันนี้ ไม่ใช่ "คราวหน้า" หรือ "เมื่อมีเวลา" เพราะ loop ที่เริ่มพรุ่งนี้มักไม่เริ่มเลย

ทั้งห้าข้อนี้ดูเล็ก แต่เมื่อรวมกัน ทำให้วันทำงานธรรมดากลายเป็นสนามฝึกได้โดยไม่ต้องเพิ่มเวลา

## ทำไมต้องห้าข้อนี้ ไม่ใช่มากกว่านี้

อาจมีคนอยากเพิ่มกฎ แต่ตำรานี้จงใจให้มีห้าข้อ เพราะกฎที่มากเกินไปจะกลายเป็นภาระ และภาระจะทำให้คนเลิกทำ ห้าข้อนี้เลือกมาเพราะแต่ละข้อป้องกันการหลุดวงในจุดที่เกิดบ่อยที่สุด ถามก่อนบอกป้องกันการรับคำตอบโดยไม่คิด ทีละอย่างป้องกันการทำมากเกินจนไม่เกิดอะไร ไม่มีน้ำป้องกันการเสียเวลาไปกับความรู้สึกว่าได้เรียนรู้ เรียกชื่อวิธีคิดป้องกันการลืม และทำวันนี้ป้องกันการเลื่อน

## เคสที่ 1: ผู้จัดการสาขาที่หยุดบอกคำตอบ

*(เคสสมมติ — สายงานหัวหน้า/ผู้จัดการสาขา)*

พี่สมศรีเป็นผู้จัดการสาขา ลูกน้องคนหนึ่งชื่อน้องฟ้าเดินมาหาบ่อย ๆ พร้อมคำถามแบบ "พี่คะ ลูกค้ารายนี้ควรทำยังไงดี" และพี่สมศรีก็ตอบให้ทุกครั้ง เพราะรู้คำตอบอยู่แล้ว และเร็วกว่า

เช้าวันหนึ่งน้องฟ้ามาอีก "พี่คะ ลูกค้าขอเลื่อนชำระ ควรรับไหมคะ"

พี่สมศรีเกือบตอบไปแล้ว แต่หยุดไว้ "ฟ้าคิดว่ายังไง"

"ไม่แน่ใจค่ะ เลยมาถาม"

"ถ้าต้องเดา ฟ้าเอนไปทางไหน"

"รับค่ะ เพราะลูกค้าคนนี้ชำระตรงมาตลอด"

"ดี ฟ้าใช้เหตุผลข้อไหน"

"ประวัติการชำระค่ะ"

"แล้วมีอะไรที่ทำให้ฟ้าไม่อยากรับไหม"

น้องฟ้าคิดอยู่ครู่ "ไม่รู้ว่าเหตุที่ขอเลื่อนเป็นเรื่องชั่วคราวหรือเรื่องใหญ่ค่ะ"

"ฟังดีนะ ถ้างั้นเรื่องเดียวที่ต้องทำวันนี้คืออะไร"

"โทรถามลูกค้าว่าเหตุคืออะไรค่ะ"

"ไปเลย แล้วเย็นนี้มาเล่าให้พี่ฟังว่าได้ยินอะไร"

**ข้อสังเกต:** พี่สมศรีใช้กฎสามข้อในไม่กี่นาที คือถามก่อนบอก ให้ทำเรื่องเดียว และให้ทำวันนี้ น้องฟ้าก็ได้ฝึกเรียกชื่อวิธีคิดของตัวเองโดยไม่รู้ตัว เมื่อเธอพูดว่า "ใช้ประวัติการชำระ" และ "ไม่รู้ว่าเป็นเรื่องชั่วคราวหรือใหญ่" ในบทที่ 9 เราจะเห็นวิธีนี้ครบเป็น Coaching Loop

## เคสที่ 2: พนักงานสินเชื่อที่จับ trigger ได้ครั้งเดียว

*(เคสสมมติ — สายงานสินเชื่อ)*

พี่เอกเป็นพนักงานสินเชื่อ ได้ยินลูกค้าพูดประโยคหนึ่งในที่ประชุมกลุ่มว่า "ผมไม่ได้กังวลเรื่องดอกเบี้ย ผมกังวลว่าถ้าฝนมาช้าจะเอาเงินที่ไหนส่ง" พี่เอกรู้สึกว่าประโยคนี้สำคัญ แต่ประชุมก็จบไป

คืนนั้นเขานึกถึงประโยคนั้นอีกครั้ง เลยเปิดสมุดเล่มเล็ก เขียนลงไปสามบรรทัด

"trigger: ลูกค้ากลัวฝนมาช้า มากกว่ากลัวดอกเบี้ย
thinking: ที่ผ่านมาฉันคุยแต่เรื่องดอกเบี้ย
action พรุ่งนี้: ถามลูกค้าอีกสองรายว่ากังวลเรื่องอะไรที่สุด"

วันรุ่งขึ้นเขาถามสองราย ได้คำตอบที่ต่างกัน รายหนึ่งกลัวราคา อีกรายกลัวแรงงาน เขาเริ่มเห็นว่าเรื่องที่เขาเคยคิดว่าเป็นเรื่องเดียวกันหมด ที่จริงต่างกันมาก

สัปดาห์ถัดมา เขาเริ่มเปิดบทสนทนากับลูกค้าด้วยคำถามนี้ทุกครั้ง และเริ่มเรียกมันกับตัวเองว่า "ถามความกังวลก่อน"

**ข้อสังเกต:** พี่เอกไม่ได้ต้องใช้เวลามาก เขาแค่จับ trigger หนึ่งจุด เขียนความคิดของตัวเอง และกำหนด action เดียวสำหรับพรุ่งนี้ จากนั้น feedback จากลูกค้าสองรายทำให้ loop หมุนต่อเอง

## ลองทำ: วันนี้

เลือกเหตุการณ์หนึ่งเรื่องจากวันนี้ อะไรก็ได้ที่ทำให้คุณหยุดสะดุดแม้แต่นิดเดียว เขียนสามบรรทัด เหมือนที่พี่เอกทำ

บรรทัดแรก เหตุการณ์คืออะไร (trigger) บรรทัดที่สอง ตอนนั้นฉันคิดอะไรอยู่ หรือคิดว่าตัวเองควรคิดอะไร (thinking) บรรทัดที่สาม พรุ่งนี้ฉันจะทำอะไรหนึ่งอย่างที่ต่างจากเดิม (action)

แค่นี้ ไม่ต้องเพิ่มข้อสี่ ถ้าอยากได้ feedback ให้เล่าสามบรรทัดนี้ให้เพื่อนร่วมงานฟังหนึ่งคน แล้วถามว่า "ถ้าเป็นคุณ จะมองต่างไปไหม"

## คำถามสะท้อน

1. ในหนึ่งวันทำงานของคุณ มี trigger กี่จุดที่คุณปล่อยผ่านไปเพราะรีบ ถ้าต้องเลือกจุดที่มีค่าที่สุดหนึ่งจุด จะเป็นจุดไหน
2. ขั้นไหนใน loop ที่คุณข้ามบ่อยที่สุด thinking, feedback หรือ repeat เพราะอะไร
3. ในห้ากฎ ข้อไหนที่ยากที่สุดสำหรับคุณ เช่น ถามก่อนบอก ข้อนี้ยากเมื่ออยู่กับใคร
4. ครั้งล่าสุดที่คุณช่วยใครสักคนโดยบอกคำตอบทันที ถ้าย้อนกลับไปถามก่อน คุณคิดว่าเขาจะได้อะไรเพิ่ม

## สิ่งที่ควรจำจากบทนี้

- การเก่งขึ้นคือ loop ห้าขั้น Trigger → Thinking → Action → Feedback → Repeat การทำซ้ำโดยไม่มี feedback ไม่ทำให้เก่งขึ้น
- ห้ากฎที่ต่อรองไม่ได้ คือ ถามก่อนบอก ทีละอย่าง ไม่มีน้ำ เรียกชื่อวิธีคิด และทำวันนี้
- ขั้นที่ถูกข้ามบ่อยที่สุดคือ thinking เพราะคนชำนาญคิดเร็วจนไม่เห็นความคิดตัวเอง
- เริ่มเล็กได้ เหตุการณ์เดียว สามบรรทัด หนึ่งการลงมือ ก็เริ่มหมุน loop ได้แล้ว
