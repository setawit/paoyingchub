# Quick Prompts – คำสั่งลัดสำหรับถามเฉพาะจุด

> ใช้เมื่อ Co-Pilot มีบทบาทตาม system-prompt แล้ว และต้องการถามแค่บางประเด็น

---

## ถามเรื่องเอกสาร

```
จากเคสที่ส่งให้ ขอแค่รายการเอกสารที่ยังขาด
และเรียงลำดับตามความจำเป็น (สำคัญมาก / สำคัญ / ควรมี)
```

---

## ถามเรื่องความเสี่ยงเฉพาะด้าน

```
วิเคราะห์เฉพาะ [Character / Capacity / Capital / Collateral / Condition]
ของเคสนี้ให้ละเอียดขึ้น
```

---

## จำลองคำถามจากกลั่นกรองเพิ่ม

```
จำลองคำถามที่กลั่นกรองสินเชื่ออาจถามเพิ่มเติม
เน้นประเด็นที่ยังไม่มีคำตอบชัดเจนใน Credit Memo
```

---

## ร่างคำตอบเฉพาะประเด็น

```
ช่วยร่างคำตอบสำหรับประเด็นนี้:
"[วางคำถามจากกลั่นกรองที่ได้รับมาจริง]"

ข้อมูลเพิ่มเติม: [ระบุข้อมูลใหม่ที่หาได้มา]
```

---

## ขอ Executive Summary

```
สรุป Executive Summary ของเคสนี้ในรูปแบบที่พร้อมนำเสนอต่อกลั่นกรองสินเชื่อ
ความยาวไม่เกิน 1 หน้า A4
```

---

## ประเมินคะแนนความพร้อมใหม่

```
หลังจากได้เอกสาร [ระบุชื่อเอกสาร] เพิ่มมาแล้ว
ขอให้ประเมิน Credit Readiness Score ใหม่อีกครั้ง
```

---

## ตรวจ Red Flag

```
ตรวจสอบว่าเคสนี้มี Red Flag ที่ต้องระวังหรือไม่
ถ้ามีให้ระบุพร้อมแนวทางจัดการ
```

---

## เปรียบเทียบกับมาตรฐาน

```
ตรวจสอบว่าค่า [DSR / LTV / D-E Ratio / อัตราส่วนที่ต้องการ]
ของเคสนี้อยู่ในเกณฑ์มาตรฐานสินเชื่อทั่วไปหรือไม่
```

---

```
ขอเริ่มวิเคราะห์เคสใหม่

```
