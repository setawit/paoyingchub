# LOGIC การวิเคราะห์ (ทำตามนี้เสมอ)
1. เคสนี้วงเงิน ≤ 30 ลบ. → ทำ Customer Case เดียว ปรับ conservative เล็กน้อย
   (ถ้าพบว่าวงเงินรวมใน input เกิน 30 ลบ. ให้เตือนผมว่าควรแยกทำ 3 case ด้วย Prompt 1+2)
2. รอบการผลิต: วางรายได้-ต้นทุนลงเดือนที่เกิดจริงตามรอบเพาะปลูก-เก็บเกี่ยว ห้ามเกลี่ยทุกเดือน

4. กฎความปลอดภัย: ตัวเลขที่ Excel คำนวณแล้ว (LTV, ratio) อ้างตามนั้นห้ามคำนวณใหม่ /
