# 🧰 ชุดเครื่องมือ Copilot — Credit Memo (ธ.ก.ส. 301.02.07) + ประมาณการการเงิน 24 เดือน

ชุดเครื่องมือนี้ออกแบบให้ **ก๊อปวางใน Microsoft Copilot ทีละเคส** เพื่อสร้าง
1. **สมมติฐานทางการเงินรายเดือน** (ป้อน Excel AGRI-CAP/SME-CAP sheet "6.2 สมมติฐาน 24 เดือน")
2. **ตารางประมาณการ 24 เดือน ฉบับร่าง** (กระแสเงินสดรายเดือน + DSCR) ไว้ cross-check กับ Excel
3. **ข้อความ Credit Memo ครบทุก section** ตามฟอร์มคำขออนุมัติสินเชื่อ 301.02.07 ฉบับจริง (25 หน้า)

## 🎯 ตรรกะหลักที่ฝังอยู่ในทุก prompt

- **Scenario ตามวงเงิน** — ≤ 30 ลบ. ทำ Customer Case เดียว (ปรับ conservative เล็กน้อย) / > 30 ลบ. ทำ 3 case: **Customer / Bank / Conservative** (ตามชื่อในฟอร์มข้อ 12.1) — Conservative Case DSCR ≥ 1.0 จึงรับได้
- **รอบการผลิต** — กระแสเงินสดต้องลงเดือนจริงตามรอบเพาะปลูก-เก็บเกี่ยว ไม่เกลี่ยเท่ากันทุกเดือน หลายธุรกิจให้แยกกระแสแต่ละตัว
- **Red flag ตาม sector** — พืชไร่ (ราคา/ภัยธรรมชาติ), โรงสี (OCF ติดลบช่วงสต๊อก = ปกติ), ฟาร์มสัตว์ (โรคระบาด/ราคาอาหารสัตว์), สหกรณ์ (ชั้นคุณภาพควบคุมภายใน + วงเงินนายทะเบียน)
- **กฎความปลอดภัย** — ตัวเลขที่ Excel คำนวณแล้วให้อ้างตามนั้นห้ามคำนวณใหม่ / ข้อมูลไม่พอให้เขียน `⚠️ ต้องการ: [ระบุ]` ห้ามแต่งขึ้นเอง / ปรับ section ตามประเภทลูกค้า (นิติบุคคล / เกษตรกร-บุคคล / สหกรณ์-กลุ่มเกษตรกร / วิสาหกิจชุมชน) อัตโนมัติ

## ⚠️ ข้อควรระวัง

- **ข้อมูลส่วนบุคคลลูกค้า** — ใช้ Copilot ใน tenant ขององค์กรเท่านั้น และพิจารณาปกปิดเลขบัตร/CIF ก่อนวาง (ใช้ "ลูกค้า ก." แทนชื่อจริงได้ ผลลัพธ์ค่อยแทนกลับ)
- **Copilot คำนวณเลขผิดได้** — ตารางประมาณการจาก Prompt 1 เป็น "ฉบับร่าง" เพื่อดูรูปทรงกระแสเงินสดเท่านั้น ตัวเลขที่ลงฟอร์มจริงต้องมาจาก Excel
- **ถ้า Copilot ตอบไม่จบ** (ข้อความยาวเกิน) — พิมพ์ "ทำต่อจากข้อที่ค้าง" หรือสั่งทีละส่วน เช่น "เอาเฉพาะ CUR ข้อ 8–11 ก่อน"
- **เคสซับซ้อนมาก** (หลายธุรกิจซ้อน, โครงสร้างหนี้พันกัน) — ใช้ AI ตัวเต็มช่วยคิดสมมติฐานเชิงลึกเป็นรายเคส แล้วเอากลับมาเข้า workflow นี้
