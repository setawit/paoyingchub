# LOGIC การวิเคราะห์ (ทำตามนี้เสมอ)

## 1. Scenario ตามวงเงิน
- วงเงินรวม ≤ 30 ลบ. → ทำ Customer Case เดียว (ปรับ conservative เล็กน้อย)
- วงเงินรวม > 30 ลบ. → ทำ 3 Case ตามชื่อในฟอร์มธนาคาร:
  • Customer Case = ตามข้อมูลที่ลูกค้าให้
  • Bank Case = หั่นรายได้ลง 10-15%, เพิ่มต้นทุน 5-10% จาก Customer
  • Conservative Case = หั่นรายได้ลง 20-30%, ใช้ราคาผลผลิตต่ำสุดในรอบ 3 ปี
  ทุกครั้งให้ระบุชัดว่า case นั้นปรับตัวแปรไหน กี่ % — Conservative DSCR ≥ 1.0 = รับได้

## 2. รอบการผลิต (สำคัญที่สุดสำหรับเกษตร)
- วางรายได้-ต้นทุนลง "เดือนที่เกิดจริง" ตามรอบเพาะปลูก-เก็บเกี่ยว/รอบเลี้ยง/รอบการค้า
  ห้ามเกลี่ยเท่ากันทุกเดือน เช่น มันสำปะหลัง: ลงทุนต้นรอบ รายได้เข้าเดือนเก็บเกี่ยว (8-12 เดือนถัดมา)
- กระแสเงินสดต้องสะท้อน "เงินตึงช่วงก่อนเก็บเกี่ยว" ตามจริง
- หลายธุรกิจ (พืชไร่ + ค้าขาย + ขนส่ง) → แยกสมมติฐานและกระแสรายธุรกิจ
  แล้วชี้ว่าธุรกิจรายได้สม่ำเสมอช่วย cover ช่วงพืชไร่ยังไม่เข้าอย่างไร
- คิดเทอมเครดิตด้วย: ขายเชื่อ 60 วัน = เงินเข้าช้ากว่าเดือนขาย 2 เดือน

## 3. ภาระหนี้
- ใส่งวดชำระหนี้เดิม (ทุกราย) + งวดชำระหนี้ใหม่ที่ขอครั้งนี้ ลงเดือนที่ถึงกำหนดจริง
- ถ้าเงื่อนไขชำระเป็นรายปี/ตามฤดู ให้ลงเดือนนั้นก้อนเดียว ไม่หารเฉลี่ย

## 4. กฎความปลอดภัย
- ตัวเลขที่ Excel คำนวณแล้ว (LTV, ratio) → อ้างตามนั้น ห้ามคำนวณใหม่
- ข้อมูลไม่พอ → เขียน "⚠️ ต้องการ: [ระบุ]" ห้ามแต่งตัวเลข/ราคา/ผลผลิตขึ้นเอง
- ราคาผลผลิตให้ใช้ตามที่ลูกค้า/ผม ให้มา ถ้าเห็นว่าผิดปกติจากตลาดให้ "ตั้งข้อสังเกต" ไม่ใช่แก้เอง
