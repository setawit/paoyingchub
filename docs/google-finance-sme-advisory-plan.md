# แผนการใช้ Google Finance เป็นเครื่องมือที่ปรึกษาทางการเงินสำหรับ SME และธุรกิจเกษตร (กลุ่มลูกค้าเป้าหมาย ธ.ก.ส.)

เอกสารนี้เป็นแผนงานเชิงปฏิบัติสำหรับการนำ **Google Finance** (เว็บ [google.com/finance](https://www.google.com/finance) และฟังก์ชัน `GOOGLEFINANCE` ใน Google Sheets) มาใช้เป็นเครื่องมือสนับสนุนงานที่ปรึกษาทางการเงิน โดยออกแบบให้ใช้ได้ทั้ง

- **พนักงาน / RM / ที่ปรึกษาสินเชื่อของ ธ.ก.ส.** — ใช้วิเคราะห์และเตรียมคำแนะนำให้ลูกค้า
- **เจ้าของธุรกิจ SME เกษตร** — ใช้ติดตามตลาดด้วยตัวเองแบบง่าย ๆ โดยไม่ต้องมีพื้นฐานการเงิน

## 1. เป้าหมายและกลุ่มลูกค้า

### ทำไมต้อง Google Finance

| เหตุผล | รายละเอียด |
|---|---|
| ฟรี | ไม่มีค่าใช้จ่าย ไม่ต้องสมัครบริการข้อมูลตลาด |
| เข้าถึงง่าย | ใช้ได้ทั้งมือถือและคอมพิวเตอร์ ผ่านบัญชี Google ที่ลูกค้าส่วนใหญ่มีอยู่แล้ว |
| อัปเดตอัตโนมัติ | สูตรใน Google Sheets ดึงราคาใหม่เอง ไม่ต้องกรอกมือ |
| แชร์ได้ | RM สร้าง dashboard หนึ่งไฟล์ แชร์ให้ลูกค้าหลายรายดูพร้อมกันได้ |

### กลุ่มลูกค้าเป้าหมาย ธ.ก.ส.

1. **เกษตรกร / วิสาหกิจชุมชน** — ปลูกข้าว อ้อย มันสำปะหลัง ยางพารา เลี้ยงสัตว์
2. **SME เกษตรแปรรูป** — โรงสี โรงงานแปรรูปอาหาร ผู้ผลิตอาหารสัตว์
3. **ผู้ค้า / ผู้ส่งออกสินค้าเกษตร** — มีรายรับ-รายจ่ายเป็นเงินตราต่างประเทศ

## 2. Google Finance ทำอะไรได้และไม่ได้ (ต้องเข้าใจก่อนใช้)

### ✅ ทำได้

- ราคา **หุ้นไทยใน SET** — ใช้สัญลักษณ์ขึ้นต้นด้วย `BKK:` เช่น `BKK:CPF`
- **อัตราแลกเปลี่ยน** — เช่น `CURRENCY:USDTHB`, `CURRENCY:CNYTHB`
- **ETF ต่างประเทศ** ที่อ้างอิงสินค้าโภคภัณฑ์ เช่น `CORN`, `SOYB`, `CANE`, `DBA`
- **ราคาย้อนหลัง** สำหรับดูแนวโน้มและทำกราฟ
- ดัชนีตลาด เช่น `INDEXBKK:SET` (SET Index)

### ❌ ทำไม่ได้

- **ไม่มีราคาสินค้าเกษตรไทยโดยตรง** — ไม่มีราคาข้าวเปลือก ยางแผ่น อ้อย มันเส้น หน้าฟาร์ม
- ไม่มีอัตราดอกเบี้ยนโยบาย ธปท. หรืออัตราดอกเบี้ยสินเชื่อ
- ไม่มีราคาสัญญาซื้อขายล่วงหน้า (futures) โดยตรง
- ข้อมูลราคาดีเลย์ประมาณ 20 นาที (ไม่ใช่เรียลไทม์ 100%)

### 🔧 วิธีทดแทนข้อจำกัด

1. **ใช้ "หุ้นตัวแทน" (proxy)** — หุ้นบริษัทเกษตรใน SET สะท้อนทิศทางราคาสินค้านั้น ๆ เช่น ราคาหุ้นกลุ่มน้ำตาลมักเคลื่อนตามราคาน้ำตาลโลก
2. **ใช้ ETF สินค้าโภคภัณฑ์โลก** — สะท้อนราคาข้าวโพด ถั่วเหลือง น้ำตาล ซึ่งเป็นต้นทุน/ราคาอ้างอิงของสินค้าเกษตรไทย
3. **เสริมด้วยแหล่งข้อมูลไทย** ดึงเข้า Google Sheets ด้วย `IMPORTHTML` / `IMPORTXML`:
   - สมาคมผู้ส่งออกข้าวไทย (ราคาข้าว FOB)
   - การยางแห่งประเทศไทย (ราคายาง)
   - สำนักงานเศรษฐกิจการเกษตร — สศก. (ราคาสินค้าเกษตรหน้าฟาร์ม)
   - ธนาคารแห่งประเทศไทย (อัตราดอกเบี้ย, อัตราแลกเปลี่ยนอ้างอิง)

## 3. ตารางจับคู่: ธุรกิจลูกค้า → สัญลักษณ์ที่ควรติดตาม

| ธุรกิจลูกค้า | สิ่งที่กระทบรายได้/ต้นทุน | สัญลักษณ์ใน Google Finance |
|---|---|---|
| เลี้ยงไก่ หมู ปลา / อาหารสัตว์ | ราคาข้าวโพด ถั่วเหลือง (ต้นทุนอาหารสัตว์) | `BKK:CPF`, `BKK:GFPT`, `BKK:TFG`, ETF: `CORN`, `SOYB` |
| ยางพารา | ราคายางโลก | `BKK:STA`, `BKK:NER` |
| อ้อย / น้ำตาล | ราคาน้ำตาลโลก | `BKK:KSL`, `BKK:BRR`, ETF: `CANE` |
| ประมง / อาหารทะเลแปรรูป | ราคาวัตถุดิบ + ตลาดส่งออก | `BKK:TU`, `BKK:ASIAN` |
| น้ำมันพืช / พืชน้ำมัน | ราคาถั่วเหลือง ปาล์ม | `BKK:TVO`, ETF: `SOYB` |
| ทุกธุรกิจเกษตร (ต้นทุนร่วม) | น้ำมันเชื้อเพลิง ปุ๋ย | `BKK:PTT`, ETF: `DBA`, หุ้นปุ๋ยโลก: `MOS`, `NTR` |
| ผู้ส่งออก | ค่าเงินบาท | `CURRENCY:USDTHB`, `CURRENCY:CNYTHB`, `CURRENCY:JPYTHB`, `CURRENCY:EURTHB` |

> **หมายเหตุ:** หุ้น proxy สะท้อน "ทิศทาง" ไม่ใช่ราคาหน้าฟาร์มจริง ใช้ดูแนวโน้มประกอบการตัดสินใจ แล้วเทียบกับราคาท้องถิ่นจาก สศก. เสมอ

## 4. สูตร GOOGLEFINANCE พร้อมใช้ (copy ไปวางได้เลย)

### 4.1 ราคาปัจจุบัน

```
=GOOGLEFINANCE("BKK:CPF", "price")          → ราคาหุ้น CPF ล่าสุด
=GOOGLEFINANCE("CURRENCY:USDTHB")           → อัตราแลกเปลี่ยน USD/THB
=GOOGLEFINANCE("BKK:CPF", "changepct")      → % เปลี่ยนแปลงวันนี้
=GOOGLEFINANCE("BKK:CPF", "high52")         → ราคาสูงสุดรอบ 52 สัปดาห์
=GOOGLEFINANCE("BKK:CPF", "low52")          → ราคาต่ำสุดรอบ 52 สัปดาห์
```

### 4.2 ราคาย้อนหลัง (ดูแนวโน้ม)

```
=GOOGLEFINANCE("CURRENCY:USDTHB", "price", TODAY()-90, TODAY(), "DAILY")
```

ได้ตารางราคาย้อนหลัง 90 วัน นำไปทำกราฟหรือกราฟจิ๋วในเซลล์เดียว:

```
=SPARKLINE(INDEX(GOOGLEFINANCE("CURRENCY:USDTHB","price",TODAY()-90,TODAY(),"DAILY"),,2))
```

### 4.3 ค่าเฉลี่ยเคลื่อนที่ (ดูว่าราคาตอนนี้ถูกหรือแพงกว่าปกติ)

```
=AVERAGE(INDEX(GOOGLEFINANCE("BKK:KSL","price",TODAY()-30,TODAY(),"DAILY"),,2))
```

เทียบราคาวันนี้กับค่าเฉลี่ย 30 วัน — ถ้าสูงกว่ามาก แนวโน้มขาขึ้น

### 4.4 แปลงสกุลเงินสำหรับใบเสนอราคา / สัญญาส่งออก

```
=A2 * GOOGLEFINANCE("CURRENCY:USDTHB")     → แปลงยอด USD ในเซลล์ A2 เป็นบาท
```

### 4.5 ดึงราคาสินค้าเกษตรไทยเสริม (นอก Google Finance)

```
=IMPORTHTML("https://www.thairiceexporters.or.th/price.htm", "table", 1)
```

(ปรับ URL/ลำดับตารางตามหน้าเว็บจริง ณ เวลาที่ใช้งาน)

## 5. Use Case สำหรับพนักงาน / RM ธ.ก.ส.

### 5.1 เตรียมข้อมูลก่อนพบลูกค้า (ใช้เวลา 5 นาที)

1. เปิด dashboard → ดูแถวของธุรกิจลูกค้า (เช่น ลูกค้าเลี้ยงไก่ → ดู `CORN`, `SOYB`, `BKK:GFPT`)
2. ดู sparkline 90 วัน + % เปลี่ยนแปลง → สรุปได้ทันทีว่าต้นทุน/ราคาขายของลูกค้ากำลังขึ้นหรือลง
3. เปิดหัวข้อสนทนา: *"ช่วงนี้ราคาข้าวโพดโลกขึ้นมา 8% ต้นทุนอาหารสัตว์ของพี่กระทบไหมครับ"* — สร้างความน่าเชื่อถือและนำเข้าสู่การเสนอผลิตภัณฑ์

### 5.2 ประกอบการวิเคราะห์สินเชื่อ / ปรับโครงสร้างหนี้

- ลูกค้าขอสินเชื่อขยายกิจการ → ดูแนวโน้มราคา proxy ของสินค้าลูกค้าย้อนหลัง 1 ปี ประกอบการประเมินความสามารถชำระหนี้
- ลูกค้าเริ่มผิดนัดชำระ → ตรวจว่าเป็นเพราะราคาสินค้าตกทั้งตลาด (ปัจจัยภายนอก) หรือปัญหาเฉพาะราย → เลือกแนวทางช่วยเหลือได้ตรงจุด

### 5.3 จับจังหวะเสนอผลิตภัณฑ์

| สัญญาณจาก dashboard | ผลิตภัณฑ์/คำแนะนำที่ควรเสนอ |
|---|---|
| ต้นทุนวัตถุดิบ (CORN/SOYB/ปุ๋ย) ขาขึ้น | สินเชื่อหมุนเวียนเพื่อสต็อกวัตถุดิบล่วงหน้า |
| บาทผันผวนแรง (USDTHB แกว่ง) | แนะนำลูกค้าส่งออกทำสัญญาขายเงินตราต่างประเทศล่วงหน้า / เผื่อ margin ในใบเสนอราคา |
| ราคาสินค้าลูกค้าขาลงต่อเนื่อง | เตรียมมาตรการพักชำระ/ปรับโครงสร้างเชิงรุก ก่อนลูกค้าเป็น NPL |
| ราคาสินค้าขาขึ้น | จังหวะเสนอสินเชื่อลงทุนขยายกำลังการผลิต |

## 6. Use Case สำหรับเจ้าของธุรกิจ SME (ใช้เองแบบง่าย)

### ชีตเดียว 3 คอลัมน์ ที่เจ้าของธุรกิจดูเข้าใจใน 1 นาที

| สิ่งที่ติดตาม | ราคาวันนี้ | แนวโน้ม 90 วัน |
|---|---|---|
| ต้นทุนอาหารสัตว์ (ข้าวโพดโลก) | `=GOOGLEFINANCE("CORN","price")` | sparkline |
| ค่าเงินบาท | `=GOOGLEFINANCE("CURRENCY:USDTHB")` | sparkline |
| หุ้นกลุ่มธุรกิจตัวเอง | `=GOOGLEFINANCE("BKK:GFPT","price")` | sparkline |

### วิธีใช้ในชีวิตจริง

- **ก่อนซื้อวัตถุดิบล็อตใหญ่** — ราคาโลกขาขึ้น? ซื้อตุนก่อน / ขาลง? ทยอยซื้อ
- **ก่อนตั้งราคาขาย** — ต้นทุนโลกขึ้นแล้วแต่ราคาหน้าฟาร์มยังไม่ขึ้น → เตรียมปรับราคา
- **ก่อนรับออเดอร์ส่งออก** — เช็ค USDTHB ก่อนเสนอราคา ถ้าบาทแข็งต้องเผื่อ margin
- **ตั้งเตือนบนมือถือ** — เพิ่มหุ้น/สกุลเงินใน watchlist ของแอป Google (ค้นชื่อหุ้นใน Google แล้วกด "ติดตาม") ระบบแจ้งเตือนเมื่อราคาเปลี่ยนแรง

## 7. โครงสร้าง Google Sheets Dashboard ตัวอย่าง (4 แท็บ)

### แท็บ 1: Watchlist (หน้าหลัก)

| คอลัมน์ | สูตร |
|---|---|
| สัญลักษณ์ | กรอกมือ เช่น `BKK:CPF` |
| ชื่อ/ความหมาย | กรอกมือ เช่น "proxy ราคาไก่-หมู" |
| ราคาล่าสุด | `=GOOGLEFINANCE(A2,"price")` |
| เปลี่ยนแปลงวันนี้ % | `=GOOGLEFINANCE(A2,"changepct")` |
| แนวโน้ม 90 วัน | `=SPARKLINE(INDEX(GOOGLEFINANCE(A2,"price",TODAY()-90,TODAY(),"DAILY"),,2))` |
| เทียบค่าเฉลี่ย 30 วัน | `=GOOGLEFINANCE(A2,"price")/AVERAGE(INDEX(GOOGLEFINANCE(A2,"price",TODAY()-30,TODAY(),"DAILY"),,2))-1` |

ใช้ conditional formatting: เขียวเมื่อ > 0, แดงเมื่อ < 0

### แท็บ 2: แนวโน้มราคา

ตารางราคาย้อนหลังเต็ม (`GOOGLEFINANCE(...,"price",TODAY()-365,TODAY(),"WEEKLY")`) + กราฟเส้นเปรียบเทียบหลายสัญลักษณ์

### แท็บ 3: อัตราแลกเปลี่ยน

USDTHB / CNYTHB / JPYTHB / EURTHB — ราคาล่าสุด, สูงสุด-ต่ำสุด 1 ปี, sparkline + ตารางแปลงเงินสำหรับใบเสนอราคา

### แท็บ 4: บันทึกคำแนะนำลูกค้า (สำหรับ RM)

| วันที่ | ลูกค้า | ธุรกิจ | สัญญาณตลาดที่เห็น | คำแนะนำที่ให้ | ติดตามผล |
|---|---|---|---|---|---|

ทำให้คำแนะนำมีหลักฐานอ้างอิง ตรวจสอบย้อนหลังได้ และใช้เป็น portfolio ผลงานของ RM

## 8. แผนการนำไปใช้ (3 เฟส)

### เฟส 1 — สร้างและนำร่อง (เดือน 1)

- สร้าง Google Sheets template ตามโครงข้อ 7
- เลือก RM นำร่อง 3–5 คน ทดลองใช้กับลูกค้าจริงคนละ 5 ราย
- เก็บ feedback: สัญลักษณ์ไหนมีประโยชน์จริง สูตรไหนพัง หน้าจอไหนลูกค้าไม่เข้าใจ

### เฟส 2 — อบรมและขยายผล (เดือน 2–3)

- ปรับ template ตาม feedback → ทำคู่มือ 1 หน้า + คลิปสั้นสอนใช้
- อบรม RM ในสาขา และสอนลูกค้า SME ที่สนใจทำชีต 3 คอลัมน์ของตัวเอง
- กำหนดให้ dashboard เป็นส่วนหนึ่งของการเตรียมตัวก่อนเยี่ยมลูกค้า

### เฟส 3 — ต่อยอด (เดือน 4+)

- Google Apps Script ส่งสรุปราคาประจำสัปดาห์เข้า LINE กลุ่มลูกค้า
- แจ้งเตือนอัตโนมัติเมื่อราคา proxy เปลี่ยนเกินเกณฑ์ (เช่น ±5% ใน 7 วัน)
- รวมข้อมูล `IMPORTHTML` จากแหล่งราคาไทย (สศก., สมาคมผู้ส่งออกข้าว) เข้า dashboard เดียวกัน

## 9. ข้อควรระวังและข้อจำกัด

1. **ข้อมูลดีเลย์ ~20 นาที** — เพียงพอสำหรับการวางแผน ไม่เหมาะกับการเทรดรายวินาที
2. **ไม่ใช่คำแนะนำการลงทุน** — ใช้เป็นข้อมูลประกอบการตัดสินใจธุรกิจเท่านั้น RM ต้องไม่ชี้นำให้ลูกค้าซื้อขายหุ้น
3. **proxy ≠ ราคาหน้าฟาร์ม** — หุ้นได้รับผลจากปัจจัยอื่นด้วย (ผลประกอบการ, ข่าวบริษัท) ต้องเทียบราคาท้องถิ่นจริงเสมอ
4. **สูตร `IMPORTHTML` อาจพังเมื่อเว็บต้นทางเปลี่ยนโครงสร้าง** — ควรมีผู้ดูแล template ตรวจสอบเป็นระยะ
5. **ข้อมูลลูกค้าในแท็บบันทึกคำแนะนำ** — ตั้งสิทธิ์การแชร์ให้เฉพาะผู้เกี่ยวข้อง ห้ามแชร์แบบ "ทุกคนที่มีลิงก์"
