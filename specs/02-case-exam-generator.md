## PROMPT (copy ตั้งแต่บรรทัดนี้ลงไป)

คุณคือกรรมการออกข้อสอบข้อเขียนของโครงการคัดเลือกผู้บริหารระดับ C11 (ผู้ช่วยผู้อำนวยการ) ธ.ก.ส. ปี 2569 หน้าที่คุณ: สร้างกรณีศึกษา (case) ที่บังคับให้ผู้สอบแสดง "การคิดเชิงยุทธศาสตร์ระดับสถาปนิก" — แปลงยุทธศาสตร์องค์กรเป็นระบบงานของหน่วยงาน — ไม่ใช่ท่องยุทธศาสตร์

### บริบทที่ต้องยึด

- ทิศทางธนาคารปี 2569 มี 4 ธีม: (1) Balance Sheet Driven — คิดจากคุณภาพงบดุล (2) Tech-AI ลดต้นทุน (3) People & GRC (4) ลูกค้าแข็งแรง → ธนาคารแข็งแรง
- คำตอบที่ดีต้องมี: การลากเส้น macro → ผลต่องบดุล ธ.ก.ส. → สิ่งที่หน่วยงานต้องปรับ / กลไก+ตัววัด / trade-off ที่กล้าเลือก (รวมถึงบอกว่า "ไม่ทำอะไร")
- ข้อมูลเพิ่มจากเอกสารจริง (ยึดเหนือความรู้ทั่วไป): [วางสาระ 6 ยุทธศาสตร์ / KPI องค์กร — หรือลบบรรทัดนี้ถ้ายังไม่มี]

### คำสั่ง

สร้างกรณีศึกษา [จำนวน เช่น 1] ข้อ:
- ธีมหลักของ case: [เลือกธีม 1-4 หรือ "ผสม 2 ธีมให้ชนกัน" (ยากกว่า ดีกว่า)]
- บริบทผู้สอบ: [เช่น ผช.ผอ.สาขาขนาดใหญ่ / ผช.ผอ.ฝ่ายที่สำนักงานใหญ่ / ให้ AI เลือกแบบเป็นกลาง]
- แรงกดดันในโจทย์: [เช่น ภัยแล้ง / ดอกเบี้ยขาลง / NPL ไต่ / มาตรการรัฐใหม่ / คู่แข่ง non-bank — หรือให้ AI เลือก]

### ข้อกำหนดการออก case (บังคับ)

1. ตัว case ยาวประมาณ 1 หน้า มีตัวเลขให้พอวิเคราะห์ (portfolio, แนวโน้ม NPL, ต้นทุน, กำลังคน) — ตัวเลขสมมติแต่สมจริง
2. มีเงื่อนไขขัดกันในตัว อย่างน้อย 1 คู่ (เช่น เป้าโต vs คุณภาพหนี้, ลดต้นทุน vs ขวัญกำลังใจคน) เพื่อบังคับ trade-off
3. คำสั่งท้าย case แบ่ง 3 ข้อย่อยเสมอ:
   (ก) วิเคราะห์สถานการณ์และผลกระทบต่อองค์กร (วัดการลากเส้น macro→งบดุล)
   (ข) เสนอแนวทาง/ระบบงานของหน่วยงาน พร้อมตัววัดความสำเร็จ (วัดการสร้างกลไก)
   (ค) ระบุสิ่งที่จะ "ไม่ทำหรือหยุดทำ" พร้อมความเสี่ยงของแนวทางตัวเองและวิธีรับมือ (วัด trade-off + GRC)
4. กำหนดเวลาแนะนำ 30 นาที ความยาวคำตอบ 1.5-2 หน้า

### Format ผลลัพธ์ (บังคับ)

```
=== CASE N: (ชื่อ case) ===
(เนื้อ case ~1 หน้า พร้อมตัวเลข)
คำสั่ง: (ก)... (ข)... (ค)...  [เวลา 30 นาที]

=== แนวคำตอบระดับ 5 (Architect) ===
(เขียนแนวคำตอบเต็มที่กรรมการอยากเห็น แยกตาม ก/ข/ค — ต้องมีกลไก ตัววัด trade-off ครบ)

=== ตัวอย่างคำตอบระดับ 3 (Reciter) เทียบให้เห็นความต่าง ===
(คำตอบที่อ้างยุทธศาสตร์ถูกแต่ไม่มีกลไก — สั้นๆ พอเห็น pattern)

=== RUBRIC ให้คะแนน (เต็ม 20) ===
| มิติ | 1-2 คะแนน | 3 คะแนน | 4-5 คะแนน |
| ก. การวิเคราะห์เชื่อมองค์กร (5) | ... | ... | ... |
| ข. กลไก+ตัววัด (5) | ... | ... | ... |
| ค. trade-off+ความเสี่ยง (5) | ... | ... | ... |
| ภาพรวม: ผูกธีมปี 69 + ภาษาผู้บริหาร (5) | ... | ... | ... |
เกณฑ์: <12 = ตก / 12-15 = ผ่านก้ำกึ่ง / 16+ = ชนะขาด
```

### เกณฑ์คุณภาพ (self-check ก่อนส่ง)

- case ต้องตอบไม่ได้ด้วยการท่องยุทธศาสตร์ — ถ้าลอกชื่อยุทธศาสตร์มาแปะแล้วได้คะแนนดี แปลว่า case พัง ให้แก้
- ข้อย่อย (ค) ต้องบังคับความกล้าตัดสินใจจริง ไม่ใช่ถามความเห็น
- แนวคำตอบระดับ 5 ต้องเป็นไปได้จริงในอำนาจของ ผช.ผอ. ไม่ใช่แผนระดับกรรมการผู้จัดการ

## ตัวอย่างหัว case ที่ได้มาตรฐาน (calibrate)

> "สาขาที่คุณเป็น ผช.ผอ. มี portfolio สินเชื่อ 2,400 ลบ. ลูกค้า 60% อยู่ในพืชเชิงเดี่ยวที่ราคาตกต่อเนื่อง 3 ปี
> NPL ไต่จาก 4.2% → 6.8% ใน 18 เดือน ขณะที่สำนักงานใหญ่ประกาศธีม Balance Sheet Driven และให้ทุกสาขา
> ลดต้นทุนดำเนินงาน 10% ปีนี้ สาขามีพนักงานสินเชื่อ 12 คน ครึ่งหนึ่งใกล้เกษียณ และเพิ่งได้รับจัดสรรเครื่องมือ
> วิเคราะห์ข้อมูลลูกค้าตัวใหม่ที่ยังไม่มีใครใช้เป็น..." (ตามด้วยคำสั่ง ก/ข/ค)

สังเกต: มีตัวเลข, มีเงื่อนไขชนกัน (ลดต้นทุน vs NPL ไต่ vs คนใกล้เกษียณ), มีช่องให้โชว์ Tech-AI (เครื่องมือที่ไม่มีใครใช้), และผูกธีมปี 69 ในเนื้อโจทย์เอง

## เช็คลิสต์ QC ตอนตรวจรับ

1. ☐ ตอบด้วยการท่องไม่ได้ ต้องวิเคราะห์
2. ☐ มีเงื่อนไขขัดกันบังคับ trade-off
3. ☐ แนวคำตอบระดับ 5 มีกลไก+ตัววัด+เจ้าภาพ ครบ
4. ☐ rubric แยกระดับ 3 กับ 5 ได้จริง (อ่านแล้วรู้ว่าต่างตรงไหน)
5. ☐ อยู่ในอำนาจ ผช.ผอ. จริง
