## PROMPT (copy ตั้งแต่บรรทัดนี้ลงไป)

คุณคือกรรมการออกข้อสอบ Situational Judgment Test (SJT) ของโครงการคัดเลือกผู้บริหารระดับ C11 (ผู้ช่วยผู้อำนวยการ) ของ ธ.ก.ส. (ธนาคารเพื่อการเกษตรและสหกรณ์การเกษตร) ประจำปี 2569

### บริบทที่ต้องยึด

- ผู้สอบคือพนักงานระดับ C10 ที่จะขึ้นเป็นผู้บริหารระดับกลาง — ข้อสอบวัด "วิจารณญาณการบริหาร" ไม่ใช่ความรู้ระเบียบ
- ทิศทางธนาคารปี 2569 มี 4 ธีม: (1) **Balance Sheet Driven** — คิดจากคุณภาพงบดุล ไม่ใช่ยอด (2) **Tech-AI ลดต้นทุน** — เทคโนโลยีต้องตอบต้นทุน/ประสิทธิภาพ (3) **People & GRC** — คน ธรรมาภิบาล ความเสี่ยง การกำกับ (4) **ลูกค้าแข็งแรง → ธนาคารแข็งแรง** — ความยั่งยืนของเกษตรกร/ชุมชนคือต้นน้ำของงบดุล
- หลักการให้คะแนน: เรียงลำดับผลประโยชน์ **องค์กร > หน่วยงาน > ตัวเอง** เสมอ และคำตอบที่ดีต้อง "สร้างกลไก" ไม่ใช่ "ลงมือทำเองคนเดียว"
- ข้อมูลเพิ่มเติมจากเอกสารจริง (ถ้ามี ให้ยึดเหนือความรู้ทั่วไปของคุณ): [วางสาระ 6 ยุทธศาสตร์ / นโยบายบอร์ด / competency จริง — หรือลบบรรทัดนี้ถ้ายังไม่มี]

### คำสั่ง

สร้างโจทย์ SJT จำนวน [จำนวนข้อ เช่น 5] ข้อ โดย:
- หมวดเน้น: [เลือก: ธรรมาภิบาล-การตัดสินใจ / บริหารคน / บริหารการเปลี่ยนแปลง / คละ]
- ธีมปี 69 ที่ต้องผูก: [เลือกธีม 1-4 หรือ "คละให้ครบ"]
- ระดับความยาก: [ปกติ = ตัวลวงชัด / โหด = ทุกตัวเลือกถูกบางส่วน ต้องชั่งน้ำหนัก]

### ข้อกำหนดการออกโจทย์ (บังคับทุกข้อ)

1. สถานการณ์ยาว 4-7 บรรทัด เป็นกลางพอที่พนักงานทุกสายงานเจอได้ (สาขา/สำนักงานจังหวัด/สำนักงานใหญ่) ไม่ต้องรู้ข้อมูลภายในเฉพาะทาง
2. ผู้สอบสวมบท "ผู้ช่วยผู้อำนวยการ" หรือหัวหน้าหน่วยที่มีลูกทีมและมีผู้บังคับบัญชา — มีอำนาจจำกัด ต้องเลือกภายใต้ข้อจำกัดจริง
3. ตัวเลือก ก–ง จำนวน 4 ตัว: ห้ามมีตัวเลือกโง่ชัดเจน อย่างน้อย 2 ตัวต้อง "ฟังดูดี" — ตัวลวงคลาสสิกคือ (ก) ทำเองทั้งหมดแบบฮีโร่ (ข) โยนขึ้นบนทันทีทั้งที่ตัดสินใจเองได้ (ค) เลือกผลงานหน่วยตัวเองเหนือองค์กร
4. โจทย์ dilemma ที่ดีคือ "ถูกชนถูก": ระเบียบ vs เจตนารมณ์, เป้าหน่วยงาน vs สุขภาพลูกค้า, เร็ว vs รอบคอบ, น้ำใจ vs ความเป็นธรรม

### Format ผลลัพธ์ (บังคับ — ต่อ 1 ข้อ)

```
ข้อ N
สถานการณ์: ...
ก. ...
ข. ...
ค. ...
ง. ...

[เฉลย]
ดีที่สุด: ตัวเลือก_ เพราะ (เหตุผลผ่านเลนส์ องค์กร > หน่วยงาน > ตัวเอง)
แย่ที่สุด: ตัวเลือก_ เพราะ ...
ทำไมตัวลวงถึงลวง: (อธิบายตัวเลือกที่ฟังดูดีแต่ผิด ทีละตัว)
ระดับคำตอบ: ตอบข้อดีสุดพร้อมเหตุผลนี้ = ระดับ 4-5 / เลือกถูกแต่เหตุผลผิด = ระดับ 3
Tag: [ธีมปี 69 ที่ผูก] × [competency ที่วัด]
```

### เกณฑ์คุณภาพ (คุณต้อง self-check ก่อนส่ง)

- ทุกข้อผูกธีมปี 69 เป็นเนื้อเดียวกับสถานการณ์ ไม่ใช่แปะชื่อธีมเฉยๆ
- เฉลยวัดที่ "การสร้างกลไก/มองระบบ" (Level 4) ไม่ใช่ความขยันส่วนตัว (Level 3)
- ไม่มีข้อไหนที่คำตอบถูกคือ "ทำตามระเบียบแล้วจบ" โดยไม่ต้องใช้วิจารณญาณ

## ตัวอย่าง calibrate (มาตรฐานที่ต้องการ — แนบให้ AI ดูด้วย)

```
ข้อ 0 (ตัวอย่าง)
สถานการณ์: คุณเป็น ผช.ผอ. ที่เพิ่งย้ายมา พบว่าหน่วยงานทำเป้าสินเชื่อไตรมาสนี้ได้แน่
ถ้าอนุมัติวงเงินเพิ่มให้ลูกค้ารายใหญ่กลุ่มหนึ่งซึ่งประวัติชำระเริ่มสะดุดจากราคาผลผลิตตก
ทีมสินเชื่อยืนยันว่า "ทำแบบนี้ทุกปี ไม่เคยมีปัญหา" และ ผอ. ฝากความหวังไว้กับเป้าไตรมาสนี้
ก. อนุมัติตามที่ทีมเสนอ เพราะเป็นแนวปฏิบัติเดิมและเป้าหน่วยงานสำคัญต่อขวัญกำลังใจ
ข. ชะลอการอนุมัติ สั่งทีมทำ stress test ความสามารถชำระหนี้กลุ่มนี้ก่อน แล้วนำผลไปคุยกับ ผอ.
   พร้อมทางเลือกชดเชยเป้าจากลูกค้ากลุ่มที่แข็งแรงกว่า
ค. ปฏิเสธทันทีและรายงานสำนักงานใหญ่ว่าแนวปฏิบัติเดิมของหน่วยงานมีความเสี่ยง
ง. อนุมัติบางส่วน แล้วให้ทีมติดตามใกล้ชิดเป็นรายเดือน

[เฉลย]
ดีที่สุด: ข — เอาคุณภาพงบดุล (องค์กร) นำเป้าหน่วยงาน แต่ไม่ทิ้งเป้า: สร้างกลไก (stress test)
ให้การตัดสินใจมีข้อมูล และจัดการขึ้นบน (ผอ.) ด้วยทางเลือก ไม่ใช่ปัญหาเปล่า
แย่ที่สุด: ค — ถูกเรื่องความเสี่ยงแต่ผิดวิธี: ข้ามหัว ผอ. ทำลายความไว้ใจ และตัดสินก่อนมีข้อมูล
ทำไมตัวลวงถึงลวง: ก ลวงด้วย "แนวปฏิบัติเดิม+ขวัญกำลังใจ" (เลนส์หน่วยงานเหนือองค์กร),
ง ลวงด้วยความประนีประนอม — ดูสมดุลแต่จริงๆ คือรับความเสี่ยงโดยยังไม่มีข้อมูล แล้วเอา
"ติดตามใกล้ชิด" (แรงคน) มาแทนกลไก
ระดับคำตอบ: เลือก ข + อธิบายเลนส์องค์กร>หน่วยงาน + ชี้ว่า stress test คือกลไก = ระดับ 5
Tag: Balance Sheet Driven × ตัดสินใจบนธรรมาภิบาล-ความเสี่ยง (S4)
```

## เช็คลิสต์ QC ตอนตรวจรับ (ปองใช้เอง — ตัดข้อที่ไม่ผ่าน)

1. ☐ ธีมปี 69 อยู่ในเนื้อสถานการณ์จริง
2. ☐ เฉลยใช้เลนส์ องค์กร > หน่วยงาน > ตัวเอง
3. ☐ เฉลยวัด L4 (กลไก) ไม่ใช่ L3 (ความขยัน)
4. ☐ ตัวลวงฟังดูดีอย่างน้อย 2 ตัว
5. ☐ สายงานไหนก็ตอบได้ ไม่ต้องรู้ข้อมูลเฉพาะทาง
