# Product Designer Skill — ธกส.

## ภาพรวม

Skill นี้ช่วย RM ตั้งแต่วิเคราะห์จนถึงเสนอ — ทั้งขึ้นบน (ธนาคาร) และลงล่าง (ลูกค้า)

| Module | งาน | ใช้เมื่อ |
|--------|-----|---------|
| **M1** | วิเคราะห์และคำนวณ | เปรียบเทียบ ธกส. vs คู่แข่ง + true cost |
| **M2** | เสนอธนาคาร | Draft บันทึกข้อความเสนอผู้บังคับบัญชา |
| **M3** | เสนอลูกค้า | สรุปเงื่อนไข 1 หน้า + ตารางผ่อน |

---

## MODULE 1: วิเคราะห์และคำนวณ

### Step 1 — รับข้อมูลจาก RM

```
ข้อมูล ธกส. (product ปัจจุบัน):
□ ประเภทสินเชื่อ
□ อัตราดอกเบี้ย (MLR / MRR / fixed)
□ วงเงินสูงสุด
□ ระยะเวลากู้สูงสุด
□ เงื่อนไขพิเศษ (grace period / หลักประกัน)

ข้อมูลคู่แข่ง (RM กรอกเอง):
□ ธนาคาร + ชื่อ product
□ อัตราดอกเบี้ย
□ เงื่อนไขสำคัญที่ต่างกัน
□ จุดเด่นที่ลูกค้าสนใจ

Pain point ที่เจอจากหน้างาน:
□ ลูกค้ากลุ่มไหนที่ product ปัจจุบันไม่ตอบโจทย์
□ เหตุผลที่ลูกค้าไปใช้คู่แข่งแทน
```

### Step 2 — คำนวณ True Cost

**Fee ที่ต้องรวมในการคำนวณ:**

```
Fee ฝั่ง ธกส.:
- ค่าวิเคราะห์โครงการ (step up ตามวงเงิน)
  วงเงิน 0-1 ล้าน      → [กรุณาระบุ]%
  วงเงิน 1-5 ล้าน      → [กรุณาระบุ]%
  วงเงิน 5-10 ล้าน     → [กรุณาระบุ]%
  วงเงิน >10 ล้าน      → [กรุณาระบุ]%
- ค่าประเมินหลักประกัน  → [กรุณาระบุ] บาท
- ค่าจดจำนอง (กรมที่ดิน) → 1% ของวงเงินจดจำนอง
- Prepayment penalty    → [กรุณาระบุ]

ประกันภัย:
- ค่าประกันสินเชื่อ (credit insurance) → [กรุณาระบุ]% ต่อปี
- ค่าประกันเจ้าของกิจการ (key person)  → [กรุณาระบุ]% ต่อปี
- ค่าประกันอาคาร/หลักประกัน           → [กรุณาระบุ]% ต่อปี

หนังสือค้ำประกัน (LG):
- หนังสือค้ำประกันไฟฟ้า → [กรุณาระบุ]% ต่อปี
- LG อื่นๆ              → [กรุณาระบุ]% ต่อปี
```

**สูตรคำนวณ Effective Rate:**

```
Effective Rate = อัตราดอก + (fee รวมทั้งหมด / วงเงิน / ระยะเวลา x 100)

ตัวอย่าง:
  วงเงิน 5 ล้าน / ระยะเวลา 5 ปี / ดอก 5%
  fee รวม = ค่าวิเคราะห์ + ประกัน + จดจำนอง + LG
  Effective Rate = 5% + (fee / 5,000,000 / 5 x 100)
```

## MODULE 2: เสนอธนาคาร

Draft บันทึกข้อความเสนอผู้บังคับบัญชา:

```
## บันทึกข้อความ

เรียน: [ผจธ. / ผช.ธญ. / ฝ่ายผลิตภัณฑ์]
จาก: [ชื่อ RM] / [สาขา]
วันที่: [วันที่]
เรื่อง: ข้อเสนอแนะปรับปรุงผลิตภัณฑ์ [ชื่อ product]

1. ที่มาและปัญหาที่พบ
   [อธิบาย pain point จากหน้างาน พร้อมตัวอย่างลูกค้า]

2. สถานการณ์การแข่งขัน
   [สรุป competitive analysis จาก M1]
   - [คู่แข่ง] เสนอเงื่อนไข X ซึ่งดีกว่า ธกส. ในเรื่อง Y
   - ลูกค้าตัดสินใจไปใช้คู่แข่งเพราะ Z

3. แนวคิดผลิตภัณฑ์/เงื่อนไขที่เสนอ
   [อธิบาย product/เงื่อนไขใหม่ที่อยากให้พิจารณา]

4. กลุ่มลูกค้าเป้าหมายและขนาดโอกาส
   - กลุ่มลูกค้า: [ประเภท/จำนวนราย]
   - ประมาณการวงเงินพอร์ตที่จะได้: X ล้าน

5. ประโยชน์ต่อธนาคาร
   - รักษาฐานลูกค้าเดิม
   - ขยายพอร์ตสินเชื่อ
   - เพิ่มความสามารถแข่งขัน

6. ความเสี่ยงที่ต้องพิจารณา
   [bullet ความเสี่ยงหลัก]

7. ข้อเสนอ
   ขอให้ฝ่ายผลิตภัณฑ์พิจารณาศึกษาความเป็นไปได้
   และกำหนดเงื่อนไขที่เหมาะสมต่อไป

   ขอแสดงความนับถือ
   [ชื่อ RM]
```

## Quality Rules

```
✅ ใช้ปี พ.ศ. เสมอ
✅ fee ที่ยังไม่ทราบ → ใส่ [กรุณาระบุ] ไม่เดาเอง
✅ ตัวเลขคำนวณต้องโชว์สูตรให้ RM ตรวจสอบได้
✅ เอกสารเสนอลูกค้า → ภาษาเข้าใจง่าย ไม่ใช่ราชการ
✅ เอกสารเสนอธนาคาร → ภาษาราชการ เป็นทางการ
✅ competitive data มาจาก RM เท่านั้น ไม่เดาเอง
```
