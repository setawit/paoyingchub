# Rate Table — ธ.ก.ส. (Reference เท่านั้น)

⚠️ ตารางนี้เป็นตัวอย่างสำหรับ AI ใช้ประกอบการคำนวณ — RM ต้องยืนยันอัตราจริงจาก CBS ก่อนแจ้งลูกค้า

## อัตราดอกเบี้ย (ตัวอย่าง)

| ประเภทสินเชื่อ | อัตราดอกเบี้ย |
|--------------|-------------|
| สินเชื่อเกษตรทั่วไป | MRR - 0.5% ถึง MRR + 1% |
| สินเชื่อ SME | MRR ถึง MRR + 2% |
| สินเชื่อฉุกเฉิน | MRR + 0.5% |
| สินเชื่อนโยบาย | ตามประกาศโครงการ |

MRR ปัจจุบัน: [RM ต้องตรวจสอบจาก CBS]

## ค่าธรรมเนียม (ตัวอย่าง)

- ค่าธรรมเนียมจัดการสินเชื่อ: 0.5-1% ของวงเงิน
- ค่าประเมินหลักประกัน: ตามสเกลของ ธ.ก.ส.
- ค่าธรรมเนียมทางกฎหมาย: ตามกรมที่ดิน

## สูตรคำนวณงวด (Equal Installment)

```
Monthly Payment = P × [r(1+r)^n] / [(1+r)^n - 1]

P = เงินต้น
r = อัตราดอกเบี้ย/เดือน (อัตราต่อปี / 12)
n = จำนวนงวด (เดือน)
```
