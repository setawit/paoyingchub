# Statement Analyzer

ใช้ skill นี้เพื่อวิเคราะห์ Bank Statement แล้วสรุปเป็นรายงานที่ RM ใช้ประกอบการพิจารณาสินเชื่อหรือติดตามลูกค้า

## Inputs ที่ต้องดึงก่อนวิเคราะห์

- `period`: ช่วงเวลาของ statement (เช่น ม.ค.-มี.ค. 2568)
- `account_type`: บัญชีออมทรัพย์ / กระแสรายวัน / อื่นๆ
- `transactions`: รายการฝาก-ถอน (masked — ไม่มีชื่อจริง)
- `purpose`: วิเคราะห์เพื่ออะไร (ขอสินเชื่อใหม่ / ติดตาม / ปรับโครงสร้าง)
- `business_type`: ประเภทกิจการลูกค้า (เกษตร / SME / บุคคล)

## การวิเคราะห์หลัก

### 1. รายได้และกระแสเงินสด
- คำนวณ average monthly inflow และ outflow
- ระบุแหล่งรายได้หลักและรายได้รอง
- ดู seasonality (สำหรับเกษตร — รายได้ตามฤดูกาล)
- คำนวณ net cash flow เฉลี่ย

### 2. พฤติกรรมการเงิน
- ความสม่ำเสมอของรายรับ (สม่ำเสมอ / ผันผวน / เป็นฤดูกาล)
- วันที่มักมีเงินเข้า / ออก
- ลักษณะการถอนเงิน (ปกติ / กระชาก / ถอนทันทีหลังฝาก)

### 3. Red Flags
โหลดรายการ red flags จาก `references/red-flags.md`

### 4. Debt Service Capacity
- ประมาณ DSR (Debt Service Ratio) จากข้อมูลที่มี
- เปรียบเทียบกับ benchmark ธ.ก.ส. (ไม่เกิน 40% ของรายได้สุทธิ)

## Output format

```markdown
## Statement Analysis — [ช่วงเวลา]

### สรุปภาพรวม
[3-4 ประโยค overview]

### รายได้และกระแสเงินสด
- รายรับเฉลี่ย/เดือน: X บาท
- รายจ่ายเฉลี่ย/เดือน: X บาท
- Net cash flow เฉลี่ย: X บาท
- ลักษณะรายได้: [สม่ำเสมอ / ฤดูกาล / ผันผวน]

### พฤติกรรมทางการเงิน
[bullet points]

### Red Flags ที่พบ
[bullet points หรือ "ไม่พบ red flags ที่มีนัยสำคัญ"]

### ความสามารถในการชำระหนี้ (ประมาณการ)
- DSR ประมาณ: X%
- ประเมิน: [ผ่านเกณฑ์ / ใกล้เกณฑ์ / เกินเกณฑ์]

### ข้อสังเกตเพิ่มเติมสำหรับ RM
[bullet points]

---
⚠️ การวิเคราะห์นี้เป็น draft — RM ต้องตรวจสอบกับข้อมูลจริงก่อนใช้ประกอบการพิจารณา
```
