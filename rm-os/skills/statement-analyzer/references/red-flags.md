# Red Flags — Bank Statement Analysis

## ความเสี่ยงสูง (ต้องระบุใน report เสมอ)

- ยอดเงินในบัญชีลดลงต่อเนื่องทุกเดือน > 3 เดือน
- ถอนเงินทันทีหลังฝากทุกครั้ง (balance แทบเป็น 0 เสมอ)
- รายรับหายไปกะทันหัน > 1 เดือน โดยไม่มีคำอธิบาย
- พบการโอนเงินรายใหญ่ไปบุคคล/บัญชีที่ไม่ชัดเจน
- มีรายการ NSF (ยอดไม่พอ) หรือเช็คคืน

## ความเสี่ยงกลาง (ระบุและอธิบาย context)

- รายได้ผันผวนสูง (เบี่ยงเบนมากกว่า 50% จาก average)
- พฤติกรรมเงินสดสูง (ฝากถอนเงินสดบ่อยโดยไม่มี pattern)
- มีการชำระหนี้ให้สถาบันการเงินอื่นจำนวนมาก
- รายรับจาก source ที่ระบุไม่ได้ชัดเจน

## ความเสี่ยงต่ำ / ปกติ (ไม่ต้องระบุเว้นแต่ถามเฉพาะ)

- รายได้ตามฤดูกาล (สำหรับเกษตร — ปกติ)
- ยอดต่ำในช่วงก่อนเก็บเกี่ยว (สำหรับเกษตร — คาดได้)
- การโอนระหว่างบัญชีตัวเองที่มี pattern ชัดเจน

## DSR Benchmark ธ.ก.ส.
- ≤ 40%: ผ่านเกณฑ์
- 40-50%: ใกล้เกณฑ์ — ระวัง
- > 50%: เกินเกณฑ์ — ต้องมีเหตุผลพิเศษ
