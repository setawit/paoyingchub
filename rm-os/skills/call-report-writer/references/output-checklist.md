# Output Checklist — Call Report Writer

ตรวจสอบก่อน output ทุกครั้ง

## โครงสร้าง
- [ ] มีครบ 5 ส่วน (วัตถุประสงค์, ผลการเยี่ยม, สถานะการเงิน, ความเห็น RM, แผนติดตาม)
- [ ] ทุกส่วนมีเนื้อหา ไม่มีส่วนใดว่างเปล่า
- [ ] มี `[RM กรุณาระบุ]` ในส่วนที่ข้อมูลไม่ครบ

## ภาษาและรูปแบบ
- [ ] ใช้ภาษาราชการ ไม่ใช้ภาษาปาก
- [ ] ตัวเลขมีหน่วยกำกับครบ
- [ ] วันที่เป็น พ.ศ.
- [ ] ไม่มีคำย่อที่ไม่ได้ขยายความ

## ความถูกต้องของเนื้อหา
- [ ] ไม่เขียนข้อมูลที่ RM ไม่ได้ให้มา
- [ ] ความเห็น RM แยกออกจาก observation ชัดเจน
- [ ] แผนติดตามมี action + timeline ชัดเจน
- [ ] ไม่มี PII ที่ไม่ได้ mask

## Security
- [ ] ไม่มีชื่อ/นามสกุลลูกค้าจริง
- [ ] ไม่มีเลขที่บัญชี, เลขบัตรประชาชน
- [ ] ใช้รหัสอ้างอิงที่ RM กำหนด

## Disclaimer
- [ ] มีข้อความ "นี่คือ draft เบื้องต้น — RM กรุณาตรวจสอบ" ที่ท้าย output เสมอ
