## โครงสร้างประโยคมาตรฐาน

### บรรยาย observation
```
จากการเยี่ยมเยียน [วันที่] พบว่า [สิ่งที่พบ] โดย [รายละเอียด]
```

### บรรยายสถานะการเงิน
```
ลูกหนี้มีรายได้จาก [แหล่งรายได้] ประมาณ [จำนวน] บาท/[งวด]
มีภาระชำระหนี้ต่อเดือนทั้งสิ้น [จำนวน] บาท
```

### แสดงความเห็น RM
```
RM มีความเห็นว่า [ความเห็น] เนื่องจาก [เหตุผล]
จึงเสนอให้ [action/recommendation]
```

### แผนติดตาม
```
RM จะดำเนินการ [action] ภายใน [ระยะเวลา]
กำหนดนัดเยี่ยมครั้งถัดไป [วัน/เดือน/ปี] เพื่อ [วัตถุประสงค์]
```

## ตัวเลขและหน่วย

- เงิน: ระบุเป็น "บาท" เสมอ เช่น 50,000 บาท (ไม่ใช่ 50K หรือ 5 หมื่น)
- พื้นที่: ไร่-งาน-วา เช่น 10 ไร่ 2 งาน
- น้ำหนัก/ผลผลิต: กิโลกรัม หรือ ตัน เช่น 3 ตัน/ไร่
- ระยะเวลา: เดือน หรือ ปี เช่น 6 เดือน, 2 ปี
- วันที่: วัน/เดือน/ปี พ.ศ. เสมอ เช่น 15/05/2568

## สิ่งที่ห้ามระบุใน Call Report

- ชื่อจริง/นามสกุลลูกค้า (ใช้รหัสอ้างอิงแทน — masking)
- เลขที่บัตรประชาชน, เลขที่บัญชี
- ข้อมูลส่วนตัวที่ไม่เกี่ยวกับสินเชื่อ (ปัญหาครอบครัว ฯลฯ เว้นแต่กระทบความสามารถชำระ)
- การ commit คำสัญญาที่ไม่ได้รับ approval จาก RM
