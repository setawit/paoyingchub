# Collateral Assessor

ใช้ skill นี้เพื่อ (1) สร้าง checklist ก่อนออกตรวจหลักประกัน หรือ (2) ร่างรายงานผลการตรวจหลักประกันหลัง site visit

## Inputs ที่ต้องดึงก่อน

- `task_type`: `pre-visit-checklist` หรือ `post-visit-report`
- `collateral_type`: `land-title` (โฉนด/นส.3ก) / `building` / `machinery` / `crop`
- `loan_purpose`: วัตถุประสงค์สินเชื่อ
- `appraised_value`: ราคาประเมิน (ถ้ามี)
- `observations` (สำหรับ post-visit): สิ่งที่พบเห็นระหว่างตรวจ

## Pre-Visit Checklist

สร้าง checklist ตามประเภทหลักประกัน

### โฉนดที่ดิน / นส.3ก
- [ ] ตรวจสอบชื่อเจ้าของกับ CBS ตรงกัน
- [ ] ตรวจภาระผูกพัน (จำนอง, อายัด)
- [ ] ตรวจขนาดพื้นที่ตรงกับเอกสาร
- [ ] ตรวจแผนที่ตั้ง — เข้าถึงได้ / ถนนสาธารณะ
- [ ] ตรวจ zoning — เขตเกษตร / ที่พักอาศัย / พาณิชยกรรม
- [ ] ถ่ายรูป 4 มุม + รูปโฉนด
- [ ] GPS coordinates

### สิ่งปลูกสร้าง
- [ ] ตรวจใบอนุญาตก่อสร้าง
- [ ] ตรวจแบบแปลน vs สภาพจริง
- [ ] ประเมินอายุและสภาพ
- [ ] ตรวจภาระผูกพัน
- [ ] ถ่ายรูปด้านนอก-ใน

## Post-Visit Report Format

```markdown
## รายงานตรวจหลักประกัน — [วันที่]

**ประเภทหลักประกัน:** [ระบุ]
**ที่ตั้ง:** [ตำบล อำเภอ จังหวัด]

**สภาพทั่วไป**
[บรรยายสภาพจริงที่พบ]

**ราคาประเมิน**
- ราคาประเมินราชการ: [X] บาท/ไร่ รวม [X] บาท
- ราคาตลาด (ประมาณ): [X] บาท
- อัตราส่วนที่ใช้ได้: [X]% = [X] บาท

**ข้อสังเกตและความเสี่ยง**
[bullet points]

**ความเห็น RM**
[เพียงพอ / ไม่เพียงพอ / ต้องการหลักประกันเพิ่ม]

---
⚠️ draft — RM กรุณาตรวจสอบกับเอกสารจริงก่อน submit
```
