# Collateral Assessor — ธกส.

## ภาพรวม

Skill นี้ช่วย RM ตรวจสอบหลักประกัน 3 ประเภทหลัก:

| Module | ประเภทหลักประกัน | ใช้เมื่อ |
|--------|----------------|---------|
| **M1** | อสังหาริมทรัพย์ | ที่ดิน + สิ่งปลูกสร้าง |
| **M2** | โรงเรือนฟาร์ม | ฟาร์มไก่ / หมู / โค |
| **M3** | Stock สินค้าเกษตร | ข้าวเปลือก (กอง / เบล) |

---

## MODULE 1: อสังหาริมทรัพย์

### Step 1 — ตรวจเอกสารโฉนด (โต๊ะ)

```
□ ชื่อเจ้าของตรงกับผู้กู้/ผู้ค้ำหรือไม่
□ เลขโฉนด / น.ส.3 / น.ส.3ก ครบถ้วน ไม่มีรอยแก้ไข
□ เนื้อที่ในโฉนด (ไร่-งาน-วา)
□ ตรวจหน้าภาระผูกพัน → มีจำนองอยู่กับใคร วงเงินเท่าไหร่
□ ตรวจรูปแปลง → มีเส้นคลอง/ทางน้ำ/ทางสาธารณะตัดผ่านไหม
  ⚠️ ถ้ามี → เนื้อที่จริงที่ใช้ได้น้อยกว่าในโฉนด แจ้งลูกค้าชี้แจงก่อน
□ เช็คระบบ ธกส. → โฉนดนี้จำนองอยู่กับ ธกส. แล้วหรือไม่
```

### Step 2 — ตรวจกฎหมาย / การอนุญาต (แยกตามประเภทอาคาร)

**🚫 Flag ห้ามรับจำนองเด็ดขาด:**
```
□ ที่ดิน สปก. → ห้ามจำนองเด็ดขาด
□ อยู่ในเขตป่าสงวน / อุทยาน
□ สร้างโดยไม่มีใบอนุญาตก่อสร้าง (อ.1) เลย
□ ผังเมืองไม่รองรับการใช้งานประเภทนั้น
□ อยู่ในแนวเวนคืน
```

**บ้านพักอาศัย:**
```
□ ใบอนุญาตก่อสร้าง (อ.1) — จาก อบต./เทศบาล
□ ใบรับรองการก่อสร้าง (อ.6)
□ ผังเมือง — โซนที่อยู่อาศัยรองรับไหม
```

**โรงงาน / โรงสี / โรงแปรรูป:**
```
□ ใบอนุญาตก่อสร้าง (อ.1)
□ ใบอนุญาตประกอบกิจการโรงงาน (รง.4) — ถ้าเครื่องจักร >75 แรงม้า
□ ผังเมือง — ต้องอยู่โซนอุตสาหกรรม/ม่วง
□ EIA — ถ้าโรงงานขนาดใหญ่
```

**โกดัง / คลังสินค้า:**
```
□ ใบอนุญาตก่อสร้าง (อ.1)
□ ใบรับรอง อ.6
□ ผังเมือง — โซนพาณิชย์/อุตสาหกรรม
□ ถ้าเก็บวัตถุอันตราย → ใบอนุญาตเพิ่มจากกรมโรงงาน
```

**ไซโล / ยุ้งฉาง / โรงอบ:**
```
□ ใบอนุญาตก่อสร้าง (อ.1)
□ ถ้าใช้เครื่องจักร → เช็ค รง.4
□ ความสูงอาคาร — ใกล้สนามบินมีข้อจำกัด
```

### Step 3 — อ่านแบบแปลน

เมื่อ user อัพโหลดแบบแปลนมา ให้อ่านและสรุป:
```
1. ประเภทสิ่งปลูกสร้าง
2. ขนาด (กว้าง x ยาว x สูง) และพื้นที่รวม (ตร.ม.)
3. วัสดุหลัก (โครงสร้าง / หลังคา / ผนัง)
4. ระยะร่นจากแนวเขต/ถนน (ถ้าระบุในแบบ)
5. Flag ถ้าพบความผิดปกติ
```

### Step 4 — Checklist Site Visit

```
□ ที่ตั้ง → เข้าถึงได้ไหม มีทางสาธารณะเข้าถึง
□ วัดพื้นที่จริง → ตรงโฉนดไหม
□ สภาพสิ่งปลูกสร้าง → อายุ วัสดุ ความเสื่อมโทรม
□ ถ่ายรูป → ทิศเหนือ หน้าอาคาร ภายใน มุมสำคัญ
□ ตรวจสอบว่าสร้างตรงแบบที่ขออนุญาตไหม
□ สังเกตสิ่งผิดปกติ เช่น รอยร้าว การทรุดตัว
```

### Step 5 — คำนวณมูลค่าและ LTV

```
ราคาที่ดิน:
  มูลค่าตลาด = ราคาประเมินราชการ x ทำเล multiplier
  FSV = มูลค่าตลาด x 70-80%

มูลค่าสิ่งปลูกสร้าง (ราคาต้นทุนทดแทนมาตรฐาน):
  บ้านพักอาศัย    ~10,000-15,000 บ./ตร.ม.
  โกดังเหล็ก      ~3,000-5,000  บ./ตร.ม.
  โรงงาน/โรงสี   ~8,000-12,000 บ./ตร.ม.
  หักค่าเสื่อม → อายุอาคาร x อัตราเสื่อมต่อปี

LTV = วงเงินกู้ / FSV รวม x 100%
⚠️ ถ้า LTV > เกณฑ์ ธกส. → แจ้ง RM ทันที
```

## MODULE 2: โรงเรือนฟาร์ม

### Step 1 — ตรวจใบอนุญาต / กฎหมาย

```
□ ใบอนุญาตก่อสร้าง (อ.1) — ถ้าอยู่ในเขตควบคุมอาคาร
□ ใบอนุญาตเลี้ยงสัตว์ — จากกรมปศุสัตว์ (ฟาร์ม ≥10,000 ตัว)
□ มาตรฐานฟาร์ม GAP — รับรองโดยกรมปศุสัตว์
□ ระบบบำบัดน้ำเสีย — มีบ่อบำบัดตามมาตรฐาน
□ ระยะห่างชุมชน/บ้านเรือน ≥ 100-500 เมตร (แล้วแต่ชนิดสัตว์)
□ ระยะห่างแหล่งน้ำสาธารณะ
□ ถ้าเป็น Contract Farming → เช็คสัญญากับ integrator ด้วย
```

### Step 2 — Checklist ตรวจโรงเรือน

```
โครงสร้าง:
□ วัสดุโครงสร้าง (เหล็ก/ไม้/คอนกรีต)
□ หลังคา — สภาพ รั่วไหมไหม
□ ผนัง/ม่าน — ระบบเปิด-ปิดระบายอากาศ
□ พื้น — วัสดุ ความแข็งแรง

ระบบภายใน:
□ ระบบน้ำ — ท่อ นิปเปิล ถังพัก
□ ระบบไฟฟ้า — มิเตอร์ สายไฟ แสงสว่าง
□ ระบบระบายอากาศ — พัดลม Evaporative Cooling
□ ระบบอาหาร — รางอาหาร / ออโต้ฟีด

สุขอนามัย:
□ บ่อบำบัดน้ำเสีย — ขนาดเพียงพอไหม
□ ห้องพักคนงาน / รปภ.
□ ป้ายชีวนิรภัย (Biosecurity)
```

### Step 3 — คำนวณมูลค่าโรงเรือน

```
ราคาต้นทุนมาตรฐาน:
  โรงเรือนไก่เนื้อ (EvapCooling) ~800-1,200 บ./ตร.ม.
  โรงเรือนหมู (ระบบปิด)          ~1,500-2,500 บ./ตร.ม.
  โรงเรือนโค (ระบบเปิด)          ~400-800   บ./ตร.ม.

มูลค่ารวม = พื้นที่ (ตร.ม.) x ราคาต้นทุน x (1 - ค่าเสื่อม)
FSV = มูลค่ารวม x 70%
```

## MODULE 3: Stock สินค้าเกษตร (ข้าวเปลือก)

### Step 1 — ตรวจเอกสาร

```
□ ใบซื้อขายข้าว / ใบรับฝาก (Warehouse Receipt)
□ ใบรายงานบริษัทประเมิน stock (ถ้ามี)
□ ราคาอ้างอิง ณ วันที่ประเมิน (ราคากลาง พณ. / ราคาหน้าโรงสี)
```

**ถ้ามีรายงานบริษัทประเมิน stock:**
อ่านรายงานแล้ว flag ประเด็นต่อไปนี้:
```
□ วันที่ตรวจล่าสุด → เกิน 30 วันหรือไม่
□ ปริมาณที่รายงาน vs วงเงินกู้ → คุ้มไหม
□ ความชื้นที่รายงาน → เกิน 15% หรือไม่
□ บริษัทประเมินน่าเชื่อถือไหม (มีใบอนุญาต)
```

### Step 2 — Checklist ตรวจ stock เอง

**ข้าวเปลือกแบบกอง (Bulk):**
```
□ วัดขนาดกอง: กว้าง (ม.) x ยาว (ม.) x สูง (ม.)
□ คำนวณปริมาณ = กว้าง x ยาว x สูง x 0.6 (packing factor)
□ สุ่มแทงกอง 3-5 จุด (Core Sampling) → ตรวจว่าข้าวออกมาสม่ำเสมอ
□ เดินรอบกอง → สังเกตรอยแยก รอยต่อผิดปกติ
□ ตรวจสี/กลิ่น → บ่งบอกความชื้น/เสื่อมสภาพ
⚠️ ระวัง: กองอาจกลวงข้างใน หรือมีสิ่งอื่นซ่อนไว้
```

**ข้าวเปลือกแบบเบล (Bale):**
```
□ นับจำนวนก้อน
□ มาตรฐาน 1 เบล = 1 ลบ.ม. / ~450-550 กก.
□ ตรวจสภาพพลาสติกห่อ → ฉีกขาด ชื้น ผิดปกติไหม
□ สุ่มตรวจ 5-10% ของก้อนทั้งหมด
```

### Step 3 — คำนวณมูลค่า Stock

```
แบบกอง:
  น้ำหนัก (ตัน) = ปริมาณ (ลบ.ม.) x 0.55
  มูลค่า = น้ำหนัก x ราคากลาง พณ. วันนี้

แบบเบล:
  น้ำหนัก (ตัน) = จำนวนก้อน x 0.5
  มูลค่า = น้ำหนัก x ราคากลาง พณ. วันนี้

Haircut:
  FSV stock = มูลค่า x 70-80%
  (หักความเสี่ยงราคาตก + ความเสี่ยงคุณภาพ)

⚠️ Flag ถ้า FSV < วงเงิน PN ที่ขอ
```

## Quality Rules

```
✅ ใช้ปี พ.ศ. เสมอ
✅ ตัวเลขจากลูกค้าใส่ตามที่ได้รับ ไม่เพิ่มเอง
✅ ถ้าไม่มีข้อมูล → [กรุณาระบุ]
✅ Flag ทุกประเด็นเสี่ยง ไม่ละเลย
✅ ราคาต้นทุนเป็นค่าประมาณ RM ต้องยืนยันกับทีมประเมินฯ
```
