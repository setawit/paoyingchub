# Workout Options — ธ.ก.ส.

## ตัวเลือกปรับโครงสร้างหนี้

| Option | เมื่อใช้ | เงื่อนไขหลัก |
|--------|---------|-------------|
| ยืดระยะเวลา | รายได้ลดชั่วคราว, cash flow ติดลบ | ไม่เพิ่มยอดหนี้ |
| ลดงวดผ่อน | รายได้ลดถาวร แต่ยังมีบางส่วน | อาจต้องยืดระยะด้วย |
| พักชำระเงินต้น | ภัยพิบัติ / เจ็บป่วยรุนแรง | ชำระดอกเบี้ยต่อ |
| รวมหนี้หลายบัญชี | มีหนี้หลายสัญญา payment chaos | ลดภาระรวม |
| ปรับลดอัตราดอกเบี้ย | NPL เรื้อรัง แต่ยังมีทรัพย์สิน | เฉพาะกรณีมีมติ |
| Write-off บางส่วน | NPL นาน > 3 ปี, ทรัพย์สินน้อย | ต้องผ่าน committee |

## เกณฑ์เลือก Option

### Watch List (ค้าง < 3 เดือน)
→ เน้นป้องกัน: ยืดระยะ หรือ พักชำระต้น 3-6 เดือน

### SM (ค้าง 3-6 เดือน)
→ Restructure ทันที: ลดงวด + ยืดระยะ + action plan เข้ม

### NPL (ค้าง > 6 เดือน)
→ ประเมิน recovery: ถ้า cooperative ทำ full restructure, ถ้าไม่ cooperative พิจารณา legal

## สัญญาณลูกค้าร่วมมือ (บวก)
- ติดต่อกลับเมื่อ RM โทรหา
- มีเอกสารพร้อม
- เสนอแนวทางเองบางส่วน
- ยังมีกิจการดำเนินอยู่

## สัญญาณไม่ร่วมมือ (ลบ)
- หลีกเลี่ยงการติดต่อ > 2 ครั้ง
- ให้ข้อมูลขัดแย้ง
- โอนทรัพย์สินไปก่อนเจรจา
- ปฏิเสธทุก option โดยไม่มีเหตุผล
