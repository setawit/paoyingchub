# Debt Workout Skill — ธกส.

## ภาพรวม

Skill นี้ครอบคลุม 3 module ตาม workflow จัดการหนี้มีปัญหา:

| Module | งาน | ใช้เมื่อ |
|--------|-----|---------|
| **M1** | Portfolio Monitor | จับสัญญาณเสี่ยงก่อนเป็น NPL |
| **M2** | Restructuring Advisor | ออกแบบโครงสร้างหนี้ใหม่ |
| **M3** | Negotiation Playbook | เจรจาตาม profile ลูกค้า |

---

## MODULE 1: Portfolio Monitor

### Early Warning Signals — 3 ระดับ

**🟡 Watch (เฝ้าระวัง)**
```
- จ่ายช้ากว่าปกติ 1-15 วัน
- โทรแล้วรับช้า / ขอเลื่อนนัดบ่อย
- ราคาสินค้าเกษตรที่ลูกค้าทำตกหนัก
- ข่าวภัยแล้ง / น้ำท่วม / โรคระบาดในพื้นที่
- เปลี่ยนพฤติกรรม เช่น เคยจ่ายตรงแต่เริ่มขอผ่อน
```

**🟠 Special Mention — SM**
```
- ค้างชำระ 1-3 งวด
- โทรไม่รับ เริ่มหนีหนี้ชัด
- ธุรกิจมีปัญหาชัดเจน (ปิดชั่วคราว / ยอดขายหด)
- ขอ restructure เอง
- หลักประกันเริ่มเสื่อมค่า
```

**🔴 NPL (เสียหาย)**
```
- ค้างชำระ >3 งวด
- หนีหนี้ชัดเจน ติดต่อไม่ได้
- หลักประกันเสื่อมค่าหนัก
- มีคดีความ / ถูกฟ้อง
```

### Checklist ประเมินสถานะ

เมื่อ RM กรอกข้อมูลลูกค้ามา ให้ประเมินและ output:

```
## สถานะพอร์ต: [ชื่อลูกค้า]

สถานะปัจจุบัน: 🟡 Watch / 🟠 SM / 🔴 NPL
ค้างชำระ: X งวด / X วัน
สัญญาณที่พบ: [bullet]

แนวทางที่แนะนำ:
→ [Watch] เพิ่มความถี่ติดตาม + บันทึก call report
→ [SM]    เริ่มกระบวนการ restructure ทันที
→ [NPL]   เตรียมเอกสารเสนออนุมัติ + เตรียมฟ้องถ้าจำเป็น
```

## MODULE 2: Restructuring Advisor

### ตัวเลือก Restructure แยกตามสถานะ

**ตอน SM (ก่อน NPL):**

| ตัวเลือก | วิธีการ | เหมาะกับ |
|---------|---------|---------|
| ขยายงวด | ยืดระยะเวลาชำระ → ลดยอดต่องวด | Cash flow ลูกค้าติดลบชั่วคราว |
| แขวนดอกเบี้ยค้าง | พักดอกเบี้ยที่ค้างไว้ก่อน ไม่ทบต้น | ลูกค้ามีภาระดอกเบี้ยสะสมสูง |
| รวมทั้งสอง | ขยายงวด + แขวนดอก | กรณีหนักหน่อย แต่ยังไม่ NPL |

**ตอน NPL (หลัง):**

| ตัวเลือก | วิธีการ | เหมาะกับ |
|---------|---------|---------|
| ขยายงวด | ยืดระยะเวลา + ปรับ schedule ใหม่ | มี willingness จ่าย แต่ไม่มีเงิน |
| แขวนดอกเบี้ยค้าง | พักดอกค้างทั้งหมด | ดอกค้างสูงมากจนจ่ายไม่ไหว |
| ลดดอกเบี้ย | ลดอัตราดอก ถ้าจ่ายหมดภายในกำหนด | จูงใจให้ปิดหนี้ได้เลย |
| รวมทุกอย่าง | ขยายงวด + แขวนดอก + ลดดอก | NPL หนัก แต่ยังมีโอกาสฟื้น |

### Decision Tree — เลือก Option ไหน

```
ลูกค้ามี cash flow พอจ่ายได้บ้างไหม?
  ├── ใช่ → ขยายงวด (ปรับให้พอดี cash flow)
  └── ไม่ → แขวนดอกเบี้ยก่อน แล้วขยายงวด

ดอกเบี้ยค้างสูงมากไหม (>30% ของเงินต้น)?
  ├── ใช่ → แขวนดอกเบี้ยค้างบังคับ
  └── ไม่ → พิจารณาตามสถานะ

ลูกค้าอยากปิดหนี้ให้จบเลยไหม?
  ├── ใช่ → เสนอลดดอกเบี้ย + กำหนด deadline
  └── ไม่ → ขยายงวด + monitor ต่อ
```

### Draft เอกสารเสนออนุมัติ Restructure

เมื่อ RM ตัดสินใจ option แล้ว ให้ draft เอกสารในรูปแบบนี้:

```
## บันทึกข้อความเสนออนุมัติปรับโครงสร้างหนี้

เรียน: [ผจธ. / ผช.ธญ.]
จาก: [ชื่อ RM] / [สาขา]
วันที่: [วันที่]

เรื่อง: ขออนุมัติปรับโครงสร้างหนี้ลูกค้า [ชื่อ]

1. ข้อมูลลูกค้า
   - ชื่อ / ประเภทธุรกิจ / สถานะปัจจุบัน

2. สถานะหนี้เดิม
   - จำนวนสัญญา / วงเงินรวม / ภาระหนี้ / ค้างชำระ

3. สาเหตุที่มีปัญหา
   [สรุปสาเหตุจาก call report]

4. แนวทาง Restructure ที่เสนอ
   - Option ที่เลือก + เหตุผล
   - Schedule การชำระใหม่
   - เงื่อนไขพิเศษ (ถ้ามี)

5. ความเห็น RM
   [ประเมิน willingness + ability ของลูกค้า]

6. ความเสี่ยงที่เหลือ + การติดตาม
   [บอกว่าจะ monitor อะไรหลัง restructure]
```

## MODULE 3: Negotiation Playbook

### แยกตาม Profile ลูกค้า

**Profile A: อยากจ่าย แต่ไม่มีเงิน**
```
แนวทาง: ให้ความช่วยเหลือ + หา solution ร่วมกัน
Tone: เป็นมิตร เห็นอกเห็นใจ

Script:
"ผมเข้าใจสถานการณ์คุณ [ชื่อ] นะครับ
ตอนนี้เราสามารถช่วยได้โดย [option]
ถ้าเราปรับ schedule แบบนี้ คุณคิดว่าจัดการได้ไหมครับ?"

Do:
✅ เสนอ restructure option ที่ fit cash flow จริงๆ
✅ ให้ลูกค้ามีส่วนร่วมในการกำหนด schedule
✅ แสดงให้เห็นว่าธนาคารอยากช่วย ไม่ใช่แค่เรียกเงิน

Don't:
❌ กดดันเรื่องกฎหมายโดยไม่จำเป็น
❌ เร่งรีบเกินไปจนลูกค้าตื่นตกใจ
```

**Profile B: มีเงิน แต่ไม่อยากจ่าย**
```
แนวทาง: กดดัน + เสนอ incentive
Tone: เป็นทางการ จริงจัง

Script:
"คุณ [ชื่อ] ครับ ตอนนี้หนี้ค้างอยู่ [X] งวด
ถ้าไม่ดำเนินการภายใน [วันที่] ธนาคารต้องดำเนินการตามขั้นตอนกฎหมาย
อย่างไรก็ตาม ถ้าจ่ายหมดภายใน [กำหนด] เราสามารถลดดอกเบี้ยให้ได้ครับ"

Do:
✅ อ้างอิงผลกระทบที่ชัดเจน (Blacklist / ฟ้อง / ยึดหลักประกัน)
✅ เสนอ incentive ลดดอกถ้าจ่ายเร็ว
✅ กำหนด deadline ชัดเจน

Don't:
❌ ปล่อยให้引延 โดยไม่มี deadline
❌ ยืดหยุ่นมากเกินไปจนลูกค้าเดา pattern ได้
```

**Profile C: หนีหนี้ ติดต่อไม่ได้**
```
แนวทาง: Escalate ตามขั้นตอน
Tone: เป็นทางการ มีหลักฐานทุกขั้น

ขั้นตอน:
1. โทรซ้ำ 3 ครั้ง บันทึกวัน-เวลา
2. ติดต่อผ่านผู้ค้ำประกัน / ญาติ
3. ส่งหนังสือทวงถามอย่างเป็นทางการ (EMS)
4. ลงพื้นที่ตามหา + ถ่ายรูปประกอบ
5. เสนอผู้บังคับบัญชาพิจารณาฟ้อง
```

**Profile D: ฟ้องร้องแล้ว**
```
แนวทาง: ส่งทีมกฎหมาย แต่ยังประนอมได้ก่อนศาลตัดสิน
Tone: เป็นทางการ ผ่านทนาย

Do:
✅ ยังเจรจาประนอมหนี้ได้ก่อนศาลตัดสิน
✅ ทุกข้อตกลงต้องเป็นลายลักษณ์อักษร
✅ ประสานทีมกฎหมาย ธกส. ก่อนทุกครั้ง

Don't:
❌ เจรจาเองโดยไม่แจ้งทีมกฎหมาย
❌ ให้ข้อตกลงปากเปล่า
```

## Quality Rules

```
✅ ใช้ปี พ.ศ. เสมอ
✅ ตัวเลขหนี้ต้องตรงกับระบบ ธกส.
✅ ทุก restructure ต้องผ่านการอนุมัติตามระดับอำนาจ
✅ บันทึก call report ทุกครั้งที่ติดต่อลูกค้า
✅ ถ้าข้อมูลไม่พอ → ถามก่อนทำงานต่อ
```
