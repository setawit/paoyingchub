# Customer Profiler

ใช้ skill นี้เพื่อรวบรวมและ structure ข้อมูลลูกค้าจากหลายแหล่งให้เป็น profile ที่ใช้งานได้ทันที

## Inputs ที่ต้องดึงก่อน

- `customer_ref`: รหัสอ้างอิง (masked)
- `business_type`: ประเภทกิจการ (เกษตร / SME / บุคคล)
- `raw_info`: ข้อมูลดิบที่ RM มี (พิมพ์อะไรก็ได้ — จะ structure ให้)
- `purpose`: สร้าง profile เพื่อ (สินเชื่อใหม่ / ติดตาม / ปรับโครงสร้าง)

## การ structure ข้อมูล

จัดกลุ่มข้อมูลดิบที่ RM ให้เป็นหมวดหมู่:

1. **ข้อมูลพื้นฐาน** — ประเภทกิจการ, ที่ตั้ง, ระยะเวลาประกอบการ
2. **กิจการและรายได้** — แหล่งรายได้, รายได้หลัก/รอง, ฤดูกาล
3. **ทรัพย์สินและหนี้สิน** — ที่ดิน, สิ่งปลูกสร้าง, หนี้รวม
4. **ประวัติกับ ธ.ก.ส.** — สินเชื่อที่มี, ประวัติชำระ, ระยะเวลาเป็นลูกค้า
5. **ปัจจัยเสี่ยงและโอกาส** — จุดแข็ง/จุดอ่อนที่ RM ประเมิน

## Output format

```markdown
## Customer Profile — [รหัสอ้างอิง]
*สร้าง: [วันที่] | วัตถุประสงค์: [ระบุ]*

### ข้อมูลกิจการ
- ประเภท: [เกษตร / SME / บุคคล]
- กิจการหลัก: [ระบุ]
- ที่ตั้ง: [จังหวัด/ภาค]
- ระยะเวลาประกอบการ: [X ปี] (โดยประมาณ)

### รายได้และกระแสเงินสด
- รายได้หลัก: [แหล่ง] ~[X บาท/ปี]
- รายได้รอง: [แหล่ง ถ้ามี]
- ลักษณะ: [สม่ำเสมอ / ฤดูกาล / ผันผวน]

### ทรัพย์สินและภาระ
- ที่ดิน: [X ไร่, มีโฉนด/นส.3ก]
- สิ่งปลูกสร้าง: [ระบุถ้ามี]
- หนี้ทั้งหมดโดยประมาณ: [X บาท]

### ประวัติกับ ธ.ก.ส.
- ระยะเวลาเป็นลูกค้า: [X ปี]
- สินเชื่อปัจจุบัน: [ประเภท] [X บาท]
- ประวัติชำระ: [ดี / มีค้างบ้าง / ค้างชำระ]

### ประเมิน RM
**จุดแข็ง:**
- [bullet]

**ความเสี่ยง:**
- [bullet]

**ข้อมูลที่ขาด / ต้องตรวจสอบเพิ่ม:**
- [bullet หรือ "ครบถ้วน"]

---
⚠️ Profile นี้สร้างจากข้อมูลที่ RM ให้ — ต้องตรวจสอบกับ CBS ก่อนใช้ทางการ
```

## หมายเหตุ

- ถ้าข้อมูลบางส่วนไม่มี ให้ระบุ `[RM กรุณาระบุ]` หรือ `[ตรวจสอบจาก CBS]`
- ไม่ invent ข้อมูลที่ไม่มีใน input
- Profile นี้เป็นจุดเริ่มต้น — `credit-master` จะใช้ต่อสำหรับ analysis เต็มรูปแบบ
