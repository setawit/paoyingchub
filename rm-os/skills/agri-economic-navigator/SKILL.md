# Agri Economic Navigator

ใช้ skill นี้เพื่อสร้าง sector context ที่ RM ใช้ประกอบการวิเคราะห์สินเชื่อเกษตรและ SME

## Inputs ที่ต้องดึงก่อน

- `crop_or_sector`: ชนิดพืช/ปศุสัตว์/กิจการ (ข้าว, ยางพารา, มันสำปะหลัง, หมู, ประมง ฯลฯ)
- `region`: ภาค/จังหวัด
- `analysis_period`: ช่วงเวลาที่ต้องการ (ปัจจุบัน / ฤดูกาลถัดไป)
- `purpose`: ประกอบสินเชื่อ / ติดตามความเสี่ยง / Business Report

## การวิเคราะห์

### 1. ราคาและตลาด
- ราคาปัจจุบัน vs ราคาปีก่อน
- แนวโน้มราคา (ขาขึ้น / ขาลง / ทรงตัว)
- ปัจจัยกำหนดราคา (ส่งออก, นโยบาย, demand จีน/อาเซียน)

### 2. ความเสี่ยงด้านการผลิต
- สภาพอากาศ/ภัยธรรมชาติในพื้นที่
- โรค/แมลงศัตรูพืช seasonal
- ต้นทุนการผลิต (ปุ๋ย น้ำมัน แรงงาน) แนวโน้ม

### 3. นโยบายและโครงการรัฐ
- โครงการประกันรายได้เกษตรกร
- โครงการพักหนี้ / มาตรการช่วยเหลือ
- นโยบาย minimum price

### 4. Sector Outlook
- โอกาส: ตลาดใหม่, พืชทดแทน, เทคโนโลยี
- ความเสี่ยง: climate change, trade policy, ราคาผันผวน

## Output format

```markdown
## Sector Analysis — [ชนิดพืช/กิจการ] — [ภาค/จังหวัด]

### ภาพรวม Sector
[2-3 ประโยค]

### ราคาและตลาด
- ราคาปัจจุบัน: [X บาท/กก. หรือ ตัน]
- เทียบปีก่อน: [+/-X%]
- แนวโน้ม: [ขาขึ้น / ขาลง / ทรงตัว]
- ปัจจัยสำคัญ: [bullet]

### ความเสี่ยงที่ควรระวัง
[bullet points]

### นโยบายรัฐที่เกี่ยวข้อง
[bullet points]

### ผลกระทบต่อสินเชื่อ
- ถ้าราคาสินค้าลดลง X%: ผลกระทบต่อความสามารถชำระ [ระดับ]
- Risk rating แนะนำ: [ต่ำ / กลาง / สูง]
```
